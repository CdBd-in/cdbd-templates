# 단계별 검수 체크리스트 (검수자용)

> **2026-06-30 1차 라이브(vip-dinner) 사용자 리뷰 반영.** ⭐ = 그날 실제로 놓친 항목 → 엄격 검수.
> 각 항목 통과=✅ / 미준수=항목명 반환. 근거 규칙: [[1-1. 워크플로우]] / [[CLAUDE.md]].
> 검수자는 산출물을 **실제로 열어 육안 대조**(Figma 스크린샷·에디터 모바일 프리뷰)하고 추정하지 말 것.

## 공통 (모든 단계 + 최종 종합 검수에서 재확인)

- [ ] **정렬 통일성** ⭐ — 한 카드/섹션 내 텍스트·버튼·요소 정렬이 일관. 위 텍스트가 중앙정렬이면 그 아래 버튼도 중앙. **작은 버튼만 좌정렬 등 혼재 ❌**.
- [ ] **줄간격은 명시값(auto 금지)** ⭐ — 100·110·120…% 10% 단위로 **명시**. `auto`/임의값 ❌. 본문 가독 권장 130~150%.
- [ ] **애매한 줄바꿈 없음** ⭐ — 텍스트 사이즈 탓에 한 단어만 다음 줄로 넘어가거나 어색한 위치에서 줄바뀜 ❌. 사이즈를 조정해 자연스럽게 끊기게.
- [ ] **이미지 중복 없음** ⭐ — 갤러리·메뉴·주요기능 등 여러 이미지 슬롯에 **동일 이미지 반복 ❌**. 각 슬롯은 고유 이미지.
- [ ] **로고/이미지 실제 생성·적용됨** ⭐ — placeholder·빈 슬롯·미생성 ❌. 로고는 심볼+워드마크(또는 gpt-image-1)로 실제 존재.

## 2단계 — 와이어프레임 (구조)

- [ ] 텍스트 카드 1개 = 속성 1개 (사이즈·정렬·색·줄간격 섞임 없음)
- [ ] 스켈레톤 고정 스펙: 프로필 텍스트 2개만 / Q&A 제목 중앙+제출버튼 카드 하단 내장 / 위치 안내=지도+주소 한 단위 / 자동 gap(SPACE_BETWEEN 등) 없음
- [ ] 모든 카드 top-level 평탄화, 페이지 gap=0, 외부여백=0(배경·테두리 없는 카드는 단일 padding)
- [ ] 편집 불가 장식(팬텀: 골드라인·점선·노치·형광펜) 없음
- [ ] **SNS 카드는 실제 채널 아이콘** ⭐ — 의미불명 원·도형 ❌. 프레임명만 "SNS"이고 SNS로 안 보이면 ❌. **실제 연결할 SNS 채널이 없으면 SNS 카드 자체를 제거**.
- [ ] **와이어프레임에만 카드 설명/주석 허용** — 카드 용도 주석은 여기(2단계)까지만. 3단계 이후로 넘기지 말 것(아래 3단계 참조).

## 3단계 — 시안 (색·폰트·이미지)

- [ ] **3개 시안이 뚜렷이 구별됨** ⭐ — 시안 A/B/C가 **서로 다른 무드**(팔레트 계열·폰트 페어링이 확연히 다름). 색/서체 미세 변주만으로 "3개"라 하면 ❌. 최소 1개는 산세리프 무드 포함.
- [ ] **시안에 카드 설명·주석 텍스트 없음** ⭐ — 와이어프레임의 카드 안내문·플레이스홀더 설명(예: 예약 카드 안의 설명 텍스트)이 시안/실제 콘텐츠로 넘어오면 ❌. 시안은 **실제 들어갈 콘텐츠만**.
- [ ] 글자-배경 대비 ≥ 3.6:1
- [ ] 버튼색-배경 대비 ≥ 3.6:1 (버튼 글자=배경색이므로 별도 확인)
- [ ] 무드 1개로 색·폰트 통일 / 한 페이지 폰트 1~2개 / 국문 본문=한글 폰트
- [ ] 보조 텍스트 = {텍스트색}×N% 투명도 (별도 회색 hex ❌)
- [ ] 버튼 텍스트 색 = {배경색}
- [ ] 헤드라인 액센트 = {버튼색}(2색 팔레트면 무드 내 별도 포인트색, 배경 대비 ≥3.6:1)
- [ ] 이미지원 = OpenAI/Thiings/Unsplash (Flow ❌)
- [ ] **로고 이미지 실제 생성** ⭐ — 로고 슬롯이 비거나 미생성 ❌.

## 4단계 — CdBd 에디터 (라이브 ↔ 시안 대조)

- [ ] **시안 1:1 재현** ⭐ — Figma 시안과 에디터를 나란히 대조. 특히 **갤러리 유형(그리드/슬라이드/넘겨보기)·단수·정렬**이 시안과 동일해야 함. 임의로 다른 유형 적용 ❌.
- [ ] 텍스트 크기·색·정렬·웨이트·줄간격이 시안 실측과 일치 (공통: auto 줄간격·정렬 혼재 ❌)
- [ ] 카드 상하 padding=시안 frame, 외부여백 0, page gap 0
- [ ] 구분선 두께·모양·색 / 프로필 이미지 크기(%) / 갤러리 둥글기·그리드 단수·간격 / 버튼 높이
- [ ] **OG 이미지 적용** ⭐ — 로고 타입 800×400 1배수 JPG, 로고 면적 9~10%. 에디터 OG 업로드가 자동 불가면 리포트 "수동 처리"에 **항상 명시**.
- [ ] **로고·메뉴·갤러리 이미지 누락/중복 없음** ⭐ — 로고 미적용 ❌, 메뉴 이미지 동일 반복 ❌.
- [ ] 카드 라벨 = 목적·내용 이름(기본 타입명 방치 ❌)

## 5단계 — 상세페이지 (피그마)

- [ ] 기존 섹션 복제 후 내용·이미지만 교체(신규 작성 ❌)
- [ ] "10회 사용 / ★4.9" 배지 삭제
- [ ] 슬롯 전부 채움: 대표이미지·썸네일·카테고리·슬러그·에디터 id·소개(제목·성과·리뷰형 설명·추천타겟)·주요기능 N·모바일 스크린샷
- [ ] **주요기능 이미지 = 의미있는 비주얼** ⭐ — **에디터 화면 캡쳐·무의미 이미지 ❌**. 각 기능을 나타내는 고유 이미지(360×300). 기능별로 서로 다른 이미지.
- [ ] **프로필 슬롯 = 프로필 이미지** ⭐ — 로고를 프로필 자리에 넣지 ❌. 대표/프로필(인물 또는 브랜드 대표 이미지)로.

## 최종 종합 검수 (리포트 작성 직전, 매니저/최종 검수자 1회)

전체 템플릿을 모바일 프리뷰로 통째 훑으며 **공통 5항목**을 재확인: 정렬 통일 · 줄간격 명시 · 어색한 줄바꿈 · 이미지 중복 · 로고/이미지 실제 적용. 하나라도 걸리면 해당 단계로 되돌려 수정(재시도 한도 내). 미해결은 리포트 ⭐로 명시.
