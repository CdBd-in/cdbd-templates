먼저 `.claude/cdbd-edit-shared.md`를 읽는다. 자동화는 skill `cdbd-card-automation` 사용.

## 담당 (Figma 시안 → 페이지 전역 설정)
- **테마 3색**: 배경 `{배경색}`·텍스트 `{텍스트색}`·버튼 `{버튼색}` hex.
- **서체**: 페이지 기본 폰트(1~2개, 국문 본문 = 한글 폰트 의무).
- **버튼 모양**: 원형/각진/둥근 중 1.
- **페이지 배경·제목**: 배경색/이미지, 페이지 제목.
- **스크롤 애니메이션**: 위로/확대/없음.
- **멀티페이지**: 페이지 목록(표지+서브) 생성.

## 🔑 자동화 (skill 레시피)
- **페이지 색상**: swatch 클릭·hex input 없이 fiber `onChange("#hex")` 직접 호출. 슬롯은 onChange 소스로 식별(배경=`base.background`·텍스트=`base.color`·버튼=`button.background`, 위치 인덱스 ❌). **한 색씩 + 사이 재렌더 대기(~1.2s) + 배경을 마지막에**(핸들러가 stale state 캡처해 앞 변경 덮어씀). skill `cdbd-card-automation#페이지-색상`.
- **경고 모달**: 첫 테마 변경 시 「이 페이지에서 앞으로 경고 보지 않기」 체크 ON → 변경. 이후 안 뜸. 서체·버튼모양 변경도 같은 모달.
- **스크롤 애니메이션**: 헤더 💡 아이콘 → 모달(위로/확대/없음) → 저장.

## 자기검증
`$B js "JSON.stringify(window.__cdbd.themeColors())"` → 3색 일치. 안 맞으면 `onChange` 재조정 루프. 버튼 텍스트 = `{배경색}` 매핑·버튼-배경 대비 ≥3.6:1 확인.

## 출력
`{theme:{background,color,button}, font, buttonShape, pages:[...]}` + 실행 위치 `https://www.cdbd.in/editor/{editorId}`.

## 🎨 페이지 테마 체크리스트

> 19개 프리셋 = [배경/텍스트/버튼] 3색 1세트(기본 프리셋1 `#fafafa`/Gray-900/Gray-900). 디자인 시스템 원본: `4-2. 페이지 테마.md`.

- [ ] **테마 변수** 준수: `{배경색}`·`{텍스트색}`·`{버튼색}`·`{버튼모양}`(원형99/각진0/둥근16px)·`{서체}`(기본 프리텐다드).
- [ ] **색상 default 최대 활용** — 카드별 임의 색 변경 ❌. 보조 텍스트는 `{텍스트색} × N%` 투명도(별도 회색 ❌).
- [ ] **경고 모달**(첫 테마 변경 시 "기존 카드별 설정 덮어씀"): 「이 페이지에서 앞으로 경고 보지 않기」 체크 ON → 변경. 서체·버튼모양 변경도 같은 모달. **멀티페이지는 각 페이지마다 첫 변경 시 1회씩**.

## 📑 멀티페이지 체크리스트

> 멀티페이지 = 페이지 컨테이너 1개 안에 여러 페이지(좌우 스와이프/이동 버튼). 홍보·카탈로그·포트폴리오에 적합.

- [ ] **생성/사이즈**: 「멀티페이지 BETA」 추천 **380×580px**(가로 380 고정·세로 자유, 페이지별 다르게 가능). 세로 580 초과 시 그 페이지만 자동 스크롤 → 표지·CTA는 카드 상/하 고정으로 여백 흡수.
- [ ] **페이지 설정**(⚙ → 페이지 설정 편집): 넘김효과(밀어내기/덮기/종이책)·무한반복·자동넘김·두페이지씩·넘김 가이드.
- [ ] **추가/복제/순서**: 좌측 사이드바 「+ 페이지 추가」 · 썸네일 호버 케밥 「복제하기」(사례 양산에 유용) · 드래그 순서변경.
- [ ] **페이지 배경 = 페이지별 독립**: 케밥 「페이지 배경 설정」(색/이미지). ⚠️ 전역 팔레트(🎨 = Text/배경/버튼·서체)는 **모든 페이지 공통** — 페이지별 배경은 반드시 per-page 케밥으로(`theme.base.background` ≠ per-page 배경).
- [ ] **페이지 이동**: 버튼/이미지 카드 → 「링크 연결」 → 「페이지 이동하기」 → 대상 페이지. 자동화 키 = **`linkButton:{type:"page", link:{href:"pageId=..."}}`**(`link` 아님). 표지 목차·하단 네비.
- [ ] **OG = 멀티 전체 1개**(페이지별 ❌). 페이지 수 base quota(≈10P) 초과 시 사용자가 cdbd.in UI 「게시」 직접 클릭(결제 트리거).

## ⚠️ 자동화 함정 — 색상 픽커

> 권장은 위 「자동화」의 `onChange("#hex")` 직접 호출. 아래는 SketchPicker 실제 클릭 fallback. 코드 레시피: skill `cdbd-card-automation`.

- [ ] **alpha만 변경하면 hex가 default로 reset** (함정19) — **매번 hex+alpha 둘 다 명시 입력**. 픽커 input 순서 `[0]=hex,[1]R,[2]G,[3]B,[4]alpha`.
- [ ] **픽커 닫힌 상태 $B fill → 의도 외 element 오염** (함정20) — 색상 fill은 **단일 시퀀스로 묶기**(open→tag→fill→events→close). step 사이 `div.z-[9999]` 픽커 1개 존재 확인.
