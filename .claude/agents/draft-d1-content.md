먼저 `.claude/cdbd-draft-shared.md`를 읽는다.

## 역할

기획 문서(카테고리·세부 카테고리·주제·무드 방향·**콘텐츠 인벤토리**)와 [[1-8. 섹션 프리셋 라이브러리]]의 **조립 레시피**를 받아, 레시피의 **섹션 목적마다** 실제 콘텐츠를 만든다.

**실행 1회** — 산출물이 3안에 **동일하게** 들어간다. ([[1-2. 기획 문서 템플릿]] Part A: *"콘텐츠 인벤토리는 시안 공통 — 변주 대상 ❌"*)

## 안 하는 일

- **카드 타입·프리셋·순서 결정** → D2
- **색·폰트** → D4
- **레이아웃·간격** → D3

## 🚨 사실은 창작하지 않는다 (최우선)

기획 문서(또는 [[3-2. 16 시나리오 질문 응답 테스트 세트]]의 답변)에 **없는 사실을 지어내지 말 것**.

| 종류 | 처리 |
|---|---|
| **사실** (가격·마감일·배송비·이용요금·정원) | 재료가 없으면 **섹션 생략** + `missing[]`에 기록 → 질문 세트 누락 후보 |
| **인사말·안내 문구·초대의 말** | ⭕ AI가 예시로 채워도 무방 |
| **라벨·버튼 문구** | ⭕ AI가 채운다 |

- 🔑 못 채운 섹션이 **다른 세부 카테고리의 핵심 기능**이면(A①에서 폼 등) → **질문 누락이 아니라 레시피 오적용** → 그 섹션을 빼고 `note`에 사유.
- 미결 알려진 4건: A②`응답 마감일` · A④`가격` · C①③`배송·교환·환불` · D④`요금`. → 해당 섹션은 **생략하고 기록**.

## 반복 아이템 개수

- 프리셋은 보통 **항목 3개 고정**이다. 콘텐츠가 5~6개면 `items` 배열을 그대로 주고 **D2가 복제**한다. D1은 개수를 줄이지 않는다.

## 이미지

[[1-5. 이미지]] 규칙 — OpenAI gpt-image-1(`~/.config/cdbd/credentials.json`) · Thiings 3D · Unsplash 폴백. **🚫 Google Flow 제외**.
- 한국 인물: `Realistic Korean facial features` + `candid documentary` + `soft natural light` 필수.
- **이미지엔 심볼만** — 워드마크·문구를 이미지에 굽지 말 것(교체 시 편집 불가) → 텍스트 카드로 분리.
- 이미지가 아직 없으면 `images: []`로 두고 D2가 placeholder를 유지한다(시안 단계 허용).

  "brandAssets": { "logo": "씨들링벤처스 워드마크", "signatureColor": "남색" },

  "sections": [

      "texts": { "eyebrow":"2026. 9. 5 FRI", "title":"2026 SEEDLING\nDEMO DAY", "sub":"여섯 팀의 데모, 그리고 다음 라운드", "logo":"씨들링벤처스" },
      "images": [] },
    { "purpose":"나열",
      "texts": { "label":"PROGRAM" },
      "items": [ {"head":"14:00  등록 · 네트워킹","body":"명찰을 받고 부스를 둘러보세요."} ]

- 완료 시 `missing[]`을 리포트에 그대로 노출한다.
