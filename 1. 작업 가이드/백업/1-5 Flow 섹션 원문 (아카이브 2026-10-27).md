## 📦 소스 ②: Google Labs Flow (실사 이미지) — 🚫 제외됨 (사용 금지)

> **이 섹션은 역사적 기록으로만 보존.** Flow는 이미지 생성 표준에서 제외됨(무인 갱신 불가·throttle). 아래 내용은 참고용이며 신규/무인 작업에서 **사용하지 말 것**. 실사는 OpenAI gpt-image-1 / Unsplash 사용.

**URL**: https://labs.google/fx/ko/tools/flow

- Google의 AI 영상·이미지 생성 도구 (Veo 모델 기반)
- 실사 사진풍 이미지 생성에 적합
- 프롬프트 기반 — 자연어로 장면·피사체·분위기 묘사

### 사용 컨텍스트

- ✅ **인물 사진** — 강사, 대표, 팀원, 후기 작성자 등
- ✅ **Special Gift / 사은품 섹션** — 굿즈, 패키지, 선물 박스
- ✅ **제품·소품 컷** — 사실적인 제품 사진이 필요할 때
- ❌ 상징적 메시지 전달 → Thiings 일러스트로

### 선정 기준 (절대 규칙)

| ✅ 반드시 | ❌ 절대 금지 |
|---|---|
| **사실적인 실사** — 다큐/스냅사진 톤 | 연출샷·광고샷 — 인위적 포즈·세팅 |
| 자연광·평범한 환경 | 스튜디오 라이팅·화려한 배경 |
| 깨끗한 구도 | **로고·텍스트·워터마크 (완전 배제)** |
| 피사체에 집중 | 과장된 카메라 각도·필터 |

> ⚠️ **로고/텍스트 금지**: AI는 텍스트 렌더링이 부정확 → 글자가 들어간 컷은 모두 폐기.
> 패키지·박스·티셔츠 등에 글자가 보이면 다른 컷으로 교체.

### 프롬프트 작성 원칙

**목표**: "연출되지 않은, 우연히 찍힌 듯한 자연스러운 실사"

| 요소 | 작성 방향 |
|---|---|
| **사진 종류** | `documentary photo`, `candid shot`, `everyday photo` (NOT `professional studio shot`) |
| **광원** | `natural daylight`, `window light`, `overcast soft light` (NOT `dramatic lighting`) |
| **앵글** | `eye-level`, `slight angle`, `casual framing` (NOT `dramatic low angle`) |
| **배경** | `plain background`, `simple home interior`, `blurred neutral background` |
| **무드** | `unposed`, `natural`, `realistic`, `not staged` |
| **비율** | `1:1 square aspect ratio` (별도 요청 없으면 디폴트) |
| **금지어** | `no text`, `no logo`, `no watermark`, `no captions`, `blank surfaces` |

**좋은 프롬프트 예시:**
```
A candid, documentary-style photo of a woman in her 30s smiling 
softly while looking off-camera. Natural window light from the side, 
eye-level angle, plain beige wall background. Unposed, realistic, 
no makeup styling. 1:1 square aspect ratio. 
No text, no logos, no watermarks anywhere.
```

```
An everyday photo of a small unbranded gift box on a wooden table, 
wrapped in plain kraft paper with a simple twine bow. Natural daylight, 
top-down casual angle, slightly soft focus. 1:1 square aspect ratio.
Blank surfaces only — no text, no logos, no labels, no captions.
```

**나쁜 프롬프트 예시 (피할 것):**
```
❌ Beautiful professional studio portrait with dramatic lighting
❌ Luxury gift box with elegant gold logo and ribbon
❌ Stylish model posing with branded packaging
```

## 🚀 자동화 스킬: `/generate-flow-image` *(환경에 설치된 경우)*

수동 30분 워크플로우를 **~60초**로 단축한 Playwright 기반 스킬.

### 사용법

```bash
python3 ~/.claude/skills/generate-flow-image/generate.py "PROMPT" [옵션]
```

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--keyword` / `-k` | (자동) | 파일명 키워드 |
| `--aspect` / `-a` | `1:1` | 비율 (1:1, 16:9, 4:3, 3:4, 9:16) |
| `--count` / `-c` | `4` | 변형 개수 (1~4) |
| `--headless` | ON | 백그라운드 실행 |
| `--interactive` | OFF | 첫 로그인 시에만 |

### 예시

```bash
# Special Gift 컷 4종
python3 ~/.claude/skills/generate-flow-image/generate.py \
 "candid documentary photo of unbranded kraft coffee pouch and 5 drip bags on wooden table, natural daylight" \
 -k coffee-gift -c 4

# 인물 1장
python3 ~/.claude/skills/generate-flow-image/generate.py \
 "candid eye-level portrait of a smiling Korean woman in her 30s, natural window light, unposed" \
 -k instructor -c 1
```

### 결과
- 저장: `~/Downloads/{keyword}.png` (count=1) 또는 `{keyword}-1.png` ~ `{keyword}-N.png`
- 해상도: 1024×1024 (Nano Banana 2 원본)
- 소요: 첫 실행 ~90초, 이후 세션 재사용 시 **~55초** (2장 기준)

### 첫 실행 (1회만)
세션 파일이 없으면 자동으로 로그인 단계 진입. 자격증명은 `~/.config/cdbd/credentials.json`에서 자동 로드.

```bash
python3 ~/.claude/skills/generate-flow-image/generate.py "test" --interactive -c 1
```

> 스킬 풀패스: `~/.claude/skills/generate-flow-image/SKILL.md`

### ⚠️ 운영 메모: Free-tier Throttling

`help@cdbd.in` 계정은 **무료 등급** (`PAYGATE_TIER_NOT_PAID`).
디스커버리 로그에서 확인됨. 무료 등급은 burst rate limit 있음.

**실측 **:
- 1~3번째 연속 세트 (~9컷): 각 60~80초 정상
- **4번째 연속 세트**: 199초 타임아웃 (1/3만 받아짐)
- 단독 재실행 (쿨다운 후): 94초 (3/3 정상)

**연속 생성 시 권장**:
- ✅ 4세트 이상 연속 → **세트 간 60초 이상 간격**
- ✅ `--retry` 플래그 사용 → 부분 결과 시 60초 쿨다운 후 자동 재시도
- ✅ `--timeout 300` 디폴트 (개선판) → throttle된 응답도 회수
- ❌ 한 번에 4세트 × 4컷 = 16컷 burst → throttle 거의 확실
