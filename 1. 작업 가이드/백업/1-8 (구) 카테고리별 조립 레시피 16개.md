> **왜 바뀌었나**: 세부 카테고리가 **16칸 → 27칸**으로 재설계되면서([[1-11. 대분류 재설계 (제안 초안)]]) ① 「행사 초대」 1개가 **5개로 분화**되고 ② **7개 칸이 신설**됐다. 또한 공통 규칙이 16군데 중복돼 한 곳을 고치면 나머지가 낡는 문제가 있어, 새 문서는 **골격 1 + 패턴 6 + 칸별 카드 27**의 3층으로 재구성했다.

> 🧾 **각 레시피의 슬롯을 실제로 채우는 질문** = [[1-9. AI 유저 플로우]] 「📝 1구간 후반 — 콘텐츠 수집 질문」 (대분류 → 세부 → 기능 애드온 3층).
>
> **⚠️ 유연한 기준 — 고정 틀 아님.** 아래는 **출발점**일 뿐, 페이지 목적·자료에 따라 **섹션을 더하거나 빼고 순서도 바꾼다.** 한 페이지는 **읽히는 목적(히어로·소개·자료…)과 동작하는 목적(위치·폼·예약·문의·구매)을 섞어** 짠다.
> **표기 = 섹션 "목적"**(괄호 = 대표 카드 힌트).
> **🔖 모든 카테고리 = 원페이지 스택 + ▸ 멀티페이지 분할 — 둘 다 필수.** [[1-9. AI 유저 플로우]] ④단계에서 **같은 디자인의 원페이지 안·멀티페이지 안을 1개씩 만들어 보여주고 유저가 고르므로**, 16개 레시피 전부 두 벌이 있어야 한다. (옛 '원N:멀티N 가중치'·'원페이지 고정' 예외는 2026-07-10 폐기.) 멀티는 **최대 3~4장** · **반복 내지(제품군·기사·프로젝트…)는 대표 1P만 표기**(실제 템플릿은 복제해 늘림) · 내비 = **표지 목차/이동 버튼 + 서브페이지 상단 복귀 헤더**(→ [[../CLAUDE.md]] 멀티페이지 네비 패턴).

> 🥇 **[상위 원칙] 모든 페이지의 첫 콘텐츠 섹션 = 반드시 「히어로」 (2026-07-22 이선호 · 필수 · 여러 번 반복)** — 어떤 카테고리든 **페이지를 임팩트 있는 히어로로 연다**. 작은 「소개」/프로필 카드·정보 나열로 페이지를 시작하지 말 것(첫인상이 약해진다). 실사례 지적: B②(명함)·B①·포트폴리오가 소개·프로필 카드로 시작 → 히어로로 교정. **레시피가 `[소개: …]`로 시작하는 것처럼 보여도, 그 소개(특히 프로필)를 히어로 자리로 끌어올리거나 히어로로 겸한다.** (아래 「👤 프로필·명함」 규칙은 이 원칙의 프로필 유형 적용 사례 · 「🛍 룩북」의 히어로→브랜드 스토리 순서도 이 원칙의 연장.)
>
> 🚫 **히어로·상품컷 = 이미지 위 텍스트 오버레이·그라데이션 스크림 ❌ (필수, 2026-07-23 이선호 지시)** — 레시피의 `[히어로: 대형 화보 + 컬렉션 제목]`·`[상품컷 + 이름/가격]`은 **이미지 위에 텍스트를 얹으라는 뜻이 아니다.** CdBd 이미지 카드엔 **그라데이션(스크림)도, 이미지 위 특정 영역 텍스트도 불가** → **이미지 카드 + 그 아래(또는 위) 별도 텍스트 카드 스택**으로 조립한다. 밝은 이미지 위 가독성용으로 밝은 글자를 썼다면 **페이지 배경에서도 대비 ≥3.6:1** 재확인. 사례: C①-볼드 구매 시안(히어로+상품 3컷)이 스크림+오버레이로 제작돼 이미지+아래 텍스트로 전면 교체. 정본: [[../CLAUDE.md]] 🧩 생성 시안 ⑦ · [[1-6-2. #### 🛍 룩북·카탈로그 (세부 4)

> 🛍 **브랜드·카탈로그 유형(룩북·판매·상세·메뉴 등) = 히어로 바로 다음에 '브랜드 스토리(소개/스토리)' 섹션이 먼저 (2026-07-22 · 필수)** — 순서는 **히어로 → 브랜드 스토리 → 이후 제품/카탈로그**. 제품·가격·구매를 바로 나열하기 전에 **브랜드가 누구이고 왜 이 컬렉션인지**를 먼저 짧게 세운다(신뢰·맥락 형성). 아래 레시피들이 스토리를 (선택)·후반부에 둔 경우도, **브랜드 소개형 페이지라면 스토리를 히어로 직후로 끌어올린다.** *(전환 최우선인 ③판매 페이지는 예외 — 구매를 상단에 두고 스토리는 뒤로.)*

> 🛍 **제품 상세페이지(판매·상세 세부, 예: C①) = 제품마다 ①여러 컷 갤러리 + ②상세 정보 필수 · 상품 카드로 간소화 ❌ (2026-07-23 이선호 지시)** — "상세 정보가 있어야 상세 페이지". **① 여러 컷**: 제품 1개당 사진이 여러 장(모델 화보·정면·측면·내부·디테일컷 등) — 단일 사진 ❌. **② 상세 정보**: 스펙(소재·크기·무게·수납·부자재 등)을 제품마다 전부. **🚫 2단 그리드 카탈로그(상품 카드 나열)로 압축하지 말 것** — 각 제품은 **전폭 단일 컬럼 상세 블록**(큰 이미지들 + 스펙 + 구매 버튼)으로. 🔀 **갤러리 표현 = 3안 차별화 레버**(CdBd 실제 갤러리 카드 기능): **세로 나열**(사진을 세로로 다 펼침) / **넘겨보기(캐러셀)**(대표 1장 + 스와이프) 중 선택 · **3안 = 나열 2 + 캐러셀 1**(예: 미니멀=캐러셀 / 에디토리얼·볼드=세로 나열). ⚠️ **「1안 캐러셀」은 제품 개당 이미지 4개 이상일 때만 (2026-07-24 이선호)** — 4장 미만이면 넘길 컷이 부족하므로 캐러셀 없이 3안 모두 세로 나열. ⚠️ 갤러리 default UI(넘겨보기 화살표·인디케이터 점)는 시안에서 재현 ❌. 정본: [[../CLAUDE.md]] 최종검수.

> 🆕 **「제품 설명」 항목 = 룩북/카탈로그 4종 유형 「상품 정보 섹션」에 모두 추가 (2026-07-23 이선호 지시)** — 상품 정보(구매/상품 나열) 섹션에 **제품을 설명하는 「제품 설명」 블록**을 넣는다. 전용 프리셋 = **[구매-에디토리얼 4593:259](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/CdBd-%ED%85%9C%ED%94%8C%EB%A6%BF--%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=4593-259)** — 카탈로그/룩북에서 **제품 디테일을 설명할 때** 사용. 구조 = `카피 문구(포인트컬러 18 Bold)` → `메인 이미지` → **`label + 설명 문구(15) ↔ 디테일 이미지` 교차 반복** → `안내 문구(13·{텍스트색}×70%)`. 즉 스펙 표만이 아니라 **디테일컷과 짝지은 서술형 설명**으로 제품을 풀어준다. 4종(①상세 ②룩북 ③판매 ④메뉴판) 레시피의 상품/구매 섹션에 `[제품 설명]` 슬롯 추가(아래 레시피 반영).
