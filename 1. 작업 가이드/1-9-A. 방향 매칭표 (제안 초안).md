# 방향 매칭표 — 16개 세부 카테고리 (제안 초안)

> ⚠️ **확정 전 초안.** 「방향」은 2026-09-02 제안한 신규 단계(세부 카테고리와 시안 사이). 확정되면 [[1-9. AI 유저 플로우]] 7단계 표에 흡수한다.

## 왜 필요한가

세부 카테고리는 **페이지 종류**만 정한다. 같은 「정보 전달형 초대장」을 골라도 **작가를 앞세울지 · 공간을 앞세울지**에 따라 페이지는 완전히 달라져야 하는데, 지금은 그걸 정하는 값이 없다. → 같은 세부 = 같은 뼈대 = 진부함.

## 기본 틀 4가지

| 틀 | 질문 | 페이지에 생기는 변화 |
|---|---|---|
| 👤 **사람** | 누가 하는가 | 프로필·인물 사진·이력이 위로 |
| 📦 **내용** | 무엇을 다루는가 | 상품·작품·글·정보가 위로, 설명 충실 |
| 🏠 **공간·분위기** | 어디서·어떤 느낌인가 | 사진 크게, 위치 강조, 글 최소 |
| ⚡ **행동** | 바로 뭘 하게 할 건가 | 예약·연락·구매 버튼 최상단, 나머지 최소 |

## 적용 규칙 4

1. **세부마다 3~4개만 노출** — 그 목적에 의미 없는 틀은 뺀다 (예: 메뉴판에 「사람」 ❌)
2. **화면에 「방향」이라는 말을 쓰지 않는다** — 유저 언어로 "무엇을 가장 먼저 보여줄까요?"
3. **기본값을 미리 골라둔다** — 입력 내용·자료에서 추론해 하나를 선택 상태로. 그냥 넘기면 그 방향으로 진행(탭 0회 가능)
4. **방향은 순서·강조만 바꾼다** — 들어가는 섹션(레시피)은 그대로. 레시피 × 방향

## A. 초대·예약

| 세부 | 방향 (화면 문구) | 틀 | 페이지가 이렇게 바뀐다 |
|---|---|---|---|
| **① 정보 전달형 초대장** | 여는 사람을 먼저 | 👤 | 주최자·작가 프로필 + 인사말 → 행사 정보 → 프로그램 |
| | 무슨 행사인지 먼저 | 📦 | 행사 설명 → 프로그램 순서 → 정보 (사진 최소) |
| | 행사장 분위기를 먼저 | 🏠 | 큰 사진·갤러리 → 위치 → 행사 정보 |
| | 신청부터 받게 | ⚡ | 신청 버튼 상단 고정 → 핵심 정보만 짧게 |
| **② 설문형 초대장** | 폼부터 바로 | ⚡ | 응답 폼 최상단 → 행사 정보 아래 |
| | 행사 설명을 먼저 | 📦 | 행사 설명·프로그램 → 폼 |
| | 주최자가 부탁하는 형식 | 👤 | 주최자 인사말 → 폼 → 정보 |
| **③ 개인화 초대장** | 받는 분 이름을 가장 크게 | 👤 | `{이름}님` 인사말 히어로 → 행사 정보 |
| | 행사 정보를 먼저 | 📦 | 일시·장소 → 개인 메시지 → RSVP |
| | 한 장의 초대 카드처럼 | 🏠 | 큰 이미지 + 짧은 문구 → 정보 최소 |
| **④ 예약 페이지** | 예약 버튼부터 | ⚡ | 회차 버튼 최상단 → 안내 아래 |
| | 공간을 먼저 보여주고 | 🏠 | 사진 갤러리 → 예약 → 위치 |
| | 누가 진행하는지 먼저 | 👤 | 강사·원장 프로필 → 예약 |
| | 무엇을 하는 시간인지 먼저 | 📦 | 프로그램 설명 → 예약 |

## B. 프로필·명함

|---|---|---|---|
| **① 프로필(링크 모음)** | 나를 먼저 | 👤 | 프로필 사진·소개 크게 → 링크 목록 |
| | 가장 눌렀으면 하는 링크부터 | ⚡ | 강조 링크 최상단 → 소개 최소 |
| | 하는 일 종류별로 묶어서 | 📦 | 그룹 헤딩 + 링크 묶음 중심 |

| | 무슨 일을 해주는지 먼저 | 📦 | 서비스 목록(제목+설명) → 상담 |
| | 일단 연락하게 | ⚡ | 전화·카톡·연락처 저장 최상단 |

| | 나를 먼저 소개하고 | 👤 | 프로필·이력 → 작업물 |
| | 화보처럼 분위기로 | 🏠 | 풀블리드 이미지 위주 → 설명 최소 |
| | 의뢰를 받게 | ⚡ | 문의 버튼·포트폴리오 PDF 상단 |
| **④ 매장·브랜드 홈** | 매장 분위기를 먼저 | 🏠 | 매장 사진 크게 → 취급 제품 → 정보 |
| | 취급 제품을 먼저 | 📦 | 제품·서비스 목록 상단 |
| | 만드는 사람 이야기 먼저 | 👤 | 대표·브랜드 스토리 → 제품 |
| | 방문·주문하게 | ⚡ | 위치·영업시간·전화 상단 |
