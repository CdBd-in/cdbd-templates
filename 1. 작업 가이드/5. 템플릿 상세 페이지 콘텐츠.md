# 템플릿 상세 페이지 콘텐츠

사용자가 `/templates/{slug}` 상세 페이지에서 보게 될 정보 = **카탈로그 메타데이터**. 사용자가 "템플릿 사용하기" 버튼을 누르기 전에 마주하는 첫 인상.

> 실제 페이지 제작(에디터 작업)은 [[4. 에디터 페이지 제작]] 참조.

---

## 🧩 구성 요소

| 항목 | 내용 | 디자인 시스템 참조 |
|---|---|---|
| **카테고리** | 5종 중 1개 (프로필·명함 / 초대·예약 / 홍보·카탈로그 / 가이드·신청 / 소식·매거진) | 좌측 상단 보라색 라벨 (Subtitle 1SB,14 · Brand/Primary Primary) |
| **제목** | 템플릿 이름 (예: "프로모션 노출과 상담 신청으로 전환을 만드는 영업용 명함") | Heading 1B,24 |
| **썸네일** | 성과 카드 좌측 원형 프로필 이미지 135×135 | — |
| **사용 성과** | "사용 성과" 라벨 + 본문 (예: 실계약 전환율 40%↑) | Heading 3B,18 · Gray-600 |
| **본문 설명** | 템플릿 핵심 설명 (다줄) | Paragraph 1M,16 |
| **추천 대상 2가지** | 체크 아이콘 + 텍스트 × 2 (Info Pale 배경 박스) | Circle Check + Subtitle 1SB,14 |
| **주요 기능 2가지** | 각각: 아이콘 이미지(38×38) + 제목(H1B,24) + 설명(Paragraph 1M,16) + 메인 이미지(Desktop 360×300 / Mobile 272×227) | Gray-50 50% opacity 배경 카드 |

## ✍️ 작성 원칙

### 카테고리 선택
- 5종 카탈로그 중 1개. 템플릿의 **주요 사용처**에 따라 결정.
- 두 카테고리 사이에서 망설인다면 → 사용자가 검색 시 어떤 키워드로 들어올지 기준으로 판단.

### 제목 작성
- "**무엇을 위해, 무엇을 하는, 무엇이다**" 구조로 압축.
- 예: "프로모션 노출과 상담 신청으로 전환을 만드는 영업용 명함"
  - 무엇을 위해 = 프로모션 노출 + 상담 신청
  - 무엇을 하는 = 전환을 만드는
  - 무엇이다 = 영업용 명함

### 사용 성과
- **수치 포함** 권장 (예: 전환율 40%↑, 예약률 2배, 조회수 1.5만+).
- 추상적 표현 ❌ → "고객 만족도 상승" 대신 "재방문 의향 88%"

### 추천 대상 (2가지)
- 구체적인 페르소나로 작성. 직군/업종/상황 명시.
- 예: "오프라인 영업 빈도가 높은 보험설계사", "신규 고객 응대가 잦은 1인 살롱 원장님"

### 주요 기능 (2가지)
- 템플릿이 가진 **차별점**에 집중. "프로필이 있어요" 같은 당연한 기능 ❌
- 예: "QR 명함 저장으로 한 번 만나도 잊히지 않기", "프로모션 배너로 본업 상품 자연 노출하기"

### D. 신규 등록 시 처리 규칙

**🗑️ 복제 시 삭제할 요소**
- **10회 사용 / ★4.9 배지** (235:10941) — 누적 사용량·평점 표시용. 신규 등록 시 데이터 없으므로 **삭제 상태로 복제**.

**📱 산출물 — 모바일 페이지 스크린샷 (필수)**
- 보드 우측 **패션룩북 프레임** (235:11001/11003/11005/11007) 영역에 들어가는 콘텐츠.
- **4단계에서 완성된 CdBd 라이브 페이지의 모바일 프리뷰 스크린샷**을 캡처해서 붙임.
- **멀티페이지인 경우 모든 페이지 스크린샷 필요**. 페이지마다 별도 프레임에 배치.
- 캡처 셀렉터: `.max-w-1\/2.transform.origin-top` (라이브 템플릿 페이지의 모바일 프리뷰)

**🪧 자동/참조 요소**
- **`cdbd.in/sample/...` 미리보기 URL** (235:11012) — 슬러그 입력 시 자동 노출 (어드민 폼에는 없음)
