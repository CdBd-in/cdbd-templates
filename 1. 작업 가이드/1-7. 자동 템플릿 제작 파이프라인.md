# 1-7. 자동 템플릿 제작 파이프라인 (무인 일일 제작)

> **한 줄 요약**: 매일 밤 8시, 네 맥에서 자동으로 신규 템플릿 1개를 제작(6단계 워크플로우의 1~5단계, 어드민 등록은 보류)하고, 아침에 네가 링크 2개만 열어 검수하면 되는 시스템.

## 0. 확정된 핵심 결정 (브레인스토밍 2026-06-30)

| 항목 | 결정 |
|---|---|
| **자율성** | 완전 무인 + 아침 리뷰. 사람 피드백 게이트 4개 → **자기 비평(검수자) 루프**로 대체. 네 검수는 아침 1회로 통합 |

## 1. 등장 역할 (전부 Claude가 연기)

### 매니저 (지휘자)
- 직접 디자인 ❌. **흐름 통제 + 상태 기록**만.
- 오늘 주제 1개 선택 → 각 단계를 담당자에게 위임 → 검수자에게 검사 위임 → **작업 기록 파일**에 진행 상황 계속 저장.
- 컨텍스트를 가볍게 유지 (실제 무거운 작업은 담당자가 자기 컨텍스트에서 수행).
- = **네 역할을 대신하는 오케스트레이터**.

### 단계별 담당자
- 단계마다 **새 담당자**(서브에이전트)가 그 단계에만 집중.
- 기존 스킬·가이드를 그대로 읽고 일함: [[../CLAUDE.md]], `figma-use`, `cdbd-card-automation`, [[1-1. 워크플로우]] 등.
- **반드시 순차 실행** — Figma 파일 1개·CdBd 에디터 1개·브라우저 1개를 공유하므로 병렬 금지.
- 끝나면 **구조화된 인수인계**(결과물 위치·Figma node ID·에디터 ID·스크린샷 경로)를 매니저에게 반환.

### 검수자
- 지금까지 *사용자가* 보던 4개 피드백 게이트를 대체.
- 담당자가 한 단계를 끝내면, **CLAUDE.md 규칙을 체크리스트로 강제**로 훑어 "통과 / 이거 고쳐"를 반환.
- 고치라고 하면 담당자가 재작업 → **최대 2~3회** 반복 → 그래도 안 되면 "미해결"로 표시하고 다음 단계.

## 2. 하루의 흐름

```
밤 20:00 자동 시작
  └─ 매니저: 시작 전 자가진단 (3장) ──실패──▶ 즉시 사용자 알림 + 그날 중단
  └─ 매니저: 오늘 주제 1개 선택 (큐에서, 최근 무드 회피)
       ├─ [1단계 콘텐츠 기획]  → 검수
       ├─ [2단계 와이어프레임] → 검수 (구조)
       ├─ [3단계 시안: 색·폰트·이미지] → 검수 (대비·무드·투명도)
       ├─ [4단계 CdBd 에디터 구현 + OG] → 검수 (시안 대조)
       │     └─ 끝에 모바일 프리뷰 스크린샷 캡처
       └─ [5단계 상세페이지 콘텐츠(피그마)] → 검수
  └─ 청소 담당: 산출물 정리 + 잔해 라벨 + 누적 목록화 (3장)
  └─ 매니저: 아침 리포트 노트 작성 (Figma·에디터 링크 포함)
```

- **매 단계 종료 시 매니저가 작업 기록 파일에 "여기까지 됐고 결과물은 여기"를 저장** → 중간에 터져도 거기서부터 재개 가능.
- 6단계(어드민 등록)는 **보류** — 이 파이프라인은 1~5단계까지.

## 3. 검수 기준 (사람 게이트 → 체크리스트)

검수자는 느낌이 아니라 **CLAUDE.md에 글로 적힌 규칙**으로 채점. 단계별로:

### 2단계 와이어프레임 검수 (구조)
- [ ] 텍스트 카드 1개 = 속성 1개 (분리됐나)
- [ ] 스켈레톤 고정 스펙: 프로필 텍스트 2개만 / Q&A 제목 중앙+제출버튼 내장 / 위치카드 한 단위 / 자동 gap 금지
- [ ] 모든 카드 평탄화(top-level), 페이지 gap=0, 외부여백=0(배경·테두리 없는 카드는 단일 padding)
- [ ] 편집 불가 장식(팬텀) 없음

### 3단계 시안 검수 (색·폰트·이미지)
- [ ] 글자-배경 대비 ≥ 3.6:1 **그리고** 버튼색-배경 대비 ≥ 3.6:1
- [ ] 무드 1개로 색·폰트 통일, 한 페이지 폰트 1~2개, 국문 본문=한글 폰트
- [ ] 보조 텍스트 = `{텍스트색}×N%` 투명도 (별도 회색 ❌)
- [ ] 버튼 텍스트 색 = `{배경색}`
- [ ] 이미지원 = OpenAI/Thiings/Unsplash (Flow ❌)

### 4단계 에디터 검수 (라이브 ↔ 시안 대조)
- [ ] 텍스트 크기·정렬·여백·줄간격, 프로필 이미지 크기, 갤러리 둥글기/단수, 버튼 높이
- [ ] OG 이미지: 로고 타입 기본, 800×400 JPG, 로고 면적 9~10%
- [ ] 카드 라벨 = 목적·내용 이름

### 5단계 상세페이지 검수
- [ ] 기존 섹션 복제 후 내용만 교체, "10회 사용/★4.9" 배지 삭제, 슬롯 전부 채움

## 4. 실패 처리 & 아침 리포트

### 실패 처리 (부분 완성 + 리포트)
1. 단계가 막히면 **N회 자동 재시도** (throttle·일시 끊김은 잠깐 쉬었다 재시도).
2. 그래도 안 되면 **거기까지 만든 것 그대로 저장** (Figma 섹션·CdBd 에디터·이미지 폴더).
3. 리포트에 **"어느 단계 / 왜 멈췄나"** 한 줄.
4. 그날 작업 깔끔히 종료 (절반짜리 억지로 밀지 않음).
5. 실패한 주제는 큐에 **"재시도 대기"**로 남김 (무한 반복 ❌, 다음 날은 새 주제로 시작).

### 아침 리포트 (vault 노트 1장)
- **위치**: `컨텍스트: 이선호/YYYY-MM-DD 자동제작 — {slug}.md`
- **담는 내용**:
  - 오늘의 결과: ✅완성 / ⚠️부분완성 / ❌실패 + 한 줄 요약
  - 주제: slug·무드·색·폰트
  - **링크 2개**: Figma 시안(`node-id=...`) + CdBd 에디터(`/editor/{id}`)
  - 검수 로그: 단계별로 검수자가 잡은 것·고친 것 (취향 판단 필요 = ⭐ 표시)
  - **CLAUDE.md 후보 규칙**: 새로 발견한 실수 유형 (사용자가 승격 결정)
  - 경고: 큐 잔량·승인 적체·누적 에디터·로그인 이슈
- **사용자 아침 루틴**: 링크 2개 열고 → ⚠️와 ⭐만 보고 → "이대로 / 수정 / 폐기" 한마디.

## 5. 안전장치 (무인 매일 운영의 진짜 적 차단)

### 시작 전 — 자가진단 (조용한 멈춤 방지)
일 시작 전 점검:
- CdBd 로그인 살아있나? → 풀렸으면 `.env`(`CDBD_EMAIL`/`CDBD_PASSWORD`)로 **자동 재로그인**
- Figma 데스크탑 앱 + MCP 연결 / OpenAI 키 / 맥 깨어있음
- 하나라도 복구 불가 → **헛돌지 않고 즉시 사용자 알림 + 그날 중단**

> **인증 수단별 만료 특성 (2026-06-30 확인)**
> | 수단 | 자동 만료? | 대응 |
> |---|---|---|
> | OpenAI API 키 | ❌ 안 풀림 (`~/.config/cdbd/credentials.json`) | 없음 |
> | Figma 데스크탑 앱 | ❌ 거의 안 풀림 (몇 달, 자동 갱신) | 없음 |
> | CdBd 쿠키 | ✅ 풀림 (며칠~몇 주) | **비번 재로그인으로 자가복구** |
> | Google Flow | ✅ 풀림 + 복구 어려움 | **사용 제외** |
> | Figma MCP 연결 | 드롭 가능 | 자가진단에서 확인 후 재연결/중단 |

### 작업 중 — 동질화·품질 저하 방지
- **매일 다른 무드 강제** — 최근 N일에 쓴 무드·카드구성을 기록, 매니저가 그걸 피해 선택.
- **배운 것 자동 기록** — 검수자가 기존 가이드에 없던 *새* 실수 유형 발견 시 리포트에 "CLAUDE.md 후보 규칙"으로 적어둠 → 사용자가 승격 결정 → 무인이어도 학습 사이클 유지.
- 이미지원 Flow 제외 확정.

### 끝난 후 — 청소 (쌓이는 쓰레기 방지)
- 그날 산출물(OG·썸네일·갤러리·시안 PNG)을 `~/Desktop/{템플릿명}/`에 정리, `/tmp` 잔해 삭제.
- 실패로 절반 만든 CdBd 에디터·Figma 섹션은 "미완성" 라벨.
- 누적 에디터 인스턴스 목록을 리포트에 적어 사용자가 주기적 정리.

### 큐·병목 관리
- **주제 큐 잔량 경고** — 백로그 3건 이하 시 "곧 소진, 새 주제 기획 필요" 알림 (자동 주제 생성으로 무리하게 넘어가지 않음).
- **승인 적체 브레이크** — 승인 대기가 N개(예: 5) 쌓이면 생산 **자동 일시정지** (검수 안 된 게 무한정 쌓이는 것 방지).

## 6. 자동 실행 등록 (맥)

- **방식**: macOS `launchd` (옛 cron보다 안정적, 맥이 절전이었어도 깨우면 따라잡음).
- **흐름**:
  1. 맥에 예약표 파일 1개 등록 → 매일 20:00 실행할 명령 기록.
  2. 명령은 짧은 시작 스크립트 실행: ① 맥 깨워두기(작업 시간 동안) ② Claude를 무인 모드로 실행 ③ "오늘의 템플릿 제작 시작" 지시문 전달.
  3. 지시문 = 매니저를 깨우는 한 문단 ("[[../CLAUDE.md]]와 본 설계 문서대로 오늘 1개 제작 + 리포트").
- **사용자 1회 작업**: 예약표 맥 등록. 이후 매일 자동. 끄려면 예약표만 내림.
- **전제 조건**:
  - 20:00에 맥이 켜져 있어야 함 (절전은 깨우지만 완전 종료는 ❌).
  - Figma 데스크탑 앱이 로그인된 채 떠 있어야 함.

## 8. 미해결 / 구현 시 결정할 것

- [ ] 단계별 재시도 횟수 N의 구체값 (기본 2~3회 제안)
- [ ] 승인 적체 브레이크 임계값 N (기본 5 제안)
- [ ] 사용자 알림 채널 — 푸시 vs 이메일 vs vault 노트만 (현재 vault 노트 확정, 추가 채널은 선택)
- [ ] "매니저를 깨우는 지시문"과 시작 스크립트의 실제 파일 위치·형식
- [ ] 작업 기록 파일(재개용 상태)의 저장 위치·형식
- [ ] 청소 담당이 "누적 에디터 정리"를 제안만 할지 자동 삭제까지 할지 (기본: 제안만, 삭제는 사용자 승인)
