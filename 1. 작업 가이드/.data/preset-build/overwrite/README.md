# 섹션 원본 덮어쓰기 도구 (기존 원본 고치기)

> 정본 절차 = [[4-5. 섹션 라이브러리]] 「✏️ 기존 섹션 원본 고치기」. 이 폴더는 그 3·4번(고치기 → 같은 키로 덮어쓰기)을 자동으로 한다.
> 새 원본 등록은 `../savepreset.sh` (새 키만 받는다).

## 준비
- gstack `browse`가 **프리뷰 도메인에 로그인된 세션**이어야 한다 → `export BROWSE_STATE_FILE=<로그인된 상태 파일>`
- 키 → 마스터 에디터·페이지 = 원본 카드 id로 찾는다(마스터 번호표 = 4-5)

## 1. 고치기 — `apply.sh`
```bash
MID=5541 ./apply.sh <페이지 번호> spec.json <이름>
# spec.json = [{"id":"<카드 id>","before":"T R B L","after":"T R B L"}, ...]   (style.padding)
```
- 고치기 전 값이 `before`와 다르면 **아무것도 안 바꾸고 멈춘다**(누가 먼저 고쳤을 수 있다)
- 고친 뒤 `reorderCard(0,1)`·`(1,0)`으로 저장하고, **고치기 전후 미리보기를 페이지 끝까지 픽셀 비교**한다 → 보이는 간격을 바꾸지 않는 수정이면 `PIXDIFF NONE`(모서리 1~2단계 차이는 무시)

## 2. 같은 키로 덮어쓰기 — `save.sh`
```bash
./save.sh <키> <섹션|헤더|푸터> <레이아웃(미니멀,에디토리얼,볼드,공통 순서 · 쉼표)> <섹션 목적|->
# 예) ./save.sh sec/bold/hero/07 섹션 볼드 히어로
#     ./save.sh ftr/01 푸터 공통 -
```
- 종류·레이아웃·목적을 **원래 키와 똑같이** 맞춘 뒤 「이미 있는 프리셋」 표시까지 확인하고 저장한다. 하나라도 다르면 저장하지 않고 창을 닫는다
- 🔴 **메모는 저장 직전 어드민에서 최신값을 읽어 다시 넣는다** — 저장 창 메모 칸은 빈 채로 열리고, 그대로 저장하면 기존 메모가 지워진다(2026-10-23 9개 실제 사고 · 원복)
