# 75안 제작 — 콘텐츠 생성 브리프 (2026-09-04)

## 목표
주제 25개 각각에 대해 **구체적·현실적 페르소나 1명**과 **그 사람이 개정된 7단계 플로우를 통과해 나온 페이지 콘텐츠**를 만든다.
결과물 = 주제당 JSON 1개 (3안 공통 콘텐츠 팩 + 3안별 스타일·무드 지정).

## 🔴 절대 전제 — 개정된 유저 플로우를 통과한 결과여야 한다
페르소나는 "이상적인 유저"가 아니다. 숙련도·자료가 제각각이며, 그에 따라 **결과 페이지도 달라야 한다.**
- **자료 빈약** 페르소나 → 섹션 수가 적고, 「가격 문의」 같은 대체 문구가 있고, 빠진 섹션이 있어야 정상
- **자료 풍부** 페르소나 → 섹션이 많고 내용이 구체적

읽을 것: `../persona-spec-0904.md` (페르소나 레코드 필수 필드 · 칩 규칙 · 빈 자리 처리 규칙)

## 콘텐츠 작성 규칙
1. **모든 텍스트는 실제 문장으로.** "상품명"·"세부 정보" 같은 플레이스홀더 금지. 지어낸 상호·지역·가격·날짜·이름까지 구체적으로.
2. **섹션 타이틀 = 고객 친화 국문.** 내부용어·업계용어·영문 아이브로 금지(예 `CONTACT` ❌ → `문의하기`).
3. **버튼 문구 = 액션형** ("전화하기"·"신청하기"). 연락처 숫자를 버튼 텍스트에 넣지 않는다.
4. **줄바꿈 고아 금지** — 마지막 줄에 1~2글자만 남지 않게 어절 경계로 끊는다.
5. 실재하지 않는 수상·인증·의학적 효능 주장 금지(규제 업종은 특히).

## 3안 차별화 (콘텐츠 레벨에서 미리 지정)
- 3안 = **미니멀 / 에디토리얼 / 볼드** 고정
- 3안은 **무드가 서로 달라야** 한다 — 배경 명도 방향을 나눠 갖고(3안 전부 다크 ❌ / 전부 밝음 ❌), 액센트 색 계열 최소 2종(웜/쿨/뉴트럴)
- **순백(#fff 근접)·순흑 금지** — 크림·오트·세이지·딥네이비·딥그린 등 유채·중간톤
- 대비 2개 필수: 텍스트↔배경 ≥3.6:1 **그리고** 버튼↔배경 ≥3.6:1 (직접 계산해서 JSON에 기록)
- 폰트는 **CdBd 44종에서만** (`../../1-4. 폰트.md`). 국문 본문 = 한글 폰트 필수.
  안전 후보: 프리텐다드 / 본고딕(Noto Sans KR) / 에스코어드림 / Gmarket Sans / 고운바탕 / 본명조
  ⚠️ 고운돋움은 명조 계열 취급 — Gmarket Sans·다른 명조와 조합 금지
  ⚠️ 비즈니스·명함 유형(2-②)은 명조 금지 → 산세리프

## 출력 형식 (JSON 1파일 = 주제 1개)
파일명: `<주제코드>.json` (예 `1-1.json`, `4-6.json` — 원문자는 숫자로)

```json
{
  "code": "1-①",
  "persona": {
    "who": "...(이름·나이·업종·지역·구체 상황 4~6문장)",
    "skill": "중", "mat": "보통", "clar": "명확",
    "step2_want": "화면에서 고른 「하고 싶은 일」 문장",
    "step2b_target": {"ai추론": "...", "유저행동": "그대로 확인|다른 추천 선택|직접 입력", "최종": "..."},
    "step3_answers": {"문항명": "답변", "...": "..."},
    "step3_none": ["「이건 없어요」로 끈 문항"],
    "step3_skipped": ["그냥 건너뛴 문항"],
    "chips": [{"칩": "오시는 길", "근거": "올리신 자료에 주소가 있어서요"}],
    "step4_type": {"결과": "원페이지", "근거": "내용이 한 화면에 담기는 분량이라서요"},
    "holes": ["가격 → 「가격 문의」+문의 버튼으로 대체", "자료 섹션 → 사진 없어 제거"]

    {"목적": "나열", "타이틀": "행사 순서", "content": {"items": [{"시간":"14:00","순서":"개회"}, ...]}}

    {"style":"미니멀","mood":"모던/시크","배경":"#hex","텍스트":"#hex","버튼":"#hex",

```

- 자료 빈약 페르소나는 `sections`가 짧아야 하고 `holes`가 채워져 있어야 한다.
- 헤더는 **3안 중 1~2안만** true (3안 전부 ❌ · 전부 false도 ❌).
