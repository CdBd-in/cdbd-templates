1. 콘텐츠 JSON의 `sections` 를 순서대로 읽는다.

   - 슬롯 수가 안 맞으면 `setRepeat()`로 반복 항목 개수를 맞춘다.
3. **섹션 타이틀**은 본문 프리셋과 별도다 — `PRESETS.json["섹션타이틀"]`에서 골라 본문 위에 `put()`.

   - 조합 규칙 A: 본문 배경/테두리 없음 + 좌측정렬 → 좌 타이틀만 / 중앙정렬 → 중앙 타이틀만
   - 조합 규칙 B: 본문에 위아래 구분선이 있으면 → 구분선 없는 타이틀만
4. `inject()` 로 텍스트를 문서 순서대로 넣는다. 넣기 전 **해당 프리셋의 TEXT 개수를 확인**하고 배열 길이를 맞춘다.
5. `applyTokens()` → `remapFonts()` → `unify()` → 각 섹션 `bottom36()`.
6. 스크린샷으로 눈으로 확인한다.
