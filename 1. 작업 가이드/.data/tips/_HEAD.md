# 입력 단계 안내 문구 — 주제 25개

> **무엇** — 유저가 시안을 보며 내용을 채우는 화면의 **모든 문구**.
> **어디서 나왔나** — 단계 구성은 [[4-4. 조립 레시피]] 5절 레시피 카드, 문구 규칙은 `.data/tips/_SPEC.md`(정본).
> **검수** — 전수 자동 검사 통과(열 수 · 기대효과 마침표 · 주제 내 중복 · 금지표현).

## 화면 구조 — 문구가 놓이는 자리 3곳

```
┌ 왼쪽 입력 패널 ─────────┐   ┌ 오른쪽 미리보기 ───────┐
│ ① 제목                  │   │       ╭──────────╮     │
│ ② 기대효과              │   │       │ ③ 말풍선 │     │
│ [ 입력칸 ]              │   │       ╰───╮╭─────╯     │
│                         │   │  ━━━━━━━━🚗──────────  │
│                         │   │    진행 바 ＋ 자동차    │
│                         │   │ ┌────────────────────┐ │
│                         │   │ │        시안        │ │
└─────────────────────────┘   └─┴────────────────────┴─┘
```

🚗 **진행 인디케이터** (2026-09-14 변경 · [Figma 7010-23500](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=7010-23500))
— 진행 바 위를 **자동차가 달려** 진행률을 보여주고, 자동차 위 **말풍선**에 메시지가 뜬다. 숫자(`3/8`)를 대신한다.

| 자리 | 단위 | 언제 |
|---|---|---|
| **① 제목** | 단계 | 항상 |
| **② 기대효과** | 단계 | 항상 |
| **③ 말풍선 — 반응** | 칸 | 채우거나 고친 **직후 2초** |
| **③ 말풍선 — 마일스톤** | 단계 | 절반 · 하나 남음 · 완료 |

우선순위 `반응 > 마일스톤`

- 🫥 **평소엔 말풍선을 숨긴다** — 반응·마일스톤이 뜨는 순간에만 나타나고, 그 밖엔 **자동차만** 보인다.
- 🚫 **팁은 띄우지 않는다 (2026-09-14 이선호)** — 옛 「③ 팁」(칸 단위 기본값 · 미리보기 위 노출)은 **폐기**했다. 안내는 **왼쪽 패널의 제목＋기대효과가 전담**한다.

## 규칙 요약 (풀버전 = `.data/tips/_SPEC.md`)

**채움 열 — AI / 사실**
- **AI** = 문장을 지어서 미리 채워둠 (인사말·소개글·스토리·카피)
- **사실** = 자료에 있으면 뽑아 채우고 **없으면 비워둠. 지어내기 절대 ❌** (이름·일시·장소·가격·계좌·연락처·정원·마감일·스펙·경력·작품 정보·통계·후기·이미지)
- 왜 — 표현은 틀려도 고치면 그만이지만 **사실은 틀리면 사고**

**제목 — 런타임 상태가 정한다**
- 그 단계에 **한 칸이라도 비어 있으면** `{항목}을 추가하면 좋아요`
- **전부 채워져 있으면** `{항목}을 미리 채워뒀어요 / 수정할 곳이 없는지 확인해 주세요.`
- 표에는 **비어 있을 때 버전만** 적는다

**기대효과** — **보는 사람(방문자)이 얻는 이득** · 25자 안팎 · 마침표

**반응** — 담백한 서술만(의인화·감상·이모지·과장 ❌) · **채움이 `AI`인 칸은 반응 없음(`—`)**

**공통 안내**(최초 1회 · 입력칸 옆) — `엔터로 줄을 나눌 수 있어요`

🚫 **「제목 위 문구」(eyebrow)는 편집 범위에서 제외** (2026-09-10) — AI가 넣고 유저는 건드리지 않는다. 단계·칸에 등장하지 않는다.
