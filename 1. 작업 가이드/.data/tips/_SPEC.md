# 입력 단계 안내 문구 — 작성 규칙 (정본)

## 이게 뭔가
AI 페이지 빌더의 「내용 채우기」 단계에 뜨는 문구. **두 자리**에 놓인다.
- **왼쪽 입력 패널** — **제목 ＋ 입력칸** (제목은 항상)
- **진행 인디케이터의 말풍선** — 진행 바 위를 달리는 자동차에 붙는다. **반응·마일스톤이 뜨는 순간에만** 나타나고 평소엔 숨는다

## 말풍선 상태 2가지
| 상태 | 성격 | 지속 |
|---|---|---|
| **방금 채움 = 반응** | 채우거나 고친 직후 | 2초 → 숨김 |
| **마일스톤** | 절반 / 하나 남음 / 완료 | 그 단계 내내 |
우선순위 `방금 채움 > 마일스톤`

> 채울 때의 안내는 **왼쪽 패널의 제목**이 전담한다 — 그 밖에 상시 노출 문구는 없다.

## 단계 만드는 법
[[4-4. 조립 레시피]] 5절의 그 주제 레시피 카드(섹션 목록)를 그대로 단계로 변환.
- 순서: **메인 이미지 → 로고 → 히어로 텍스트 → (레시피 섹션 순서대로) → 찾아오시는 길 → 문의 → SNS**
- 히어로 텍스트 단계는 칸이 2개(제목 / 설명) → 칸마다 반응
- 🚫 **「제목 위 문구」(eyebrow)는 편집 범위에서 제외** — AI가 넣고 유저는 건드리지 않는다. 단계·칸으로 만들지 말 것
- 헤더·푸터처럼 자동으로 붙는 건 단계로 만들지 않음
- **6~11단계**가 적정. 억지로 늘리지 말 것
- 🔘 **칸마다 필수/선택을 정한다 ** — 필수 = 이름·제목·일시처럼 없으면 그 섹션이 성립 안 되는 칸 / 선택 = 설명·부가 문구(색인 `*` 옵션 슬롯 부류). **필수가 다 차면 하단 `이건 없어요` 버튼이 `다음`으로 바뀐다**(AI가 미리 채운 칸도 「참」). 분류 기준 정본 = [[4-12. 입력 유형 카탈로그]] §2-0 · 표에는 「필수/선택」 열로 붙인다(272행 재작성 때)

### 📍 「장소」와 「찾아오시는 길」은 다른 단계다 

| | **장소** | **찾아오시는 길** |
|---|---|---|
| **어느 섹션** | 핵심 정보 (라벨＋값) | 위치 안내 (지도) |
| **입력 방식** | **단순 텍스트** 한 줄 | **주소 검색**(목록에서 고르기) ＋ **상세주소**(단순 텍스트) |
| **예** | `그랜드 하얏트 서울 그랜드볼룸` | `서울 강남구 테헤란로 521` ＋ `3층 그랜드볼룸` |
| **칸 수** | 1 | **2** |

- 🔑 **왜 검색이어야 하나** — CdBd 위치 안내 카드는 **주소를 검색 목록에서 골라야 좌표가 생기고 지도·길찾기가 열린다.** 직접 타이핑만 하면 「지도 보기」가 동작하지 않는다. 📍 **필수 충족 판정도 같은 기준 ** — 주소 칸은 **검색 결과에서 1개 선택을 완료해야 「채워짐」**. 타이핑만 한 상태는 미충족(`이건 없어요` 유지 · [[4-12. 입력 유형 카탈로그]] §2-0).
- 🏠 **상세주소는 검색으로 안 잡힌다** — 층·호수·건물 안 위치는 도로명 주소에 없으므로 **따로 텍스트로** 받아 **지도 아래 주소 옆에 이어 붙인다**.
- 🧭 **둘 다 나올 수 있다** — 장소(이름)는 핵심 정보에서 *"어디서 하나"*를, 찾아오시는 길은 *"어떻게 가나"*를 답한다. 겹치는 게 아니라 역할이 다르다.
- ➕ **단계 위치** — 레시피의 `[위치 안내]` 자리 = **문의 바로 앞**.
- ⏭ **조건부·선택 주제**(온라인 전용 · 고객 집 방문 · 오프라인 매장 없음)는 **이 단계를 통째로 건너뛴다** — 건너뛰면 단계 수도 1 줄어든다.

## 🔴 채움 주체 — AI가 채울 수 있는 것 / 비워둘 것 (필수)

표에 **「채움」 열을 반드시 넣는다.** 두 가지뿐이다.

| 표기 | 뜻 | 무엇이 여기 해당하나 |
|---|---|---|
| **AI** | AI가 문장을 **지어서 채워둔다** | 표현·문장 — 인사말 · 소개글 · 초대의 말 · 스토리 · 섹션 제목 · 설명 문구 · 카피 · 안내 문구 톤 |
| **사실** | **자료에 있으면 뽑아 채우고, 없으면 비워둔다.** 지어내기 절대 ❌ | 이름 · 일시 · 기간 · 장소 · 주소 · 가격 · 금액 · 계좌 · 연락처 · 정원 · 마감일 · 회차 · 스펙 · 실측 · 자격 요건 · 경력 · 학력 · 수상 · 작품 정보(작가·연도·재료·크기) · 통계 · 후기 |

**이미지**는 `사실`로 본다 — 유저 업로드가 원칙, 「AI 이미지 생성」 버튼은 유저가 누를 때만.

### 왜 나누나
AI가 **일시·가격·연락처를 그럴듯하게 지어내면** 유저가 못 알아채고 그대로 발행한다 → 잘못된 정보가 나간 페이지. 표현은 틀려도 고치면 그만이지만, **사실은 틀리면 사고**다.

## 반응 규칙
- 그 단계에서 **실제로 좋아진 점**을 말할 것. `좋아요!` 같은 뭉뚱그린 칭찬 ❌
- **매 단계 달라야 함**(반복되면 3번째부터 안 읽힘)
- **채움이 `AI`인 칸은 반응 없음(`—`)** — 유저가 채우는 행위가 없다(고쳤을 때도 없음)
- 반복 입력(항목 여러 개)은 칭찬 대신 **개수 변화**: `프로그램 5개가 됐어요`
- **끝에 이모지 1개** — 칸 종류가 이모지를 정한다(아래 🎨 팔레트)

## 마일스톤
단계 수에 맞춰 배치. 8단계 기준:
`벌써 절반이나 왔어요 🙌` (4/8) · `이제 하나 남았어요 💪` (마지막 직전) · `다 채우면 다른 시안도 보여드릴게요 🎉` (마지막)

## 문체
해요체 · 능동형 · 긍정형. `~해야 합니다` `~하세요` ❌ → `~하면 좋아요` `~해도 돼요`

## 🅰 왼쪽 패널 문구 — 제목

**반응·마일스톤**은 진행 인디케이터의 **말풍선**에 뜬다(순간 노출 · 평소 숨김).
이것과 별개로 **왼쪽 입력 패널의 제목**이 있고, 이건 **단계 단위**다(칸마다 ❌) · **항상 보인다**. 왼쪽 패널 = **제목 ＋ 입력칸**.

### 🟣 제목의 주어 = 명사형 섹션 타이틀 
`{항목}` 자리는 **그 단계가 채우는 섹션의 명사형 타이틀(AI 생성)**을 넣고 **포인트 색 + 미리보기 연결선**으로 표시한다. ① 조사 을/를 = 마지막 글자 받침(숫자·영문은 읽는 소리) ② 여러 줄 타이틀 = **「이름표 역할의 명사형 줄」만**(라벨·카피 ❌ — `안내`＋`가격과 발송 안내`면 **`가격과 발송 안내`** · 크기·위치 아닌 역할로 판정) ③ **히어로 3단계 = 고정 이름**(타이틀 없음) ④ **문장형 타이틀 섹션 = AI가 명사형 이름표를 함께 생성**해 주어로 사용(예: 「주문하시면 2일 안에…」 → 주어 「가격과 발송 안내」). 풀버전 = [[4-7. 입력 단계 안내 문구]] 「🟣 제목의 주어」.

### 상태에 따라 두 벌
| 상태 | 제목 | 설명 |
|---|---|---|
| **비어 있음** | `{항목}을(를) 추가하면 좋아요` | — |
| **채워져 있음** (AI 생성 또는 자료 추출) | `{항목}을(를) 미리 채워뒀어요` | — (제목 한 줄만 · 둘째 줄 없음) |

### 실제 예시 (1-① 행사 초대장 · Figma 확정본)
| 단계 | 제목 |
|---|---|
| 메인 이미지 | 메인 이미지를 추가하면 좋아요 |
| 로고 | 로고 이미지를 추가하면 좋아요 |
| 프로그램 | 프로그램을 추가하면 좋아요 |
| SNS | SNS 채널을 추가하면 좋아요 |

### 표 형식 (열 6개)
`# | 단계 / 칸 | 채움 | 필수 | 왼쪽 제목 | 방금 채움`
- **필수 열** = `필수`/`선택` — 판정 3규칙: ① **단독 칸 단계 = 무조건 필수**(그 칸이 곧 건너뛰기 판단) ② 복수 칸 = **본체 필수 · 부가 선택**(히어로 설명·상세주소·직함·제품 스펙 행 등) ③ AI 칸도 같은 기준 ④ **자료 조건부 칸**(스펙·실측 — 자료에 있을 때만 그 슬롯 섹션이 뽑힘)은 빈 채로 나타나지 않으므로 **필수**. 버튼 규칙(필수 다 차면 `이건 없어요`→`다음`) = [[4-12. 입력 유형 카탈로그]] §2-0
- **왼쪽 제목**은 **단계의 첫 행에만** 적고, 같은 단계의 나머지 칸은 `〃` 로 둔다

### ⚖️ 제목 형태는 「런타임 상태」가 정한다 — 문서에는 **비어 있을 때 버전만** 적는다 
한 단계 안에 AI 칸과 사실 칸이 섞이는 경우가 많다(히어로 = AI 카피 + 행사명·일시).
그래서 제목을 문서에서 미리 고정하지 않는다.

- **문서(이 표)에는 항상** `{항목}을 추가하면 좋아요` **형만 적는다.** 채움이 `AI`인 단계도 마찬가지 — 자료가 없어 못 채우는 경우가 있으므로.
- **채워진 상태의 문구는 공식이라 표에 적지 않는다** — 화면에서 `{항목}을 미리 채워뒀어요` 로 자동 전환.
- 판정 단위는 **단계**다. 그 단계의 칸이 **하나라도 비어 있으면** 「추가하면 좋아요」, **전부 채워져 있으면** 「미리 채워뒀어요」.

### 🎙 반응(방금 채움) 톤 — 따뜻한 한마디 ＋ 이모지

> 이 한마디는 유저가 한 칸을 채울 때마다 2초 뜨는 **격려**다. 사실 보고처럼 쓰면 읽히지 않는다.
> 다만 **아무 이모지나 쓰면 산만**해지므로 **칸 종류가 이모지를 정한다** — 문구를 쓰는 사람이 고르지 않는다.

**✅ 두 갈래만**
1. **감탄형**(이미지 칸) — `멋진 {무엇}이네요` → `멋진 메인 이미지네요 👀` · `멋진 프로필 사진이네요 👀`
2. **효과형**(정보 칸) — `{무엇}이 확실해졌어요 / 또렷해졌어요 / 분명해졌어요 / 쉬워졌어요` → `브랜드가 확실해졌어요 ✨` · `찾아오기 쉬워졌어요 📍`
3. **개수형**(반복 입력) — `{무엇} N개가 됐어요 📋` (무엇인지 앞에 붙인다 · ❌ `5개가 됐어요`)

**🎨 이모지 팔레트 — 칸 종류별 고정 10종**

| 이모지 | 붙는 칸 |
|:--:|---|
| 👀 | 이미지 · 사진 · 화보 · 갤러리(장수 포함) |
| ✨ | 로고 · 브랜드 · 이름 · 제목 |
| 🗓 | 일시 · 기간 · 마감 · 운영시간 · 발행일 |
| 📍 | 장소 · 주소 · 지도 |
| 💰 | 가격 · 요금 · 혜택 · 쿠폰 · 계좌 |
| 📋 | 글로 된 반복 항목(개수) · 목록 · 정리 |
| ✅ | 조건 · 규정 · 유의사항 · 자격 · 안내 |
| 📞 | 문의 · 연락처 |
| 🔗 | SNS · 링크 · 채널 |
| 🛒 | 구매 · 주문 · 혜택 받기 버튼 |

**마일스톤 3종**(진행 격려 전용 · 위 팔레트와 별도) — `벌써 절반이나 왔어요 🙌` · `이제 하나 남았어요 💪` · `다 채우면 다른 시안도 보여드릴게요 🎉`

**🚫 그래도 쓰지 말 것**
| 유형 | 예 |
|---|---|
| 뭉뚱그린 칭찬 | `좋아요!` · `잘하셨어요` (무엇이 좋아졌는지 없음) |
| 의인화 | `이름이 앞에 섰어요` · `간판이 걸린 느낌이에요` |
| 이모지 2개 이상 | `멋진 메인 이미지네요 👀✨` |
| 과장 | `완벽해졌어요` · `힘있게 자리잡았어요` |

**길이·중복** — 16자 안팎 · 마침표 없음 · 이모지는 **맨 끝 1개**(앞에 반각 공백) · **한 주제 안에서 같은 문구·같은 서술어가 연달아 오지 않게**. 이모지는 칸 종류가 정하므로 **한 주제에 같은 이모지가 여러 번 나와도 정상**이다.

### 🕯 예외 — 무거운 소식은 이모지·감탄 ❌
`6-① 공지·알림`은 **휴관·이전·폐업**처럼 무거운 소식이 들어온다. 이 주제만 **반응도 마일스톤도 담백하게**(이모지 없이 `발행처가 표시됐어요` · `본문 내용이 정리됐어요` · `절반까지 왔어요`) 쓴다.

### 🚫 채움이 `AI`인 칸은 「방금 채움」 반응이 없다 
AI가 이미 문장을 지어 채워둔 칸이므로 **유저가 「채우는」 행위 자체가 없다.** 열에 `—`를 적는다.

- 유저가 그 문장을 **고쳤을 때도 반응 없음** — `채워졌어요`는 사실과 다르고, 고친 것을 칭찬하면 과하다
- 반응은 **`사실` 칸에만** 나온다(유저가 실제로 입력하는 자리)
- 결과적으로 반응이 붙는 칸이 줄어드는데, **그게 맞다** — 반응이 매 칸마다 나오면 무시된다
