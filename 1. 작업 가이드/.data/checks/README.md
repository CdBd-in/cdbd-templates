## margin-check.js — 여백 검사

**무엇을 보나** — [[1-6-2. CdBd 카드 기능]] 「⚠️ 여백은 「배경·테두리가 있느냐」로 정한다」 표 그대로. 배경 없는 카드는 **안쪽 여백 하나로** 위치를 정하고, 배경·테두리 박스는 **바깥 여백(화면 끝 20↑)과 안쪽 여백(박스↔글자)** 을 따로 갖는다.

| 규칙 | 걸리는 것 | 고치는 법 |
|---|---|---|
| **R1** | 배경 없는 글자·이미지·선이 화면 끝에서 **20 미만** | 카드 안쪽 여백 20↑ · 글상자 `FIXED` → `FILL` ([[4-8. 시안 검수 체크리스트]] ⑦⑧) |
| **R2** | 배경 박스가 화면 끝에서 **20 미만** (양쪽 다 0이면 R5) | 감싸는 프레임(바깥 여백) 좌우 20↑ |
| **R3** | 박스 안 글자가 박스 끝에서 **12 미만** (권장 16~24 · 색 띠 안은 20) | 박스 안쪽 여백을 늘린다 · **칸마다 배경**이면 줄 전체 배경 하나로(2열 칸별 배경은 재현 불가) |
| **R4** | 배경 없는 프레임이 **겹겹이 여백**(래퍼 + 카드) | 한 겹으로 합친다 · 섹션 마지막 카드면 아래 = 36 |
| **R5** | 화면 끝까지 닿는 **색 띠** — **허용 예외** | 의도한 띠인지만 확인 (오류로 세지 않음) |
| **R6** | 한 섹션 안 큰 박스(폭 180↑) 바깥 여백이 **제각각** · 띠와 안쪽 박스 혼재 | 한 값으로 |
| **R7** | 박스 아래 안쪽 여백 28↑ **그리고** 위보다 16↑ — 섹션 끝 36이 박스 안으로 샘 | 36은 바깥 래퍼로 ([[4-8. 시안 검수 체크리스트]] ⑤) |

**재는 법** — 패딩 숫자가 아니라 **화면에 놓인 실제 위치**로 잰다. 섹션 프레임 자체 여백·래퍼가 몇 겹이든 결과가 같다.
- 글자는 **글상자 끝**으로 잰다 — 지금 견본이 짧아도 긴 글이 들어오면 거기까지 찬다.
- 예외 = **늘어나지 않는 표식**(3글자 이하 — 번호·불릿·이모지)과 **여러 칸 줄의 가운데 정렬 글자** → 실제 잉크 위치(±2 허용).
- 박스 = 채움·테두리가 있는 프레임. **이미지 자리**(회색 박스·사진) · **페이지 배경과 같은 색 채움**(안 보이는 배경) 제외 · 글자 하나짜리 낮은 박스(**버튼·알약**)는 안쪽 검사 제외.

**돌리는 법** — `use_figma`에 **입력 한 줄 + 이 파일 내용**을 붙인다(파일 키 `24O01lprp5i2ufl7CbZXXx`).
- **라이브러리 전체** — `const TARGET_IDS_IN = [...]` ← `.data/preset-index/preset-index.json`의 `id` 전부(정확). `const CONTAINER_ID_IN = '34:23'`(라이브러리 페이지)도 되지만 연구용 프레임(「06-V1 …」「10-V1 …」「20-V1 …」 13개)이 섞여 걸린다.
- **시안 페이지** — `const PAGE_IDS_IN = ['페이지 프레임 id']` → 직계 자식을 섹션으로 본다. 페이지 배경 = 그 프레임 채움(다르면 `const BG_IN = 'r,g,b@100'`).
- 결과 = `{ checked, sectionsWithErrors, summary, sectionsPerRule, errors: [{ section, sectionId, findings: [{ rule, card, cardId, detail }] }], bandSections }` — `sectionsWithErrors`는 R5(허용 예외)를 빼고 센다.

**언제 돌리나**
- 섹션 원본을 **새로 만들거나 고친 뒤** — [[4-5. 섹션 라이브러리]] 채택 관문(오류 0이어야 등록)
- 데일리 루프 **신규 섹션 제작 · S3 회전 점검** — [[4-13. 데일리 퀄리티 루프]]
- 시안 **완료 보고 전** — [[4-8. 시안 검수 체크리스트]] B 여백

**한계** — 가로 여백 중심(세로는 R7 하나). 섹션 사이 간격·섹션 하단 36(4-8 ⑨)·한 페이지 안 인셋 통일은 아직 안 본다. 표식 판정(3글자 이하)은 어림이라 긴 번호(「STEP 01」)는 글상자로 잰다.

**기록** — 2026-10-23 첫 전수: 라이브러리 355개 중 **9개 위반 → 고쳐서 0** (글상자 FIXED가 여백을 뚫음 3 · 래퍼 두 겹 5(그중 4개는 섹션 끝이 36이 아니라 56) · 칸마다 배경 1). 처음 판정식(패딩 값으로 잼)은 42개를 잡았지만 대부분 오탐(섹션 자체 여백 · 가운데 정렬 번호 칸 · 색 띠)이라 「화면 위치로 잰다」로 바꿨다.
