# 에디터 페이지 제작

사용자가 "템플릿 사용하기" 클릭 시 받게 될 **실제 페이지**. 카드 구성 + 디자인의 영역.

> 카탈로그 메타데이터(카테고리·제목·사용 성과 등)는 [[5. 템플릿 상세 페이지 콘텐츠]] 참조.

---

## 🎯 세 가지 차원

| 차원 | 내용 |
|---|---|
| **내용** | 텍스트, 이미지 |
| **구조** | 어떤 카드를 어떤 순서로 사용할지 (원페이지/멀티페이지, 분량) |
| **디자인** | 테마 색상, 섹션 분리, 둥글기/모양 통일 |

---

## 🛠 에디터 구조

### Desktop 3-column (원페이지)
```
좌측 (max-w 480px) — 미리보기 보드 (실제 모바일 렌더링, 380px 카드 폭)
중앙 (max-w 480px) — 카드 보드 (카드 리스트, 추가/순서/토글/핀/삭제)
우측 (max-w 480px) — 디자인 보드 (선택된 카드의 디자인 속성)
```

### Desktop 4-column (멀티페이지)
```
최좌측 (116px Fixed) — 페이지 목록 패널 (썸네일 수직, 추가/복제/삭제)
+ 원페이지와 동일한 3컬럼
```

### 상단 헤더
- ← / → (실행 취소·재실행)
- 페이지 이름 편집 (Input/Text Field/Special/Page Title)
- 💡 애니메이션 / 🎨 팔레트 (페이지 테마 진입)
- 👁 미리보기 / **URL 생성하기** (Brand/Primary)

> 참조: `3-2-1. 에디터_공통.md`, `3-2-3. 에디터_카드 보드.md`, `3-2-4. 에디터_디자인 보드.md`, `3-2-5. 멀티페이지 에디터.md`

## 🎨 페이지 테마 (Page Theme)

**19개 색상 프리셋** — 각 프리셋은 [배경색 / 텍스트색 / 버튼색] 3색 1세트. 기본값은 프리셋 1 (`#fafafa` / Gray-900 / Gray-900).

> 추가 팔레트 후보는 [[1-1. 색상 팔레트 라이브러리]] 참조 (총 101개, 무드별 분류).

### 테마 변수 (`{}` 표기)
| 변수 | 의미 |
|---|---|
| `{버튼색}` | 페이지 테마 버튼 색 (단색 영역 기본값) |
| `{배경색}` | 페이지 테마 배경 색 (이미지 배경 시 Picker 저장 단색) |
| `{버튼모양}` | 페이지 테마 버튼 모양 (border-radius: 원형 99px / 각진 0 / 둥근 16px) |
| `{서체}` | 페이지 테마 서체 (한글 26종 + 영문 18종, 기본: 프리텐다드) |
| `{텍스트색}` | 페이지 테마 텍스트 색 |

### 색상 사용 원칙
- ✅ **색상이 사용되는 모든 요소에 최대한 테마 default 색상 활용** — 카드별 색상을 임의로 변경하지 말고 `{버튼색}`·`{텍스트색}` 그대로 사용
- ✅ **캡션/유의사항 등 보조 텍스트는 텍스트색의 투명도를 조절** (예: 텍스트 색 × 60%, × 40%) — 별도 회색 지정 ❌
- 색상 표기는 `텍스트 색 × N%` 형식으로 자동 계산됨

> 참조: `4-2. 페이지 테마.md`

## 🃏 카드 종류 — 15종

| # | 카드 | 핵심 용도 | 키 옵션 |
|---:|---|---|---|
| 1 | **메뉴** | 페이지 내 네비게이션 메뉴 (탭 구조) | 한눈에 보기 / 햄버거형 · 프리셋 6종 |
| 2 | **프로필** | 인물·브랜드 프로필 (이미지+이름+소개) | 기본형 / 강조형 / 명함형 |
| 3 | **텍스트** | 텍스트 한 단위 | **하나의 카드 = 하나의 텍스트 속성** |
| 4 | **이미지** | 단일 이미지 | 8가지 모양 (각진/둥근/원형/아치/구름/꽃/반짝이/마름모) |
| 5 | **갤러리** | 여러 이미지 | 나열하기 / 넘겨보기(캐러셀) / 그리드 (최대 15장) |
| 6 | **유튜브** | 유튜브 영상 | URL 기반 임베드, 자동재생/컨트롤러 옵션 |
| 7 | **버튼** | CTA 버튼 (링크) | 가로 버튼형 / 카드형 / 배경형 + 이미지 추가 가능 |
| 8 | **질문과 답변** | 설문 폼 (객관식/주관식) | 직접 만들기 / 상담 신청서 / 만족도 조사 / 사전 참석 신청서 (프리셋) |
| 9 | **예약** | 예약 시스템 | 일정·장소·옵션 설정 + 방문 체크 (QR) |
| 10 | **위치 안내** | 지도 + 주소 + 길찾기 | 구글맵 / 네이버맵 |
| 11 | **SNS** | SNS 아이콘 모음 | 홈페이지/인스타/카톡/유튜브/틱톡/X |
| 12 | **구분선** | 섹션 구분 | 실선/대시/점선/물결, 두께·상하여백 조절 |
| 13 | **코드** | HTML 직접 삽입 | 자유 코드 입력 |
| 14 | **2단 카드** | 2-4단 분할 레이아웃 | 구성 가능: 텍스트·이미지·버튼·예약 |
| 15 | **상품** | 외부 상품 URL 자동 임포트 | 그리드 / 가로 바, 캐러셀 옵션, 스마트스토어 연동 |

### 모든 카드 공통 옵션 (항상 마지막 순서)
- **카드 디자인** — 배경 / 테두리 / 모서리(각진·둥근) / 내부여백 / 외부여백
- **레이어 추가** — 카드 위에 이미지 레이어 (장식 요소)

### 링크 연결 옵션
- 페이지 이동하기 (멀티페이지 default)
- URL 열기 (원페이지 default)
- 전화하기 / 문자 보내기 / 이메일 보내기 / 연락처 저장하기(vCard)

> 참조: `4-1. 공통.md` ~ `4-17. 2단 카드.md`

## ✅ 작업 원칙 (필수 준수)

### 1. 범용성
- 페이지뿐만 아니라 **각 카드도 반복 복제 사용**될 수 있음을 염두에 둘 것
- 카드 1개가 독립적인 의미 단위로 작동해야 함

### 2. 텍스트 카드 분리
- **하나의 텍스트 카드 = 하나의 텍스트 속성**
- 제목 + 본문을 한 카드에 묶지 말고 → 제목 카드 + 본문 카드로 분리
- 이유: 편집 용이성 (사용자가 부분 수정 시 영향 최소화)

### 3. 보조 텍스트 색상
- 캡션, 유의사항 등 보조 텍스트는 **텍스트색 투명도 조절** 사용
- 별도 회색 컬러 ❌ → `{텍스트색} × 60%`, `× 40%` 등 활용

### 4. 테마 default 색상 활용
- 색상이 사용되는 모든 요소는 최대한 **`{버튼색}` / `{배경색}` / `{텍스트색}` default 그대로**
- 카드별 커스텀 색상 지정 최소화

### 5. 장식적 그래픽 이미지 배제
- **편집 불가능한 장식적 그래픽** 요소 ❌
- 단, 로고·프로필 이미지 등 **교체해서 사용하는 이미지는 OK**
- "꾸미기 위한 이미지"는 사용자가 바꿀 수 없으므로 카드 디자인으로 표현해야 함

## 📐 디자인 통일성 체크리스트

### 페이지 단위
- [ ] 테마 색상 1세트 선택 (19개 프리셋 또는 [[1-1. 색상 팔레트 라이브러리]]에서 선택) — 페이지 전체 일관성
- [ ] 페이지 서체 1개 선택 — 모든 텍스트 통일
- [ ] 버튼 모양 1개 선택 (원형/각진/둥근) — 모든 버튼·메뉴 모서리 통일

### 섹션 분리 방법
- [ ] **구분선 카드** — 명확한 구분
- [ ] **여백 카드** (= 구분선의 변형, 두께 0/상하여백만) — 부드러운 구분
- [ ] **카드 배경** — 카드 배경색으로 그룹화
- [ ] **카드 모서리** — 둥글기 통일

### 카드 모서리 일관성
- 페이지 테마 `{버튼모양}` 따라가는 카드: 메뉴 버튼, 버튼, Q&A 제출 버튼, 예약 버튼, 위치 안내 버튼
- 개별 설정 가능한 카드: 이미지, 갤러리, 동영상, 카드 자체 디자인
- → 전체적으로 같은 모서리 톤(원형/각진/둥근)으로 통일

## 🚦 페이지 구조 패턴 (관찰 기반)

### 원페이지 (1~14번)
- 모바일 페이지 1개를 위→아래 스크롤
- 길이 다양: 17개(템플릿 14) ~ 52개(템플릿 8)
- 헤더(로고+제목) → 본문(섹션 반복) → 푸터(SNS+로고) 패턴

### 멀티페이지 (15, 16, 17번 — 홍보·카탈로그)
- 페이지 넘김 효과: 밀어내기 / 확대 1 / 확대 2
- 페이지마다 사이즈 설정 가능 (기본 380×620)
- 페이지 테마는 모든 페이지 공통 적용
- 카드 적은 페이지(2~3개) + 정보 많은 페이지(10~32개) 혼합 가능

### 카테고리별 카드 활용 경향
| 카테고리 | 자주 쓰는 카드 |
|---|---|
| 프로필·명함 | 프로필, 텍스트, 버튼, 갤러리, SNS, 연락처 저장 버튼 |
| 초대·예약 | 텍스트(초대글), 이미지, 예약, Q&A(참석 정보), 위치 안내 |
| 홍보·카탈로그 | 이미지, 갤러리, 상품, 버튼, 텍스트 |
| 가이드·신청 | 텍스트, Q&A, 버튼(서명), 이미지 |

## ⏭ 작업 흐름

사용자가 "X 카테고리 템플릿 만들어줘" 요청 시:

1. **상세 페이지 콘텐츠 기획** → [[5. 템플릿 상세 페이지 콘텐츠]] 참조
   - 카테고리 / 제목 / 사용 성과(수치 포함) / 추천 타겟 2가지 / 주요 기능 2가지

2. **에디터 페이지 구조 설계**
   - 카테고리 타겟·주요 기능과 직결된 카드 선정
   - 원페이지 vs 멀티페이지 결정
   - 카드 순서 + 각 카드의 텍스트/이미지 내용

3. **디자인 통일성 확보**
   - 페이지 테마: 19개 기본 프리셋 OR [[1-1. 색상 팔레트 라이브러리]]에서 무드 매칭
   - 카드 배경·모서리·구분선·여백 전략

4. **에디터에서 실제 생성**
   - 빈 페이지 시작 (`/templates` → 빈 페이지로 시작하기)
   - 카드 하나씩 추가하며 위 설계 반영
