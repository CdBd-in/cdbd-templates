# 조립 레시피 — 27칸 (제안 초안)

> ⚠️ **확정 전 초안.** 분류 체계는 [[1-11. 대분류 재설계 (제안 초안)]] 정본(대분류 6 × 세부 27).
> 🗄 **구버전** = [[1-8. 섹션 프리셋 라이브러리]] 「🧩 카테고리별 조립 레시피」 16개 — **아카이브로 보존**, 이 문서가 대체한다.

---

## 0. 이 문서의 모델 — **3층**

기존 16개 레시피를 전수 분해해 보니 **예외 없이 같은 골격**이었다. 칸마다 다른 것은 **세 가지뿐**이다.

| 층 | 무엇 | 개수 | 바뀌는가 |
|---|---|:--:|---|
| **① 공통 골격** | 여는 부분 · 닫는 부분 | **1** | 27칸 전부 동일 |
| **② 배치 패턴** | 본체 순서 규칙 + 멀티 분할 | **6** | 칸마다 하나 지정 |
| **③ 칸별 카드** | ★결정 블록 · 보조 블록 · 조건부 | **27** | 칸의 정체 |

🔑 **이 구조를 쓰는 이유** — *"문의 섹션은 3안 모두 다른 프리셋"* 같은 **공통 규칙이 바뀌면 골격 한 곳만** 고친다. 구버전은 같은 규칙이 16군데 흩어져 있어 한 곳을 고치면 나머지가 낡았다.

### 재료 = 섹션 목적 13칸
`히어로 · 소개 · 핵심 정보 · 스토리 · 안내 사항 · 나열 · 자료 · 예약 · 폼 · 구매 · 프로모션 · 위치 안내 · 문의` (+ 구조 뼈대 `헤더 · 푸터`)
→ 서랍·프리셋 실물 = [[1-8. 섹션 프리셋 라이브러리]] 「📚 섹션 카탈로그」

### ⚠️ 유연한 기준 — 고정 틀 아님
아래는 **출발점**이다. 페이지 목적·유저 자료에 따라 **섹션을 더하고 빼고 순서도 바꾼다.** 한 페이지는 **읽히는 목적**(히어로·소개·자료)과 **동작하는 목적**(위치·폼·예약·문의·구매)을 섞어 짠다.

## 1. 공통 골격 — 27칸 전부 동일

```
┌ 여는 부분 ────────────────────────────────
│ [헤더]     선택 — 로고·발행처
│ [히어로]    필수 — 페이지 첫 콘텐츠 섹션. 예외 없음
├ 본체 ─────────────────────────────────────
│ [도입]      선택 — 소개·스토리 (이게 뭔지 · 누구인지)
│ [★ 결정 블록] 필수 — 그 칸의 정체 (§4)
│ [보조 블록]  0~3개
├ 닫는 부분 ────────────────────────────────
│ [위치 안내]  조건부 — 오프라인 장소가 있을 때만
│ [문의]      사실상 필수
│ [푸터]      필수
└───────────────────────────────────────────
```

### 골격에 걸린 공통 규칙 (여기 한 곳에만 적는다)

| 규칙 | 내용 |
|---|---|
| 🥇 **첫 섹션 = 히어로** | 어떤 칸이든 **임팩트 있는 히어로로 연다.** 작은 소개·프로필 카드로 시작 ❌. 인물형(2번 대분류)은 **프로필을 히어로 자리로 끌어올려** 겸한다 |
| 🧢 **헤더** | 3안 중 **1안 이상 포함 · 3안 전부 ❌**(유무가 차별화 레버) · 페이지와 반드시 구분(면 또는 하단선) · 로고 헤더를 넣은 안은 **히어로에서 로고 반복 ❌** |
| 📮 **문의** | **3안 모두 다른 프리셋** — 버튼만 있어 복붙되기 제일 쉬운 섹션. 채움/틴트/Outlined · 세로/가로 2단을 안마다 다르게 |
| 🖼 **이미지 위 텍스트 ❌** | 레시피의 `[히어로: 화보 + 제목]`은 **이미지 위에 글을 얹으라는 뜻이 아니다.** 이미지 카드 + 별도 텍스트 카드 스택으로 |
| 🧱 **평탄화** | CdBd는 평면 카드 스택 — 섹션은 개념이지 컨테이너가 아니다. 여러 카드를 한 래퍼로 묶지 말 것 |
| 📏 **섹션 간 여백** | 각 섹션 **마지막 카드의 하단 여백 = 36** |
| 🏷 **섹션 타이틀** | 화면에 보이는 제목은 **고객 친화 국문**. 내부용어·업계용어 ❌ |

> 나머지 조립·통일·위계 규칙 = [[1-8. 섹션 프리셋 라이브러리]] 「🧷 페이지 조립 규칙」 (통일 8항목 · 타이틀 팔레트 8종 · 차별화 레버).

## 2. 배치 패턴 6개 — 본체 순서 규칙

**P1~P3는 [[1-10. 초대장 사례 사전 (초안)]]의 말투 3갈래와 정확히 대응**한다. P4~P6은 그 밖(진열·전환·인물).

### P1 알림형 — 읽고 끝
> 말투 📢 **알림** "알아두세요"
```
히어로 → [★본문] → 부가 안내 → 문의(짧게)
```
- **가장 짧다** (5~7섹션) · **위치 ❌ · 폼 ❌**
- 긴급 상황이면 **로고·이미지·SNS를 전부 생략해도 성립**해야 한다
- ▸ **멀티 2P** — P1 요약 + [자세히 보기] / P2 전문·부가

### P2 안내형 — 오게 함
> 말투 🎉 **초대** "와주세요" (부고만 📢 알림 톤)
```
히어로 → 도입(인사말·소개) → [★때·장소·프로그램] → 보조 → 위치 안내 → 문의
```
- **위치 안내 필수** (「가야 할 곳」이 이 패턴의 정의)
- ▸ **멀티 3P** — P1 표지·초대 / P2 프로그램·정보 / P3 회신·위치

### P3 접수형 — 받는 게 목적
> 말투 📝 **접수** "알려주세요"
```
히어로 → 도입(짧게) → 보조(왜 신청하나 = 혜택·분야·조건) → [★폼/예약] → 안내 사항(유의·마감) → 문의
```
- ⚠️ **폼이 화면 절반 안에** 들어와야 한다 — 설명이 길어져 폼이 바닥으로 밀리면 실패
- **문의는 폼과 별도로** 둔다(폼 거치지 않는 즉시 연결 = 전화·카톡)
- ▸ **멀티 3P** — P1 표지 / P2 안내·조건 / P3 폼

### P4 진열형 — 여러 개 보여줌
```
히어로 → 스토리(브랜드·컨셉) → [★아이템 반복] → 보조 → 문의
```
- **아이템 반복이 본체의 8할** · 아이템 1개 = 독립 섹션 단위
- 브랜드형이면 **히어로 직후 스토리**를 먼저 세운다(왜 이 컬렉션인가)
- ▸ **멀티 3~4P** — P1 표지+목차 / P2 반복 내지(대표 1P만 표기·실제론 복제) / P3 마무리

### P5 전환형 — 사게 함
```
히어로 → [★CTA·구매 1차] → 근거(핵심정보·프로모션·리뷰) → 상세 → 안내 사항 → [★CTA 재노출]
```
- 🔑 **CTA가 최상단 + 최하단 두 번** — P4와의 유일한 결정적 차이
- 스토리는 **뒤로** (전환 최우선이라 P4와 반대)
- ▸ **멀티 2~3P** — P1 판매(히어로·구매·가격) / P2 상세·근거 → 하단 CTA

### P6 인물형 — 사람이 주인공
```
[프로필 = 히어로 겸] → 소개 → [★실적·작업물·링크] → 보조 → 문의(연락처 저장)
```
- **프로필이 최상단** — 갤러리·이력·연락처를 프로필보다 위에 ❌
- ▸ **멀티 2P** — P1 프로필+주요 채널 / P2 더 보기

## 3. 옵션 블록 사전 — 어느 칸에나 붙는다

**유형을 가르지 않는 블록.** 결정 블록과 헷갈리지 말 것.

`지도 · 갤러리 · 계좌 · 문의·SNS · 유의사항 · FAQ · 첨부 문서 · 개인화`

> 🔑 **개인화(수신자마다 다른 링크)는 유형이 아니라 「전달 방식」** — 27칸 어디에나 얹힌다. 구버전이 이걸 독립 세부(A③)로 뒀던 게 분류 오류였다.
> 🔑 **계좌도 유형이 아니다** — 경조사·부고·모집·후원에 두루 붙는다.

### 🔀 조건부 규칙 — 상황이 골격을 바꾸는 경우

실사례 20건([[../3. 신규 템플릿 기획/3-4. 모바일 페이지 제작 사례 20건]])에서 나온 것.

| 조건 | 골격이 이렇게 바뀐다 |
|---|---|
| **온라인 전용** (장소 없음) | `[위치 안내]` ❌ → `[안내 사항] 접속 방법 · 다시보기` |
| **서비스 장소 = 고객의 집** | `[위치 안내]` ❌ → `[안내 사항] 방문 가능 지역` |
| **반복 회기** (하루가 아님) | `[핵심정보]` 대신 `[나열] 회차표`(요일·기간) |
| **다국어** | 언어별 섹션 반복 또는 **멀티페이지를 언어로 분할** · 글보다 그림·번호·색 |
| **내부 문서** (직원·점주용) | 마케팅 톤 ❌ · 프로모션·SNS 섹션 제거 · 페이지 비밀번호 |
| **상시 갱신형** | 「지금 상태」 한 줄이 **히어로** · 편집 지점이 눈에 띄게 |
| **재고·정원이 소진됨** | `[핵심정보]`에 잔여·마감 표시 · 마감 후 문구 대비 |
| **법정 표기 의무** (식품·가맹) | `[안내 사항]`을 **필수**로 승격 · 과장 표현 금지 |

## 4. 칸별 레시피 카드 27

> 표기 = 섹션 **목적**(괄호 = 담을 내용). `★` = 결정 블록. **골격(헤더·히어로·문의·푸터)은 §1 참조** — 카드에는 그 칸에서 특별한 경우만 적는다.

---

### 1. 행사·안내 (6)

#### 1-① 경조사 초대장
**P2 안내형** · 🎉 초대 · ★ **주인공 인물** (이름·사진 — 1인 또는 쌍)
```
[헤더] ❌ 보통 안 씀
[히어로] 대표 이미지 + 「초대합니다」
[소개] 인사말·모시는 글
[★소개] 주인공 (신랑신부 / 아기·부모 / 주인공 어르신)
[핵심정보] 일시 · 장소
[자료] 갤러리 (선택)
[폼] 참석 회신 (선택)
[안내 사항] 마음 전하실 곳(계좌) (선택)
[위치 안내] 필수
[문의] 연락처
```
> 🔑 **개인화 초대장은 별도 칸이 아니다** — 이 카드에 「수신자 이름 삽입」이 얹힌 것(§3).
> 👵 **수신자가 어르신인 경우가 많다** — 한 장에 정보가 다 들어오고 글씨가 큼직하게. 링크 이동 최소화.

#### 1-② 행사 초대장
**P2 안내형** · 🎉 초대 · ★ **식순** (시간 + 순서 나열)
```
[헤더] 로고 (주최 기관)
[히어로] 행사명 + 일시
[소개] 주최자 인사말
[핵심정보] 일시 · 장소
[★나열] 식순 (시간 + 순서)
[나열] 내빈 · 연혁 (선택)
[폼] 참석 회신 (선택)
[안내 사항] 좌석 · 주차 · 복장
[위치 안내] · [문의]
```
> 📊 **CdBd 실사용 1위 유형** — 기업·기관 기념행사 초청장. 우선순위 높음.

#### 1-③ 세미나·강연 안내
**P2 안내형** · 🎉 초대 · ★ **연사 × N + 세션 목록**
```
[헤더] 로고
[히어로] 행사명 + 부제 + 일시
[소개] 이 행사는 무엇인가
[핵심정보] 일시 · 장소(또는 온라인)
[★소개] 연사 × N (사진 · 이름 · 소속)
[★나열] 세션 · 시간표
[안내 사항] 준비물 · 참가비 · 접속 방법
[폼/예약] 신청
[위치 안내] 조건부 (§3 온라인 전용)
[문의]
```
> 💰 **경쟁 우위 지점** — 연사·타임테이블·참여기업 섹션은 이벤터스에서 **월 30만원대 상위 요금제 기능**이다. CdBd는 기본 제공 가능.

#### 1-④ 개업·오픈 안내
**P2 안내형** · 🎉 초대 · ★ **기간 + 볼거리·혜택**
```
[헤더] 로고
[히어로] 오픈 알림 + 공간 사진
[소개] 어떤 곳인가
[★핵심정보] 기간 (시작~종료) · 운영시간
[★나열] 볼거리 · 참여 점포 · 프로그램
[프로모션] 오픈 혜택 · 이벤트 (선택)
[자료] 공간 · 상품 사진 (선택)
[위치 안내] 필수
[문의]
```
> 하루가 아니라 **기간**이 주인공. 반복 회기(주 2회 × 6주)면 `[나열]`에 회차표(§3).

#### 1-⑤ 예약
**P3 접수형** · 📝 접수 · ★ **회차 예약 버튼** (시간 · 정원)
```
[헤더] 로고
[히어로] 무엇을 예약하나
[소개] 짧게
[핵심정보] 가격 · 소요시간 · 대상
[★예약] 회차 버튼
[안내 사항] 취소 · 환불 · 준비물
[자료] 사진 (선택)
[위치 안내] 조건부 (§3 고객 집 방문)
[문의]
```
> 🎟 **버튼 1개 = 예약 세션 1개.** 회차가 여러 개면 세션마다 카드를 따로 놓는다. 시안에서 달력·시간표 UI를 그리지 말 것 — 뷰어에선 일반 버튼과 같아 보인다.
> 시간 슬롯 배분형(픽업 시간대별 정원)도 이 칸.

#### 1-⑥ 부고·추모
**P2 안내형** · 📢 **알림** · ★ **장례 정보** (빈소 · 발인 · 장지)
```
[헤더] ❌
[히어로] 「부고」 + 고인 성함    (사진 ❌ · 무채색)

[★소개] 고인 · 상주 · 유족 관계

#### 2-① 프로필 (링크 모음)

[헤더] ❌

> 🔑 채널 버튼 = **버튼 카드 세로 반복**(SNS 카드는 푸터 아이콘 묶음 전용).

#### 2-② 영업용 명함
**P6 인물형** · ★ **사람 + 하는 일 + 연락 수단**

[나열] 취급 분야 · 서비스
[자료] 대표 실적 · 납품처 (선택)
[스토리] 회사 비전 (선택)
[폼] 상담 신청 (선택)
[★문의] 연락처 저장(주 CTA) + 전화 · 유선 · 이메일
[위치 안내] (선택)

> 🎖 **연락처 저장(vCard) = 주 CTA** — 전화·이메일과 같은 무게로 두지 말 것(위계 = 채움 > 틴트 > Outlined).
> 🏷 **섹션 타이틀 무조건 국문 2단어** — 영문 아이브로(CONTACT·SERVICE·CAREER) ❌ → `대표 실적`·`업무 분야`·`상담 신청`.
> 🔤 **명조(serif) 금지 → 산세리프** (신뢰·격식이 핵심).
> ⚠️ 신뢰 근거가 자격증이 아니라 **취급 브랜드 + 납품처**인 경우가 많다(B2B).

#### 2-③ 포트폴리오
**P6 인물형 + P4 진열형** · ★ **작업물** (이미지 중심)

[★자료] 작업물 갤러리 (반복)
[나열] 경력 요약 (짧게)
[문의] 협업·의뢰 문의
[푸터] SNS
```
> 🎨 **변형 3종**(칸을 나누지 않고 프리셋으로) — **이미지형** / **프로젝트형**(프로젝트당 1P · 멀티 4P) / **영상형**(유튜브 카드 나열 — 갤러리 카드와 다름).
> ⚠️ **경력을 길게 쓰면 2-④로 가야 한다** — 여기선 짧게.

### 4. 상품·홍보 (6)

> 🛍 **브랜드형 공통** — 순서는 **히어로 → 브랜드 스토리 → 제품**. 제품·가격을 바로 나열하기 전에 *브랜드가 누구이고 왜 이 컬렉션인지*를 먼저 짧게 세운다. *(전환 최우선인 4-④는 예외 — 구매가 위, 스토리는 뒤.)*

#### 4-① 상품 상세
**P4 진열형** · ★ **제품별 상세 블록 반복**
```
[헤더] 로고
[히어로] 브랜드 첫인상 + 컬렉션 제목
[스토리] 브랜드 설명
[★제품 블록 반복] ─ 갤러리(여러 컷) → 이름·가격 → 설명 → 스펙/소재 → 실측 → 구매
[프로모션] 쿠폰 · 할인 (선택)
[안내 사항] 배송 · 교환 · 환불
[위치 안내] · [문의]
```
> 🛍 **"상세 정보가 있어야 상세 페이지"** — 제품마다 ①**여러 컷**(모델·정면·측면·내부·디테일) ②**스펙 상세** 필수. **2단 그리드 상품 카드로 압축 ❌** → 제품별 **전폭 단일 컬럼**.
> 🔁 **상세(스펙·실측·소재)는 「각 제품 바로 아래」** — 페이지 뒤에 모으지 말 것(어느 제품 건지 끊긴다).
> 🚫 **상세를 품은 제품 프리셋을 쓰면 별도 상세 섹션 ❌**(중복).
> 🎠 **갤러리 표현 = 3안 차별화 레버** — 세로 나열 2 + 캐러셀 1. ⚠️ **제품당 이미지 4장 이상일 때만 캐러셀.**
> 💲 **텍스트 위계** — 상품명 18 Bold {텍스트색} / **가격 {버튼색} 강조** / 설명 {텍스트색}×70% / 스펙 라벨 100%·값 70%.

#### 4-② 룩북·컬렉션
**P4 진열형** · ★ **룩(look)별 화보 섹션 반복**
```
[헤더] 로고
[히어로] 대형 화보 + 컬렉션 제목
[스토리] 컬렉션 컨셉
[★룩 섹션 반복] ─ 타이틀 「LOOK N」 → 화보·누끼 이미지 → 룩 설명 1줄
[구매] 구매 링크 (선택)
[문의]
```
> 👗 **룩 하나 = 독립 섹션 · 타이틀 = `LOOK 1`·`LOOK 2`…**(영문 넘버형). 한 덩어리로 뭉치지 말 것.
> 🚫 **룩북엔 상세 정보(소재·치수·실측·스펙) ❌** — 그건 4-① 전용. 룩북은 **화보 + 컬렉션 설명**만.
> 🎠 갤러리 = 3안 중 1안 이상 캐러셀 (룩당 이미지 4장 이상일 때만).

#### 4-③ 카탈로그 🆕
**P4 진열형** · ★ **여러 품목 목록** (얕게 · 많이)
```
[헤더] 로고
[히어로] 브랜드 / 카탈로그 제목
[스토리] 브랜드 소개 (짧게)
[나열] 분류 · 인덱스 (품목이 많으면)
[★구매] 품목 카드 반복 — 이름 + 대표컷 + 핵심 스펙 1~2줄
[안내 사항] 주문 · 배송 방법
[문의]
```
> 🔑 **4-①과의 갈림 = 「깊고 적게 / 얕고 많이」.** 여기선 **상세 스펙·실측 ❌**(품목당 1~2줄). 박람회 품목집 · B2B 취급 품목 · 부동산 매물 목록.
> 📊 **CdBd 실사용의 절반이 패션·리테일 시즌 카탈로그** — 4-①②③④ 중 물량이 가장 큰 구역.

#### 4-④ 판매·주문
**P5 전환형** · ★ **구매 CTA** (상단 + 하단 반복)
```
[헤더] 로고
[히어로] 상품 대표컷 + 한 줄 카피

> 🔑 **5-② 모집과의 갈림 = 「유료 판매 / 무료·선발」**(갈림 질문 ③). 강의가 여기 걸린다.
> 공동구매(옵션별 조합가 · 계좌 · 마감 시각)도 이 칸 — `[핵심정보]`에 계좌·배송일.

#### 4-⑤ 출시·사전예약 🆕

[히어로] 혜택 한 줄 (숫자 · %)
[★프로모션] 혜택 내용 · 쿠폰 코드

[구매/문의] CTA 재노출
```
> 🎨 **할인 강조색은 빨강이 아니라 그 무드의 액센트**({버튼색}).
> 프리셋 = 「할인 상품 리스트 + 쿠폰」(카테고리·상품명·할인율%·세일가 + 쿠폰 박스 + 안내 문구).

### 5. 신청·문의 (5) — 전부 P3

#### 5-① 신청·접수
**P3 접수형** · ★ **폼** (행사 정보는 짧게)
```
[헤더] 선택
[히어로] 무엇을 신청하나
[소개] 짧은 안내 (2~3줄)
[핵심정보] 일시 · 장소 (있으면 · 짧게)
[안내 사항] 응답 마감일 · 수집 항목 안내
[★폼] 신청 폼 (RSVP + 부가 항목: 동반자 · 식사 옵션 · 소속 · 사전 질문)
[안내 사항] 개인정보 · 유의사항
[문의]
```
> 🔑 **1-③ 세미나와의 갈림 = 「보여주기 먼저 / 받기 먼저」**(갈림 질문 ②). 연사·시간표가 주인공이면 1-③, 폼이 주인공이면 여기.
> 📋 **Q&A 카드 1장 = 제목 1개** — 여러 질문을 한 카드에 묶는다. **제출 버튼은 카드 하단 내장**(별도 버튼 카드 ❌). 제목은 **중앙정렬 + 국문**.

#### 5-② 모집
**P3 접수형** · ★ **모집 요강** (정원 · 마감 · 선발)
```
[헤더] 로고
[히어로] 무엇을 모집 + 마감
[소개·스토리] 왜 이걸 하나
[★핵심정보] 정원 · 모집 기간 · 대상
[★나열] 🔀 조건부 (아래)
[프로모션] 혜택 · 처우 · 얼리버드
[자료] 후기 · 사례 (선택)
[★폼/예약] 지원 신청
[안내 사항] 결과 발표 · 환불 · 유의
[위치 안내] (선택) · [문의]
```
> 🔀 **조건부 필드 — 칸을 나누지 않는다**(§15 층위 규칙 ②). 섹션은 같고 `[나열]`의 항목만 바뀐다:
> | 무엇을 뽑나 | `[나열]` 내용 |
> |---|---|
> | **채용** | 직무 설명 · 자격 요건 · 전형 절차·일정 |
> | **수강생** | 커리큘럼 · 타임테이블 · 강사 |
> | **가맹·대리점** | 초기 비용 · 수익 구조 · 기존 점포 실적 · 본사 지원 |
> | **멤버·서포터즈·체험단** | 활동 내용 · 기간 · 선발 기준 |
> 🔑 **4-④ 판매와의 갈림 = 「무료·선발 / 유료 판매」** · **5-④ 상담과의 갈림 = 「정원·선발이 있나」**(갈림 질문 ③④).
> ⚖️ **가맹 모집은 수천만 원 결정** — 정보량 최다 · **과장 표현이 법적 위험**(가맹사업법) → `[안내 사항]` 필수.

#### 5-④ 상담·문의 받기 🆕
**P3 접수형** · ★ **문의 폼**
```
[헤더] 로고
[히어로] 무엇을 상담받을 수 있나 + 한 줄
[소개] 우리가 누구인가 (짧게 — 신뢰 근거)
[나열] 상담 가능한 분야 3~5
[자료] 사례 · 후기 (선택)
[★폼] 문의 폼 (이름 · 연락처 · 문의 내용 · 예산)
[안내 사항] 회신 소요 시간 · 운영시간
[문의] 전화 · 카톡 (폼 거치지 않는 즉시 연결)
```
> 🔑 **2-② 명함과의 갈림 = 「사람이 앞 / 폼이 앞」**(갈림 질문 ②).
> 📊 **국내 수요가 큰데 구버전엔 칸이 없었다** — 웨이브온 템플릿 34개 중 **「상담·견적」이 7개(20%)**.
> 「자료 요청 · 뉴스레터 구독」도 이 칸(리드 수집).

#### 5-⑤ 공모전·대회 🆕
**P3 접수형** · ★ **부문 + 자격 + 시상**
```
[헤더] 로고
[히어로] 대회명 + 접수 마감
[소개] 취지
[★나열] 부문 · 종목
[★핵심정보] 참가 자격 · 접수 기간 · 참가비
[★나열] 시상 내역
[나열] 심사 일정 · 기준
[안내 사항] 규정 · 제출물 · 저작권
[★폼] 참가 신청
[문의]
```
> 결정 블록이 3개로 쪼개져 있으나 셋이 한 묶음(**요강**)이다.
> 첨부 문서(참가 신청서·동의서)가 붙는 경우가 많다.

#### 5-⑥ 후원·기부 🆕
**P3 접수형** (전환 성격) · ★ **취지 + 사용처 + 후원 방법**
```
[헤더] 로고
[히어로] 무엇을 위한 후원인가
[★스토리] 취지 — 사람 이야기
[★핵심정보] 어디에 쓰이나 (항목별 숫자)
[자료] 활동 사진 (선택 · ⚠️ 초상권)
[★안내 사항] 후원 방법 · 계좌
[폼] 정기 후원 신청 (선택)
[문의]
```
> 🔀 **변주 — 연간 사용 보고**(이미 후원 중인 사람 대상): `[스토리] 올해 이야기 → [★핵심정보] 항목별 사용 내역 → [자료] 성과 → [핵심정보] 내년 계획 → [문의] 유지·증액`.
> ⚠️ **남의 돈 사용 보고서** — 숫자와 사람 이야기가 동시에 필요. 아동·수혜자 사진은 초상권 제약.

### 6. 소식·자료 (4)

#### 6-① 공지·알림
**P1 알림형** · 📢 알림 · ★ **본문 글**
```
[헤더] 발행처 (선택)
[히어로] 공지 제목 + 발행일
[★스토리] 공지 본문
[핵심정보] 적용 시작일 · 마감일 (있으면)
[안내 사항] 유의사항 (선택)
[문의] 담당자 연락
```
> 🔀 **변주 2종 (칸은 안 나눔)**
> | 변주 | 성격 | 수명 | 히어로에 오는 것 |
> |---|---|---|---|
> | **일회성 공지** | 한 번 알리고 끝 | 며칠 | 공지 제목 |
> | **상시 갱신형 현황** | 한 줄만 계속 바뀜 | 상시 | **「지금 상태」 한 줄** (대기일 · 잔여 재고 · 진행률) |
> ⏱ **긴급형은 30분 안에 만들어져야 한다** — 로고·이미지·SNS를 **전부 건너뛴 상태에서도 성립**해야 성공.
> 🔧 **상시 갱신형은 편집 지점이 눈에 띄어야** 한다(제작자가 현장에서 폰으로 한 줄만 고친다).
> 감사장 · 연하장 · 이전/폐업 안내도 이 칸(중간 톤 — 조사는 아니지만 초대도 아님).

#### 6-② 매거진·소식지
**P4 진열형** · ★ **글 나열** (제목 + 발췌 + 본문)
```
[헤더] 발행 정보 · 헤드라인
[히어로] 대표 이미지
[★나열] 소식컷 (제목 + 요약 + 이미지) 반복   또는   [★스토리] 기사 본문
[나열] 지난 호 · 연관 기사 (선택)
[문의] · [푸터] SNS
```

#### 6-③ 도록·작품집
**P4 진열형** · ★ **이미지 + 캡션 나열**
```
[헤더] 전시명
[히어로] 전시 대표 이미지
[핵심정보] 전시 기간 · 장소 · 관람 시간
[스토리] 기획 의도 · 작가 노트 (선택)
[★자료] 작품 이미지 + 캡션(제목·작가·재료·크기) 반복
[위치 안내] 전시장
[문의] 관람 문의
```
> 🔑 **작품 캡션 = 2단 카드 양끝정렬**(좌 항목명 / 우 값) 또는 이미지 아래 텍스트 카드 2줄(제목 런 + 정보 런).
> 🔑 **6-②와의 갈림 = 「글이 주인공 / 이미지가 주인공」**(갈림 질문 ⑤ — 2-③↔2-④와 같은 축).

#### 6-④ 가이드·이용안내
**P1 알림형(긴 버전)** · ★ **단계·항목별 안내 반복**
```
[헤더] 로고
[히어로] 가이드 제목
[핵심정보] 이용 시간 · 요금 · 대상
[★나열] 단계 · 항목별 안내 반복      ← 🔢 넘버링 필수
[자료] 시설 · 이용 사진 (선택)
[안내 사항] 주의사항 · 금지사항
[폼] 자주 묻는 질문 (Q&A)
[위치 안내] · [문의]
```
> 🔢 **넘버링 필수** — 가이드는 「순서·단계」가 핵심. 이용방법·준비물·커리큘럼 나열에 번호(01·02·03…). **3안 중 최소 1안은 넘버 대신 이모지**(차별화 · 예 준비물 🧴 / 단계 1️⃣).
> 🌏 **다국어 변주** — 언어별 섹션 반복 또는 멀티페이지를 언어로 분할 · 글보다 그림·번호·색(§3).
> 🔒 **내부 문서 변주**(직원·점주용) — 마케팅 톤 ❌ · 프로모션·SNS 제거 · 페이지 비밀번호.
