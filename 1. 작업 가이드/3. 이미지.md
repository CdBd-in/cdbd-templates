# 이미지

CdBd 템플릿 제작 시 예시 이미지(일러스트·아이콘·실사 사진)가 필요한 경우의 소싱·관리 가이드.

## 📦 소스 ①: Thiings (3D 일러스트)

**URL**: https://www.thiings.co/things

- 무료 3D 렌더 아이콘 라이브러리 (10,000+ AI 생성)
- 일관된 입체감·재질 표현 → 한 페이지 내 여러 개 써도 톤이 흐트러지지 않음
- 키워드 기반 검색 (`/things/{slug}` 구조)

### 선정 기준

| ✅ Do | ❌ Don't |
|---|---|
| 범용적이고 한눈에 알아보기 쉬운 아이콘 | 너무 구체적이거나 복잡한 아이콘 |
| 상징성 높은 보편적 모티프 | 특정 브랜드·인물·문화권에 종속된 모티프 |
| 1~2초 안에 의미 파악 가능 | 설명이 필요한 추상적 표현 |

**판단 기준**: "이 아이콘을 처음 본 사람도 의미를 즉시 이해할 수 있는가?"

## 📦 소스 ②: Google Labs Flow (실사 이미지)

**URL**: https://labs.google/fx/ko/tools/flow

- Google의 AI 영상·이미지 생성 도구 (Veo 모델 기반)
- 실사 사진풍 이미지 생성에 적합
- 프롬프트 기반 — 자연어로 장면·피사체·분위기 묘사

### 사용 컨텍스트

- ✅ **인물 사진** — 강사, 대표, 팀원, 후기 작성자 등
- ✅ **Special Gift / 사은품 섹션** — 굿즈, 패키지, 선물 박스
- ✅ **제품·소품 컷** — 사실적인 제품 사진이 필요할 때
- ❌ 상징적 메시지 전달 → Thiings 일러스트로

### 선정 기준 (절대 규칙)

| ✅ 반드시 | ❌ 절대 금지 |
|---|---|
| **사실적인 실사** — 다큐/스냅사진 톤 | 연출샷·광고샷 — 인위적 포즈·세팅 |
| 자연광·평범한 환경 | 스튜디오 라이팅·화려한 배경 |
| 깨끗한 구도 | **로고·텍스트·워터마크 (완전 배제)** |
| 피사체에 집중 | 과장된 카메라 각도·필터 |

> ⚠️ **로고/텍스트 금지**: AI는 텍스트 렌더링이 부정확 → 글자가 들어간 컷은 모두 폐기.
> 패키지·박스·티셔츠 등에 글자가 보이면 다른 컷으로 교체.

### 프롬프트 작성 원칙

**목표**: "연출되지 않은, 우연히 찍힌 듯한 자연스러운 실사"

| 요소 | 작성 방향 |
|---|---|
| **사진 종류** | `documentary photo`, `candid shot`, `everyday photo` (NOT `professional studio shot`) |
| **광원** | `natural daylight`, `window light`, `overcast soft light` (NOT `dramatic lighting`) |
| **앵글** | `eye-level`, `slight angle`, `casual framing` (NOT `dramatic low angle`) |
| **배경** | `plain background`, `simple home interior`, `blurred neutral background` |
| **무드** | `unposed`, `natural`, `realistic`, `not staged` |
| **비율** | `1:1 square aspect ratio` (별도 요청 없으면 디폴트) |
| **금지어** | `no text`, `no logo`, `no watermark`, `no captions`, `blank surfaces` |

**좋은 프롬프트 예시:**
```
A candid, documentary-style photo of a woman in her 30s smiling 
softly while looking off-camera. Natural window light from the side, 
eye-level angle, plain beige wall background. Unposed, realistic, 
no makeup styling. 1:1 square aspect ratio. 
No text, no logos, no watermarks anywhere.
```

```
An everyday photo of a small unbranded gift box on a wooden table, 
wrapped in plain kraft paper with a simple twine bow. Natural daylight, 
top-down casual angle, slightly soft focus. 1:1 square aspect ratio.
Blank surfaces only — no text, no logos, no labels, no captions.
```

**나쁜 프롬프트 예시 (피할 것):**
```
❌ Beautiful professional studio portrait with dramatic lighting
❌ Luxury gift box with elegant gold logo and ribbon
❌ Stylish model posing with branded packaging
```

### 📦 서브 가이드: 제품 실사컷 규칙

Special Gift, 제품 소개, 카탈로그 등 **제품이 주인공인 컷**에 적용. 인물 컷과는 다른 별도 규칙.

> **핵심 철학**: 무드 < 정보 전달. 사용자가 "이게 뭔지 / 몇 개인지 / 어떻게 생겼는지" 1초 안에 파악할 수 있어야 함.

#### 1️⃣ 앵글 & 자세

| 항목 | 규칙 | 이유 |
|------|------|------|
| **앵글** | `eye-level angle`, `slightly off-center composition` | 세워진 제품의 입체감·정면이 모두 드러남 |
| ❌ 회피 | `top-down`, `dramatic low angle` | 제품 식별 어려움, 만든 사람 자기과시 느낌 |
| **제품 자세** | `standing upright`, `NOT lying down` | 3D 존재감, 진열대 같은 신뢰감 |
| **박스류** | `tilted slightly toward camera so the inside is visible` | 내용물 노출 → 무엇이 들었는지 즉시 인지 |

#### 2️⃣ 프레이밍

```
✅ fully framed with comfortable margins on all sides
✅ both items entirely within frame
✅ 1:1 square aspect ratio
❌ 가까이 찍어서 가장자리 잘림
```

> ⚠️ 프롬프트에 **"fully framed", "comfortable margins", "entirely within frame"** 명시 — 안 쓰면 AI가 멋부리려고 클로즈업해서 자름

#### 3️⃣ 제품 식별성 (Distinguishability) — 가장 중요

여러 제품이 한 컷에 들어가면 **시각적으로 명확히 구분**되어야 함.

| 함정 | 해결 |
|------|------|
| 둘 다 같은 크라프트지 → 뭐가 뭔지 모름 | 한쪽에 **투명창 / 다른 색 / 다른 형태** 추가 |
| 박스 닫힌 채 → 안에 뭐 들었는지 모름 | **open box, tilted to show inside** |
| 여러 개 펼쳐놓음 → 산만 | **box/tray로 그룹화** |

**예시 — 원두 + 드립백 세트:**
```
LEFT: a coffee bean pouch with a transparent clear plastic front window 
      revealing the dark roasted whole coffee beans inside, kraft back panel
RIGHT: an open plain kraft paper gift box tilted slightly toward camera, 
       containing 5 individually wrapped drip coffee bags arranged neatly 
       side-by-side in a single row inside the box
```
→ 한 번에 "원두 / 드립백 / 5개"가 모두 인지됨.

#### 4️⃣ 광원 (Lighting)

| 톤 | 프롬프트 키워드 | 용도 |
|----|----------------|------|
| **화사·밝음** (CdBd 기본) | `bright, fresh, airy natural daylight from a large window, soft diffused light` | Special Gift, 신제품, 카탈로그 |
| 따뜻·아늑 | `warm afternoon light, golden hour` | 무드 중심 (예: 라이프스타일 컷) |
| ❌ 회피 | `dramatic lighting, moody, dark shadows` | 제품 식별 약화 |

> **"natural daylight"만 쓰면 AI가 어둑한 톤으로 가는 경향** — `bright, fresh, airy` 형용사 3개 명시.

#### 5️⃣ 배경 (Background)

| 등급 | 프롬프트 키워드 | 용도 |
|------|----------------|------|
| **A. 최우선** | `minimal clean uncluttered background, softly blurred plain neutral wall` | 제품에 집중 |
| **B. 허용** | `pale light wood surface, neutral linen tabletop` | 약간의 텍스처 (페일 톤만) |
| **C. 회피** | `cafe atmosphere, plants, mugs, decorative props, patterned fabric` | 산만 |

**부정문 필수 명시:**
```
NO cafe props, NO plants, NO mugs, NO additional objects, 
NO patterned fabrics visible
```

#### 6️⃣ 표면 (Tabletop)

- ✅ `pale light wood`, `neutral linen`, `off-white surface`
- ❌ `dark walnut`, `glossy black`, `rustic weathered wood`
- 어두운 우드는 화사함을 죽임. 페일 톤이 CdBd 모바일 카드 위에 얹혔을 때 안정적.

#### 7️⃣ 제품 실사컷 마스터 프롬프트 템플릿

복제해서 변수만 바꿔 쓰는 베이스 프롬프트:

```
A clean product-focused documentary photo of {제품 카테고리 명사}
standing upright on a pale light wood surface or neutral linen tabletop, 
fully framed with comfortable margins on all sides.

LEFT ITEM: {제품 1의 형태·재질·색상·식별 포인트 (예: 투명창 / 라벨 없는 크라프트 / 알루미늄 캡)}
RIGHT ITEM: {제품 2의 형태·재질·색상·식별 포인트}

Both items standing upright, NOT lying down.
Bright, fresh, airy natural daylight from a large window, soft diffused light, 
eye-level angle, slightly off-center composition.

Minimal clean uncluttered background — softly blurred plain neutral wall, 
NO cafe props, NO plants, NO mugs, NO additional objects, NO patterned fabrics visible.

Realistic product photography, not staged. 
1:1 square aspect ratio with both items entirely within frame.
Absolutely no text, no logos, no labels, no printed letters, no watermarks, 
no barcode anywhere — all surfaces blank.
```

#### 8️⃣ 검수 체크리스트 (생성 후)

- [ ] 1:1 정사각형 + **잘림 없음** (가장자리 여백 충분)
- [ ] 각 제품 **세워져 있음** (누워있지 않음)
- [ ] 제품 간 **시각적 구분 가능** (같은 재질·형태 X)
- [ ] 내용물 / 개수 / 형태 **1초 안에 파악 가능**
- [ ] **화사한 톤** (어둑하지 않음)
- [ ] 배경 **깔끔** (소품 없음)
- [ ] 글자·로고·라벨·바코드 **0개**

### 🏷 서브 가이드: 온라인몰 썸네일컷 규칙

쇼핑몰 제품 썸네일·상세 페이지 메인 컷에 적용. **순수 흰 배경 + 제품만 분리(isolated)**된 스튜디오 컷.

> **핵심 철학**: 무드 X 컨텍스트 X. **제품 = 화면의 전부**.
> 상세 페이지에서 제품 라이브러리 그리드에 얹혔을 때 시각적 노이즈 0.

#### 🆚 '제품 실사컷' vs '온라인몰 썸네일컷' 비교

| 항목 | 📦 제품 실사컷 (lifestyle) | 🏷 온라인몰 썸네일컷 (e-commerce) |
|------|--------------------------|--------------------------------|
| **용도** | Special Gift, 후기, About 섹션 | 상품 그리드, 상세 페이지 메인 컷 |
| **배경** | 페일 우드·리넨 (살짝 텍스처) | **순수 흰색 seamless** (0 텍스처) |
| **표면** | 테이블 톱이 보임 | **표면 없음** — 제품이 흰색 위에 떠 있음 |
| **광원** | 화사한 자연광 (창문 느낌) | **균등한 스튜디오 디퓨즈 라이트** |
| **그림자** | 자연스러운 캐스트 그림자 | **subtle drop shadow** (제품 바로 아래만) |
| **컨텍스트** | 페일 월·블러 배경 약간 | **컨텍스트 0** — 제품만 |
| **앵글** | eye-level + 살짝 옆 | eye-level 정면 또는 살짝 위 3/4 |
| **무드** | 다큐멘터리·캔디드 | 카탈로그·중립 |

#### 1️⃣ 배경 (가장 큰 차이)

```
✅ pure white seamless background
✅ no surface, no table, no shadow context
✅ products isolated on white
✅ only a very subtle soft drop shadow directly underneath
```

> **"on a white background"만 쓰면 약함** — AI가 흰 천이나 흰 책상으로 해석하기도. 위 4줄을 모두 명시.

#### 2️⃣ 광원

```
✅ bright even diffused studio lighting from above and front
✅ no dramatic shadows, no colored tints
```

스튜디오 디퓨즈 = 부드러운 박스 라이트. 자연광 키워드 (window light, daylight)는 피함.

#### 3️⃣ 앵글

| 제품 타입 | 권장 앵글 |
|----------|----------|
| **평면적 (원두·식재료)** | top-down 또는 eye-level 정면 |
| **세워진 패키지 (봉투·박스)** | eye-level frontal |
| **잔·그릇류** | slightly elevated 3/4 angle (잔 모양 + 내용물 모두 보임) |
| **세트 상품** | slightly elevated 3/4 angle (구성품 모두 보임) |

#### 4️⃣ 동일 제품 라인업 (사이즈/메뉴별 모음컷)

여러 변형을 한 컷에 보여줄 때 (예: 용량별, 메뉴별):

```
✅ identical {제품} in {N} distinctly different {variant axis}
✅ arranged in a perfectly aligned single row from left to right
✅ evenly spaced
✅ perfectly aligned at the same height
✅ identical in shape  (variant 축만 다르고 나머지는 통일)
```

> **"identical" 강조 필수** — 안 쓰면 AI가 디자인을 각각 다르게 만들어 산만해짐.

**축 예시:**
- **사이즈 축**: `small 50g, medium 200g, large 500g`
- **메뉴 축**: `classic espresso / con panna / breve / macchiato` (각각 표면 디테일 명시)

#### 5️⃣ 시각적 변별점 강조 (메뉴/맛 컷)

같은 잔에 담긴 다른 음료가 한 컷에 있을 때, **표면 디테일**을 매우 구체적으로 지시:

```
CUP 1: classic single espresso — pure dark brown coffee with thin golden crema
CUP 2: con panna — espresso with generous swirl of pure white whipped cream on top
CUP 3: breve — espresso topped with creamy steamed half-and-half showing 
       visible light caramel and cream layered tones
CUP 4: espresso macchiato — espresso with small dollop of bright white milk foam in center
```

> 색상·층·토핑을 명시해야 AI가 진짜 그 음료처럼 그림. "espresso variations" 같은 두루뭉술은 X.

#### 6️⃣ 세트 상품 컷 (구성품 그룹)

잔+받침+스푼 같은 패키지 세트는:

```
✅ all components in a single composition
✅ cup placed centered on its matching saucer
✅ spoon resting elegantly on saucer beside the cup
✅ slightly elevated 3/4 angle to show all components together
```

빈 잔 (empty cup, no coffee inside) — 음료가 아닌 **세트 자체**가 상품임을 강조.

#### 7️⃣ 온라인몰 썸네일컷 마스터 프롬프트 템플릿

```
A clean e-commerce product thumbnail: {제품 상세 설명 — 형태·재질·색상·내용물·정렬}.

Pure white seamless background, no surface, no shadow context — {제품} isolated 
on white with only a very subtle soft drop shadow directly underneath.

Bright even diffused studio lighting from above and front, 
no dramatic shadows, no colored tints. 
{앵글 선택: eye-level frontal | slightly elevated 3/4 angle | top-down}, 
slightly off-center composition.

Comfortable white margins on all sides. 
Hyperrealistic product photography, not styled, not staged. 
1:1 square aspect ratio.

Absolutely no text, no logos, no labels, no printed letters, no watermarks, 
no barcodes, no menu cards, no fabric, no other props — 
clean isolated product shot.
```

#### 8️⃣ 검수 체크리스트 (생성 후)

- [ ] 배경이 **순수 흰색** (회색·베이지·우드 X)
- [ ] 제품 외 **다른 사물 0개** (소품·테이블·천 X)
- [ ] 그림자가 **subtle** — 제품 바로 아래에만 살짝
- [ ] 광원이 **균등** (드라마틱 명암 X)
- [ ] 여러 변형 컷의 경우 **identical 형태**, 변형 축만 차이
- [ ] 모든 제품 **완전 프레임 내**, 여백 충분
- [ ] 글자·로고·라벨·바코드 **0개**

#### 🆚 썸네일컷 vs 누끼컷

| 항목 | 🏷 온라인몰 썸네일컷 | ✂️ 누끼컷 |
|------|---------------------|-----------|
| **배경** | 순수 흰색 (불투명) | **alpha 투명** (배경 X) |
| **용도** | 상세 페이지 메인 컷 | **카드·그리드 셀에 박아 넣기** (배경색이 셀 컬러 따라감) |
| **파일 형식** | JPG 또는 PNG | **PNG (alpha 채널 필수)** |
| **생성 방법** | `/generate-flow-image` 1단계 | 1단계 + **사용자 가공 요청 1단계** |
| **alpha bbox 크롭** | 불필요 | **필수** (PIL `getbbox()` + `crop()`) |

#### 🔄 누끼 처리 워크플로우 (블록·blocking)

**⚠️ 누끼 가공 전 원본을 최종 셀(노트/페이지)에 박지 않는다.** 별도 위치(`~/Downloads/`)에 두고 사용자 가공 완료 신호 받은 뒤 진행.

```
1️⃣ 베이스 컷 생성
   /generate-flow-image 으로 흰 배경 썸네일컷 N장 생성
   → ~/Downloads/{keyword}-1.png ... -N.png

2️⃣ 베스트 컷 선정
   사용자와 함께 1장 결정 (예: bag-sizes-1.png)

3️⃣ 누끼 가공 요청 (사용자에게 정형 메시지로)
   ↓ 아래 「요청 메시지 템플릿」 참고

4️⃣ 대기 (BLOCKING)
   사용자가 ~/Downloads/{keyword}-cutout-raw.png 저장 후 완료 신호 보낼 때까지 후속 작업 대기

5️⃣ alpha bbox 크롭 (자동화)
   PIL 로 투명 여백 제거 → ~/Downloads/{keyword}-cutout.png (최종)

6️⃣ 검증 + 사용
   alpha 채널 있음 + 콘텐츠가 프레임 가장자리에 닿음 → 노트에 임베드/카드에 배치
```

#### 📝 사용자 요청 메시지 템플릿

누끼 가공이 필요할 때 아래 형식으로 요청:

```markdown
🎨 **누끼 가공 요청**

| 항목 | 값 |
|------|-----|
| **원본 파일** | `~/Downloads/{keyword}.png` |
| **목표 파일** | `~/Downloads/{keyword}-cutout-raw.png` |
| **처리 내용** | 1) 배경 제거 (alpha 채널 PNG로) <br> 2) 저장만 — alpha bbox 크롭은 제가 자동 처리합니다 |
| **추천 도구** | Figma (Remove background) / Photoshop / Photopea (무료) / remove.bg |

**참고 컨텍스트**: {왜 누끼가 필요한지 한 줄}

가공 완료되면 알려주세요. 후속 작업(alpha bbox 크롭 + 사용처 배치)은 자동으로 진행하겠습니다.
```

#### 🐍 alpha bbox 크롭 자동화 (가공 완료 후 실행)

사용자가 `{keyword}-cutout-raw.png`를 저장하고 완료를 알리면 아래 스크립트로 자동 정리:

```python
from PIL import Image
import os

raw = os.path.expanduser("~/Downloads/{keyword}-cutout-raw.png")
out = os.path.expanduser("~/Downloads/{keyword}-cutout.png")

img = Image.open(raw)
if img.mode != "RGBA":
    raise SystemExit(f"❌ alpha 채널 없음 (모드: {img.mode}). 배경 제거 미완료.")

bbox = img.getbbox()  # 투명이 아닌 영역의 최소 직사각형
if not bbox:
    raise SystemExit("❌ 전체 투명. 배경 제거가 잘못됨.")

cropped = img.crop(bbox)
cropped.save(out, "PNG", optimize=True)
print(f"✓ 크롭 완료: {cropped.size[0]}×{cropped.size[1]} → {out}")
```

> ⚠️ **anti-pattern**: 사용자가 보낸 `-cutout-raw.png`를 그대로 사용하면 alpha 여백이 남아 그리드 셀마다 시각 면적이 다르게 보임. **반드시 PIL 크롭 거친 `-cutout.png`만 사용**.

#### ✅ 가공 결과 검증 체크리스트

- [ ] PNG `RGBA` 모드 (alpha 채널 존재)
- [ ] alpha bbox 크롭 완료 (PIL 후처리) — 콘텐츠가 모서리에 닿음
- [ ] 머리카락·잔 손잡이 등 **가장자리 자연스러움** (반-누락 X)
- [ ] 그림자가 의도적으로 남았다면 자연스럽게 처리됨

## 💾 파일 관리 규칙 (공통)

두 소스 모두 동일하게 적용:

| 항목 | 규칙 |
|---|---|
| **저장 위치** | `~/Downloads/` (로컬 다운로드 폴더) |
| **볼트 내 저장** | ❌ 하지 않음 — 옵시디언 볼트를 가볍게 유지 |
| **파일명** | 심플한 영문 키워드 (예: `download.png`, `coffee.png`, `earth.png`) |
| **확장자** | `.png` 우선, 실사는 `.jpg`도 허용 |
| **비율 (기본값)** | **1:1 (정사각형)** — 별도 요청 없으면 무조건 1:1 |

> ⚠️ 파일명은 **검색·생성 시 사용한 핵심 키워드**로. 길거나 복잡한 이름 금지.
> ⚠️ **1:1 비율 디폴트**: 모바일 카드 레이아웃에 최적. 16:9·세로형 등은 사용자가 명시 요청 시에만.

## 🔍 워크플로우

### 공통 단계
1. **컨텍스트 분석** → 표현하려는 의미를 영문 키워드 1~2개로 압축
2. **타입 결정** → 일러스트(Thiings)인지 실사(Flow)인지 판단
3. **다각도 후보 선정** → 같은 컨셉도 다른 상징·구도로 표현 가능한지 검토
4. **다운로드** → `~/Downloads/{keyword}.{확장자}`로 저장
5. **비교·결정** → 컨텍스트 적합도 비교 후 채택

### Thiings 전용
- `https://www.thiings.co/things/{slug}` 페이지에서 메인 이미지 확인
- `<meta property="og:image">` 태그가 메인 이미지 URL

### Flow 전용
- 프롬프트 작성 → 생성 → 마음에 드는 컷 다운로드
- 같은 프롬프트로 변주(variation) 여러 장 받아두기

### 후보 제안 시 원칙

같은 섹션이라도 **여러 의미적 각도**에서 후보 제시 — 사용자가 톤 결정 가능.

예) 환경단체 명함의 'Vision' 섹션 → 3가지 각도
- 보호 대상 = `earth` (환경 자체)
- 미래 지향 = `sprout` (성장·희망)
- 통찰 = `telescope` (비전의 직역)

## 🚀 자동화 스킬: `/generate-flow-image`

수동 30분 워크플로우를 **~60초**로 단축한 Playwright 기반 스킬.

### 사용법

```bash
python3 ~/.claude/skills/generate-flow-image/generate.py "PROMPT" [옵션]
```

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--keyword` / `-k` | (자동) | 파일명 키워드 |
| `--aspect` / `-a` | `1:1` | 비율 (1:1, 16:9, 4:3, 3:4, 9:16) |
| `--count` / `-c` | `4` | 변형 개수 (1~4) |
| `--headless` | ON | 백그라운드 실행 |
| `--interactive` | OFF | 첫 로그인 시에만 |

### 예시

```bash
# Special Gift 컷 4종
python3 ~/.claude/skills/generate-flow-image/generate.py \
  "candid documentary photo of unbranded kraft coffee pouch and 5 drip bags on wooden table, natural daylight" \
  -k coffee-gift -c 4

# 인물 1장
python3 ~/.claude/skills/generate-flow-image/generate.py \
  "candid eye-level portrait of a smiling Korean woman in her 30s, natural window light, unposed" \
  -k instructor -c 1
```

### 결과
- 저장: `~/Downloads/{keyword}.png` (count=1) 또는 `{keyword}-1.png` ~ `{keyword}-N.png`
- 해상도: 1024×1024 (Nano Banana 2 원본)
- 소요: 첫 실행 ~90초, 이후 세션 재사용 시 **~55초** (2장 기준)

### 첫 실행 (1회만)
세션 파일이 없으면 자동으로 로그인 단계 진입. 자격증명은 `~/.config/cdbd/credentials.json`에서 자동 로드.

```bash
python3 ~/.claude/skills/generate-flow-image/generate.py "test" --interactive -c 1
```

> 스킬 풀패스: `~/.claude/skills/generate-flow-image/SKILL.md`

### ⚠️ 운영 메모: Free-tier Throttling

`help@cdbd.in` 계정은 **무료 등급** (`PAYGATE_TIER_NOT_PAID`).
디스커버리 로그에서 확인됨. 무료 등급은 burst rate limit 있음.

**실측 (2026-06-18)**:
- 1~3번째 연속 세트 (~9컷): 각 60~80초 정상
- **4번째 연속 세트**: 199초 타임아웃 (1/3만 받아짐)
- 단독 재실행 (쿨다운 후): 94초 (3/3 정상)

**연속 생성 시 권장**:
- ✅ 4세트 이상 연속 → **세트 간 60초 이상 간격**
- ✅ `--retry` 플래그 사용 → 부분 결과 시 60초 쿨다운 후 자동 재시도
- ✅ `--timeout 300` 디폴트 (개선판) → throttle된 응답도 회수
- ❌ 한 번에 4세트 × 4컷 = 16컷 burst → throttle 거의 확실

## 🛠 기술 메모 (자동화용)

### Thiings 메인 이미지 추출

```bash
# slug에서 메인 이미지 URL 추출
slug="earth"
url=$(curl -sL "https://www.thiings.co/things/$slug" \
  -H "User-Agent: Mozilla/5.0" \
  | grep -oE '<meta property="og:image" content="[^"]*"' \
  | head -1 | sed 's/.*content="//;s/"$//')

# 다운로드
curl -sfL "$url" -o "$HOME/Downloads/${slug}.png"
```
