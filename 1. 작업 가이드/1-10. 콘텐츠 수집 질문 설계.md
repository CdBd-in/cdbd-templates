# 콘텐츠 수집 질문 설계

> **이 문서 = 유저가 3문항에 답한 직후, "무엇을 더 물어야 페이지를 채울 수 있는가"의 정본.**
> [[1-9. AI 유저 플로우 (제품 설계도)]] 1구간(질답)의 **후반부**에 해당. 앞의 3문항이 "어떤 페이지인가"를 정한다면, 이 질문들은 "그 페이지에 들어갈 내용"을 받는다.
>
> **한 줄 요약**: 공통 6 → 대분류 6 → 세부 2~3 → 고른 기능만큼. 평균 12~16문항 중 **필수는 7~9개**.

---

## 🎯 설계 원칙 3

1. **묻는 건 "내용"뿐, "디자인"은 안 묻는다** — [[1-9. AI 유저 플로우 (제품 설계도)]]의 핵심 불변식(정보=고정 / 색·폰트·배치=개방). 색·폰트·레이아웃 질문을 여기에 넣지 말 것.
2. **빈칸이면 AI가 채운다** — 🟢필수는 최소만. 🟡선택은 비워두면 예시 문구·기본값으로 채우고 유저는 **고치기만** 한다. (백지 공포 차단)
3. **자료를 올렸으면 대부분 이미 차 있다** — 자료 업로드(선택 옵션)를 거친 유저에게 이 화면은 **"확인·보정"** 화면이지 입력 화면이 아니다.

> 🧭 **질문 = 섹션 슬롯.** 모든 질문은 [[1-8. 섹션 프리셋 라이브러리]] 「콘텐츠 목적 13칸」 중 하나를 채운다. 어느 칸도 안 채우는 질문은 **삭제 대상**(= 안 물어도 되는 질문).

## 🏛 4층 구조

| 층 | 무엇 | 언제 물음 | 채우는 곳 |
|---|---|---|---|
| **① 공통** | 페이지 이름·첫 문장·로고·연락 | 항상 (16개 전부) | 헤더 · 히어로 · 푸터 · 문의 |
| **② 대분류별** | **핵심 정보** (일시·장소 / 이름·연락처 / 아이템 / 발행정보) | 대분류 4개 중 하나 | 핵심정보 · 소개 · 구매 · 나열 |
| **③ 세부별** | 그 세부의 **"← 핵심" 섹션** | 세부 16개 중 하나 | 레시피의 핵심 칸 |
| **④ 기능 애드온** | 예약·폼·구매·프로모션… | Q3에서 고른 것만 | 기능형 섹션 5칸 |

**중복 제거 규칙**: ②③④에서 같은 항목이 겹치면 **한 번만** 묻는다 (예: 메뉴판의 주소 = ④ 위치 안내의 주소).

## 1층. 공통 질문 (16개 카테고리 전부)

레시피 어디에나 있는 `헤더 / 히어로 / 푸터 / 문의` 를 채운다.

| # | 질문 | 채우는 섹션 | 필수 |
|---|---|---|---|
| **C1** | 페이지 이름을 뭐라고 부를까요? (브랜드·행사·본인 이름) | 헤더 · 페이지 제목 | 🟢 |
| **C2** | 첫 화면에 크게 넣을 한 문장은? | 히어로 헤드라인 | 🟢 |
| **C3** | 로고 이미지가 있나요? | 헤더 · 푸터 | 🟡 |
| **C4** | 첫 화면 대표 사진 | 히어로 | 🟡 |
| **C5** | 연락받을 방법 (전화 / 카톡 / 이메일 / 폼) — 복수 | 문의 · 푸터 | 🟢 |
| **C6** | SNS 주소 (인스타·유튜브 등) | 푸터 | 🟡 |

## 2층. 대분류별 공통 — **핵심 정보 수집부**

각 대분류 레시피에서 **모든 세부가 공유하는** 섹션만 뽑았다.

### A. 초대·예약 → `핵심정보` + `위치 안내`

| # | 질문 | 필수 |
|---|---|---|
| **A1** | **행사명** | 🟢 |
| **A2** | **일시** (날짜 + 시작 시각) | 🟢 |
| **A3** | **장소명 + 주소** (지도 검색으로 선택) | 🟢 |
| **A4** | 주최자·초대하는 사람 이름 | 🟢 |
| A5 | 초대 인사말 (본문) | 🟡 |
| A6 | 드레스코드·주차·동반자 등 안내사항 | 🟡 |

> ⚠️ **A3 주소는 반드시 검색 드롭다운에서 선택**해야 지도 버튼이 동작한다. 직접 타이핑만 하면 좌표(`lat`/`lng`)가 안 생겨 "지도 안 열림". → [[../CLAUDE.md]] 위치 안내 카드 ④

### B. 프로필·명함 → `소개(프로필)` + `나열(연락처)`

| # | 질문 | 필수 |
|---|---|---|
| **B1** | **이름** | 🟢 |
| **B2** | **직책·직함** | 🟢 |
| **B3** | **소속(회사·브랜드)명** | 🟢 |
| **B4** | **연락처** (전화 / 이메일) | 🟢 |
| B5 | 프로필 사진 | 🟡 |
| B6 | 한 줄 자기소개 | 🟡 |
| B7 | 회사 로고 | 🟡 |

> 프로필 카드는 텍스트 **2개만**(이름 + 소개글) 들어간다. 직책·소속은 소개글 한 줄로 합치거나 별도 텍스트 카드로 분리. → [[../CLAUDE.md]] 프로필 고정 스펙

### C. 룩북·카탈로그 → `구매` 또는 `자료` (반복 아이템)

| # | 질문 | 필수 |
|---|---|---|
| **C1** | **브랜드·매장명** | 🟢 |
| **C2** | **컬렉션·시즌·카테고리 이름** | 🟢 |
| **C3** | **아이템 목록** — 아이템당 `사진 / 이름 / 가격 / 한 줄 설명` (반복) | 🟢 |
| C4 | 아이템을 묶는 그룹이 있나요? (예: 음료·디저트 / 상의·하의) | 🟡 |
| C5 | 브랜드 스토리 | 🟡 |

> 🔑 **C3의 반복 개수 + C4의 그룹 수 = 원/멀티 분기의 실질 재료.** 그룹이 2개 이상이면 멀티페이지 **반복 내지**가 그룹 수만큼 복제된다. → [[1-8. 섹션 프리셋 라이브러리]] 조립 레시피

### D. 소식·매거진 → `헤더(발행정보)` + `나열` / `스토리`

| # | 질문 | 필수 |
|---|---|---|
| **D1** | **발행처 이름** | 🟢 |
| **D2** | **발행일 / 호수** | 🟢 |
| **D3** | **헤드라인** (대표 소식 제목) | 🟢 |
| **D4** | **글 목록** — 글당 `제목 / 요약 / 사진 / 본문` (반복) | 🟢 |
| D5 | 대표 이미지 | 🟡 |

## 3층. 세부 16개별 추가 질문

각 세부의 **"← 핵심" 섹션**(→ [[1-8. 섹션 프리셋 라이브러리]] 조립 레시피)만 추가로 묻는다.

### A. 초대·예약

| 세부 카테고리 | 추가 질문 |
|---|---|
| **① 행사를 알리기 위한 초대장** | A7. 프로그램·순서가 있나요? (시각 + 내용 반복) |
| **② 사전 정보를 수집하기 위한 초대장** | A7. **참석 여부 외에 받을 항목** (동반자 인원 / 식사 옵션 / 소속 / 사전 질문…) — 복수<br>A8. 이름·연락처를 받나요? |
| **③ 개인 맞춤 메세지를 담은 초대장** | A7. **받는 사람 이름** (링크마다 다르게)<br>A8. 개인에게 전할 메시지 본문 |
| **④ 방문 일정을 예약받기 위한 페이지** | A7. **예약 가능 날짜·시간대**<br>A8. **회차당 정원**<br>A9. 예약 유의사항 (취소·환불) |

### B. 프로필·명함

| 세부 카테고리 | 추가 질문 |
|---|---|
| **① 연락처·채널을 연결하기 위한 프로필 페이지** | B8. **연결할 채널 목록** (링크 + 버튼에 쓸 이름 반복) |
| **② 상담·문의를 이끌어내기 위한 영업용 명함** | B8. **상담 신청 시 받을 항목** (이름·연락처·문의 내용·예산…)<br>B9. 취급 서비스·제품 요약 |
| **③ 작업물·이력을 보여주기 위한 포트폴리오** | B8. **작업물 목록** — 작업당 `사진 / 제목 / 설명` (반복)<br>B9. 경력·이력 |
| **④ 매장·브랜드를 소개하기 위한 홈페이지** | B8. **영업시간**<br>B9. **매장 주소** (지도)<br>B10. 매장·제품 사진 |

### C. 룩북·카탈로그

| 세부 카테고리 | 추가 질문 |
|---|---|
| **① 상품을 자세히 소개하기 위한 상세 페이지** | C6. **상품 상세 스펙** (소재·사이즈·구성 등 `항목명 + 값` 반복)<br>C7. 배송·교환·환불 안내 |
| **② 컬렉션을 화보처럼 보여주기 위한 룩북** | C6. **룩 사진** (룩당 여러 장, 그룹 반복)<br>C7. 컬렉션 컨셉 설명 |
| **③ 상품을 바로 구매하게 하기 위한 판매 페이지** | C6. **구매 링크** (상품별 URL)<br>C7. 할인·쿠폰이 있나요? |
| **④ 메뉴·품목을 한눈에 보여주기 위한 메뉴판** | C6. **메뉴 그룹별 항목** (이름 + 가격 반복)<br>C7. **매장 주소·영업시간** |

> C6(상세 스펙 · 메뉴 항목) = `2단 카드` 양끝정렬 행(좌 라벨 / 우 값). 행 1개 = 카드 1장. → [[../CLAUDE.md]] 양끝정렬 행

### D. 소식·매거진

| 세부 카테고리 | 추가 질문 |
|---|---|
| **① 새 소식을 빠르게 알리기 위한 공지 페이지** | D6. **공지 본문**<br>D7. 적용 시작일·마감일 |
| **② 여러 글·기사를 모아 보여주기 위한 매거진** | D6. 글 카테고리 (그룹 반복) |
| **③ 전시 작품을 기록·소개하는 도록** | D6. **작품 목록** — 작품당 `사진 / 제목 / 작가 / 재료·크기 / 설명`<br>D7. 전시명·기간·장소 |
| **④ 이용 안내를 위한 가이드북** | D6. **단계·항목별 안내** (제목 + 내용 반복)<br>D7. 자주 묻는 질문 |

## 4층. 기능 애드온 — Q3(필수 내용/기능) 답변에 따라 붙음

Q3에서 **고른 것만** 묻는다. [[1-8. 섹션 프리셋 라이브러리]]의 **기능형 섹션**(예약·폼·구매·위치안내·문의)이 채택되는 지점.

| Q3 선택 항목 | 붙는 질문 | 채우는 섹션 |
|---|---|---|
| 예약하기 | 날짜·시간대 / 정원 / 본인 인증 여부 | 예약 |
| 상담신청 폼 | 받을 항목 목록 (객관식 문항이면 보기까지) | 폼 |
| 문의 연락처 | 전화번호 / 이메일 / 카톡 링크 | 문의 |
| 상품 구매 링크 | 상품별 URL | 구매 |
| 쿠폰·프로모션 | 혜택 내용 / 기간 / 코드 | 프로모션 |
| 사진·영상 | 사진 파일 / 유튜브 주소 | 자료 |
| 타임테이블·커리큘럼 | 시각 + 내용 반복 | 나열 |
| 위치 안내 | 주소 (**검색 선택 필수**) | 위치 안내 |
| 고객 리뷰 | 리뷰 문구 + 작성자 | 자료 |
| 자주 묻는 질문 | 질문 + 답변 반복 | 폼(Q&A) |
| SNS·채널 링크 | 채널별 주소 | 푸터 |

> ⚠️ **예약 카드는 크레딧 소모** — 예약 완료 1건당 1크레딧(방문체크 옵션 ON이면 7크레딧). 잔액 0이면 카드 추가 자체가 막힌다. → [[../CLAUDE.md]] 예약 카드 제작 실무 함정
