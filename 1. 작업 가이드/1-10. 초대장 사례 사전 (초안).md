# 초대장 사례 사전 (초안)

> ⚠️ **확정 전 초안.** 새 플로우([Figma 236-4870](https://www.figma.com/board/dA9nFFGnHhwjNuQYNVGR2B/AI-%EC%9C%A0%EC%A0%80-%EC%9B%8C%ED%81%AC%ED%94%8C%EB%A1%9C%EC%9A%B0?node-id=236-4870))는 **카테고리를 유저에게 고르게 하지 않는다** — 자료 업로드 또는 한 줄 설명에서 AI가 유형을 **추론**하고 「이 내용에는 [○○]를 추천해요」로 확인만 받는다.
> → 그래서 필요한 건 **선택지 16칸**이 아니라 **AI가 이름을 정확히 붙일 수 있을 만큼 촘촘한 사례 사전**이다.

---

## 1. 왜 「16칸」이 아니라 「사전」인가

| | 옛 방식 | 새 플로우 |
|---|---|---|
| 유저가 하는 일 | 16칸 중 **고른다** | 자료를 올리거나 **한 줄 설명한다** |
| 카테고리의 역할 | **선택지** (닫혀 있어야 함) | **AI의 어휘** (넓을수록 좋음) |
| 없는 유형이면 | 「직접 입력」으로 흘러 품질 하락 | 사전에 있으면 **정확히 이름 붙임** |
| 좋은 개수 | 적을수록 좋음 (고르기 쉬움) | **많을수록 좋음** (맞힐 확률↑) |

> 🔑 **선택지는 닫혀야 하고, 사전은 열려야 한다.** 같은 목록을 두 용도로 쓰던 게 문제였다.

## 2. 분류 축 3개

초대장은 한 줄로 못 가른다. **축 3개**가 각각 다른 걸 결정한다.

| 축 | 무엇을 결정하나 | 값 |
|---|---|---|
| **A. 누가 부르나** (주최) | 톤·무드·서체 | 개인·가족 / 가게·브랜드 / 기업 / 기관·학교·공공 / 문화·예술 / 종교·커뮤니티 |
| **B. 왜 모이나** (성격) | 콘텐츠·문구 | 축하 / 개시·기념 / 배움 / 거래·영업 / 감상·체험 / 친목 / 의례·추모 |
| **C. 페이지가 해야 하는 일** (기능) | **카드 구성 = 페이지 구조** | 아래 7종 |

### 축 C — 기능 7종 (구조를 결정하는 진짜 축)

| # | 기능 | 하는 일 | CdBd 대응 | 지원 |
|---|---|---|---|---|
| C1 | **알림형** | 알리기만 하고 회신 안 받음 | 텍스트·이미지·위치 | ✅ |
| C2 | **회신형 (RSVP)** | 참석 여부만 받음 | Q&A 폼 | ✅ |
| C3 | **수집형** | 동반인·식사·차량 등 상세 수집 | Q&A 폼(다문항) | ✅ |
| C4 | **예약형** | 회차·시간을 골라 잡음 | 예약 카드 | ✅ |
| C5 | **증표형** | 입장 티켓·QR·좌석 | 예약 QR 방문체크 | ⚠️ 개발 중 |
| C6 | **개인화형** | 받는 사람마다 다른 링크 | 엑셀 → 링크 N개 | ✅ |

> 💡 **한 페이지가 여러 기능을 겹쳐 가진다.** 청첩장 = C1+C2+C7, 컨퍼런스 = C1+C3+C5.
> → 기능은 **택1이 아니라 체크박스**로 다뤄야 한다.

## 4. 지금 CdBd 질문 세트가 못 담는 것 (★ 유형 24개)

현재 A 대분류 질문(A1~A9)은 **「공식 행사」 한 종류**에 맞춰져 있다 — `행사명 · 일시 · 장소 · 주최자 · 로고 · 메인이미지 · 연락처 · 프로그램 · 행사 설명`.

| 빠진 정보 묶음 | 어떤 유형이 필요로 하나 | 제안 |
|---|---|---|
| **인물 쌍·가족 관계** (신랑신부·혼주 / 아기·부모 / 고인·상주) | 청첩장 · 돌잔치 · 부고 | 「주최자」를 **역할 + 이름 반복**으로 확장 |
| **마음 전하실 곳 (계좌)** | 청첩장 · 부고 · 잔치 · 후원 | 신규 필드 (은행·예금주·계좌) |
| **준비물·교통·비상연락처** | 워크숍 · 캠프 · 인센티브 투어 | 「안내사항 × N」 필드 |
| **연사·출연자 여러 명** | 컨퍼런스 · 세미나 · 공연 | 「인물 × N (사진·이름·소속·소개)」 |
| **좌석·티켓·QR** | 시상식 · 공연 · 박람회 | C5 기능 (예약 QR 개발 대기) |
| **접속 링크 (온라인 행사)** | 웨비나 · 온라인 설명회 | 「참여 방법」 필드 |
| **동의서·의안 등 문서** | 캠프 · 주주총회 · 공청회 | 파일 첨부 |
