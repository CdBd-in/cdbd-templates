# 카드 매칭 가이드 — 콘텐츠 의도 → 카드 타입

신규 템플릿 기획·구현 시 **"이 섹션엔 어떤 카드를 써야 하지?"** 를 결정하기 위한 가이드. 17개 기존 템플릿 554개 카드의 라벨(=사용자가 부여한 콘텐츠 목적)과 실제 카드 타입의 매핑을 역분석한 결과.

> ⚠️ **카드 라벨 ≠ 카드 타입**. 라벨은 자유텍스트, 타입은 15종 고정. 동일 라벨이 여러 타입에 걸칠 수 있고 (예: 라벨 "이미지" → 갤러리·이미지·프로필 카드 어디든), 동일 콘텐츠 의도라도 디자인 의도에 따라 선택지가 달라짐.

---

## 🎯 핵심 결정 원칙 (먼저 확인)

콘텐츠 의도를 카드에 매핑하기 전, 다음 3가지 질문으로 후보를 좁힌다.

1. **카드의 default 기능이 그 의도와 일치하는가?** (지도 → 위치 안내, 영상 → 유튜브, 예약 슬롯 → 예약, 폼 입력 → Q&A) — 일치하면 그 카드. 디자인으로 흉내내지 말 것.
2. **편집 단위가 얼마인가?** — 텍스트 한 줄이면 텍스트 1장, 사진 여러 장을 묶음으로 보여주려면 갤러리.
3. **사용자가 같은 패턴을 반복 복제할 가능성이 있는가?** — 있다면 텍스트 카드 한 줄 = 한 속성 원칙 (5대 원칙 #2).

## 🃏 카드 타입별 라벨 패턴 사전

각 카드 타입이 실제로 어떤 콘텐츠 목적에 쓰였는지 라벨 군집화.

### 텍스트 (278/554 = 50%) — 모든 템플릿
가장 범용. 콘텐츠 목적별 군집:

| 군집 | 대표 라벨 | 출현 템플릿 |
|---|---|---|
| **헤더/타이틀** | 행사명, 행사 제목, 초대장 제목, 메인 타이틀, 컬렉션 제목, 상단 슬로건, 회사명 | 모든 템플릿 |
| **본문/설명** | 기업 소개, 초대 내용, 행사 소개, 제품 설명, 브랜드 설명, 본문 | 모든 템플릿 |
| **연락처 필드 (1개 = 1카드)** | 이름, 직책, 휴대폰, 이메일, OFFICE, MOBILE, EMAIL, HOMEPAGE | 1, 5, 9, 12 명함류 |
| **일시·장소** | 행사 일시, 행사 시간, 장소, 운영 기간, 행사 시간 정보 | 3, 4, 6, 7, 14 |

## ⚙️ 신규 페이지 기획 시 카드 결정 체크리스트

1. **콘텐츠 인벤토리 작성** — 페이지에 들어갈 모든 정보·이미지를 항목별로 나열
2. **각 항목마다 위 룩업 표 적용** — 1순위 카드부터 시도
3. **5대 원칙 검증**:
   - 텍스트 한 줄에 여러 속성 묶이지 않았는지 (#2)
   - 보조 텍스트에 별도 hex 안 썼는지 (#3)
   - 편집 불가 장식 그래픽 안 넣었는지 (#5)
4. **카드 default 기능 우선** — 지도/영상/예약/폼은 디자인으로 흉내내지 말 것
5. **반복 패턴은 N장으로** — 혜택 3개·제품 5개는 카드 N장으로 복제 가능하게
6. **빈 카드는 spacer**: 구분선 두께 0, 텍스트 빈 콘텐츠로 간격 조정
7. **상품·코드 카드 활용 검토** — 카탈로그면 상품, 외부 임베드면 코드 고려
8. **다중 버튼 배치 = 2단 카드** — 가로 2~4개 버튼이 필요하면 메뉴 카드 ❌, 2단 카드(2-4단 분할)에 버튼 N개 삽입 ✅
