# 입력 단계 안내 문구 — 주제 25개

> **무엇** — 유저가 시안을 보며 내용을 채우는 화면의 **모든 문구**.
> **어디서 나왔나** — 단계 구성은 [[1-12. 조립 레시피]] §4 레시피 카드, 문구 규칙은 `.data/tips/_SPEC.md`(정본).
> **검수** — 272행 전수 자동 검사 통과(열 수 · 팁 20자 · 기대효과 마침표 · 주제 내 중복 · 금지표현).

## 화면 구조 — 문구가 놓이는 자리 4곳

```
┌ 왼쪽 입력 패널 ─────────┐   ┌ 오른쪽 미리보기 ──┐
│ ●●●○○○○○  3/8          │   │  ③ 팁 · 반응 ·    │
│ ① 제목                  │   │     마일스톤      │
│ ② 기대효과              │   │ ┌───────────────┐ │
│ [ 입력칸 ]              │   │ │   시안        │ │
└─────────────────────────┘   └─┴───────────────┴─┘
```

## 규칙 요약 (풀버전 = `.data/tips/_SPEC.md`)

**채움 열 — AI / 사실**
- **AI** = 문장을 지어서 미리 채워둠 (인사말·소개글·스토리·카피)
- **사실** = 자료에 있으면 뽑아 채우고 **없으면 비워둠. 지어내기 절대 ❌** (이름·일시·장소·가격·계좌·연락처·정원·마감일·스펙·경력·작품 정보·통계·후기·이미지)
- 왜 — 표현은 틀려도 고치면 그만이지만 **사실은 틀리면 사고**

**제목 — 런타임 상태가 정한다**
- 그 단계에 **한 칸이라도 비어 있으면** `{항목}을 추가하면 좋아요`
- **전부 채워져 있으면** `{항목}을 미리 채워뒀어요 / 수정할 곳이 없는지 확인해 주세요.`
- 표에는 **비어 있을 때 버전만** 적는다

**팁 10규칙(요약)** — 15자 안팎 · **그 칸에서만 성립** · 당연한 말 ❌ · **사실 정보에 내용 조언 ❌**(개수·분량 권유 금지) · 안심(`없어도 괜찮아요`)은 기본값 ❌ · `맞는지 봐주세요` ❌ · **마땅치 않으면 비워둘 것**

**기대효과** — **보는 사람(방문자)이 얻는 이득** · 25자 안팎 · 마침표 · 팁과 내용 겹침 ❌(기대효과=「왜 넣나」 / 팁=「넣을 때 알아둘 것」)

**반응** — 담백한 서술만(의인화·감상·이모지·과장 ❌) · **채움이 `AI`인 칸은 반응 없음(`—`)**

**공통 안내**(팁 아님 · 최초 1회) — `엔터로 줄을 나눌 수 있어요`

🚫 **「제목 위 문구」(eyebrow)는 편집 범위에서 제외** (2026-09-10) — AI가 넣고 유저는 건드리지 않는다. 단계·칸에 등장하지 않는다.

## 작성 메모 (검수용 · 화면에 안 보임)

### 채움 주체 판정
- **지어내면 사고인 칸은 전부 「사실」** — 모집 정원·기간·대상 · **자격 요건·처우**(5-② 5·6·7) · 참가 자격·접수 기간·**참가비**·시상 내역(5-⑤ 6·7) · **사용처 항목별 숫자·계좌·예금주**(5-⑥ 5·7) · 정기 후원 금액 구간(5-⑥ 8) · 회신 시간·운영시간(5-④ 8) · 모든 연락처·이미지
- **AI로 둔 칸은 「표현」만** — 취지·스토리·소개글·히어로 카피·폼 질문 문구. 숫자·기간·금액을 품은 칸은 AI로 두지 않았음
- **히어로 설명 칸의 채움은 주제마다 갈린다** — 5-⑤는 접수 마감(사실)이 문장의 본체라 「사실」, 5-②·5-④·5-⑥은 카피라 「AI」. 5-②는 원래 마감을 히어로 설명에 넣는 안이었으나 **AI가 날짜를 지어낼 위험**이 있어 마감은 「모집 정보」(사실) 단계로 옮기고 히어로 설명은 순수 카피로 바꿈

### 왼쪽 패널 제목 판정 (단계 단위)
- **「미리 채워뒀어요」는 단계 전체가 AI일 때만** — 5-④ 히어로(전 칸 AI)는 미리 채운 형, 5-②·5-⑤ 히어로는 사실 칸이 있어 「추가하면 좋아요」 형
- ⚠️ **확인 필요 1건** — `히어로 · 제목 위 문구` 행이 편집 범위에서 빠지면서 **5-⑥ 히어로가 전 칸 AI**가 됐다(사실이던 eyebrow가 빠짐). 규칙대로면 제목이 「히어로 문구를 미리 채워뒀어요 / 수정할 곳이 없는지 확인해 주세요.」로 바뀌어야 하나, **이번 지시가 「반응 열만 수정」**이라 기존 문구를 그대로 뒀다
- 기대효과는 전부 **방문자가 얻는 이득**으로만 씀 — 「관리가 편해요 · 나중에 수정하기 쉬워요」 류 제작자 편의 없음
- **팁과 겹치지 않게 각도를 갈랐음**(같은 단계에서 두 문장이 같은 말이 되던 6건 교정): 5-② 5 팁=지원 자격 판단 / 기대효과=마감 · 5-⑤ 5 팁=자기 부문 찾기 / 기대효과=분야가 여럿임 · 5-⑤ 7 팁=참가 결정 / 기대효과=상금 외 기회 · 5-④ 8 팁=회신 시간 / 기대효과=운영시간 · 5-⑥ 2 팁=후원처 확인 표시 / 기대효과=사칭 방지 · 5-⑥ 9 팁=영수증 문의 / 기대효과=직접 확인 경로

### 반응(방금 채움) 톤
- **AI 칸은 전부 `—`** — 유저가 채우는 행위가 없어 반응 없음. 4주제 반응 대상 = **사실 칸 30개**(AI 12칸은 빈칸)
- **담백 규칙으로 전면 재작성** — 의인화·화자 감상(`내 얘기구나 싶어져요`·`대회의 뜻이 전해졌어요`·`현장이 그대로 전해져요`)·감탄·이모지(`👀`)·과장 전부 제거
- 서술어는 6종(**채워졌어요 · 반영됐어요 · 표시됐어요 · 추가됐어요 · 정리됐어요 · 분명해졌어요**)과 **개수 변화**만 사용 · 12자 안팎 · 마침표 없음 · **한 주제 안에서 같은 서술어가 연달아 오지 않게** 배치(AI 빈칸을 건너뛴 실제 노출 순서로 확인)
- ℹ️ **정리됐어요는 지금 안 쓰임** — 이 서술어를 달았던 칸(소개 글·신청 항목·취지 글·문의 항목)이 전부 AI라 `—`가 됐다. 사실 칸만 남은 결과이며 나머지 5종으로 겹침 없이 배치됨
- 후원·기부는 감동·호소 없이 **반영 사실 위주**(계좌 정보가 채워졌어요 · 항목이 3개가 됐어요 · 정기 신청이 반영됐어요)

### 팁 검수 (자기 점검 1회 완료)
- **다른 칸에도 성립하나** — 전 팁을 같은 주제의 다른 칸에 대입해 봄. 걸린 것 1건: 5-② 히어로 제목/설명이 둘 다 `한 줄로 적어요` 꼴이라 설명을 `어떤 사람이면 좋을지 덧붙여요`로 교체
- **당연한 말** — 「적은 순서대로 보여요」·「전화하면 연결돼요」 류 없음. 기능 안내는 모르면 못 쓰는 것만(5-⑥ 6 초상권 동의 · 5-⑤ 9 첨부 안내)
- **후원·기부 톤** — 팁·기대효과·반응 **세 열 모두** 「더 모여요 · 후원이 늘어요 · 목표 달성」 계열 배제. 투명성(있는 그대로 · 예금주 · 동의 · 사칭 방지)과 확인 경로(사용처 확인 · 영수증 문의 · 선택권)만 다룸

- **주제 간 각도 분리** — 마감 관련 팁이 5-②·5-⑤에 모두 필요했으나 서로 다른 칸·다른 각도로 나눔(모집 정보의 `지원할 수 있는지 여기서 판단해요` ↔ 히어로 설명의 `마감일이 보이면 미루지 않아요`)
