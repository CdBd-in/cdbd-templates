# 템플릿 상세 페이지 콘텐츠

사용자가 `/templates/{slug}` 상세 페이지에서 보게 될 정보 = **카탈로그 메타데이터**. 사용자가 "템플릿 사용하기" 버튼을 누르기 전에 마주하는 첫 인상.

> 실제 페이지 제작(에디터 작업)은 [[1-4. 에디터 페이지]] 참조.

---

## 🧩 구성 요소

| 항목 | 내용 | 디자인 시스템 참조 |
|---|---|---|
| **카테고리** | 5종 중 1개 (프로필·명함 / 초대·예약 / 홍보·카탈로그 / 가이드·신청 / 소식·매거진) | 좌측 상단 보라색 라벨 (Subtitle 1SB,14 · Brand/Primary Primary) |
| **제목** | 템플릿 이름 (예: "프로모션 노출과 상담 신청으로 전환을 만드는 영업용 명함") | Heading 1B,24 |
| **썸네일** | 성과 카드 좌측 원형 프로필 이미지 135×135 | — |
| **사용 성과** | "사용 성과" 라벨 + 본문 (예: 실계약 전환율 40%↑) | Heading 3B,18 · Gray-600 |
| **본문 설명** | 템플릿 핵심 설명 (다줄) | Paragraph 1M,16 |
| **추천 대상 2가지** | 체크 아이콘 + 텍스트 × 2 (Info Pale 배경 박스) | Circle Check + Subtitle 1SB,14 |
| **주요 기능 2가지** | 각각: 아이콘 이미지(38×38) + 제목(H1B,24) + 설명(Paragraph 1M,16) + 메인 이미지(Desktop 360×300 / Mobile 272×227) | Gray-50 50% opacity 배경 카드 |

## ✍️ 작성 원칙

### 카테고리 선택
- 5종 카탈로그 중 1개. 템플릿의 **주요 사용처**에 따라 결정.
- 두 카테고리 사이에서 망설인다면 → 사용자가 검색 시 어떤 키워드로 들어올지 기준으로 판단.

### 제목 작성
- "**무엇을 위해, 무엇을 하는, 무엇이다**" 구조로 압축.
- 예: "프로모션 노출과 상담 신청으로 전환을 만드는 영업용 명함"
  - 무엇을 위해 = 프로모션 노출 + 상담 신청
  - 무엇을 하는 = 전환을 만드는
  - 무엇이다 = 영업용 명함

### 사용 성과
- **수치 포함** 권장 (예: 전환율 40%↑, 예약률 2배, 조회수 1.5만+).
- 추상적 표현 ❌ → "고객 만족도 상승" 대신 "재방문 의향 88%"

### 추천 대상 (2가지)
- 구체적인 페르소나로 작성. 직군/업종/상황 명시.
- 예: "오프라인 영업 빈도가 높은 보험설계사", "신규 고객 응대가 잦은 1인 살롱 원장님"

### 주요 기능 (2가지)
- 템플릿이 가진 **차별점**에 집중. "프로필이 있어요" 같은 당연한 기능 ❌
- 예: "QR 명함 저장으로 한 번 만나도 잊히지 않기", "프로모션 배너로 본업 상품 자연 노출하기"

## 🖼️ OG 이미지(썸네일) 규칙

> **출처**: `cdbd-design-service/룩북/2. 디자인 가이드/2-1. 공통.md` (「OG 이미지(썸네일) 디자인」) + `cdbd-design-service/룩북/1. 제작 프로세스/1-1. 공통.md` (「OG 이미지(썸네일) 규칙」)
>
> 콘텐츠 공유(카카오톡·SNS 등) 시 노출되는 썸네일. **4단계 CdBd 에디터 작업** 중 페이지 OG 이미지로 업로드.

### 규격

| 항목 | 값 |
|---|---|
| **사이즈** | **800 × 400px** (2:1 비율) |
| **해상도** | **1배수** — 일반 페이지(3배수)와 다른 예외 |
| **형식** | JPG |
| **파일명** | `og.jpg` (로고/룩 타입 공통) |

### 디자인 타입

**별도의 요청이 없는 한, 로고 타입을 기본값으로 사용.**

#### 1️⃣ 로고 타입 (기본값)
단색 배경 위에 브랜드 로고 배치.

**배경 색상 (3가지 옵션)**
- ✅ **페이지 테마 색상 적용** (페이지의 `{배경색}` 또는 `{버튼색}` 그대로) — 가장 추천
- ✅ **White** (`#FFFFFF`)
- ✅ **Black** (`#000000`)

**정렬**: 수직·수평 중앙

**로고 크기 (면적 기준)**:
- OG 프레임 전체 면적 = 800 × 400 = **320,000 px²**
- 로고는 **「배경·여백이 제거된 bounding box」 면적이 OG 프레임 면적의 약 9~10%** (≈ 28,800~32,000 px²)
- 🚨 **면적 기준이므로 로고 가로세로 비율(워드마크·정사각·세로 심볼)에 관계없이 시각 비중 일정 유지**
  - 너비%로 환산하면 가로로 긴 로고는 작아 보이고 세로로 긴 로고는 커 보여 비중 어긋남 → ❌
- **참조 예시**: `maje` (워드마크) — 268 × 113 = 30,284 px² → **9.46%**

#### 2️⃣ 룩(이미지) 타입
대표 화보·메인 이미지를 OG 영역에 배치.
- 별도 요청이 있는 경우에만 사용

---

### 🪪 샘플 로고 제작 규칙 (실제 브랜드 로고가 없을 때)

신규 템플릿은 가상의 브랜드명을 사용하므로 OG용 **샘플 로고를 직접 제작**.

**구성**: `[심볼(선택)] + [워드마크]`

#### 폰트
- 페이지 무드에 맞는 **CdBd 폰트** 사용 — [[1-2. 폰트 라이브러리]] 9개 무드 분류 활용
- 무드와 폰트 무드 일치시키기 (예: 럭셔리/엘레강스 페이지 → 럭셔리/엘레강스 무드 폰트)

#### 심볼 (선택 사항)
워드마크 앞쪽에 작은 심볼 추가 가능. 필수 아님.

**심볼 소스**: 무료 아이콘 라이브러리에서 키워드 검색 → 다운로드.
출처 가이드: `cdbd-design-system/디자인 시스템/5. 신규 기획 가이드/5-1. 아이콘 제작 가이드.md` 「외부 아이콘 라이브러리 검색 순서」

**검색 순서 (CdBd 디자인 톤 우선순위)**

| 순서 | 라이브러리 | URL |
|---|---|---|
| 1 | Griddy Icons | https://griddyicons.com/ |
| 2 | Lucide Icons | https://lucide.dev/icons/ |
| 3 | Bootstrap Icons | https://icons.getbootstrap.com/ |
| 4 | Tabler Icons | https://tabler.io/icons |

**프로세스**: 1순위(Griddy)부터 키워드 검색 → 적합한 아이콘 없으면 다음 순위로 → 다운로드 → 심볼로 사용.

가져오기 스펙(사이즈 지정 가능 시): **24px, stroke 2px**.

### D. 신규 등록 시 처리 규칙

**🗑️ 복제 시 삭제할 요소**
- **10회 사용 / ★4.9 배지** (235:10941) — 누적 사용량·평점 표시용. 신규 등록 시 데이터 없으므로 **삭제 상태로 복제**.

**📱 산출물 — 모바일 페이지 스크린샷 (필수)**
- 보드 우측 **패션룩북 프레임** (235:11001/11003/11005/11007) 영역에 들어가는 콘텐츠.
- **4단계에서 완성된 CdBd 라이브 페이지의 모바일 프리뷰 스크린샷**을 캡처해서 붙임.
- **멀티페이지인 경우 모든 페이지 스크린샷 필요**. 페이지마다 별도 프레임에 배치.
- 캡처 셀렉터: `.max-w-1\/2.transform.origin-top` (라이브 템플릿 페이지의 모바일 프리뷰)
