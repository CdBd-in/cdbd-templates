# 카드 default 기능 vs 디자인 선택

신규 템플릿을 제작·디자인할 때, **카드가 기본으로 제공하는 UI**는 디자인에서 다시 만들지 말 것. 사용자가 받는 가치는 "카드 그대로 갖다 쓰면 동작함"이다 (CLAUDE.md 「카드 default 기능 신뢰」 원칙).

> 이 문서는 구 `2-0. 디자인 특성 분석 절차`(기존 템플릿 분석 전용, 2026-06-24 삭제)에서 **신규 제작에 유효한 부분만** 추출·정리한 것.

---

## 🚫 카드 default 기능 — 디자인에서 다시 만들지 말 것

아래 항목들은 카드의 기본 기능이지 디자이너의 시각 선택이 아님. 시안·에디터에서 별도로 그리거나 강조 장치로 추가하지 말 것.

| 카드 종류 | default 기능 (재현 ❌) |
|---|---|
| **유튜브** | 영상 임베드, 플레이 버튼, 썸네일 |
| **위치 안내** | 지도 임베드, 핀 마커 |
| **Q&A** | 필수 별표, placeholder, 체크박스/라디오 모양 |
| **예약** | 예약 위젯 UI, 캘린더, 옵션 선택기 |
| **갤러리** | 기본 그리드 자체 (단, 그리드 vs 캐러셀 vs 나열 선택은 디자인) |
| **SNS** | SNS 아이콘 세트 |
| **메뉴** | 탭 네비 구조 |
| **프로필 카드** | 사진+이름+소개 기본 구조 (단, 원형/풀블리드 등 모양 선택은 디자인) |
| **멀티페이지** | 페이지 인디케이터 도트 |
| **CTA 버튼 반복 자체** | 비즈니스 페이지는 버튼이 여러 개 반복되는 게 당연. "반복" 자체는 디자인 통일성이 아님 |

## ✅ 실제 디자인 선택 — 여기서 결정

신규 템플릿에서 디자이너가 실제로 결정하는 것:

- **컬러 / 모서리 / 보더 / 그라데이션 처리**
- **풀블리드·박스·강조 색면으로 감싸기**
- **카드 후처리** (B&W, 빛바램 톤 등 사진 보정 통일 — 단, 사용자 교체 이미지 전제)
- **타이포 페어링** (영문 디스플레이 + 한글 부제 등)
- **갤러리 표현 방식** (그리드 vs 캐러셀 vs 나열)
- **프로필/이미지 모양** (원형 vs 풀블리드 등)

## ⛔ 편집 불가 장식(팬텀) 배제

CLAUDE.md 5대 원칙 #5 「편집 불가 장식 그래픽 배제」의 실무 기준. 다음 같은 **사용자가 바꿀 수 없는 장식**은 신규 제작에서 넣지 말 것:

- 점선·대시 디바이더, 골드 라인, 노치/스티커 모양
- 형광펜 하이라이트, 다이아몬드/도트 마커 등 순수 장식 요소
- 손그림 일러스트·장식 그래픽 (단, 로고/프로필처럼 **사용자 교체 가능 이미지는 OK**)

> 강조가 필요하면 → 장식 그래픽 ❌ → **헤드라인 포인트 컬러(`{버튼색}`) · 섹션 강조 배경(`{버튼색}×N%`) · 텍스트 위계**로 해결 (CLAUDE.md 포인트 컬러 규칙 참조).

## 📐 디자인 특성 섹션 작성 시 주의

신규 템플릿 노트에 `## 디자인 특성` 섹션을 쓸 때:

- **표준 포맷은 CLAUDE.md** 「✏️ 디자인 특성 섹션 표준 포맷」 참조 (중복 기재 ❌)
- **카드 default 기능은 "반복되는 디자인 요소"에 적지 말 것** (위 🚫 표)
- **존재하지 않는 요소(팬텀) 기재 ❌** — "골드", "형광펜", "노치", "점선", "흑백", "그라데이션", "마스코트" 같은 표현을 쓸 땐 실제 적용 여부 재확인
- **모서리는 3가지 옵션뿐** (각진/둥근/원형) — 픽셀값 적지 말 것
- **페이지 테마는 (배경/텍스트/버튼) 3-튜플** (이름 + hex)
