# 신규 템플릿 기획 워크플로우

> 사용자가 새 템플릿 기획을 요청하면 아래 6단계를 순서대로 진행. 각 단계마다 **사용자 피드백 게이트**가 있으며, 게이트 통과 후에만 다음 단계로 넘어감.
>
> ⚠️ **본 워크플로우는 실제 작업하며 변경될 수 있음** — 변경 시 본 노트와 [[../CLAUDE.md|CLAUDE.md]]의 "신규 템플릿 기획 워크플로우" 섹션을 동시 업데이트할 것.

---

## 🗺 단계 개요

| # | 단계 | 출력물 | 게이트 |
|---|---|---|---|
| 1 | 콘텐츠 기획 | 카테고리 · 주제 · 무드 · 색·폰트 결정 | 기획 피드백 |
| 2 | 피그마 스켈레톤 | 카드 구성 + 이미지 자리(주석) | 스켈레톤 피드백 |
| 3 | 피그마 이미지 채움 | 완성된 피그마 화면 | 피그마 완성본 피드백 |
| 4 | CdBd 에디터 구현 | 라이브 페이지 + OG + 제목 + 모바일 스크린샷 | CdBd 페이지 피드백 |
| 5 | 상세 페이지 콘텐츠 (피그마) | 카탈로그 상세 페이지 섹션 | 상세 페이지 피드백 |
| 6 | CdBd 어드민 등록 | 라이브 등록 완료 | — |

## 1단계 — 콘텐츠 기획

**목적**: 사용자가 요청한 카테고리·주제에 맞는 페이지 콘텐츠 구성을 결정.

### 입력
- 사용자 요청 (카테고리, 주제, 톤·앤·매너 등)

### 작업
- **카테고리 선정** (5종 중 1개)
  - 카테고리 미충족 분야 우선 고려:
    - 🚨 소식·매거진 (0개)
    - 가이드·신청 (1개)
- **무드 결정** → [[1-1. 색상 팔레트 라이브러리]] + [[1-2. 폰트 라이브러리]] 9개 무드 동일 → 무드 1개 결정 시 색·폰트 동시 선정
- **페이지 콘텐츠 기획** — 어떤 정보를 어떤 순서로 배치할지 초안 작성 (텍스트 위주, 카드 단위 분리)

### 출력
- 카테고리 · 주제 · 무드 · 페이지 콘텐츠 초안

### 게이트
- → **사용자 기획 피드백**

---

## 2단계 — 피그마 스켈레톤 제작

**목적**: 실제 CdBd 카드 속성만 사용해서 페이지 구조를 피그마에 빠르게 시각화. **이미지 없이** 카드 구성만 확인.

### 피그마 파일
- **등록 파일**: [Figma — CdBd 템플릿 등록 (node-id=1-746)](https://www.figma.com/design/oi8zIHLfy59O5zV8aysqq4/CdBd-%ED%85%9C%ED%94%8C%EB%A6%BF-%EB%93%B1%EB%A1%9D?node-id=1-746)

### 제약
- **CdBd에서 사용 가능한 15종 카드 속성 내**에서만 구성 — 가이드: [[4. 에디터 페이지 제작]]
- 5대 원칙 준수:
  1. 범용성 (카드 단위 복제 가능성 고려)
  2. 텍스트 카드 분리 (1 카드 = 1 텍스트 속성)
  3. 보조 텍스트는 투명도로
  4. 테마 default 색상 최대 활용
  5. 편집 불가 장식 그래픽 배제

### 이미지 처리
- **이미지 영역은 자리만 잡기** — 프레임만 배치
- **프레임 내부에 주석으로 표기** — "어떤 이미지를 사용할 것인지" 메모 (예: "메인: 부드러운 베이지 톤 정장 인물 사진, Google Flow 실사")

### 게이트
- → **사용자 스켈레톤 피드백**

---

## 3단계 — 피그마 이미지 채움

**목적**: 스켈레톤 피드백 반영 후 실제 이미지 추가하여 완성된 페이지 화면 제작.

### 이미지 소스
[[3. 이미지]] 규칙 준수:
- **Thiings 3D** (3D 오브젝트 — 펀/플레이풀 무드)
- **Google Flow (Nano Banana)** (실사 인물·제품 — 럭셔리/엘레강스, 페미닌, 프로페셔널 등)
- 9개 무드별 추천 이미지 소스 매핑 따르기

### 게이트
- → **사용자 피그마 완성본 피드백**

---

## 4단계 — CdBd 에디터 구현

**목적**: 피그마 최종 화면을 실제 CdBd 라이브 에디터에서 구현 + 등록에 필요한 부가 메타 설정.

### 작업
1. **라이브 에디터 페이지 제작** — [[4. 에디터 페이지 제작]] 가이드 준수
   - 피그마 카드 구성을 1:1로 옮김
   - 테마 변수(`{버튼색}`·`{배경색}`·`{텍스트색}`) 적용
   - 카드별 default 기능 신뢰
2. **OG 이미지 설정**
3. **페이지 제목 설정**

### 게이트
- → **사용자 CdBd 페이지 피드백**

### 게이트 통과 후 — 📱 모바일 스크린샷 캡처 (5단계 입력물)

페이지 확정 후 **모바일 프리뷰 스크린샷** 캡처:
- 셀렉터: `.max-w-1\/2.transform.origin-top` (라이브 템플릿 페이지의 모바일 프리뷰)
- **멀티페이지인 경우 모든 페이지 스크린샷 필요** — 페이지 1, 페이지 2, … 각각 캡처
- 자동화: gstack `browse` 사용 가능

```bash
# 예시 (필요 시)
$B goto https://www.cdbd.in/templates/{slug}
$B screenshot --selector ".max-w-1\\/2.transform.origin-top" /tmp/{slug}-p1.png
# 멀티페이지: 페이지 2 클릭 후 다시 캡처
```

## 5단계 — 템플릿 상세 페이지 콘텐츠 (피그마)

**목적**: 카탈로그 상세 페이지(`/templates/{slug}`)에 노출될 메타데이터를 피그마 상세 페이지 파일에 작성.

### 피그마 파일
- **상세 페이지 파일**: [Figma — CdBd 템플릿 등록 상세 (node-id=34-23)](https://www.figma.com/design/oi8zIHLfy59O5zV8aysqq4/CdBd-%ED%85%9C%ED%94%8C%EB%A6%BF-%EB%93%B1%EB%A1%9D?node-id=34-23)

### 작업 방식
- **🔁 신규 작성 ❌ → 기존 섹션 복사 후 내용·이미지만 교체** (구조 동일)
- 복사 원본 예시: [node-id=235-10917](https://www.figma.com/design/oi8zIHLfy59O5zV8aysqq4/CdBd-%ED%85%9C%ED%94%8C%EB%A6%BF-%EB%93%B1%EB%A1%9D?node-id=235-10917) (신제품 소개 템플릿)

### 🗑 복제 직후 삭제할 것
- **10회 사용 / ★4.9 배지** — 누적 데이터 없으므로 삭제 상태로 시작

### 채울 슬롯
섹션 내부에 이미 들어있는 슬롯 (그대로 채우기):

| 슬롯 | 내용 |
|---|---|
| 대표 이미지 | 보드 상단 200×200 = 소개 박스 내 134×134 (동일 이미지 2곳) |
| 썸네일 | 보드 중앙 thumb 프레임 (145+145 stacked) |
| 카테고리 | 소개 박스 좌상단 보라색 라벨 |
| 슬러그 | 보드 우상단 텍스트 + 미리보기 URL |
| 에디터 id | 보드 우상단 숫자 |
| 소개 — 제목 | 소개 박스 헤드라인 |
| 소개 — 성과 (라벨 + 설명) | "사용 성과" 라벨 + 한 줄 설명 |
| 소개 — 리뷰 형식 설명글 | 본문 paragraph (4-5줄) |
| 소개 — 추천 타겟 | 하단 체크리스트 (보통 2개) |
| 주요 기능 N | 주요기능-1, 주요기능-2, … (제목 + 설명 + 아이콘 38×38 + 이미지 360×300) |
| **모바일 페이지 스크린샷** | 보드 우측 패션룩북 프레임 — 4단계 캡처물. **멀티페이지면 모든 페이지** |

## 6단계 — CdBd 어드민 등록

**목적**: 피드백 반영된 상세 페이지 콘텐츠 확정 후 실제 어드민에서 템플릿 등록.

### 어드민 진입
- **URL**: https://cdbd-admin.vercel.app/login (CdBd와 동일 계정)
- **경로**: 템플릿 → 템플릿 관리 → 템플릿 추가

### 어드민 폼 구조
**좌측 컬럼** (기본 메타)
- 언어 \* · 템플릿명 \* · 제목 \* · 슬러그 \* · 썸네일 이미지 \* · 에디터 ID \* · 카테고리(5종 체크) · 활성화

**우측 상단 박스 "상세 정보"** = 피그마 소개 frame
- 상세 이미지(대표 프로필) · 부제목 라벨 · 부제목 설명 · 본문 · 항목(+추가, 추천 대상 반복)

**우측 하단 박스 "스와이퍼 영역"** = 피그마 주요기능-N frame (반복)
- 각 항목: 제목 \* · 설명 \* · 표시 순서 · 아이콘 이미지(38×38) · 설명 이미지(360×300)

### 매핑표
- [[5. 템플릿 상세 페이지 콘텐츠#🔁 어드민 폼 ↔ 피그마 슬롯 매핑]] — 어드민 필드 ↔ 피그마 슬롯 1:1 매핑

### 완료 조건
- 활성화 체크 → 템플릿 생성 → 라이브 노출 확인
