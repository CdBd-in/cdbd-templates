## 디자인 특성

- **전체 인상**: 럭셔리 · 포멀 · 야간 — 딥 네이비 배경 위 골드 액센트 + 명조/Playfair 세리프 조합으로 블랙타이 만찬의 격식을 표현
- **페이지 테마**: 배경 딥 네이비 #0F172A / 텍스트 화이트 #FFFFFF / 버튼 샴페인 골드 #CFA770
- **포인트 컬러**: 샴페인 골드 #CFA770 (섹션 제목 RSVP·LOCATION, 브랜드명, 회신 마감 = 버튼색), 보조 텍스트 = 텍스트색 × 45~85% (별도 회색 ❌)
- **컬러 대비**: 강 — 딥 네이비 위 화이트 본문. 버튼 텍스트 = 배경색(네이비)으로 골드 위 대비 충족(버튼 대비 규칙)
- **모서리 처리**: 각진 (buttonRadius 0px · 이미지 0px). 프로필 이미지만 원형
- **카드 배경**: 대부분 투명(페이지 네이비 위). **Q&A·위치 안내**만 슬레이트 패널(#1E293B) + 외부여백 20px 인셋으로 통일, **푸터 4장**은 더 어두운 #0B111E로 색 띠
- **텍스트 사이즈 대비**: 큼 — 영문 행사명 35px Playfair vs 본문 13~14px 본명조, 섹션 제목 28px 골드, 캡션 12px
- **반복되는 디자인 요소**:
  - Playfair Display(영문 헤드라인) + 본명조(국문 본문) 2폰트 페어링
  - 섹션 제목(골드 28px) 아래 **짧은 중앙 구분선**(좌우 패딩 150px) 액센트 반복
  - 라벨+값 2줄 텍스트 카드(일시·장소·드레스 코드) — 라벨 작게·흐리게 / 값 크게·진하게
  - 골드 단일 액센트를 섹션 제목·브랜드명·마감일에만 절제 사용
  - 슬레이트 패널(Q&A·위치) 인셋 카드 배경 통일
- **레이아웃 특징**: 헤더 이미지 → 호스트 프로필 → 초대문(레이블·행사명·일시/장소/드레스코드) → 좌석 배치도 → RSVP(예약) → 참석 정보(Q&A) → LOCATION(지도·주차) → 비서실 버튼 → 푸터의 단일 페이지 세로 흐름. 모든 카드 top-level 평탄화(gap 0 · 카드 상하 패딩으로 간격), 섹션 구분은 구분선 + 골드 제목 + 인셋 패널로.
