## 디자인 특성

- **전체 인상**: 럭셔리 · 엘레강스 · 포멀 — 다크 차콜 배경 위 샴페인 골드 액센트 + 명조/라틴 세리프 조합으로 프리미엄 임원 만찬의 격식을 표현
- **페이지 테마**: 배경 다크 차콜 #15191A / 텍스트 웜 크림 #E9E3D6 / 버튼 샴페인 골드 #C4A26A
- **포인트 컬러**: 샴페인 골드 #C4A26A (eyebrow "INVITATION · 2026", 일시·장소·드레스 라벨, 섹션 제목, 행사 순서 시간·입장 안내 번호 01/02/03, 브랜드 로고 = 버튼색), 보조 텍스트 = 텍스트색 × N%(본문 ≈ #D4CFC3, 별도 회색 ❌)
- **컬러 대비**: 강 — 다크 차콜 위 크림 본문. 버튼 텍스트 = 배경색(차콜)으로 골드 위 대비 충족(버튼 대비 규칙)
- **모서리 처리**: 둥근 (버튼 라운드 · 지도 라운드). 프로필/상단 로고 원형
- **카드 배경**: 대부분 투명(페이지 차콜 위) — 섹션 구분은 구분선 + 골드 제목이 담당. 이미지는 상단 로고 + 히어로(만찬장) 2장, 지도 1개. 인셋 색 패널 없음
- **텍스트 사이즈 대비**: 큼 — 국문 대제목(만찬명) 크게 vs 본문·라벨 작게, 섹션 제목 중간, eyebrow/캡션 작게
- **반복되는 디자인 요소**:
  - 라틴 세리프(INVITATION · PRESTIGE) + 국문 명조(대제목·본문) 2폰트 페어링
  - 골드 대문자 영문 eyebrow + 국문 제목 조합
  - 라벨+값 세로 2줄(일시·장소·드레스) 중앙정렬 — 라벨 골드 작게 / 값 크게
  - 2단 카드 반복: 좌 시간(18:30…)·번호(01/02/03) 골드 + 우 내용, 항목 사이 구분선
  - 골드 단일 액센트를 eyebrow·라벨·섹션 제목·번호에만 절제 사용
- **레이아웃 특징**: 로고 → eyebrow → 대제목 → 초대 인사 → 일시/장소/드레스 → 히어로 이미지 → 모시는 글 → 행사 순서(2단+구분선 반복) → 참석 예약(예약 카드) → 입장 안내(QR 3스텝 2단) → 행사장 위치(지도) → 오시는 길 → 문의(전화·이메일·연락처 저장 버튼 3개) → 문의 안내의 단일 페이지 세로 흐름. 모든 카드 top-level 평탄화(gap 0 · 카드 상하 패딩으로 간격), 섹션 구분은 구분선 + 골드 제목으로.
