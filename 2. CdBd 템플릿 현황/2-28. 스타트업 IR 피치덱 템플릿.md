## 디자인 특성

- **전체 인상**: 프로 · 테크 · 신뢰 — 밝은 배경 + 블루 액센트로 IR 자료의 명료함·전문성. 섹션 제목·지표를 또렷하게 구조화한 피치덱 문법
- **페이지 테마**: 배경 화이트(오프화이트) / 텍스트 다크 / 버튼·액센트 블루 #1B4DDB
- **포인트 컬러**: `{버튼색}` 블루 #1B4DDB — 지표 수치·CTA·챕터 강조
- **컬러 대비**: 강 — 밝은 배경 위 다크 텍스트 + 블루 액센트
- **모서리 처리**: 둥근
- **카드 배경**: 밝은 배경 위 무배경/저투명 카드, 서브페이지 상단 헤더는 채움 바
- **텍스트 사이즈 대비**: 큼 — 원라이너·섹션 제목 대형, 라벨·본문 소형
- **폰트**: 프리텐다드 단일 (국문 본문 = 한글 폰트 규칙 준수)
- **반복되는 디자인 요소**:
  - 서브페이지 상단 고정 2단 카드 헤더(회사명 + 홈 복귀)
  - 페이지 하단 「다음 페이지 / 표지로」 버튼 쌍
  - 제품·지표를 2단 카드로, 팀을 프로필 카드로
  - 블루 수치·CTA 강조
- **레이아웃 특징**: 멀티페이지 4장(표지 → 문제·솔루션·제품 → 시장·지표·모델 → 팀·투자·문의). 표지 목차 메뉴로 진입, 서브페이지 상단 헤더로 복귀. 마지막 페이지의 미팅 문의 Q&A가 핵심 전환 장치

## 제작 메모

- **주요기능(스와이퍼) 2**: ① 실제 제품 화면을 갤러리로(좌우 넘겨보기) ② 투자자가 폰에서 바로 미팅 요청(마지막 페이지 Q&A 폼)
- **⚠️ 사용자 편집과 교차**: 강현이 인수인계 기준, 사용자가 에디터에서 표지의 지표 대시보드 제거·이미지 자리 조정·표지 내비게이션(둘러보기/CTA) 변경 등을 진행 → **라이브 구조가 시안 2a와 일부 상이**할 수 있음
- **⚠️ 미확인 항목**: 에디터 ID · 정확한 카드 개수(확정 시안 안 2a 매니페스트 기준 도출, 에디터 card-driver 실측 시 정정)
