## 디자인 특성

- **전체 인상**: 내추럴 · 오가닉 · 따뜻함 — 밝은 그레이 배경에 틸(teal) 액센트와 고운돋움의 부드러운 정서로 홈베이킹 공방의 정갈하고 손맛 있는 톤
- **페이지 테마**: 배경 라이트 그레이 #eff0f0 / 텍스트 차콜 #232323 / 버튼 틸 #078080 (🌿 내추럴 · HappyHues 8)
- **포인트 컬러**: 틸 #078080 (버튼·레벨 제목 액센트), 보조 텍스트 = 텍스트색 × N% (별도 회색 ❌)
- **컬러 대비**: 중~강 — 밝은 배경 + 차콜 본문 + 비비드 틸 CTA. 버튼 텍스트 = 배경색(밝음)으로 틸 위 고대비
- **모서리 처리**: 둥근 (버튼·카드)
- **카드 배경**: 레벨별(입문·심화·창업) 풀블리드 **색 띠 밴드 = `{버튼색}×8%`** (rgba 7,128,128,0.08) · 외부여백 0으로 좌우 끝까지 연속 띠 형성. 밴드 사이는 투명(배경색)으로 교차 구분
- **텍스트 사이즈 대비**: 보통~큼 — 레벨 제목·반 안내 제목은 Bold, 본문/안내는 정갈한 소형
- **반복되는 디자인 요소**:
  - 레벨 3종(입문·심화·창업) 동일 구조 밴드 반복 → 시각·구조 통일
  - 틸 단일 액센트를 버튼·레벨 제목에만 절제 사용
  - 둥근점(dotted) 구분선으로 대섹션 분절
  - 통합 프로필 카드(명함형 · 원형 사진) 단일 depth
  - 넘겨보기 carousel 갤러리 + 페이지 도트 (스튜디오 + 레벨별 작품)
- **레이아웃 특징**: 강사 프로필 → 클래스 개요 → 스튜디오 갤러리 → 난이도 안내 → [입문 → 심화 → 창업 밴드] → 납부·환불 → 위치 안내 → 상담(2단 버튼)의 단일 페이지 세로 흐름. 모든 카드 top-level 평탄화(380w · gap0 · 카드 상하 padding으로 간격), 레벨 밴드만 색 띠로 박싱.
