## 디자인 특성

- **전체 인상**: 모던 · 시크 + 비비드 — 잉크 블랙 배경에 오렌지 네온 액센트로 심야 루프탑 파티의 열기를 압축. 영문 대형 타이포가 포스터처럼 강한 첫인상
- **페이지 테마**: 배경 잉크 블랙 #0F0E17 / 텍스트 오프 화이트 #FFFFFE / 버튼 네온 오렌지 #FF8906
- **포인트 컬러**: `{버튼색}` 오렌지 #FF8906 — 이벤트명 2행 · 출연 시간 · 티켓 가격 · 예매 버튼에 반복
- **컬러 대비**: 강 — 다크 배경 위 화이트 텍스트 + 오렌지 액센트
- **모서리 처리**: 원형(pill) — 예매 버튼
- **카드 배경**: 대부분 무배경(다크 페이지 배경 노출), 티켓 티어 3장만 `{버튼색}×10%` 오렌지 틴트 패널로 묶어 강조
- **텍스트 사이즈 대비**: 큼 — Bebas Neue 대형 타이틀(60) · 일시(45) · DJ 이름(30) vs 본문·라벨(12~18)
- **폰트**: Bebas Neue(영문 대형 타이틀 전용 — 이벤트명·일시·DJ 이름) + Noto Sans KR(본문 Light/Regular/Medium/Bold)
- **반복되는 디자인 요소**:
  - 오렌지 대문자 섹션 라벨(INVITATION · TIME · PLACE · LINE UP · TICKETS · LOCATION)
  - Bebas Neue 영문 대형 타이포 ↔ 한글 본문의 대비
  - 보조 텍스트 = `{텍스트색}` 투명도(55~75%)
  - 오렌지 액센트 흐름: 출연 시간 → 티켓 가격 → 예매 버튼
- **레이아웃 특징**: 포스터형 히어로(이벤트명 → 태그라인 → 메인 비주얼) → 초대의 글로 온기 → 일시/장소 사실 정보 → 라인업(누가 언제) → 티켓 등급 → 예매 → 유의사항 → 오시는 길 순의 파티 초대 흐름. **타임테이블을 별도 섹션으로 두지 않고 라인업 카드에 출연 시간을 병합**해 "누가 언제"를 한눈에 처리한 것이 특징
