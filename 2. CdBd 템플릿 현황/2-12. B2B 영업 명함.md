## 디자인 특성

- **전체 인상**: 클린·기업형·테크 — 화이트 본문에 민트·티얼 헤더 그라데이션으로 신재생 에너지 B2B 영업의 모던하고 신뢰감 있는 인상
- **페이지 테마**: 배경 화이트 #FFFFFF / 텍스트 다크 네이비 / 버튼 비비드 블루 #2D7DE6
- **포인트 컬러**: 페일 민트 #E8F5F1 (헤더 그라데이션), 민트/티얼 #3BC2A6 액센트
- **컬러 대비**: 중 — 흰 배경 + 블루 강조의 정돈된 정보형 콘트라스트
- **모서리 처리**: 둥근 — 명함 카드·정보 박스가 부드럽게 라운드
- **카드 배경**: 흰색 카드 + 페일 민트 강조 헤더 + 텍스트 위주 정보 블록
- **텍스트 사이즈 대비**: 보통 — 이름/이력/사례 위계가 명확
- **반복되는 디자인 요소**:
  - 페일 민트 그라데이션 헤더 + 영문 라벨
  - 좌측 컬러 보더 + 좌측 정렬 라벨의 정보 박스(보유 역량/주요 이력)
  - 가로형 사례 사진 카드 + 캡션
- **레이아웃 특징**: 명함 헤더 → 연락처 → 역량/이력/책임 영역 → 사례 사진 → 신청 폼 순의 영업 자료형 흐름, 정보 밀도가 높지만 카드별로 깔끔히 분리됨
