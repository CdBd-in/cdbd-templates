## 디자인 특성

- **전체 인상**: 모던·시크·프로페셔널 — 다크 잉크 배경 위에 퍼플 액센트로 인사팀(B2B) 채용 행사의 격식 있고 세련된 톤
- **페이지 테마**: 배경 다크 잉크 #16161A / 텍스트 화이트 #FFFFFE / 버튼 퍼플 #7F5AF0 (HappyHues 13)
- **포인트 컬러**: 퍼플 #7F5AF0 (버튼·강조), 차콜 #222226 (보조 카드 배경), 보조 텍스트 = 화이트 × 75%
- **컬러 대비**: 강 — 다크 배경 + 화이트 텍스트 + 비비드 퍼플 CTA의 고대비 구성
- **모서리 처리**: 둥근 (버튼·CTA 16px) — 단, 이미지·갤러리 셀은 각진(0)
- **카드 배경**: 다크 잉크 페이지 배경 위에 차콜(#222226) 강조 카드가 정보 섹션(일시·장소 등)을 감싸며 교차
- **텍스트 사이즈 대비**: 큼 — 영문 리드(YOU ARE INVITED)·행사명 헤딩이 크고 본문은 작고 정갈, 프리텐다드 단일 서체
- **반복되는 디자인 요소**:
  - 영문 디스플레이(ABC COMPANY · YOU ARE INVITED) + 한글 본문 페어링
  - 구분선으로 섹션(소개 → 행사정보 → 신청 → 출석)을 명확히 분절
  - 퍼플 단일 액센트를 CTA·강조에만 절제 사용
  - 차콜 강조 카드로 핵심 정보(일시·장소) 박싱
- **레이아웃 특징**: 헤더 비주얼 → 회사·슬로건 → 행사명·초대문 → 일시·장소·지도 → 사전 참석 신청서(Q&A) → 출석 등록(예약) → 인사팀 문의의 단일 페이지 세로 흐름. 모집(RSVP)부터 현장 출석 등록까지 한 페이지에서 완결.
