> 🃏 **상품 링크 = 버튼 카드** — 제품마다 「자사몰에서 보기」 버튼으로 자사몰 상세·주문에 직접 연결(카탈로그 최초로 구매 연결을 버튼으로 처리). 상품 카드가 아니라 **[이미지 → 제품명 → 스펙 → 버튼]** 4카드 스택으로 제품 1개를 구성해, 사용자가 카드 단위로 편집·복제할 수 있게 함.
> 🃏 **영업 직통이 두 번** — 상단(프로필 직후 **메뉴 카드** 3종: 전화·이메일·명함 저장) + 하단(**버튼 3개** 전화·이메일·명함 저장). 스크롤 어디서든 연락이 손 닿는 곳에 있게 배치.
> 🃏 **신뢰 지표 4개 = 2단 카드 2장(2×2)** — 설립·거래처·월생산·인증을 값+라벨 양끝정렬로.

## 디자인 특성

- **전체 인상**: 내추럴 · 오가닉 — 따뜻한 크림·브라운 톤 + 정돈된 여백. B2B 스펙(박스당 개수·유통기한·최소주문)은 표처럼 또렷하게, 그 위에 디저트 사진의 온기를 얹음
- **페이지 테마**: 배경 크림 #F4ECE0 / 텍스트 딥 브라운 #40301F / 버튼 테라코타 #B25B3E
- **포인트 컬러**: `{버튼색}` 테라코타 #B25B3E — 자사몰 버튼·지표 수치·박람회 부스 강조 배경에 반복
- **컬러 대비**: 강 — 크림 배경 위 딥 브라운 텍스트 + 테라코타 버튼 (버튼 글자 = 크림색)
- **모서리 처리**: 각진
- **카드 배경**: 크림 페이지 배경 위 무배경 카드, 박람회 부스 정보만 `{버튼색}` 틴트 강조 배경
- **텍스트 사이즈 대비**: 큼 — 본명조 헤드라인(브랜드명·섹션 타이틀) 크게, 스펙·라벨은 작게 + 투명도
- **폰트**: 본명조(Noto Serif KR, 헤드라인) + 프리텐다드(본문·스펙 — 정보 가독성)
- **반복되는 디자인 요소**:
  - 본명조 제목 + 프리텐다드 본문 조합
  - 제품 1개 = 이미지 → 이름 → 스펙 → 버튼 4카드 스택 (반복·복제 단위)
  - 신뢰 지표·연락을 양끝정렬 2단 카드/메뉴로 정리
  - 영업 직통 연락 상단·하단 2회 반복
- **레이아웃 특징**: 부스 정보 → 히어로 → 브랜드·슬로건 → 신뢰 지표(2단) → 영업 담당자 프로필 → 영업 직통(상단) → 생산 현장 갤러리 → 제품 카탈로그 4종 → 위치 → 하단 영업 직통 CTA 순. **회사 신뢰 → 제품 스펙 → 즉시 문의**를 한 스크롤로 잇는 흐름

## 제작 메모

- **상품 링크 = 버튼 카드** — 상품 카드 대신 버튼으로 자사몰 연결(제품마다 링크만 교체). 링크 없는 주문형(제품 4)은 문의 버튼으로 대체
- **영업 직통 = 메뉴 + 버튼** — 상단은 메뉴 카드(전화·문자·vCard default 액션), 하단은 개별 버튼 3장(전화/이메일/명함 저장). B2B 현장은 폼(Q&A)이 아니라 즉시 통화·이메일이 맞아 **Q&A·예약 카드 미사용**
- **위치 안내** — 지도+주소+버튼 한 단위, 버튼 채움(Outline 불가), 제목은 위 별도 텍스트 카드
