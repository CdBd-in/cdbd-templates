## 디자인 특성

- **전체 인상**: 모던 · 시크 · 미니멀 — '여백'을 콘셉트로 한 절제된 인테리어 포트폴리오. 명조 헤드라인과 넉넉한 여백으로 신뢰감·전문성을 전달
- **페이지 테마**: 배경 오프화이트 #F7F6F3 / 텍스트 잉크 블랙 #191919 / 버튼 잉크 블랙 #191919
- **포인트 컬러**: 없음(무채색 톤온톤) — 서브페이지 상단 다크바(#191919)가 유일한 채움 대비
- **컬러 대비**: 강 — 크림 배경 위 잉크 블랙 텍스트·버튼
- **모서리 처리**: 각진
- **카드 배경**: 크림 페이지 배경 위 무배경 카드, 서브페이지 상단 헤더만 다크바
- **텍스트 사이즈 대비**: 큼 — 본명조 헤드라인 크게, 영문 라벨·보조 텍스트는 작게 + 투명도
- **폰트**: 본명조(Noto Serif KR, 제목·헤드라인) + 프리텐다드(본문) + Montserrat(영문 대문자 라벨)
- **반복되는 디자인 요소**:
  - 본명조 제목 + 프리텐다드 본문 조합
  - 영문 대문자 섹션 라벨(ABOUT · PROJECT · ESTIMATE)
  - 2단 카드로 반복 정보(번호+설명, 실적, 인증) 양끝 정렬 정리
  - 서브페이지 상단 고정 다크바 헤더(홈 복귀)
  - 넉넉한 상하 여백
- **레이아웃 특징**: 멀티페이지 4장(표지 → 소개 → 프로젝트 → 견적·문의). 표지 목차 버튼 3개로 진입하고 서브페이지 상단 다크바 헤더로 복귀. 전후 비교 갤러리 넘겨보기 + 무료 견적 Q&A 폼이 핵심 전환 장치
