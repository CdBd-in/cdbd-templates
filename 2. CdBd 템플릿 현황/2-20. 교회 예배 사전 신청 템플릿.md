## 디자인 특성

- **전체 인상**: 클래식 · 경건 · 내추럴 — 아이보리 크림 배경에 골드/브론즈 액센트와 고운바탕(명조) 헤드라인으로 창립 40주년 기념 예배의 격식과 따뜻함을 표현
- **페이지 테마**: 배경 아이보리 크림 #F9F4EF / 텍스트 딥 네이비 잉크 #020826 / 버튼 골드 브론즈 #8C7851
- **포인트 컬러**: 골드 브론즈 #8C7851 (헤드라인·eyebrow·섹션 제목 액센트 = 버튼색), 보조 텍스트 = 텍스트색 × 60~75% (별도 회색 ❌), 강조 카드 배경 = 크림 톤 #ECE3D6
- **컬러 대비**: 중~강 — 밝은 크림 배경 + 딥 네이비 본문 + 골드 액센트. 버튼 텍스트 = 배경색(크림)으로 골드 위 대비(≈3.9:1, 버튼 대비 규칙 충족)
- **모서리 처리**: 둥근 (로고 8px · 예배당 사진 14px · 회차 요약 박스 16px · 버튼 pill). 텍스트 카드는 0
- **카드 배경**: 대부분 투명(페이지 크림 위에 얹힘). **회차 요약 2단 카드만** 크림 톤 박스(#ECE3D6)로 강조, 예배당 사진은 1:1 라운드 컷
- **텍스트 사이즈 대비**: 큼 — 헤드라인 27px 고운바탕(골드) vs 본문 13~14px 고운돋움, eyebrow 12px 골드
- **반복되는 디자인 요소**:
  - 고운바탕(명조) 헤드라인 + 고운돋움(고딕) 본문 2폰트 페어링
  - 골드 단일 액센트를 헤드라인·eyebrow·섹션 제목에만 절제 사용
  - eyebrow 소형 라벨(ALL SESSIONS · 전체 회차) — 영문 대문자 + 한글 조합
  - 회차 블록(제목·일시 2단 카드 + 예약카드) 동일 구조 반복 → 시각·구조 통일
  - 보조 텍스트 = 텍스트색 × 투명도(60~75%)로 위계 분리
- **레이아웃 특징**: 로고 → 헤드라인·인사말 → 예배당 사진 → 전체 회차 요약(2단) → [1회차 제목·일시 2단 + 예약] → [2회차 …] → 구분선 → 담임목사(프로필) → 위치(제목·주소·지도) → 운영팀 연락의 단일 페이지 세로 흐름. 모든 카드 top-level 평탄화(gap0 · 카드 상하 시안 패딩으로 간격), 회차 블록만 카드 단위로 반복.
