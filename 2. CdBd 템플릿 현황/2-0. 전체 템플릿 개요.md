# CdBd 템플릿 전체 현황

CdBd.in에 등록된 템플릿의 카테고리, **실제 카드 타입**, 페이지 구성을 정리. 카드 타입은 에디터 내부 SVG 시그니처를 분석해 15종 표준 카드 종류로 매핑함.

> 📌 **기존 17개 스냅샷(2026-06-17) + 신규 제작분**: 아래 글로벌 통계·매트릭스(554카드·17개)는 **2026-06-17 기존 템플릿 분석 스냅샷**으로 그대로 유지. 이후 신규 제작·라이브 등록된 템플릿은 [[#🆕 신규 제작 템플릿 (기존 17개 이후)]] 섹션에 별도 누적.

> ⚠️ **카드 라벨 vs 카드 타입 구분**:
> - **카드 타입** = 디자인 시스템 15종 표준 (텍스트, 이미지, 버튼 등)
> - **카드 라벨** = 사용자가 용도에 맞춰 편집한 이름 (예: "로고 이미지" → 실제는 이미지 카드)

## 🔍 카테고리별 카드 사용 경향

### 프로필 · 명함 (7개)
**주요 카드**: 텍스트(연락처/소개), 이미지(로고/프로필), 버튼(CTA)
- Q&A 카드로 상담 신청 폼 자주 포함
- SNS 카드로 마무리

### 초대 · 예약 (5개)
**주요 카드**: 텍스트(초대글/일정), 이미지(분위기 컷), 구분선(섹션 분리)
- 위치 안내 카드 빈번 사용
- 예약 카드는 일부만(템플릿 4, 8, 14)
- Q&A는 RSVP/만족도 조사용

### 홍보 · 카탈로그 (4개)
**주요 카드**: 이미지(메인 컷/제품), 텍스트(설명), 버튼(구매 유도)
- 멀티 페이지 활용 (3/4 = 75%)
- ⚠️ **상품 카드 0회 사용** — 카드 타입과 카테고리 미스매치
- 갤러리 거의 사용 안 함 (1회만)

### 가이드 · 신청 (1개)
**주요 카드**: 텍스트(긴 안내), 구분선(섹션 분리), 이미지(설명 그래픽)
- 단 1개 템플릿 (B2B 운영 지원 템플릿) → 카테고리 빈약
