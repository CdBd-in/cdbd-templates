## 디자인 특성

- **전체 인상**: 내추럴 · 클린 · 미니멀 — 크림 배경 + 세이지/올리브 텍스트로 저자극·비건 스킨케어의 담백함. 세리프 헤드라인이 화보 무드를 더함
- **페이지 테마**: 배경 크림 #F5F1EA / 텍스트·버튼 세이지 올리브 #4F5A3F
- **포인트 컬러**: `{버튼색}` 올리브 #4F5A3F — 가격·구매 버튼·섹션 제목. 2톤(배경·올리브)에 가까운 절제된 팔레트
- **컬러 대비**: 중~강 — 크림 배경 위 올리브 텍스트 (버튼 글자 = 크림색)
- **모서리 처리**: 둥근
- **카드 배경**: 크림 페이지 배경 위 무배경 카드, Before/After·프로미스 블록에 저투명 톤
- **텍스트 사이즈 대비**: 큼 — EB Garamond 세리프 헤드라인 크게, 성분·용량·라벨은 작게 + 투명도
- **폰트**: EB Garamond(영문 세리프 헤드라인) + 프리텐다드(국문 본문·성분·가격)
- **반복되는 디자인 요소**:
  - 세리프 헤드라인 + 프리텐다드 본문 조합
  - 제품 = 화보→정보→성분→B&A→후기→구매 미니 상세 블록 반복
  - CLEAN PROMISE·B&A를 2단 카드로 정리
  - 올리브 가격 강조 · 보조 텍스트 = `{텍스트색}` 투명도
- **레이아웃 특징**: 브랜드·컬렉션 → 클린 프로미스 → 제품별 상세 블록 반복 → 문의 순. 제품마다 상세페이지 수준의 정보를 한 스크롤에 담는 것이 핵심
