## 디자인 특성

- **전체 인상**: 클린 · 모던 · 프로페셔널 — 화이트 배경 + 블루 액센트로 정돈된 신뢰감. 단가·과정·후기를 정보 블록으로 또렷하게 나열
- **페이지 테마**: 배경 화이트(오프화이트) / 텍스트 잉크 #12151C / 버튼 블루 #4C8DFF
- **포인트 컬러**: `{버튼색}` 블루 #4C8DFF — 가격·실적 수치·프로세스 번호·CTA에 반복 (버튼 글자는 잉크색 대비 확보)
- **컬러 대비**: 강 — 화이트 배경 위 잉크 텍스트 + 블루 액센트
- **모서리 처리**: 둥근
- **카드 배경**: 화이트 페이지 배경 위 무배경/저투명 카드, 서비스·실적·프로세스 블록에 리듬
- **텍스트 사이즈 대비**: 큼 — 이름·헤드라인 대형, 영문 섹션 라벨(SERVICES·ABOUT·PROCESS) 소형
- **폰트**: 프리텐다드 단일 (국문 본문 = 한글 폰트 규칙 준수)
- **반복되는 디자인 요소**:
  - 영문 대문자 섹션 라벨(SERVICES · ABOUT · GOOD FIT · PROCESS · PORTFOLIO · FAQ)
  - 서비스/실적/프로세스를 값+라벨 위계로 정리
  - 블루 수치 강조 · 보조 텍스트 = `{텍스트색}` 투명도
- **레이아웃 특징**: 이름·헤드라인 → 서비스·단가 → 실적 → ABOUT → GOOD FIT → 프로세스 → 포트폴리오 → 후기 → FAQ → 상담 폼 → 문의 버튼 순. **단가를 앞에 공개**하고 마지막에 폼으로 접수받는 흐름

## 제작 메모

- **단가 공개 + 조건 필터 폼** — 예상 예산·희망 일정을 객관식으로 받아 첫 상담부터 구체화(헛걸음 감소)
- **주요기능(스와이퍼) 2**: ① 단가표를 먼저 보여줘 문의 문턱 낮추기 ② 예산·일정을 미리 받는 상담 신청 폼
- **⚠️ 미확인 항목**: 에디터 ID(어드민 편집 페이지가 editor_id를 노출하지 않음) · 정확한 카드 개수/타입(라이브 발행 페이지 기준 도출, 에디터 card-driver 실측 시 정정 필요). 특히 서비스 3종이 텍스트 카드인지 2단 카드인지, FAQ가 Q&A인지 텍스트 나열인지는 에디터 확인 권장
