## 3. 파이프라인 구조 (모래시계)

```
[입력] 기획 문서(1단계) + 조립 레시피(1-8 · 카테고리별 섹션 목적 순서)
   │
   ▼
D1 내용 구성 ─ 1회 (3안 공통)
   │  콘텐츠 팩 (텍스트 + 이미지)
   ├─ 안1  미니멀    × 무드A : D2 조합 → D3 통일 → D4 무드
   ├─ 안2  에디토리얼 × 무드B : D2 → D3 → D4
   └─ 안3  볼드      × 무드C : D2 → D3 → D4
   │
   ▼
D5 검수 ─ 1회 (3안 전체 · 읽기 전용)
   │  ├ 안별: 통일 8항목 · CdBd-legal · 대비 · 프리셋 원본 무결성
   │  └ 3안 간: 차별성(쌍둥이 ❌ — **무드가 다른 건 차별성 근거 ❌, 구조가 달라야 함**)
   │
   │  문제 있음 → 담당(D2/D3/D4) 재실행 → D5 재검수 (최대 2회) → 초과 시 사용자 게이트
   ▼
[출력] 시안 3안 (「조합 테스트」 페이지 가로 배치) + 리포트
```

**레인은 직렬 실행** — Figma는 한 번에 한 곳만 안전하게 쓸 수 있으므로 안1 완주 → 안2 → 안3.

## 4. 에이전트 5개

> 공통 규칙은 `.claude/cdbd-draft-shared.md`에 두고 5개가 모두 먼저 읽는다 (기존 `cdbd-edit-shared.md`와 같은 패턴).

### D1 — `draft-d1-content` (내용 구성)

- **입력**: 기획 문서(카테고리·세부 카테고리·주제·무드 방향·콘텐츠 인벤토리) + 조립 레시피
- **담당**: 레시피의 **섹션 목적마다** 실제 카피(제목·본문·버튼 문구·라벨) + 이미지 생성/수급
  - 이미지 = [[1-5. 이미지]] 규칙 (OpenAI gpt-image-1 · Thiings 3D · Unsplash · 🚫 Flow 제외)
- **실행 횟수**: **1회** — 산출물이 3안에 동일하게 들어감
- **안 하는 일**: 카드 타입·구조 결정(D2) · 색·폰트(D4)
- **출력 (콘텐츠 팩)**:
```json
{
  "slug": "...", "category": "초대·예약 ① 행사 초대",
  "recipe": ["헤더","히어로","스토리","핵심정보","위치안내","폼","푸터"],
  "sections": [
    {"purpose":"히어로","texts":{"eyebrow":"...","title":"...","sub":"..."},"images":["/tmp/hero.png"]}
  ]
}
```
- **닭-달걀 해소**: D1은 프리셋 슬롯을 모른다. **조립 레시피가 섹션 목적 목록을 주므로** 목적별로 카피를 쓰고, 어느 프리셋에 담을지는 D2가 정한다.

### D2 — `draft-d2-assemble` (섹션 조합)

- **입력**: 콘텐츠 팩 + `style`(미니멀|에디토리얼|볼드) + 레시피
- **담당**:
  1. 레시피의 목적마다 **해당 스타일 서랍에서 프리셋 1개 선택** (선택 이유 기록)
  2. **복제**해서 「조합 테스트」 페이지에 세로 조립 (폭 380)
  3. 콘텐츠 팩의 텍스트·이미지 주입
  4. 헤더·푸터 선택 (**선택 요소** — 필수 아님 · 스타일 무관)
- **🔒 철칙**: **원본 프리셋 수정 절대 ❌.** 스타일 서랍(미니멀·에디토리얼·볼드 섹션)은 **읽기 전용**. 반드시 복제본만 조작. (같은 파일에서 작업하므로 라이브러리 오염 위험)
- **안 하는 일**: 통일(D3) · 색·폰트(D4) → **디폴트 테마 그대로** 둔다
- **출력**: `{style, frameId, picks:[{purpose, presetNodeId, reason}], headerId|null, footerId|null}`

### D3 — `draft-d3-unify` (페이지 통일)

- **입력**: D2 프레임
- **담당**: **☑ 카드 간 통일 8항목** ([[1-8. 섹션 프리셋 라이브러리]] 정본)
  1. 카드 좌우 여백 (기본 20)
  2. 섹션 타이틀 디자인
  3. 섹션 간 여백 = **각 섹션 마지막 카드의 하단 여백**
  4. 모서리 둥글기 (이미지·지도·카드배경 · 각진/둥근/원형 3종뿐)
  5. 카드 배경색·테두리
  6. 버튼 모양 (전역)
  7. 서체 (본문 1 + 제목 1 최대)
  8. 구분선 색상
- **작업 상태**: **여전히 디폴트 테마** (색은 3토큰 자리표시자 그대로)
- **안 하는 일**: 프리셋 교체(D2) · 무드 색(D4)
- **출력**: `{frameId, unified:[{item, value, appliedTo:n}]}`

### D4 — `draft-d4-mood` (무드 적용)

- **입력**: D3 프레임 + `mood`
- **담당**:
  - 3토큰 교체: `#fafafa`→`{배경색}` · `#292929`→`{텍스트색}` · `#6C4CFF`→`{버튼색}`
  - 폰트: 본문 1 + 제목 1 (국문 본문 = 한글 폰트 필수)
  - **대비 검증**: `텍스트↔배경 ≥3.6:1` **그리고** `버튼↔배경 ≥3.6:1` (버튼 텍스트 = `{배경색}` 고정 매핑 때문)
- **안 하는 일**: 구조·통일 규칙 변경 → D2·D3가 정한 **역할은 유지, 값만 교체**
- **출력**: `{frameId, mood, tokens:{bg,text,btn}, fonts:{body,heading}, contrast:{textBg, btnBg}}`

### D5 — `draft-d5-review` (검수 · 읽기 전용)

- **입력**: 시안 3안 프레임
- **담당 ① 안별**:
  - 통일 8항목 준수
  - **CdBd-legal**: 평면 카드 스택 · 15카드 · 자간 0 · 줄간격 짝수(1.2/1.4/1.6) · 이탤릭 ❌ · 버튼 원형 · 모서리 3종 · Auto gap(SPACE_BETWEEN) ❌ · 카드 고정 스펙(프로필 gap·Q&A 제목 중앙·위치 gap 16)
  - 대비 (텍스트·버튼 각각 ≥3.6:1)
  - **프리셋 원본 무결성** (D2가 원본을 건드렸는지)
- **담당 ② 3안 간**: **차별성** — **구조가** 실질적으로 다른가 (변주 축 3개 이상)
  - ⚠️ **무드(색·폰트)가 다른 것은 차별성 근거로 인정 ❌.** 3안은 무드가 어차피 다르므로(전제 9), 검수는 **무드를 제외하고 구조만** 본다. 무드 차이에 속아 "다르다"고 판정하면 "색·폰트만 다른 쌍둥이"를 통과시키게 됨.
- **고치지 않음** — 문제마다 **담당 에이전트를 지정**해 반환
- **출력**:
```json
{
  "verified": true,
  "perDraft": [{"style":"미니멀","diffs":[{"item":"섹션 간 여백","actual":"40/24/40","expected":"40 통일","owner":"D3"}]}],
  "crossDraft": {"ok": false, "reason": "미니멀·볼드가 정렬만 다르고 구조 동일", "owner":"D2"}
}
```

## 11. 3안의 무드 — ✅ 확정 (2026-07-16)

**결정: 무드도 3개 다르게** (3안 = 레이아웃 스타일 3 × 무드 3) — [[1-9. AI 유저 플로우]] ⑤ "구조+무드 모두 다르게" 채택.

**결정 시 검토한 충돌:**

| 문서 | 입장 |
|---|---|
| [[1-1. 워크플로우]] 1단계 | 무드 **방향 1개**를 정함 (9무드 중 1) |
| [[1-9. AI 유저 플로우]] ⑤ | 시안 3안 = "**구조+무드 모두 다르게**" ← **채택** |
| [[1-8. 섹션 프리셋 라이브러리]] 「🎨 디자인 결정」 | "두 축은 독립 — 3안 차이는 **레이아웃 스타일이 주로 좌우**하므로 **디자인 무드까지 얽을 필요 없음**" ← **실무와 어긋나게 됨** |

**이 결정의 부작용과 처리:**
- 3안이 무드까지 다르면 **"달라 보이는" 착시**가 생긴다 → 구조가 사실상 같아도 다르게 느껴짐.
- → **D5 차별성 검수는 무드를 제외하고 구조만 판정**한다(§4 D5 ②). 이 가드레일이 없으면 쌍둥이를 통과시킨다.
- → 1-8의 "무드까지 얽을 필요 없음" 문장은 **문서 정합 대상**(§12).
