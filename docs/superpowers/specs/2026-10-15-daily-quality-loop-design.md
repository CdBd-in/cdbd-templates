# 데일리 퀄리티 루프 — 설계 스펙

> 2026-10-15 · 이선호 인터뷰 3라운드 + 피드백 7회 반영 확정판
> 목적: AI 페이지 빌더 산출물의 디자인·내용 퀄리티를 매일 자동으로 끌어올리는 반복 프로세스

---

## 1. 목적과 원칙

**매일 [리서치 → 스코어링(확인) → 기준 강화 + 신규 섹션 추가(확인)]를 자동화**한다.

- 디자인 퀄리티 기준이 모호하다 → **좋은 시각 자료를 매일 대량 수집**하고, 좋음/나쁨 판단을 **이선호와 공유된 루브릭**으로 만든다
- 섹션(프리셋) 선정·활용이 약하다 → **색인 메타 + 거르기 로직**으로 기계화한다. 섹션 수는 **무제한 성장 + 색인 강화**로 대응(상한·폐기 ❌)
- **승인 전 정본 반영 절대 금지** — 루브릭·색인·어드민 MD·섹션 라이브러리에는 이선호가 승인한 것만 들어간다. 미확인분은 보류 누적

## 2. 전체 흐름

```
매일 오전 10:00 자동 실행 (launchd `in.cdbd.daily-quality-loop` · 무인 템플릿 빌드 자리 승계 · 2026-10-20 이선호 지시로 20:00→10:00 변경)
  R 리서치 → S1·S2·S3 스코어링 → P 제안 → 데일리 리포트 노트 생성
다음날 아침
  이선호가 리포트에서 체크박스 승인/거부 (5~15분)
다음 실행 시작 시 (전날 리포트 파싱)
  ✅ 승인 → 정본 반영 (루브릭 승격 · 색인/어드민 메모 등록 · 필요시 4-9-5/MD-08 전파)
  ❌ 거부 → 폐기 (Figma 제작물은 아카이브 페이지로 이동)
  ⬜ 미확인 → 보류 누적 (리포트 상단 「미승인 N건」 표시)
```

### S1 — 레퍼런스 채점 (절대 점수제)

- **상대평가 ❌** — **채택선 70+만 리포트**. 0건이면 「오늘 채택 없음」으로 보고

- 100점 = **완성도 40 + CdBd 재현성 30 + 신규성 30**:
  - **완성도 40** = 루브릭 D축의 레퍼런스 적용판 — D2(위계·정렬·여백 일관) + D4(타이포 체계·디테일) + D5(무드 일관) + 가독성(대비 3.6 철학). D1·D3은 유저 입력이 없어 적용 불가
  - **재현성 30** = CdBd-legal 제약 체크리스트(4-13에 압축 수록 + 원본 링크) — 세로 카드 스택 환원 가능 · 카드 20종+에디터 옵션 내 · 자간 0/이탤릭 ❌/외곽선 ❌ · 이미지 위 텍스트는 배경 이미지 2경로. **감점 가중식**: 재현 불가 요소가 사례의 주인공이면 크게, 장식이면 조금
  - **신규성 30** = 기존 자산 대조 — 섹션 색인 355개(slots·서랍) + 기존 규칙(4-8·루브릭)에 **없는** 섹션 패턴/기준 후보/명확히 나은 변주를 주는가. 셋 다 아니면 0 (근-중복 ❌)

## 5. 색인 메타 — 신규 3필드

**기록 위치 = 어드민 프리셋 「메모」 필드(정본) + 로컬 `preset-index.json`(미러)** — 충돌 시 어드민 우선, 같은 작업 안에서 양쪽 갱신 (팔레트 양방향 동기화와 같은 규칙)

**어드민 메모 고정 포맷** (파서는 아래 3키만 읽음 · 그 아래 줄 자유 메모 허용):
```
content: 가격, 스펙
weight: heavy
items: 2~4
```

| 필드 | 범위 | 기준 |
|---|---|---|
| `content` 🥇 | 전 섹션 | **4-7 질문 세트 279칸 + 4-12 부품 23종에서 역산한 ~20개 닫힌 어휘.** 태그마다 「다는 조건」 한 줄(슬롯·견본 텍스트 기준, 주관어 ❌) · 서랍(목적 13칸)이 이미 거르는 건 안 닮 · 신규 태그는 리포트 승인 경유 · **목록 초안을 리포트 1호에서 통째로 승인** |
| `weight` | 전 섹션 | heavy=색 밴드·풀블리드·대면적 틴트 / medium=이미지 1+·틴트 카드 / light=투명 배경·텍스트 위주. **리듬 체크 로직과 한 묶음으로만 도입**: ①뽑을 때 light 3연속이면 다음 후보 medium+ 조건, heavy 연속 방지 ②검수 때 weight 나열만으로 단조/과밀 플래그 |
| `items_range` | **제약 있는 섹션만** | 기존 산문 규칙의 기계화 — 핵심 정보 max 4 · 2열 min 2 · 캐러셀 min 4 · 갤러리 max 15 등. **필드 없음 = 자유** (CdBd 평면 스택은 카드 복제로 확장) |

**삭제된 필드와 이유** (재제안 금지):
- `evidence` — 선정 로직이 안 읽음, 출처 추적은 리포트가 담당
- `mood_fit` — 섹션은 무드 중립이 설계 원칙(채택 관문 1 테마 적응성). 무드 종속 섹션은 태그가 아니라 관문에서 거르거나 중립으로 고쳐 등록
- `images`·`items`·`logo`·`text_len` — 기존 `slots` 필드에서 스크립트 파생 가능 (저장 중복 ❌)

**기계 파생**: 이미지 수·항목 수·로고 유무·텍스트 구성은 색인 `slots` 파싱 스크립트로 (rebuild-picklist.py 방식)

2. S1 세부 배점·content 태그 목록 — **리포트 1호에서 실물과 함께 승인** (스펙 단계에서 숫자 못 박지 않음)
3. `/ai/create` 플로우의 생성 크레딧 소모 여부 — 첫 실행 실측
4. 루브릭 기준선(80/70) — 1~2주 운영 데이터로 보정

## 10. 성공 기준

- 매일 아침 리포트가 자동 생성되고, 리뷰가 15분 이내로 끝난다
- S2 점수 추이가 주 단위로 상승한다 (기준 강화 → 산출물 향상 연결 입증)
- 섹션 선정에서 「내용에 안 맞는 섹션」 결함(루브릭 D1)이 감소한다
- 레퍼런스 채택·신규 섹션이 근거(출처 링크)와 함께 추적 가능하다
