## 🧭 채택 시안 요약 (작성 근거)

채택된 시안은 PDF 명세 §2-01-4의 기본 구성에서 **예약카드를 분리하지 않고 "출석 등록" 안내 카드 + 버튼으로 단순화**한 버전. 따라서 상세 페이지 콘텐츠도 **"한 페이지에서 RSVP·직군·관심 분야를 한 번에 받고, 출석 등록까지 페이지 안에서 잇는다"** 로 메시지 톤을 정렬.

시안 카드 구성 (9개):
1. 이미지 — 주최측 로고 (ABC COMPANY · 보라 원형 + A 모노그램)
2. 텍스트 — `YOU ARE INVITED` + `2026 채용설명회`
3. 텍스트 — 초대 메시지
4. 텍스트 — 일시·장소
5. 위치 안내 — 지도
6. 질문과 답변 — **사전 참석 신청서** (성함·전화·지원 직군 복수선택·관심 분야)
7~8. 버튼 — **출석 등록** 안내 + `출석 등록하기`
9. 버튼 — 인사팀에 문의하기

무드: **🌑 모던/시크** (다크 배경 + 퍼플 강조 + 화이트 격조)

### 추천 대상 (항목 반복 · 2개)
> 💡 피그마 슬롯 = 추천 대상 2개. PDF의 페르소나 4종 중 가장 모집단이 큰 2개로 압축.

1. **외부 폼 2개 + 엑셀 병합으로 좌석표가 안 끝나는 대기업·중견기업 인사팀**
2. **D-30 ~ D-Day 사이에 RSVP·세션·도착 인증을 한 번에 운영해야 하는 채용 BD·행사 담당**

## C. 우측 하단 "스와이퍼 영역" — 주요 기능 2개

> 💡 PDF 명세는 4개 특징이나 피그마 슬롯은 2개. 채택 시안 카드 구성과 정합되는 2개를 선택.

### 주요기능-1 — 사전 참석 신청서 한 카드로 통합 집계
| 필드 | 카피 |
|---|---|
| 제목 | **구글폼·엑셀 병합 없이, 신청서 한 장으로 끝** |
| 설명 | 성함·전화번호·지원 직군(복수 선택)·관심 분야를 **질문과 답변 카드 하나**에 묶었습니다. 외부 폼 2개와 엑셀을 따로 돌리지 않아도, 한 번의 응답으로 RSVP·세션·관심사가 동시에 집계됩니다. |
| 표시 순서 | 1 |
| 아이콘 이미지 (38×38) | **디자인 시스템 카드 배지 — `Icon/Special/Badge/QnA`** ([node 13220:36068](https://www.figma.com/design/9GM1FagjqiyrQHyHLBGoFj/CdBd-Design-System?node-id=13220-36068)) · 색상 override **WHITE**. 채택 시안 6번 카드(질문과 답변)와 1:1 정합 |
| 설명 이미지 (360×300) | 시안 6번 카드 클로즈업 — 직군 체크박스 5개(개발/디자인/마케팅/기획/영업) + `신청하기` 버튼 가시화 |

### 주요기능-2 — 출석 등록 + QR 패스 SMS
| 필드 | 카피 |
|---|---|
| 제목 | **출석 등록까지 페이지 안에서, QR 패스는 SMS로 자동 발송** |
| 설명 | 출석 등록 안내 카드에서 시간대를 선택하고 휴대폰 본인 인증을 마치면, 도착 인증 패스 QR이 SMS로 발송됩니다. 행사 당일 입구 줄·수기 명단 체크 없이 QR 한 번으로 출석이 끝납니다. |
| 표시 순서 | 2 |
| 아이콘 이미지 (38×38) | **디자인 시스템 카드 배지 — `Icon/Special/Badge/Reservation`** ([node 13220:36080](https://www.figma.com/design/9GM1FagjqiyrQHyHLBGoFj/CdBd-Design-System?node-id=13220-36080)) · 색상 override **WHITE**. 출석 등록(예약 기능)을 대표 |
| 설명 이미지 (360×300) | 시안 7~8번 카드 클로즈업 — `출석 등록` 안내 텍스트 + 보라 `출석 등록하기` 버튼 + (오버레이) SMS 도착 인증 화면 |

## E. 신규 등록 처리 규칙 체크리스트

- [x] 카테고리 = **초대·예약** 1개만 체크
- [x] 슬러그 = `recruit-rsvp` (영문 소문자 + 하이픈, [[CLAUDE.md#🆔 슬러그 명명 규칙|규칙]] 정합)
- [ ] 복제 시 **`10회 사용 / ★4.9` 배지 삭제** (신규 등록은 누적 데이터 없음)
- [ ] 추천 대상 항목 = **2개**로 유지 (피그마 슬롯 정합)
- [ ] 주요 기능 = **2개** (아이콘 38×38 + 설명 이미지 360×300 각각 첨부)
- [ ] 대표 이미지 = 보드 상단 200×200 = 소개 박스 134×134 **동일 이미지**
- [ ] 본문은 페이지 전·중·후 흐름을 한 단락 안에 담을 것 (외부 폼 통증 → 카드 통합 → 출석까지)

## F. 미정 / 사용자 확인 필요

- ❓ **에디터 ID** — 4단계 라이브 페이지 구현 후 채움
- ❓ **아이콘 이미지 2종 (38×38)** — 신규 제작 필요. 무드 🌑 모던/시크 정합 (다크 배경 + 퍼플) 권장
- ❓ **부제목 라벨 카피** — `사용 성과`로 기본 선택. 인사팀 톤에 맞춰 `도입 결과`·`주요 효과`로 교체 가능
- ❓ **추천 대상 2개 표현** — PDF 페르소나 4종 중 2개로 압축했음. 사용자가 다른 조합 선호 시 교체
- ❓ **본문 중 "8시간 → 30분"** — 채택 가능한 수치인지 확인 (PDF는 "좌석 배정 시간 80%↓"만 기재, "30분"은 본 문서가 환산)
