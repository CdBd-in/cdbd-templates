## 🧭 채택 시안 요약 (작성 근거)

채택된 시안은 PDF 명세 §2-01-4의 기본 구성에서 **예약카드를 분리하지 않고 "출석 등록" 안내 카드 + 버튼으로 단순화**한 버전. 따라서 상세 페이지 콘텐츠도 **"한 페이지에서 RSVP·직군·관심 분야를 한 번에 받고, 출석 등록까지 페이지 안에서 잇는다"** 로 메시지 톤을 정렬.

시안 카드 구성 (9개):
1. 이미지 — 주최측 로고 (ABC COMPANY · 보라 원형 + A 모노그램)
2. 텍스트 — `YOU ARE INVITED` + `2026 채용설명회`
3. 텍스트 — 초대 메시지
4. 텍스트 — 일시·장소
5. 위치 안내 — 지도
6. 질문과 답변 — **사전 참석 신청서** (성함·전화·지원 직군 복수선택·관심 분야)
7~8. 버튼 — **출석 등록** 안내 + `출석 등록하기`
9. 버튼 — 인사팀에 문의하기

무드: **🌑 모던/시크** (다크 배경 + 퍼플 강조 + 화이트 격조)

## H'. 썸네일 배경색 산정 룰

**썸네일(thumb)의 배경색은 페이지의 포인트 색상(보통 = 버튼색)에 dim 15%를 별도 색상 레이어로 얹어 만든다.** Dim 방향은 베이스 색상의 명도에 따라 결정:

| 베이스 색상 HSL Lightness | Dim 방향 |
|---|---|
| **L ≥ 50** (밝음) | **Black dim 15%** (별도 SOLID 레이어, opacity 15%) → 약간 어둡게 |
| **L < 50** (어두움) | **White dim 15%** (별도 SOLID 레이어, opacity 15%) → 약간 밝게 |

**구현 (Figma)**:
```
thumb.fills = [
  { type: 'SOLID', color: BASE },                                  // 베이스 (페이지 버튼색)
  { type: 'SOLID', color: { r: 0, g: 0, b: 0 }, opacity: 0.15 },   // dim 오버레이 (밝은 베이스면 black, 어두우면 white)
]
```
