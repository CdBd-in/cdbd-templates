# S2 실기 스크립트 — 어느 것을 쓰나 (2026-10-22 갱신)

| 스크립트 | 상태 | 비고 |
|---|---|---|
| **`s2js.sh`** | 🟢 **현행 권장** | JS(DOM) 기반. `browse snapshot`이 이 빌드에서 버튼을 0개로 반환해 `s2run.sh`가 공전하는 문제를 우회 |
| `s2run.sh` | 🟡 보조 | snapshot ref 기반. 경로·가드는 고쳤으나 **T4(snapshot 빈 트리)에 여전히 취약** |

## s2js.sh 사용법
```bash
export S2_AR=".../아카이브/YYYY-MM-DD/s2"
export BROWSE_STATE_FILE=/tmp/browse-s2-state.json   # 🔒 기본값 · 다른 browse 작업과 격리
./s2js.sh <사례ID> "<설명>"
```

## 🔒 반드시 지키는 것
1. **격리 세션** — 리서치 등 다른 browse 작업과 데몬을 공유하면 S2가 엉뚱한 사이트를 CdBd로 착각해 런이 통째로 무효가 된다(2026-10-22 실제 발생 · `아카이브/2026-10-22-5호/무효런/`).
2. **도메인 가드** — 매 단계 URL을 확인하고 CdBd 밖이면 `exit 3`.
3. **자동 우회 금지** — 막히면 **중단·기록**이지 「항목 지우기」로 넘어가지 않는다(§0-9).
4. **버튼 탐색은 글자 + `aria-label` 둘 다** — 「보내기」·「자료 첨부」는 아이콘뿐이라 innerText가 빈 값.
5. **클릭 결과를 로그에 남긴다** — 조용한 실패는 한참 뒤 엉뚱한 지점에서 발각된다.
6. **관측값이 비어 있으면 「미측정」** — 버튼 0개·텍스트 0자는 「막힘」이 아니다. 두 번째 경로(JS DOM·스크린샷)로 교차 확인할 것. (리포트 5호 제안 M · 승인 대기)

## 알려진 환경 특성
- 로그인 = **비밀번호 칸에서 Enter**(「로그인하기」 클릭 무반응)
- 시안 생성 중에는 **버튼 0개 + `browse text` 빈 값** — 정상이다. 「시작하기」 등장까지 폴링할 것
- 에디터 프리뷰 스크롤 컨테이너 = `div.absolute.inset-0.overflow-y-scroll`

## 🔎 에디터 자동 검사 (`editor-audit/` · 2026-10-23)
`s2js.sh`가 에디터에 도착하면 **마지막에 자동으로** 돈다(실패해도 런은 유지 · 「미측정」 기록).
화면 채점이 80점↑을 준 페이지에서도 **빈 줄·견본 값·여백 겹침·견본 이모지**가 나왔다(2026-10-23 피드백 6건) → 화면이 아니라 **에디터 데이터로** 잡는다.

```bash
export BROWSE_STATE_FILE=/tmp/browse-s2-state.json        # 격리 세션
./editor-audit/run.sh <출력폴더> <에디터ID> [<에디터ID> …]   # 덤프 → 검사 → <ID>-audit.md / .json
CDBD_BASE=https://www.cdbd.in ./editor-audit/run.sh …       # www 도메인 에디터일 때(그 도메인 로그인 필요)
```
- 결과 한 줄 = `치명 C · 주요 M · 경미 m · 데이터 점수` — **치명 1개 = 즉시 FAIL**(무드 미적용·견본 값 잔존)
- 각 줄 끝 `→ 빌더 / 원본 / 개발` = **고칠 곳**(빌더 = MD·생성 · 원본 = 섹션 원본 수정)
- 판정 기준 정본 = [[4-9-5. 빌더 산출물 자동 스코어링 기준]] §3 S11 — **체크를 바꾸면 audit.py도 같이**
- 원본 대조(빈 줄의 원본 결함 구분 · 여러 줄 칸 · 견본 이모지)는 `presets.json`(프리셋 어드민 목록 · 출력폴더에 없으면 자동으로 받음)이 있어야 한다
