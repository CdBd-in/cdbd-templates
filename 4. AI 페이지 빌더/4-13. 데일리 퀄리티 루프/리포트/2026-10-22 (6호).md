## 3. S2 — Z3(사진전) 재시도: 에디터 완주

5호에서 Z3는 **문의 유형 화면(②)에서 검증 실패로 「다음」이 사라져 중단**됐습니다. "다음 호" 과제대로 재시도했습니다.

- **입력**: 원본 로그 기반으로 재구성한 설명(정확히 동일하지 않을 수 있음, 투명하게 명시) — "PHOTO EXHIBITION 빛의 기록 — 김서연, 박도윤, 이하늘 세 작가가 담은 빛의 순간들을 대구에서 만나보세요. 2026년 11월 3일(화)~11월 30일(월), 대구 중구 봉산문화회관 2전시실, 화~일 오전 10시-오후 6시(월요일 휴관), 관람료 무료."
- **로그인 확인**: `account@emka.group` 로그인 전 세션 충돌 신호(409·"다른 기기에서 사용 중" 등) **없음** 확인 후 진행(규칙 6).
- **결과**: 이번엔 문의 화면에서 유형/값이 **비어있는 상태(추가하기 placeholder)로 남아** 검증 오류가 발생하지 않았고, **46초 만에 에디터(`/editor/7011`)까지 완주**했습니다. → **②는 간헐적 버그임을 재확인**(5호가 이미 "3회 중 1회"로 기록한 것과 일치, 이번엔 0회).
- **산출물**: 제목·부제·행사정보(일시·관람시간·장소·관람료)는 전부 정확하게 카드로 생성됨(스크린샷: `아카이브/2026-10-22-6호/s2/Z3retry-editor-board.png`). 참여작가 설명·오시는 길·문의 카드는 **최종 산출물에 없음**(10장 카드 전부 확인 — 자동 삭제 추정, 아래 참고).
- 💰 크레딧: 발행(URL 생성) 버튼을 누르지 않았으므로 과금 없음(행위 기준 확인 — 잔액 표기 자체는 홈 화면에서 패턴 매칭 실패로 **미확인**).

### 🆕 기존 ⑥("마지막 확인 미리보기 견본값 혼동")의 새 증거 (참고용 — 새 항목 아님)

이번 재시도의 「마지막 확인」 화면에 **"문의 📞 02-000-0000 💬 pf.kakao.com/_cdbd ✉️ cdbd@cdbd.com 🏠 www.cdbd.com 아직 비어있는 곳이 4개 있어요"** 가 동시에 떴습니다. `02-000-0000`·`pf.kakao.com/_cdbd`·`cdbd@cdbd.com`은 CdBd 자체 견본 연락처이고, 유저는 문의 수단을 입력한 적이 없습니다. "비어있음"이라는 경고와 실제 같은 자리에 견본 연락처가 **보이는** 모순이 ⑥과 동일 패턴으로 재현됐습니다.

- **좋은 소식 1가지**: 에디터(`editor/7011`)의 실제 카드 텍스트를 전수 검사한 결과 `02-000-0000`·`pf.kakao.com`·`cdbd@cdbd.com` 문자열이 **전혀 없었습니다** → 이번 건으로는 **이 버그가 "미리보기 렌더링에 한정"되고 실제 저장 데이터를 오염시키지는 않는다**는 정황이 하나 더 쌓였습니다. 기존 개발 전달 문구("①미리보기는 실제 저장된 값만 보여 주세요")에 참고로 붙일 만합니다.
- ⚠️ **증거 등급 — §0-8 기준 미충족, 새 항목 승격 안 함**: 이 화면의 스크린샷은 **저희 쪽 자동화 스크립트의 경로 버그로 저장되지 않았습니다**(상대경로로 `screenshot`을 호출해 조용히 실패 — 아래 5절 도구결함 참고). 텍스트 로그(`아카이브/2026-10-22-6호/s2/Z3retry-log.txt` 1행)에는 해당 화면의 전체 문구가 타임스탬프와 함께 남아 있어 교차 확인은 가능하지만, **§0-8이 요구하는 이미지 증거가 없어 새 개발 전달 항목으로 올리지 않고 기존 ⑥에 참고 각주로만 남깁니다.**
