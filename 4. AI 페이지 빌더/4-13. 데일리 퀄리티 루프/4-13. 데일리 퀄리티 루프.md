## 4. content 태그 사전 — 🚧 초안 (리포트 1호 승인 대기)

> 4-7 질문 세트 279칸 + 4-12 부품 23종에서 역산한 **닫힌 어휘 22개**. 복수 태그 허용. 서랍(목적 13칸)이 이미 거르는 정보(주소·폼 질문·히어로 카피 등)는 태그 ❌. **신규 태그 추가는 리포트 승인 경유.**

| 태그 | 다는 조건 (기계 판정) | 대표 근거 칸 |
|---|---|---|
| `일시·기간` | 단일 날짜/일시 패턴(`YYYY.`·`hh:mm`·종료 `~`) + 요일 라벨 반복 아님 | 행사 일시·출시일·마감일 |
| `운영시간` | 반복 행 라벨 = 요일 어휘(월~일·평일·주말) + 값 `hh:mm` | 영업시간·매장 정보 |
| `장소명` | `장소` 라벨 행 + 지도 슬롯 없음 (텍스트 한 줄) | 행사 장소·전시장 이름 |
| `가격·요금` | 통화 패턴(`원`·`₩`) 또는 정상가→판매가/할인율 쌍 | 가격·참가비·이용 요금 |
| `혜택·쿠폰` | 쿠폰 코드 박스 또는 `N% 할인`·`증정`·`무료` 견본 | 오픈 혜택·쿠폰 |
| `계좌·송금` | 계좌번호 패턴 + 은행명·예금주 | 후원 계좌 |
| `메뉴·품목` | 반복 행 = 이름(+가격)(+이미지), 행별 구매 버튼 없음 | 메뉴·취급 품목 |
| `스펙·제원 표` | 항목 내 라벨+값 반복 + 단위·재질 견본(cm·kg·소재) | 제품 스펙·실측 |
| `시간표·프로그램` | 반복 행마다 `hh:mm` + 항목 제목 쌍 | 행사 프로그램·세션 |
| `절차·단계` | 넘버링 견본(`01`·`STEP`) + 시각 없음 | 이용 단계·주문 방법 |
| `분류 2단` | 그룹 라벨 + 하위 항목 2단 반복 | 카탈로그 인덱스·부문 |
| `모집 요강` | 라벨 집합 {정원·대상·자격·접수 기간·참가비·마감} 중 1+ | 모집 정보·참가 자격 |
| `인물` | 반복 항목 = 인물 사진 + 이름 + 소속·직함 | 연사·강사·팀 |
| `이력·경력` | 연도 범위 패턴(`YYYY–YYYY`) + 소속/역할 | 경력·학력·수상 |
| `실적·수치` | 큰 숫자+단위(28px↑) 또는 납품처 명단 | 대표 실적 |
| `후기·사례` | 별점(`★`)·작성자·인용부호 중 1+ 반복 | 후기·사례 |
| `FAQ` | 반복 항목 = Q/A 텍스트 쌍 | 자주 묻는 질문 |
| `유의사항·규정` | 한 줄 리스트 + {유의·취소·환불·배송·교환·규정·준비물} | 유의사항·배송·환불 |
| `사진 모음` | 이미지 슬롯 2+ (IMAGE fill 포함) + 이미지별 텍스트 쌍 없음 | 공간·활동 사진 |
| `소식·아티클` | 반복 = 제목+요약(+이미지)(+링크/날짜) | 소식·지난 호 |
| `채널·링크` | 반복 행 = 버튼명+URL 쌍 또는 SNS 묶음(문의 서랍 밖) | 링크 모음 |
| `영상` | 유튜브/영상 임베드 슬롯 | 대표 영상 (§7-A 신설 예약) |

경계 판례: 준비물·배송·교환·환불 → `유의사항·규정` 흡수 / 일시↔운영시간↔시간표 = 3갈래 조건으로 분리 / 작품 캡션 = `사진 모음`+`스펙·제원 표` 복수 부여 / 버튼 없는 진열 행은 `메뉴·품목`(구매 서랍과 구분 = 행별 구매 버튼 유무).

**기록 위치**: 어드민 프리셋 「메모」(정본) + `preset-index.json`(미러 · 충돌 시 어드민 우선). 메모 고정 포맷:
```
content: 가격·요금, 스펙·제원 표
weight: heavy
items: 2~4
```
🚧 개발 확인 대기: 메모가 AI 섹션 선정 입력에 포함되는가.

## 5. weight · items_range 판정 기준 (정본)

- `weight` — **heavy** = 색 밴드·풀블리드 이미지·대면적 틴트 / **medium** = 이미지 1+ 또는 틴트 카드 배경 / **light** = 투명 배경·텍스트 위주. 🔗 **리듬 체크 로직과 한 묶음**: 조립 중 light 3연속 → 다음 후보 medium+ / heavy 연속 금지. 검수 시 weight 나열만으로 단조(전부 light)·과밀(heavy 연속) 플래그.
- `items_range` — **제약 있는 섹션에만** (없으면 자유): 핵심 정보 max 4 · 2열 min 2 · 캐러셀 min 4 · 갤러리 max 15. 기존 산문 규칙의 섹션별 기계화.
- 삭제된 필드 (재제안 ❌): `evidence`(리포트가 추적 담당) · `mood_fit`(섹션은 무드 중립 — 무드 종속이면 관문에서 거를 것) · images/items/logo/text_len(기존 `slots` 파싱으로 파생).
