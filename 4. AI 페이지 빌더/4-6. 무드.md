# 무드 — AI가 색·폰트를 정하는 기준

> 🎯 **이 문서의 역할** = **「어떻게 고르나」**(판단 기준).
> 📚 **「무엇이 있나」**(자산 목록)는 원본이 정본 — 팔레트 316개 전체 표 = [[1-3. 색상 팔레트]] · 폰트 44종 전체 표 = [[1-4. 폰트]].
> 🔑 **무드 하나를 정하면 색과 폰트가 같이 정해진다.** 두 문서가 **같은 9개 무드 체계**를 쓰기 때문이다. 그래서 AI는 「색을 고르고 폰트를 고르는」 게 아니라 **「무드를 고른다」**.

> 🎉 **펀 무드는 「깔끔한 고딕」으로 간다** *(2026-09-11 이선호 확정)* — 이 무드의 시그니처 폰트(HS산토끼체·모야모야·와구리체·창원단감아삭체·학교안심 마법사·Tiqui Taca)는 **전부 시안 사용 금지 10종**이다(§5). 남은 것으로 억지로 캐릭터 느낌을 내려 하지 말고 **프리텐다드 같은 깔끔한 고딕**으로 간다.
> - **발랄함은 서체가 아니라 「색 · 큰 글자 · 둥근 모서리 · 이미지」로 낸다** — 펀 팔레트 30개가 이미 밝고 채도 높다.
> - **제목으로 성격을 낸다** — 굵고 발랄한 **G마켓 산스**, 아동·교육 톤이면 **학교안심 돋보기**(단정한 교과서체). 둘 다 **제목 전용**이고 본문은 프리텐다드로 받는다.
> ⚠️ **🔥 비비드는 제목 전용 무드** — 본문은 모던/시크나 프로/비즈니스에서 빌려 온다.

## 2. 무드를 정하는 순서 6단계

> 🚫 **표 맨 윗줄부터 집지 말 것.** 이게 가장 자주 뚫린다 — 예전에 시안 3안이 전부 같은 출처·표 상단 팔레트로 나왔다. **표 상단 앵커링은 랜덤보다 나쁘다**(랜덤은 매번 다르지만 앵커링은 매번 같은 걸 낸다).

```
①~③ = 「검색 조건 만들기」          ⑥ = 「서랍에서 뽑기」
```

1. **🎬 주제의 실제 장면에서 색을 뽑는다** — 그 페이지가 존재하는 공간·사물의 색. **표를 열기 전에.** (북토크라면 → 잉크·크림·전구 호박·가죽·야간 남색)
2. **🏷 브랜드 자산을 앵커로** — 로고 색·시그니처 색이 있으면 3토큰 중 하나에 반영.
3. **🎨 무드로 톤 조정** — 같은 「전구빛」도 모던이면 차분한 황동, 드리미면 밝은 호박.
4. **✅ 대비 2개 직접 계산** — `텍스트↔배경 ≥ 3.6:1` **그리고** `버튼↔배경 ≥ 3.6:1`.
5. **🔁 3안 분산** — §3.
6. **📚 그 무드 서랍에서 채택** — 조건에 가까운 줄을 고른다. **새로 만들지 않는다.**

### 뽑는 방식 = 층화 랜덤

「가장 나은 하나」를 고르려 하면 **매번 같은 자리를 집는다.** 그래서:

```
후보 = 그 무드 서랍에서 ①~③ 조건에 맞는 것만 추림
안별로 「배경 명도 칸」을 먼저 배정 (밝음/밝음/어두움 등)
 → 그 칸 안에서 랜덤으로 뽑음
직전 배치에 쓴 팔레트는 후보에서 제외 · 난수 시드는 기록에 남김
```

서랍이 무드당 30개 안팎이라 칸을 나눠도 후보는 충분하다. 프리셋도 같은 로직 → [[4-5. 섹션 프리셋 라이브러리]] 「거른 뒤 랜덤」.

### 라이브러리에 정말 없으면

가장 가까운 팔레트를 고르고 **한 토큰만** 브랜드 색으로 교체한다(3토큰 전부 창작 ❌). 어느 팔레트의 어느 토큰을 바꿨는지 보고하고, 쓸 만하면 [[1-3. 색상 팔레트]]에 새 줄로 추가해 다음부터 「고르는」 대상이 되게 한다.

## 3. 시안 3안은 서로 달라야 한다

> ⚠️ **①(주제에서 뽑기)은 3안을 수렴시킨다** — 같은 주제니까 같은 재료로 간다. 그래서 ①을 지킬수록 이 규칙이 더 중요해진다.

| 축 | 규칙 |
|---|---|
| **배경 명도** | 3안이 방향을 나눠 갖는다. **금지 = 3안 전부 같은 방향**(3라이트·3다크). 비율은 자유(밝음2:다크1도, 다크2:밝음1도 OK) |
| **순백/순흑 탈피** | 화이트-근접·블랙-근접만 쓰지 말 것. 라이트 = 크림·오트·베이지·세이지 / 다크 = 딥네이비·딥그린·에스프레소·잉크 · 중간 명도도 OK |
| **액센트 hue** | **최소 2계열**(웜/쿨/뉴트럴). **3안 전부 웜 ❌** — 명도만 벌리는 건(황동 vs 호박) 같은 웜이라 부족 |

**교정 예**: 안1 라이트+뉴트럴(종이·차콜) / 안2 라이트+웜(크림·가죽) / 안3 다크+쿨(야간·달빛블루) — 명도는 1·2가 겹치지만 hue가 갈리고, 3안은 둘 다 혼자다.

## 4. 색 규칙 (AI가 지켜야 할 것만)

### 역할 매핑

| 팔레트 | 색1 | 색2 | 색3 |
|---|---|---|---|
| **3색** (기본) | `{배경색}` | `{텍스트색}` | `{버튼색}` |
| **2색** | `{배경색}` | `{텍스트색}` + `{버튼색}` (동일) | — |

- **2색보다 3색이 기본** — 2색은 액센트가 없어 위계가 약하다.
- **보조 텍스트는 `{텍스트색} × 60%` / `× 40%`** — 별도 회색 지정 ❌.
- **섹션·카드 강조 배경은 `{버튼색} × N%`** (텍스트색 ❌).

### 버튼이 안 읽히는 문제

CdBd는 **버튼 글자 = `{배경색}` 고정**이다. 그래서 **`{버튼색}`↔`{배경색}` 대비가 낮으면 버튼 글자도 같이 안 읽힌다.**

- 🔴 [[1-3. 색상 팔레트]]의 「대비」 열은 **텍스트↔배경만** 잰 값이다. **버튼 대비는 반드시 직접 계산.**
- ⚠️ MyMind·HappyHues 출처 69개 중 **22개가 버튼 대비 미달**. Huemint 180개는 양쪽 다 검증 완료.
- 🔤 **예외** — 버튼 글자를 `{텍스트색}`으로 바꾸면 살아나는 팔레트가 6개 있다(4단계에서 `block.innerStyle.color`). 단 이 예외는 **글자 가독성만** 고치고 **버튼이 배경에 묻히는 형태 문제는 못 고친다.**

## 5. 폰트 규칙 (AI가 지켜야 할 것만)

| 규칙 | 내용 |
|---|---|
| **44종 밖 ❌** | CdBd 에디터에 없는 폰트는 4단계에서 재현 불가. **Figma에서 로드된다고 쓸 수 있는 게 아니다.** 자주 하는 실수: IBM Plex Sans KR · Black Han Sans · Space Grotesk · Gothic A1 · Fredoka · Jua · Syne · Cormorant · 제주명조 · Unbounded |
| **과잉 컨셉 10종 ❌** | HS산토끼체 · 베이글팻 · 학교안심 마법사 · 카페24 모야모야 · 와구리체 · 창원단감아삭체 · 평창평화체 · 파셜산스 / Tiqui Taca · Poiret One — **44종엔 있지만 시안 채택 ❌**. 허용 예외 3종 = 태백 은하수체 · 마포꽃섬 · Zeyada |
| **국문 본문 = 한글 폰트** | 영문 폰트로 한글 본문을 쓰면 시스템 fallback으로 렌더링돼 통일성이 깨진다. 영문 폰트는 **제목·로고 등 장식 텍스트만** |
| **한 페이지 = 1~2개** | 기본 1개. 제목/본문 분리할 때만 2개. 3개 이상 ❌ |
| **텍스트만 반복되는 페이지 = 2종 필수** | 사진·색 밴드·틴트 카드가 없어 리듬이 없는 페이지(공지·안내문)는 **제목·본문 서체를 반드시 분리**. 반대로 이미지가 리듬을 만드는 페이지는 1종도 OK |
| **제목 서체는 「톤」에도 맞아야** | 명조(세리프) = 감성·에디토리얼·문학. **기능성·정보 전달형(공지·휴관·모노톤)엔 명조가 계속 겉돈다** → 이런 유형은 제목도 산세리프로 대비를 준다 |
| **비즈니스·명함 = 명조 ❌** | 세무·법무·컨설팅·영업용 명함은 본문·제목 **모두 산세리프**. 프로/비즈니스 무드 표엔 명조가 없지만, **다른 무드의 명조를 끌어오는 실수**를 막기 위해 명시 |
| **고운돋움 = 명조 취급** | 이름만 「돋움」, 골격은 명조. ① **G마켓 산스 + 고운돋움 ❌** ② **고운돋움 + 다른 명조 ❌**. 위반 발견 = 고운돋움 → 프리텐다드 |
| **디스플레이 폰트로 본문 ❌** | 베이글팻·HS산토끼체·평창평화체 등은 제목 전용. 반대로 **KoPub돋움은 본문 전용**(제목 ❌ → 프리텐다드) |
| **안전 폴백** | 망설여지면 **프리텐다드 단일**. 명조 페이지의 폴백은 **본명조 단일** |

## 6. 「무드에 맞음」이 「주제에 맞음」은 아니다

> 🔴 **가장 비싼 실패.** 라이브러리의 **그 무드 서랍에 실재하는 색**이라도 주제와 안 맞으면 실패다. 실측 2건 — **바다·서핑**인데 3안 모두 블루 없음 · **미술관 전시 도록**인데 **연분홍 배경**(모던/시크 서랍에 실재하는 색이었다).

- ✅ **3안 중 최소 1안은 주제 장면이 연상되는 색** — 바다=블루/틸 · 녹차=그린 · 원두=브라운
- ✅ **「담는 그릇」이 되어야 하는 주제 = 뉴트럴 배경** — 기관·전시·도록·B2B 제조 → 그레이·오프화이트·아이보리 + 절제된 액센트. **파스텔 핑크·마젠타 배경 ❌**
- ✅ **신뢰형(세무·법무·컨설팅·명함) = 차분한 톤** — 쨍한 원색·형광 ❌
- ✅ **화보·미니멀·여리여리한 주제 = 쨍한 팔레트 지양** — 대비 2개는 지키되 **채도를 낮춘다**
- 🔍 **자동 탐지** — 배경 hue **300~360(핑크·마젠타)** 이거나 **채도×명도 > 0.35** 인 안을 스캔해 주제와 대조 (75안 스캔에서 2건 적발)
