# 무드 — AI가 색·폰트를 정하는 기준

> 🎯 **이 문서의 역할** = **「어떤 주제가 어떤 무드인가」**(판단 기준)만.
> 📚 **자산 목록**(팔레트 315개 표 · 폰트 44종 표)과 **선택 절차·색/폰트 규칙 전문**은 원본이 정본 — [[1-3. 색상 팔레트]] · [[1-4. 폰트]]. 이 문서는 **판단 기준 + 원본으로 가는 포인터**만 둔다(규칙 전문을 여기 복제하지 않는다).
> 🔄 **고치는 곳** — 목록·규칙이 바뀌면 원본(1-3 · 1-4)을, 무드 판단 기준이 바뀌면 이 문서를 고친다.
> 🔑 **무드 하나를 정하면 색과 폰트가 같이 정해진다.** 두 원본이 **같은 9개 무드 체계**를 쓰기 때문이다. 그래서 AI는 「색을 고르고 폰트를 고르는」 게 아니라 **「무드를 고른다」**.

---

> 🏷 **무드 이름 간소화** — 유저에게 보이는 칩 이름을 **한 단어**로 줄였다. 뒷말(오가닉·로맨틱·엘레강스…)은 **전부 뺀다**.
> `내추럴/오가닉→내추럴` · `페미닌/로맨틱→페미닌` · `럭셔리/엘레강스→럭셔리` · `프로페셔널/비즈니스→프로페셔널` · `모던/시크→모던` · `비비드/대담한→비비드` · `빈티지/노스탤직→빈티지` · **`펀/플레이풀→플레이풀`** · **`드리미/감성적→감성적`**
> ⚠️ 마지막 둘은 **앞말이 바뀐다** — 「펀」·「드리미」라고 부르지 말 것. 9개 카테고리의 **내용·분류 기준은 그대로**이고 **이름만** 바뀌었다.

## 1. 무드 9개 — 언제 쓰나

| 무드 | 이럴 때 |
|---|---|
| 🌿 내추럴 | 카페·웰빙·친환경·식물·수제 |
| 🌸 페미닌 | 뷰티·웨딩·플로리스트·디저트 |
| ✨ 럭셔리 | 호텔·주얼리·파인다이닝·갤러리 |
| 💼 프로페셔널 | 세무·법무·컨설팅·의료·금융·B2B·명함 |
| 🌑 모던 | 패션·디자인 스튜디오·미니멀·연극·공연 |
| 🔥 비비드 | 프로모션·세일·스포츠·신상품·이벤트 |
| 🎨 빈티지 | 책방·아카이브·레트로·매거진·핸드메이드 |
| 🎉 플레이풀 | 아동·교육·캐릭터·로컬 푸드·굿즈 |
| 🌙 감성적 | 시·에세이·향수·명상·감성 굿즈·갤러리 카페·연극·공연 |

- 📚 **무드별 팔레트 목록·개수** = [[1-3. 색상 팔레트]] 무드별 표 · **무드별 폰트 추천·조합** = [[1-4. 폰트]] 무드별 표 + 「🤝 어울리는 폰트 조합 가이드」. (수치를 여기 적지 않는다 — 원본이 늘면 어긋난다.)
- 🎉 **플레이풀은 「깔끔한 고딕」으로 간다** — 시그니처 폰트 6종이 전부 시안 금지 10종이라, 발랄함은 서체가 아니라 **색·큰 글자·둥근 모서리·이미지**로 낸다 → [[1-4. 폰트#🎉 플레이풀 조합]].
- 🔥 **비비드는 제목 전용 무드** — 본문은 모던·프로페셔널에서 빌려 온다 → [[1-4. 폰트#🔥 비비드 조합]].

## 4. 색 규칙

- **역할 매핑**(3색 = 배경/텍스트/버튼 · 2색 = 배경/텍스트+버튼 동일 · 3색이 기본) → 정본 [[1-3. 색상 팔레트#🎯 역할 매핑 규칙]]
- **버튼 글자색**(기본 `{배경색}` · 예외 13개만 「버튼글자」 열에 `텍스트색` · 라이브러리에서 고르는 한 대비 재계산 ❌) → 정본 [[1-3. 색상 팔레트#🔤 「버튼글자」 열 — 버튼 안 글자색]]
- **기본값 닮은 팔레트 제외**(`#fafafa`·`#292929`·`#6C4CFF` 근처 = 무드 적용 실패로 보임) → 정본 [[1-3. 색상 팔레트#🎯 팔레트 채택 절차 — 6단계 (필수)]] ⑥
- 🚫 **투명도(보조 텍스트 · 강조 배경)는 정하지 않는다** — 섹션 원본에 **이미 들어 있다**. 무드 적용은 **색 hex만 바꾸는 일**이고, 투명도는 그대로 따라온다. *(AI 빌더 고유 규칙 — 여기가 정본)*

## 6. 「무드에 맞음」이 「주제에 맞음」은 아니다

> 🔴 **가장 비싼 실패.** 라이브러리의 **그 무드 서랍에 실재하는 색**이라도 주제와 안 맞으면 실패다. 실측 2건 — **바다·서핑**인데 3안 모두 블루 없음 · **미술관 전시 도록**인데 **연분홍 배경**(모던 서랍에 실재하는 색이었다). *(같은 규칙이 [[1-3. 색상 팔레트#🎯 팔레트 채택 절차 — 6단계 (필수)]] ③에도 있다 — 고치면 양쪽 함께.)*

- ✅ **3안 중 최소 1안은 주제 장면이 연상되는 색** — 바다=블루/틸 · 녹차=그린 · 원두=브라운
- ✅ **「담는 그릇」이 되어야 하는 주제 = 뉴트럴 배경** — 기관·전시·도록·B2B 제조 → 그레이·오프화이트·아이보리 + 절제된 액센트. **파스텔 핑크·마젠타 배경 ❌**
- ✅ **신뢰형(세무·법무·컨설팅·명함) = 차분한 톤** — 쨍한 원색·형광 ❌
- ✅ **화보·미니멀·여리여리한 주제 = 쨍한 팔레트 지양** — 대비 2개는 지키되 **채도를 낮춘다**
- 🔍 **자동 탐지** — 배경 hue **300~360(핑크·마젠타)** 이거나 **채도×명도 > 0.35** 인 안을 스캔해 주제와 대조 (75안 스캔에서 2건 적발)

### 레퍼런스 무드 메모 — 「주제 장면 색」 예시 (점수 대신 여기에 적는다)

> 레퍼런스 채점에서 무드는 **점수에 넣지 않는다**(프리셋엔 무드가 실리지 않음 · [[4-13. 데일리 퀄리티 루프]] §3). 대신 **주제와 색이 잘 맞물린 사례**는 여기에 적어 두고, 채택 절차 ①「주제의 실제 장면에서 색을 뽑는다」의 재료로 쓴다. 색은 이 메모에서 **고르지 않는다** — 라이브러리 315개에서 비슷한 줄을 찾는 **검색 조건**으로만 쓴다.

| 주제 | 장면 색 | 무드 | 출처 |
|---|---|---|---|
| 골프·컨트리클럽 | 크림 배경 · 딥 포레스트그린(어두운 구간) · 골드 액센트 버튼 · 세리프 로고타입 | ✨ 럭셔리 | Emerald Fairways (dribbble · 2026-10-21) |
