# 4-11. 실패·예외 처리

> 🔴 **왜 필요한가**: MD 지침은 전부 **「자료가 있고, 유저가 협조하고, 후보가 넉넉한」** 정상 경로만 쓰여 있다. 실제로는 아래가 **매일** 일어난다. 지금은 전부 *"알아서"* 상태다.
> 📥 칸 정의 = [[MD-00. 단계별 누적 정보]]
> 🔒 유저에게 보여줄 **문구**는 확정되면 [[4-10. 어드민 고정값]]으로 옮긴다.
> 🚫 **정식 경로는 여기 적지 않는다** — 우리가 **설계해서 제공하는 길**은 실패가 아니다.
> 예 ⓐ **자료 없이 시작**(① 화면에서 **첨부 0개로 그냥 설명만** 쓰는 것) ⓑ **AI 정리본을 유저가 고침**(②·③·④·⑪은 애초에 **고치라고 만든 확인 화면**이다). 둘 다 목록에서 뺐다(2026-09-11 이선호).
> 🔄 **2026-09-11 플로우 변경 반영** — ①이 **설명 입력＋자료 첨부 한 화면**이 되면서([[4-2. AI 유저 플로우]] §1) **「자료가 아예 없다」는 이제 감지할 상황조차 아니다**(기본 상태에 가깝다). 옛 `없어요, 그냥 시작할게요` 버튼도 없어졌다. 반대로 **「설명 글이 비었다」(B1)** 는 더 중요해졌다 — 자료가 있어도 설명은 받기 때문.
> 표기 — ✅ 대응 정해짐 / 🚧 **결정 필요** / 🔬 감지 방법부터 미정
> 🔴 **①의 설명 글은 이 흐름 전체에서 유일한 「없으면 못 가는」 입력**이다(B1) — 자료는 0개여도 된다.

## A. 자료 — 11건 *(6건 확정 · 2026-09-11)*

| # | 상황 | 어떻게 알아채나 | 대응 |
|:--:|---|---|---|
| A1 | **스캔 PDF·사진만** — 글자가 없음 | 추출 텍스트 0자 | ✅ **사진 속 글자 읽기(OCR) 를 돌린다** (2026-09-11 이선호) · 비용 때문에 **앞 20쪽까지만**(A8과 같은 상한) · 그래도 0자면 **유저가 ①에 쓴 첫 입력 글만으로** 진행 |
| A2 | 암호 걸린 파일 · 손상 파일 | **업로드 직후 열어보기 검사** | ✅ **업로드 단계에서 막는다** — 그 파일만 빨갛게 표시하고 *"이 파일은 열리지 않아요"*, 나머지는 그대로 진행 |
| A3 | 지원 안 되는 형식 (ai·psd·zip) | 확장자 | ✅ **업로드 단계에서 막는다** — 고르기 전에 **받을 수 있는 형식만** 보이게(`accept`) |
| A4 | 용량 초과 | 업로드 | ✅ **파일당 20MB · 합계 50MB · 최대 10개** · 이미지는 **올리기 전에 자동 축소**(긴 변 2000px)라 사실상 안 걸림 |
| A5 | **URL 접근 실패** — 404 · 로그인 필요 · 비공개 SNS | **붙여넣는 즉시** 열어보기 | ✅ **입력칸에서 바로 알린다** — 초록 체크 / *"이 주소는 열리지 않아요"*. 다음 화면까지 끌고 가지 않는다 |
| A6 | URL은 열리나 **글자가 거의 없음** (자바스크립트로 그리는 사이트 · 이미지뿐) | 추출 텍스트 200자 미만 | ✅ ① **화면에 다 그려진 뒤** 읽는다(브라우저로 열어서) → ② 그래도 부족하면 **화면을 찍어 OCR·이미지 이해**로 뽑는다(A1과 같은 처리) |
| A7 | **자료가 주제와 무관** (재무제표만 올림) | 첫 입력 글과 자료의 주제가 어긋남 | 🚧 **첫 입력 글을 우선**하고 자료는 버릴지 · ②에서 *"이 자료로는 파악이 어려워요"* 를 띄울지 |
| A8 | **자료가 너무 많다** (200p 회사소개서) | 길이 | 🚧 앞 N쪽만? 요약 후 처리? |
| A9 | **여러 주제가 섞임** (회사소개+채용+행사) | 주제 후보 2개 이상 동점 | 🚧 ②에서 *"어느 쪽을 만들까요?"* 1회 물음 — **첫 입력 글이 한쪽을 가리키면 그걸로 결정**(묻지 않음) |
| A10 | **개인정보 포함** (명단·연락처 엑셀) | 패턴 탐지 | 🚧 페이지에 싣지 않기 + 경고 |
| A11 | **규제 업종** (의료광고·금융·주류·의약) | 주제·키워드 | 🚧 문구 자동 생성 제한 |
