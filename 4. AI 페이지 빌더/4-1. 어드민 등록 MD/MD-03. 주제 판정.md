# MD-03. 주제 판정

## 1. 입력

| 칸 | 언제나? | 쓰임 |
| --- | :---: | --- |
| **설명 글** | 🟢 **항상 있다** | 유저가 확인·수정을 끝낸 페이지 설명 1개 — **판정의 본체** |
| **목적** | 🟢 **항상 있다** | 유저가 확정한 목적 문구 1개 — 맺음 동사가 주제를 가른다 |
| **첫 입력 글** | 🟢 **항상 있다** | 유저가 맨 처음 직접 쓴 말 — 후보가 둘로 갈릴 때 **깨는 패** |
| **자료** | 🟡 **0개일 수 있다** | 첨부한 파일 · URL — 본문에서 근거를 찾을 때만 |

## 2. 출력

| | 값 |
| --- | --- |
| **주제 코드** | 25개 중 **1개** (`1-①` 꼴) |
| **목적 분류** | P1~P6 중 **1개** — 고르지 않고 **주제에서 따라 붙인다**(3-D) |

🚫 **둘 다 화면에 나오지 않는다.** 유저는 이 코드도, 「행사·안내」 같은 분류 이름도 볼 일이 없다.

## 3. 규칙

### 3-A. 판정은 「본문이 하는 말」로 한다 — 제목으로 하지 않는다

| | |
| --- | --- |
| ✅ **근거로 쓴다** | 설명 글의 **본문 문장** · **목적 문구** · 자료의 **본문** |
| 🚫 **근거로 쓰지 않는다** | **제목 · 파일명 · 행사명 · 브랜드명** — 단서로만 보고, 이것만으로 주제를 정하지 않는다 |

🧪 **자가 점검 한 문장** — *"제목을 가리고 본문만 읽어도 같은 주제가 나오나?"* 아니면 제목에 끌린 것이다.

**맺음 동사가 주제를 가른다** — 본문이 결국 무슨 말로 끝나는지를 본다.

| 본문이 이렇게 끝난다 | 가는 대분류 |
| --- | --- |
| `초대합니다` · `모십니다` · `오세요` | **1 행사·안내** |
| `접수합니다` · `신청 받습니다` · `모집합니다` | **5 신청·문의** |
| `알려드립니다` · `안내드립니다` · `공지합니다` | **6 소식·자료** |
| `판매합니다` · `주문하세요` · `할인합니다` | **4 상품·홍보** |
| `소개합니다` · `~하는 곳입니다` (정체를 밝힘) | **2** 또는 **3** |

🔁 **같은 사업이라도 시점마다 다른 주제다** — 유저는 사업 이름을 안 바꾸므로 **이름만 보면 반드시 틀린다.**

| 시점 | 본문 동사 | 주제 |
| --- | --- | --- |
| 참가자를 받는다 | `접수합니다` | `5-⑤` 공모전·대회 |
| 결과를 알린다 | `발표합니다` | `6-①` 공지·알림 |
| 시상식에 부른다 | `초대합니다` | `1-①` 행사 초대장 |

> 📌 실제 사례 — 제목이 `2026 ○○예술대전 **공모전**`인데 본문은 *"수상자 시상식에 초대합니다"* 였다. 제목으로 배정하면 `5-⑤`로 가고 **응모 자격·접수 기간·참가비·심사·제출물이 전부 빈칸**이 된다. 본문 동사가 `초대합니다`이므로 **`1-①`**이 맞다.

### 3-B. 두 번에 나눠 고른다 — 대분류 6 → 주제 25

**① 대분류 먼저**

| 대분류 | 이 대분류로 보내는 신호 |
| --- | --- |
| **1 행사·안내** | 본 사람이 **어딘가로 온다** · 정해진 날이 있다 |
| **2 프로필·명함** | 맨 위에 오는 것이 **사람 얼굴·이름** |
| **3 소개·홈페이지** | 맨 위에 오는 것이 **상호·로고·공간 사진** · 한 건이 아니라 **상시** |
| **4 상품·홍보** | **파는 것**이 주인공 |
| **5 신청·문의** | **받는 것(폼)**이 주인공 |
| **6 소식·자료** | **읽고 끝난다** · 갈 곳이 없다 |

**② 그 다음 주제**

| 주제                | 이 주제로 보내는 신호                         |
| ----------------- | ------------------------------------ |
| `1-①` 행사 초대장      | 정해진 날 **한 번** 열리는 자리 · **식순·순서**가 있다 |
| `1-②` 세미나·강연 안내   | **연사·시간표**가 내용의 절반 이상                |
| `1-③` 개업·오픈 안내    | **여는 날부터 며칠간** 열려 있고 아무 때나 와도 된다     |
| `1-④` 예약          | 오는 사람이 **날짜·시간(회차)을 골라야** 한다         |
| `2-①` 프로필 (링크 모음) | 보낼 **채널·링크가 3개 이상**이고 그 이동이 목적       |
| `2-②` 영업용 명함      | 한 사람의 **연락 수단**(전화·연락처 저장)이 끝에 온다    |
| `2-③` 포트폴리오       | 작업물이 **이미지**로 쌓인다                    |
| `2-④` 이력서·경력      | 경력·학력·수상이 **시간순 글**로 쌓인다             |
| `3-①` 소개 홈        | **상시 운영**하는 곳이 누구·무엇을 하는지            |
| `3-②` 메뉴·가격 안내    | **품목 + 가격**이 반복되고 **그 자리에서** 판다      |
| `4-①` 상품 상세       | **한 종을 깊게** — 스펙·실측이 있다              |
| `4-②` 룩북·컬렉션      | **한 가지가 섹션 하나를 통째로** 쓴다 — 화보 **여러 컷** ＋ 설명 1줄 (가격·구매 링크는 붙어도 된다) |
| `4-③` 카탈로그        | **한 가지가 카드 한 장** — 대표컷 **1장** ＋ 1~2줄 · 가짓수가 많다 |
| `4-④` 판매·주문       | **지금 사라**는 버튼이 위아래로 반복된다             |
| `4-⑤` 출시·사전예약     | 아직 **안 팔고** 알림·대기명단만 받는다             |
| `4-⑥` 프로모션·이벤트    | **마감 있는 혜택**(할인·쿠폰)이 맨 앞에 온다         |
| `5-①` 신청·접수       | **폼**이 본체 · 행사 정보는 짧다                |
| `5-②` 모집          | **정원·마감·선발**이 있다 (수강생·멤버·체험단·채용·가맹)  |
| `5-④` 상담·문의 받기    | **고를 회차도 정원도 없이** 연락처만 남긴다           |
| `5-⑤` 공모전·대회      | **부문·심사·시상**이 있다                     |
| `5-⑥` 후원·기부       | **취지 + 사용처 + 계좌**                    |
| `6-①` 공지·알림       | 읽고 끝 · **갈 곳이 없다**                   |
| `6-②` 매거진·소식지     | **꼭지가 여러 편** 묶여 있고 그 꼭지가 **글**이다     |
| `6-③` 도록·작품집      | **이미지 + 캡션**(작가·연도·재료·크기)이 반복된다      |
| `6-④` 가이드·이용안내    | **절차·단계·FAQ·수칙**                     |

> 🔖 **한 권으로 묶인 것(사보·소식지·프로그램북)은 `6-②`다.** 여는 말·목차가 앞에 있고 뒤에 부가 안내가 붙어도 **주제는 하나**다 — 앞뒤가 붙었다고 다른 주제를 겹쳐 세지 않는다.
> ⚠️ 꼭지가 **강좌·프로그램 안내**여도, **글로 쓰였고 사진이 주인공이 아니면 `6-②`**다. 꼭지가 여럿이라고 `3-① 소개 홈`(상시 운영하는 곳 소개)으로 보내지 않는다.

### 3-C. 갈릴 때 — 축 7개로 가르고, 최대 1개만 확인한다

주제가 둘로 좁혀지면 아래 축 중 **그 짝을 가르는 축 하나**를 골라 유저에게 확인한다.

| 축 | 확인 문장 (유저에게 보이는 말) | 가르는 짝 |
| --- | --- | --- |
| **①** | "이 페이지를 본 사람이 **어딘가로 오게 되나요?**" | 1번 ↔ 6번 · `3-②` ↔ `4-③` |
| **②** | "**내용을 충분히 보여주고** 받을까요, **바로 받을까요?**" | `1-②`↔`5-①` · `2-②`↔`5-④` · `4-①`↔`4-④` |
| **③** | "**지금 주문·결제를 받나요?**" | `4-④`↔`4-⑤` · `5-②`↔`4-④` |
| **④** | "**고를 수 있는 시간(또는 정원)이 있나요?**" | `1-④`↔`5-④` · `5-②`↔`5-④` |
| **⑤** | "보여줄 게 **사진·작업물**인가요, **글·경력**인가요?" | `2-③`↔`2-④` · `6-②`↔`6-③` |
| **⑥** | "**마감 있는 할인·혜택**이 주인공인가요?" | `4-⑥`↔`4-③` · `4-⑥`↔`4-②` — 주인공이면 `4-⑥` · 할인이 **품목마다 다르면** `4-③` 구조에 `4-⑥` 말투 |
| **⑦** | "한 가지에 **사진이 여러 장**인가요, **한 장**인가요?" | `4-②`↔`4-③` — 여러 장이면 `4-②`(한 가지 = 섹션 하나) · 한 장이면 `4-③`(한 가지 = 카드 하나) |

**지킬 것 4가지**
- **분류 이름을 문장에 쓰지 않는다** — `예약형인가요 상담형인가요` ❌ → **상황 문장**으로
- **추천을 미리 찍어 두고 확인만 받는다** — 고르게 하는 게 아니라 맞는지 보는 것
- **상한 1개** — 갈림이 둘 이상 겹치면 나머지는 정해서 넘긴다
- **"둘 다예요"면 더 많이 담는 쪽으로** 정하고 되묻지 않는다 (예: 예약＋상담 → 예약 쪽에 문의 버튼을 더한다)

### 3-D. 목적 분류는 고르지 않는다 — 주제에서 따라 붙는다

| 주제 | 목적 분류 | | 주제 | 목적 분류 |
| --- | --- | --- | --- | --- |
| `1-①` 행사 초대장 | **P2** ＋P3 | | `4-③` 카탈로그 | **P4** ＋P5 |
| `1-②` 세미나·강연 안내 | **P2** ＋P3 ＋P4 | | `4-④` 판매·주문 | **P5** ＋P4 |
| `1-③` 개업·오픈 안내 | **P2** ＋P3 ＋P4 | | `4-⑤` 출시·사전예약 | **P5**(약) ＋P3 →P1 |
| `1-④` 예약 | **P3** ＋P4 | | `4-⑥` 프로모션·이벤트 | **P5** ＋P4 →P1 |
| `2-①` 프로필 (링크 모음) | **P6** 🔒 | | `5-①` 신청·접수 | **P3** 🔒 |
| `2-②` 영업용 명함 | **P6** ＋P3 | | `5-②` 모집 | **P3** ＋P4 |
| `2-③` 포트폴리오 | **P6＋P4** 🔒 | | `5-④` 상담·문의 받기 | **P3** ＋P4 ＋P6 |
| `2-④` 이력서·경력 | **P6** 🔒 | | `5-⑤` 공모전·대회 | **P3** ＋P4 |
| `3-①` 소개 홈 | **P2＋P4** ＋P3 | | `5-⑥` 후원·기부 | **P3** ＋P4 ＋P5 |
| `3-②` 메뉴·가격 안내 | **P4** ＋P3 | | `6-①` 공지·알림 | **P1** 🔒 |
| `4-①` 상품 상세 | **P4** ＋P5 | | `6-②` 매거진·소식지 | **P4** →P1 |
| `4-②` 룩북·컬렉션 | **P4** ＋P5 | | `6-③` 도록·작품집 | **P4** ＋P2 |
| | | | `6-④` 가이드·이용안내 | **P1** ＋P4 |

- **굵은 것이 기본값** · `＋`는 조건이 맞을 때 **얹히는 것** · `→`는 조건이 맞으면 **갈아타는 것** · `🔒`는 고정
- 조건은 그 주제의 조립 레시피에 적혀 있다 (예: `6-②` 는 **꼭지가 1편뿐이면** P4 대신 P1)

### 3-E. 판정이 안 설 때

| 상황 | 처리 |
| --- | --- |
| **후보 주제가 2개로 갈린다** | 3-C의 축으로 가른다. 축으로도 안 갈리면 **첫 입력 글이 가리키는 쪽**으로 정하고 묻지 않는다 |
| **여러 주제가 섞여 보인다** | **분량이 가장 큰 것 하나**를 주제로 잡는다. 나머지는 그 레시피 안에서 섹션으로 담는다 — 주제를 둘 이상 세지 않는다 |
| **25개 주제 어디에도 안 맞는다** | **가장 가까운 주제**로 정하고, 그 레시피에서 **해당 없는 섹션은 뺀다**. 새 주제를 만들지 않는다 |
| **대상 밖이다** — 청첩장·돌잔치·환갑·부고 | 비즈니스용 페이지가 아니므로 **이 25개 주제로 판정하지 않는다** |
