# MD-04. 타겟

## 1. 입력

- **첫 입력 글** — 유저가 **「페이지 설명 입력」 화면**에서 직접 쓴 말 (🟢 **항상 있다**)
- **자료** — 유저가 첨부한 파일 · URL (🟡 **0개일 수 있다**)
- **설명 글** — 유저가 확인·수정을 끝낸 페이지 설명 1개
- **목적** — 유저가 확정한 목적 문구 1개
- **주제 코드** — 앞 단계에서 자동 판정한 주제(25개 중 1개 · **화면 노출 ❌**) → **나열 순서 ②(그 주제에서 흔한 타겟)**와 **무드 후보(§4)**를 만든다

## 2. 출력

① 타겟 문구 1개(입력창에 채워짐) ② 선택지 5개 ③ 나열 순서 ④ **무드 후보 목록**(주제가 만든 후보에서 타겟으로 뺀 나머지 · **화면 노출 ❌**)

## 3. 규칙

**타겟 문구 (입력창에 미리 채움)**
- 🔑 **명사구 — 아래 선택지 칩과 같은 형식** · **문장 ❌**
  - 문장 어미(`~예요`·`~입니다`) · 서술형 · 질문형 전부 ❌ — *"책을 좋아하는 동네 단골을 위한 페이지예요"* ❌ → **`책 좋아하는 동네 단골`** ✅
  - 이유 = 유저가 칩을 누르면 그 자리에 들어오므로, **미리 채운 문구와 칩의 생김새가 같아야** 고르는 행동이 자연스럽다
- **비워 두지 않는다** — 앞 단계 내용에서 읽어낸 타겟을 채워 보여준다
- **누구인지 채워서 구체적으로** — `고객` · `일반인` ❌ → `퇴근길 직장인`
- **칩보다 구체적이어도 된다** — 칩은 12자로 깎지만 입력창 문구는 **수식어 1개까지** 붙여 더 좁혀도 좋다 (칩 `동네 단골` / 문구 `책 좋아하는 동네 단골`)
- **추측한 내용이어도 단정해서 쓴다** — `아마도` · `~인 것 같아요` ❌. 틀렸으면 유저가 고친다

**선택지 5개**
- 선택지는 **「누가 볼 페이지인가」**로 — 주제를 다시 묻지 않는다
- **개수 5개 고정** · 라벨 **12자 이내**(칩 1줄)
- **라벨 = 유저가 쓰는 말로** — 분류·업종 용어 ❌ (단 `모집`·`접수` 같은 **업무 용어는 그대로**)
- **라벨은 명사구** — 문장도 질문형도 ❌
- 📋 **나열 순서 = 근거가 센 것부터** ① **첫 입력 글·자료에 실제로 나온 것**(= 위 입력 1·2번) → ② 그 주제에서 흔한 것 → ③ 일반적인 것
- **서로 겹치지 않게** — 포함 관계 ❌
- ⚠️ **여기서 무드를 「정하지」 않는다 — 「후보를 줄일」 뿐** — 무드 1개를 확정하고 색·폰트로 바꾸는 일은 [[MD-07-2. 무드]] 소관. 이 문서는 **§4로 후보 목록을 넘겨준다**
- 그러니 라벨을 **무드에 맞추려고 업종처럼 짓지 말 것** — 라벨은 어디까지나 **「누가 보는가」**

## 4. 무드 후보 좁히기

> 🔑 **주제가 후보를 만들고, 타겟이 그중 몇 개를 뺀다.** 타겟은 무드를 **지목하는 힘은 약하고 배제하는 힘은 세다** — 같은 `첫 방문 손님`도 카페면 🌿, 세무사면 💼이라 지목은 못 하지만, `기업 담당자`에게 🎉펀이 아닌 건 확실하다.

### ㉠ 주제 → 무드 후보 (후보를 만든다)

| 무드 | 이런 주제·업종일 때 |
|---|---|
| 🌿 내추럴/오가닉 | 카페 · 웰빙 · 친환경 · 식물 · 수제 |
| 🌸 페미닌/로맨틱 | 뷰티 · 웨딩 · 플로리스트 · 디저트 |
| ✨ 럭셔리/엘레강스 | 호텔 · 주얼리 · 파인다이닝 · 갤러리 |
| 💼 프로페셔널/비즈니스 | 세무 · 법무 · 컨설팅 · 의료 · 금융 · B2B · 명함 |
| 🌑 모던/시크 | 패션 · 디자인 스튜디오 · 미니멀 |
| 🔥 비비드/대담한 | 프로모션 · 세일 · 스포츠 · 신상품 · 이벤트 |
| 🎨 빈티지/노스탤직 | 책방 · 아카이브 · 레트로 · 매거진 · 핸드메이드 |
| 🎉 펀/플레이풀 | 아동 · 교육 · 캐릭터 · 로컬 푸드 · 굿즈 |
| 🌙 드리미/감성적 | 시 · 에세이 · 향수 · 명상 · 감성 굿즈 · 갤러리 카페 |

### ㉡ 타겟 라벨 → 제외 (후보를 뺀다)

유저가 고른 **타겟 라벨**의 성격으로 ㉠의 후보에서 **뺀다**. 🚧 **초안 — 검토 필요**

| 타겟 성격 | 빼는 무드 | 왜 |
|---|---|---|
| 기업·기관 담당자 (B2B · 관공서 · 협력사) | 🎉 펀 · 🌙 드리미 · 🌸 페미닌 | 결재·검토하며 보는 화면 |
| 아이 · 학부모 | ✨ 럭셔리 · 🌑 모던/시크 | 차갑고 격식 차린 인상 |
| 어르신 · 지역 주민 | 🌑 모던/시크 · 🌙 드리미 | 옅은 색·작은 글씨로 읽힌다 |
| 동종업계 전문가 (수주 · 포트폴리오) | 🎉 펀 · 🎨 빈티지 | 취미처럼 보인다 |
| 10~20대 · 팬 | 💼 프로페셔널 | 딱딱하다 |
| 예비 신랑신부 · 기념일 손님 | 💼 프로페셔널 · 🔥 비비드 | 사무적이거나 소란스럽다 |

**제외 안전장치 3개**
- **㉠이 지목한 무드는 빼지 않는다** — 주제가 우선. (예: 아동 교육 주제의 🎉펀은 `학부모` 타겟이어도 유지)
- **후보가 3개 미만으로 줄면 제외를 멈춘다** — 다 빼고 하나만 남기면 [[MD-08. 시안 B·C]]가 쓸 후보가 없다
- **표에 없는 타겟은 아무것도 빼지 않는다** — 애매하면 **남긴다**

- **무드 이름은 내부 기준** — 화면에 노출하지 않는다(타겟 칩은 유저 말로)
- **무드 하나가 정해지면 색과 폰트가 함께 정해진다** — 확정과 색·폰트는 [[MD-07-2. 무드]] 소관
