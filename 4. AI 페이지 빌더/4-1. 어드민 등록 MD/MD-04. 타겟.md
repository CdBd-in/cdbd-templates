# MD-04. 타겟

## 1. 입력

- **설명 글** — 유저가 확인·수정을 끝낸 페이지 설명 1개
- **목적** — 유저가 확정한 목적 문구 1개

## 2. 출력

① 타겟 문구 1개(입력창에 채워짐) ② 선택지 5개 ③ 나열 순서 ④ 라벨 → 무드 매핑

## 3. 규칙

**타겟 문구 (입력창에 미리 채움)**
- **한 문장** (글자 수 상한 ❌) · **비워 두지 않는다** — 앞 단계 내용에서 읽어낸 타겟을 **문장으로 채워** 보여준다
- **누구인지 채워서 구체적으로** — *"고객을 위한 페이지예요"* ❌ → *"책을 좋아하는 동네 단골을 위한 페이지예요"* ✅
- **해요체 존댓말** — `합니다`체 ❌ · **서술형으로**(질문형 ❌)
- **추측한 내용이어도 단정해서 쓴다** — `아마도` · `~인 것 같아요` ❌. 틀렸으면 유저가 선택지로 고친다

**선택지 5개**
- 선택지는 **「누가 볼 페이지인가」**로 — 주제를 다시 묻지 않는다
- **개수 5개 고정** · 라벨 **12자 이내**(칩 1줄)
- **라벨 = 유저가 쓰는 말로** — 분류·업종 용어 ❌ (단 `모집`·`접수` 같은 **업무 용어는 그대로**)
- **라벨은 명사구** — 문장도 질문형도 ❌
- 📋 **나열 순서 = 근거가 센 것부터** ① **첫 입력 글·자료에 실제로 나온 것** → ② 그 주제에서 흔한 것 → ③ 일반적인 것
- **서로 겹치지 않게** — 포함 관계 ❌
- 무드 기준은 **라벨 → 무드 9개 중 하나**로 떨어지게
- ⚠️ 무드는 **여기서 정하고 [[MD-07-2. 무드]]가 색·폰트로 바꾼다** — 두 곳이 다른 무드를 고르지 않도록 **라벨 → 무드 매핑은 아래 §5 표 하나만** 쓴다

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 4. 라벨 → 무드 매핑 (무드 9개)

| 무드 | 이런 타겟·주제일 때 |
|---|---|
| 🌿 내추럴/오가닉 | 카페 · 웰빙 · 친환경 · 식물 · 수제 |
| 🌸 페미닌/로맨틱 | 뷰티 · 웨딩 · 플로리스트 · 디저트 |
| ✨ 럭셔리/엘레강스 | 호텔 · 주얼리 · 파인다이닝 · 갤러리 |
| 💼 프로페셔널/비즈니스 | 세무 · 법무 · 컨설팅 · 의료 · 금융 · B2B · 명함 |
| 🌑 모던/시크 | 패션 · 디자인 스튜디오 · 미니멀 |
| 🔥 비비드/대담한 | 프로모션 · 세일 · 스포츠 · 신상품 · 이벤트 |
| 🎨 빈티지/노스탤직 | 책방 · 아카이브 · 레트로 · 매거진 · 핸드메이드 |
| 🎉 펀/플레이풀 | 아동 · 교육 · 캐릭터 · 로컬 푸드 · 굿즈 |
| 🌙 드리미/감성적 | 시 · 에세이 · 향수 · 명상 · 감성 굿즈 · 갤러리 카페 |

- **무드 이름은 내부 기준** — 화면에 노출하지 않는다(타겟 칩은 유저 말로)
- **무드 하나가 정해지면 색과 폰트가 함께 정해진다** — 색·폰트로 바꾸는 일은 [[MD-07-2. 무드]] 소관
