# MD-06. 페이지 구성

> 📍 **화면**: 6 · 페이지 유형 → 7 · 시안 생성 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6918-10557)
> 🗒 **출처**: 피그마 코멘트 2건 (2026-09-10, codeisneverodd) — 섹션 배치 + 멀티 분할
> 🔀 **옛 MD-05(섹션 배치) + MD-07(멀티 분할) 통합** (2026-09-11) — 「어떤 섹션을 어떤 순서로」와 「그걸 몇 장으로 나눌지」는 **한 번에 결정해야** 앞뒤가 맞는다.

## 1. 무엇을 정하는 MD인가

① 페이지에 넣을 **섹션 목록** ② **배치 순서** ③ 멀티페이지면 **페이지 분할**(몇 장 · 각 장에 어떤 섹션).

## 2. 입력

앞 단계 내용(설명 · 목적 · 추가 항목 · 타겟) ＋ [[MD-05. 페이지 유형 판정]] 결과

## 3. 출력

`[페이지1: 섹션 a → b → c] [페이지2: …]` 형태의 구성표

## 4. 규칙

### 4-A. 섹션 고르기·순서

- **공통 골격**(히어로 → … → 문의)을 먼저 깔고 **주제별 카드**로 채운다
- **최상단은 반드시 히어로** — 작은 소개 카드로 페이지를 열지 않는다
- **추가 항목 칩**([[MD-03. 추가 항목]])에서 켜진 것을 지정된 자리에 끼운다
- 🎲 **고른 뒤에는 「거른 뒤 랜덤」** — 후보를 내용으로 거르고, 그중 **랜덤**으로 뽑는다([[4-5. 섹션 라이브러리]] 🎲)
- 🖼 **이미지가 없으면 이미지 칸이 적은 섹션을 고른다** — 스타일을 바꾸는 게 아니라 **여기서** 해결한다

### 4-B. 멀티페이지 분할

- 표지(P1)에 **목차** · 서브페이지엔 **상단 고정 헤더**로 복귀
- **한 페이지에 목적이 둘 이상 섞이지 않게**
- 분할 기준은 [[MD-05. 페이지 유형 판정]]의 관문(챕터 ≥3 · 장면형 · 카드 ≥35)과 같은 축을 쓴다

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.
