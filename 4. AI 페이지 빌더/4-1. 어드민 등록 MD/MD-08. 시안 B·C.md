# MD-08. 시안 B·C

> 📍 **화면**: 9 추가 2안 물어보기 → 10 시안 비교 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6979-17853)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

시안 A와 **같은 근거**(07-1·07-2·07-3)를 쓰되 **서로 다르게** 나오도록 B·C를 만드는 규칙과 **노출 순서**.

## 2. 입력

**시안 A의 생성 기록** — 레이아웃 유형 · 무드/팔레트 명도 칸 · 섹션 id 목록 · 시드

## 3. 출력

시안 B · C ＋ 보여줄 순서

## 4. 규칙

### ⏱ 만드는 시점 = 유저가 요청한 뒤

🚫 **미리 만들어 두지 않는다** (2026-09-11 이선호). ⑨에서 `지금 시안으로 충분해요`(짧은 길)를 고르면 **미리 만든 2벌이 통째로 버려진다.**
💡 나중에 만들면 ⑦에서 **유저가 채운 최신 내용**이 그대로 들어간다.

### 🎲 다양성 = 「기록 제외」로 확보

시안 A가 **실제로 쓴 값**을 제외 목록으로 쓴다 — 3안을 나란히 놓고 비교할 필요가 없다.

```
섹션마다: 후보에서 「A가 쓴 섹션」 제외 → 랜덤 (후보 ≤3개면 공용 허용)
무드:     「A가 쓴 배경 명도 칸」 제외 → 남은 칸에서 랜덤
레이아웃:  A가 쓴 유형 제외 → 남은 2개
```

### 📋 노출 순서

- **A와 가장 다른 것을 B로** (차별화 레버)
- 단 [[MD-07-1. 레이아웃 유형]]의 **배제 규칙은 그대로 적용** — 배제된 유형은 C로 밀거나 쓰지 않는다
- 📮 **문의 섹션은 3안 모두 다른 것으로** — 버튼만 있어 제일 복붙되기 쉬운 섹션

> 🚧 여기에 실제 생성 지침을 채운다.
