# MD-08. 시안 B·C

> 🔗 **B·C도 [[MD-07-1. 레이아웃 유형]] · [[MD-07-2. 무드]] · [[MD-07-3. 텍스트 구성]]을 그대로 따른다** — 그 셋은 **안 하나를 만드는 공통 규칙**이다. 이 문서는 그 위에 얹는 **「A와 다르게」 층**만 정한다(제외 · 분산 · 노출 순서).

## 1. 입력

- **시안 A 기록** — 시드 · 레이아웃 유형 · 팔레트 id · **배경 명도 칸 · 액센트 계열** · 쓴 섹션 id 배열

## 2. 출력

시안 B · C ＋ 보여줄 순서

## 3. 규칙

### ⏱ 만드는 시점 = 유저가 요청한 뒤

🚫 **미리 만들어 두지 않는다**. **「추가 2안을 볼까요?」 화면**에서 `지금 시안으로 충분해요`(짧은 길)를 고르면 **미리 만든 2벌이 통째로 버려진다.**
💡 나중에 만들면 **「내용 채우기」 화면**에서 **유저가 채운 최신 내용**이 그대로 들어간다.

### 🎲 다양성 = 「기록 제외」로 확보

시안 A가 **실제로 쓴 값**을 제외 목록으로 쓴다 — 3안을 나란히 놓고 비교할 필요가 없다.

⚠️ **순서 = 공통 규칙 먼저, 제외는 그다음.** 07-1의 배제(긴 글엔 미니멀 ❌ 등) · 07-2의 무드 후보 추리기를 **먼저** 통과시킨 뒤, 남은 것에서 「A가 쓴 값」을 뺀다. **다양성 때문에 배제된 값을 쓰지 않는다.**

```
섹션마다: 후보에서 「A가 쓴 섹션」 제외 → 랜덤 (후보 ≤3개면 공용 허용)
무드:     「A가 쓴 배경 명도 칸」 제외 → 남은 칸에서 랜덤
레이아웃:  A가 쓴 유형 제외 → 남은 2개
```

### 🎨 색은 두 축으로 갈라야 한다

> ⚠️ **주제에서 색을 뽑으면 3안이 저절로 닮는다** — 같은 주제니까 같은 재료를 쓴다. 실제로 두 안이 **둘 다 「어두운 배경 + 따뜻한 호박색」**으로 붙은 적이 있다.

| 축 | 규칙 |
|---|---|
| **배경 명도** | 3안이 방향을 나눠 갖는다. **금지 = 3안 전부 같은 방향.** 비율은 자유(밝음2:다크1도, 다크2:밝음1도 OK) |
| **액센트 계열** | **최소 2계열**(따뜻함 / 차가움 / 중립). **3안 전부 따뜻한 색 ❌** — 명도만 벌리는 건(황동 vs 호박) 같은 계열이라 부족 |

**교정 예** — A 밝음＋중립(종이·차콜) / B 어두움＋차가움(야간·달빛블루) / C 밝음＋따뜻함(크림·가죽). 명도는 A·C가 겹쳐도 계열이 갈린다.

- 🎬 **단 3안 중 최소 1안은 「주제 장면이 연상되는 색」** — 바다 = 블루/틸 · 녹차 = 그린 · 원두 = 브라운. **분산을 챙기다 주제를 잃지 않게** 하는 안전장치다(실제로 바다·서핑 주제인데 3안 전부 파랑이 없던 적이 있다).

### 📋 노출 순서

- **A와 가장 다른 것을 B로** (차별화 레버)
- 단 [[MD-07-1. 레이아웃 유형]]의 **배제 규칙은 그대로 적용** — 배제된 유형은 C로 밀거나 쓰지 않는다

### 차별화 레버

같은 속성이 **한 안 안에서는 「통일」**, **안 사이에서는 「차별화」** 로 쓰인다.

| 레버 | 한 안 **안**에서 | 안 **사이**에서 |
|---|---|---|
| 버튼 모양 | 1종 (테마 전역) | **최소 2종** (각진 · 둥근 · 원형 중) |
| 섹션 제목 형식 | 1형식 | 안마다 다른 형식 |
| 모서리 | 1값 | **각진 ↔ 둥근**으로 가른다 |
| 좌우 여백 | 1값 | **셋 다 20에서 출발**해 **위로만** 벌린다 · **20보다 좁게 ❌** |
| 색 | 3토큰 역할 고정 | **배경 명도 방향 + 액센트 계열** 분산 |
| 구조 | — | 도입 · 정보 밀도 · 이미지 비중 · 카드 타입 · 순서 중 **3개 이상** 다르게 |
| 문의 섹션 | 그 안의 버튼 스타일로 통일(수미상관) | **3안 모두 다른 섹션** (버튼만 있어 제일 복붙되기 쉽다) |

> ⚠️ **통일만 잘하면 「각자 잘 통일된 쌍둥이」가 된다** — 실제로 세 시안이 전부 같은 라벨 크기 · 원형 버튼 · 다크＋따뜻한 색이었던 적이 있고, **각 안 안에서는 완벽히 통일**돼 있었다. 통일 점검으로는 이걸 못 잡는다.
