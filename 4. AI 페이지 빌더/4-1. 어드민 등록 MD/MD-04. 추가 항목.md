# MD-04. 추가 항목

> 📍 **화면**: v2 · 3 목적 선택 — 입력창 **아래 칩** 「있으면 더 좋은 것들」 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6919-13797)
> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

**「이것도 담을까요?」 제안 칩 5개**와 **나열 순서**를 만든다. 매번 앞 단계 내용을 바탕으로 **새로 생성**한다(고정값 ❌).

⚠️ **성격은 「목적」이 아니라 「담을 내용·기능」이다**.
유저는 바로 위 입력창에서 **목적을 이미 말했다.** 이 칩은 그 목적을 다시 고르게 하는 게 아니라, **함께 있으면 좋을 섹션을 추가로 권하는 것**이다. → **칩 하나 = 페이지에 섹션 하나 추가.**

## 2. 입력

- **설명 글** · **목적** — 무엇을 권할지의 근거
- **내부 판정**의 주제코드 → 그 주제의 **조립 레시피 = 이미 들어갈 섹션 목록**(= 제외 대상)

> 📥 칸 정의 = [[MD-01. UX 라이팅]] 「부록 — 단계별 누적 정보」

## 3. 출력

칩 **5개** + **나열 순서**. 칩 하나 = `{ 화면에 보일 문구, 추가할 섹션 목적, 들어갈 자리 }`

## 4. 규칙

- 🔴 **필수 섹션은 칩으로 올리지 않는다** — 레시피에 **이미 들어가는 섹션**을 제안하면 유저는 「이미 되는 걸 또 고르는」 셈이 된다. 후보 = **레시피 필수 섹션을 뺀 나머지**
- 🔴 **조건 1** — 칩마다 **어떤 「섹션 목적」을 쓸지 미리 정해져 있어야 한다**
- 🔴 **조건 2** — 섹션 목적 용어는 **어드민 프리셋 편집기와 반드시 일치** → **목록 정본 = [[MD-07. 페이지 구성]] §7**(히어로·소개·핵심 정보·스토리·안내사항·나열·자료·예약·폼·구매·프로모션·위치 안내·문의)
- 🗣 **칩 문구는 유저 말로** — 섹션 목적 용어를 그대로 노출하지 않는다 (`폼` ❌ → `참석 신청받기`)
- **개수 5개 고정** · 칩 문구 **12자 이내**(칩 1줄)
- 📋 **나열 순서 = 근거가 센 것부터** ① **첫 입력 글·자료에 실제로 나온 것** → ② 그 주제에서 흔한 것 → ③ 일반적인 것
- **칩끼리 겹치지 않게** — 포함 관계 ❌ (`문의` ↔ `상담 문의`)
- 예시 매핑: 참석 신청받기 = **폼** / 정원 안내하기 = **소개** / 문의사항 = **문의**
- 🔀 **갈림 질문 흡수** — AI가 주제 둘 사이에서 갈리면, **둘을 가르는 섹션을 칩으로 올려** 유저 선택으로 결정한다. **별도 질문 화면을 띄우지 않는다.** 갈리는 축은 아래 5가지뿐이다

  | 축 | 무엇을 가르나 |
  |---|---|
  | ① 오나 / 안 오나 | 이 페이지를 본 사람이 **어딘가로 오게 되나** |
  | ② 보여주기 먼저 / 받기 먼저 | **충분히 보여주고** 받나, **바로** 받나 |
  | ③ 지금 돈을 받나 | **지금 주문·결제**를 받나 |
  | ④ 자리·시간이 정해져 있나 | **고를 수 있는 시간(또는 정원)** 이 있나 |
  | ⑤ 사진이 주인공 / 글이 주인공 | 보여줄 게 **사진·작업물**인가 **경력·이력**인가 |

  - **분류 이름을 칩 문구에 쓰지 않는다** — *"예약형인가요 상담형인가요"* ❌ → **상황 문장**으로
  - **「둘 다」인 경우 = 더 많이 담는 쪽**으로 정하고 되묻지 않는다 (예: 예약＋상담 → 예약 페이지에 문의 버튼 추가)
  - **한 번에 하나까지** — 갈림이 둘 이상 겹치면 나머지는 AI가 정하고 **시안으로 보여준다**

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 5. 함께 지키는 것

- **섹션 목적 13칸** = [[MD-07. 페이지 구성]] §7 — 그 목록 밖의 이름을 지어내지 않는다
- **「필수 섹션」 = 그 주제의 조립 레시피에 이미 들어가는 섹션** — 칩 후보에서 뺀다. 후보는 **그 나머지**다
- **위 갈림 5축은 칩을 뽑는 내부 판정 로직** — 화면에는 축 이름도, 분류 이름도 나오지 않는다

## 6. 원본 코멘트

```
input 아래 보조 선택지로 제시할 문장 N개.
조건1) 이 선택지들은 어떤 프리셋 섹션 목적을 사용할 것인지 미리 정해져 있어야함.
조건2) 프리셋 섹션 목적은 어드민의 프리셋 편집기와 용어를 반드시 통일해야함
```
