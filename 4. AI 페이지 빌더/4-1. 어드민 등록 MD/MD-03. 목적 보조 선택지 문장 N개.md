# MD-03. 목적 보조 선택지 문장 N개

## 1. 무엇을 정하는 MD인가

input 아래 보조 선택지로 제시할 **문장 N개**를 만든다.

## 2. 입력

이전 단계 설명 글 + MD-02의 목적 문장

## 3. 출력

input 아래 보조 선택지로 제시할 **문장 N개**

## 4. 규칙

- 🔴 **조건 1** — 선택지마다 **어떤 「프리셋 섹션 목적」을 쓸지 미리 정해져 있어야 한다**
- 🔴 **조건 2** — 프리셋 섹션 목적 용어는 **어드민 프리셋 편집기와 반드시 일치**
- 예시 매핑: 참석 신청받기 = 폼 / 정원 안내하기 = 소개 / 문의사항 = 문의

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.
