# MD-00. 단계별 누적 정보 (전 MD 공통 입력 계약)

> 🚫 **이 문서는 어드민에 등록하지 않는다** — 우리끼리 보는 **전체 지도**다. 각 MD는 **혼자서도 읽히도록** 자기 입력을 직접 풀어 쓴다.
> 📌 각 MD가 입력을 적을 땐 **여기 있는 이름 그대로** 쓴다(줄임 기호·화면 번호 ❌).

| 칸 | 담기는 값 | 채우는 MD |
|---|---|---|
| **첫 입력 글** | 유저가 **「페이지 설명 입력」 화면**에서 **직접 쓴 말** (예시 칩으로 채운 글 포함) — 🟢 **항상 있다** · 비면 **다음으로 못 간다**(유일한 필수 입력) | 페이지 설명 입력 화면 |
| **자료** | **첨부한** 파일 · URL — 🟡 **0개일 수 있다** · **「페이지 설명 입력」·「페이지 설명 확인」 두 화면**에서 붙이고 뺄 수 있다 | 페이지 설명 입력·확인 화면 |
| **설명 글** | 유저가 **「페이지 설명 확인」 화면**에서 **확인·수정을 끝낸** 페이지 설명 1개 | [[MD-01. 페이지 설명]] |
| **목적** | 유저가 확정한 목적 문구 1개 | [[MD-02. 목적]] |
| **추가 항목** | 유저가 **켠 칩만** `{문구, 섹션 목적}` 배열 (**들어갈 자리는 [[MD-06. 페이지 구성]]가 정한다**) | [[MD-03. 추가 항목]] |
| **타겟** | 타겟 문구 1개 ＋ 유저가 고른 **라벨 배열** | [[MD-04. 타겟]] |
| **내부 판정** | 주제코드(25) · 목적 분류(P1~P6) — **화면 노출 ❌** (※ **무드 후보는 [[MD-07-2. 무드]]가 만든다**) | 01~04 진행 중 자동 |
| **페이지 유형** | `원페이지 / 멀티페이지` (근거 한 줄은 유형별로 미리 써 둠) | [[MD-05. 페이지 유형 판정]] |
| **구성** | `{섹션 목적, 섹션 id, 순서, 페이지 번호}` 배열 | [[MD-06. 페이지 구성]] |
| **시안 A 기록** | 시드 · 레이아웃 유형 · 팔레트 id · 배경 명도 칸 · 쓴 섹션 id 배열 | 07-1 · 07-2 · 07-3 |
| **채운 내용** | 유저가 채운 칸 / 비어 있는 칸 | 내용 채우기 화면 |

| 02 목적 | 설명 글 | 목적 |

| 05 페이지 유형 | 설명 글 · 목적 · 추가 항목 · 타겟 | 페이지 유형 (근거 문구는 고르기만) |
| 06 페이지 구성 | 설명 글부터 페이지 유형까지 | 구성 (＋ 켠 칩의 **들어갈 자리·순서**) |

| 07-2 무드 | 타겟 · 내부 판정 | 시안 A 기록(팔레트·명도 칸) |
| 07-3 텍스트 | 목적 · 타겟 · 내부 판정 · 구성 | 시안 텍스트 · 비운 칸 목록 |
| 08 시안 B·C | **시안 A 기록** | 안 B · C |
| 09 채우기 팁 | 구성 · 채운 내용 | 칸별 팁 **선택**(미리 써 둔 문구에서) |

## 모든 MD 공통 작성 규칙 — 🚫 모호한 표현 금지 (2026-09-11 이선호)

> 🔑 **MD는 사람에게 읽히는 설명서가 아니라 AI가 매번 같은 결과를 내게 하는 기준이다.** *「구체적으로」·「적절히」·「흔한 것」* 처럼 **읽는 사람마다 답이 갈리는 말**을 쓰면, 같은 입력에도 결과가 매번 달라진다. 문서 하나만 보고도 **일관되고 품질 좋은 결과**가 나오게 쓴다.

**🚫 쓰지 않는 말** — `적절히` · `자연스럽게` · `구체적으로` · `간결하게` · `흔한` · `일반적인` · `필요하면` · `가능한 한` · `잘` · `적당히` · `대체로`

**✅ 대신 쓰는 것 4가지** (하나 이상)

| 방법 | 무엇 | 예 |
|---|---|---|
| **① 목록으로** | 고를 것을 다 적는다 | `구체적으로` → **관계 / 속성** 2축 표 |
| **② 금지어로** | 안 되는 말을 나열 | `분류 용어 ❌` → `타겟`·`세그먼트`·`F&B`·`B2B` … |
| **③ 숫자로** | 세거나 잴 수 있게 | `짧게` → **12자 이내** · **5개 고정** |
| **④ 판정 문장으로** | **예/아니오로 답이 갈리는 한 문장** | `겹치지 않게` → *"한 사람이 두 칩에 동시에 해당되면 겹친 것"* |

**🧪 다 쓴 뒤 자가 점검 2개**
- **다른 사람 둘이 이 줄만 읽고 각자 만들면 같은 게 나오나?** — 아니면 ①~④로 다시 쓴다
- **실행 시점에 확인할 수 없는 근거를 깔지 않았나** — *"그 주제 페이지 10개 중 절반"* 처럼 **세어 볼 데이터가 없는 기준** ❌. 손에 있는 입력(첫 입력 글·자료·주제 코드)만으로 답이 나와야 한다

⚠️ **예외 = 판단을 사람에게 넘기는 자리** — 🚧 표시를 달고 *「검토 필요」*라고 적는다(애매한 채로 두되 **애매하다는 걸 드러낸다**).
