# MD-08. 시안 스타일 선택

> 📍 **화면**: 6 · 페이지 유형 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6919-10907)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)
> 🚧 **상태**: 골격만 — 본문 지침 작성 대기

## 1. 무엇을 정하는 MD인가

**미니멀 / 에디토리얼 / 볼드** 중 1안으로 쓸 스타일를 만든다.

## 2. 입력

자료 분량 · 이미지 개수 · 주제

## 3. 출력

**미니멀 / 에디토리얼 / 볼드** 중 1안으로 쓸 스타일

## 4. 규칙

- ⚠️ 기준 **미확정** — 현재 방향: 기본 에디토리얼 / 자료 빈약 = 미니멀 / 이미지 6장↑ = 볼드
- 이 MD가 정하는 건 **1안 스타일 1개뿐**. 2·3안 스타일은 [[MD-12. 시안 노출 순서]]가 **나중에** 정한다
- 🚫 **3안을 미리 만들지 않는다 (2026-09-11 이선호)** — 1안만 만들고, **안1이 쓴 값을 기록**해 둔다. 2·3안은 ⑨에서 유저가 요청할 때 그 기록을 **제외하고** 뽑는다(「짧은 길」로 끝나면 미리 만든 시안은 통째로 버려진다).

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.
