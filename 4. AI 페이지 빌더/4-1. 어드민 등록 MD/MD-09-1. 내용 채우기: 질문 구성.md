# MD-09-1. 내용 채우기: 질문 구성

> 🔑 **케이스마다 화면을 미리 그려 두지 않는다.** 인풋은 **종류 12개와 반복 여부**만 정해져 있고, **채택한 섹션의 정보 구조를 보고 그때그때 조합**한다.

## 1. 입력

| 값 | 내용 |
|---|---|
| **구성** | `{섹션 목적, 섹션 id, 순서, 페이지 번호}` 배열 |
| **섹션 슬롯** | 각 섹션이 가진 빈칸의 이름·개수·반복 구조 |
| **시안 텍스트** | 각 섹션에 이미 들어간 글 |
| **설명 글 · 자료** | 유저가 쓴 설명과 첨부한 파일·URL |

## 2. 출력

**질문 단계 배열.** 단계 하나는 이렇게 생겼다.

```
{
  주어        : 왼쪽 제목에 들어갈 섹션 이름표
  칸 배열     : [{ 라벨, 인풋 종류, 필수/선택, 플레이스홀더 }, ...]
  반복        : 없음 | 1단 | 2단
  안내 문구   : 있음 | 없음
  버튼 텍스트 칸 : 있음 | 없음
}
```

## 3. 규칙

### 3-0. 질문 문구 (왼쪽 패널 제목)

단계마다 왼쪽 맨 위에 **한 줄**이 붙는다. 이 줄이 「무엇을 채우는 단계인지」를 말한다.

| 칸 상태 | 문구 |
|---|---|
| 비어 있다 | **`{주어}{을/를} 추가하면 좋아요`** |
| AI가 미리 채웠다 | **`{주어}{을/를} 미리 채워뒀어요`** |

**주어 = 그 단계가 채우는 섹션의 이름표.** 아래 순서로 찾는다.

1. 섹션 제목이 **두 줄(작은 라벨 ＋ 제목)**이면 → **라벨 줄**
2. 한 줄이면 → **그 제목**
3. 신청 폼이면 → **폼 제목** (`참가 신청서`)
4. 제목이 문장이면 → **그 섹션에 지어 둔 명사형 이름표**

**지킬 것**

- 🚫 **칸 라벨을 주어로 쓰지 않는다** — `이미지를 추가하면 좋아요` ❌ (무슨 섹션인지 알 수 없다)
- 🚫 **라벨 줄의 말이 제목에 그대로 들어 있으면 라벨을 주어로 쓰지 않는다** — `안내` ＋ `가격과 발송 안내` 같은 겹침은 **제목 줄**을 쓴다
- **조사** — 주어 마지막 글자에 **받침이 있으면 `을`, 없으면 `를`**
- **주어만 포인트 색**으로 칠하고, 오른쪽 미리보기의 그 섹션과 **선으로 잇는다**
- **히어로는 고정 이름 3개** — `메인 이미지` · `로고 이미지` · `히어로 문구`

### 3-1. 인풋 종류 12가지 — 이 밖의 입력 UI는 만들지 않는다

| 종류 | 받는 것 | 생김새 |
|---|---|---|
| **일반 텍스트** | 문장·설명 | 넓은 입력칸 · 엔터 = 줄바꿈 |
| **제목 텍스트** | 이름·제목처럼 **한 줄로 끝나는 말** | 좁은 입력칸 |
| **숫자 ＋ 단위** | 가격 · 정원 | 입력칸 오른쪽에 단위 글자(`원`·`명`) |
| **날짜** | 날짜 | 달력 |
| **시간** | 시각 | 시계 |
| **단일 이미지** | 사진 1장 | 업로드 박스 ＋ `AI 이미지 생성` 버튼 |
| **복수 이미지** | 사진 여러 장 | 업로드 박스 ＋ `항목 추가` |
| **링크(URL)** | 주소 | 입력칸 ＋ 형식 검사 |
| **주소** | 장소 | 검색 입력칸(결과 목록에서 고름) ＋ 상세 주소 입력칸 |
| **고르기** | 정해진 것 중 하나 | 드롭다운 |
| **켜기·끄기** | 켜고 끄기 | 스위치 |
| **갈래 선택** | 유형 · 선택지 | 선택 버튼 · 체크박스 |

- **켜기·끄기는 값을 받지 않는다.** 두 가지 일만 한다 — ⓐ **다른 칸을 숨기거나 드러낸다** ⓑ **그 항목의 속성을 켠다**(`필수` · `복수 선택`)
- 위 12가지로 만들 수 없는 입력이 나오면 **멈추고 검토 요청**한다. 🚧 캘린더 그리드 · 슬라이더 · 태그 입력 · 서식 있는 글 편집기는 **아직 없다**

### 3-2. 반복 여부 판정

| 판정 | 조건 | 결과 |
|---|---|---|
| **반복 없음** | 그 섹션이 그 정보를 **한 벌만** 담는다 | 칸을 그대로 나열 |
| **1단 반복** | **같은 꼴의 칸 묶음이 2벌 이상** 들어간다 | 묶음 한 벌 ＋ `항목 추가` |
| **2단 반복** | 반복되는 항목 **안에** 또 반복되는 칸이 있다 | 바깥 ＋ 안쪽 각각 추가 버튼 |

- **반복은 2단까지만.** 3단이 필요해 보이면 **멈추고 검토 요청**한다
- **추가 버튼 문구 = `항목 추가`** 로 고정한다. 단 **2단일 때 안쪽 버튼**은 무엇이 늘어나는지 드러나는 이름을 쓴다(`옵션 추가` · `메뉴 추가`) — 둘 다 `항목 추가`면 어느 단계가 늘어나는지 알 수 없다

### 3-3. 한 단계의 뼈대

```
[주 입력 묶음]   칸 1~4개
   └ 반복이면 이 묶음이 통째로 늘어난다
[안내 문구]      선택 · 0~1개
[버튼 텍스트]    그 섹션에 버튼이 있을 때만
```

- **칸이 5개 이상이면 두 단계로 나눈다**
- **안내 문구는 반복 바깥**에 둔다 — 항목마다 늘어나지 않는다

**가로 · 세로 놓기**

| 칸 | 놓는 법 |
|---|---|
| **한 벌이 2~3칸** | **가로 한 줄** — 제목＋내용 · 날짜＋시간 · 정상가＋할인가 · 유형＋값 · 날짜＋시간＋정원 |
| **한 벌이 4칸 이상** | **줄을 나눈다** — 앞 3칸을 한 줄, 나머지를 다음 줄 |
| **일반 텍스트 · 이미지 · 주소** | **언제나 한 줄을 다 쓴다** — 다른 칸과 가로로 묶지 않는다 |

**가로 줄의 폭**

| 경우 | 폭 |
|---|---|
| 칸들이 **같은 성격**(날짜·시간 / 정상가·할인가 / 날짜·시간·정원) | **똑같이 나눈다** |
| 한쪽이 **짧은 이름이나 고르기**(제목·유형·요일) | 그 칸을 **좁게 고정**하고 나머지 칸이 **남은 폭을 채운다** |

### 3-4. 라벨 정하기

**고정 라벨 7개** — 아래 뜻에 해당하면 **항상 이 말**을 쓴다.

| 라벨 | 언제 |
|---|---|
| `이미지` | 모든 사진 칸 |
| `제목` | 반복 항목의 이름 칸 |
| `내용` | 반복 항목의 본문 칸 |
| `날짜` | 날짜 칸 |
| `시간` | 시각 칸 |
| `안내 문구` | 단계 맨 아래 부가 한 줄 |
| `버튼 텍스트` | 버튼에 들어갈 말 |

**그 밖의 라벨을 지을 때 5가지**

1. **명사로 끝낸다** — `가격` ✅ / `가격 입력` ❌
2. **2~6자**
3. **그 칸 하나가 받는 것만** 가리킨다 — 두 가지를 묶은 라벨 ❌
4. **주제어를 넣지 않는다** — `프로그램 제목` ❌ → `제목`. 무엇에 대한 칸인지는 **왼쪽 패널 제목**이 이미 말하고 있다
5. **한 단계 안에 같은 라벨 두 개 ❌** — 앞에 구분어를 붙인다(`시작 날짜`·`종료 날짜` / `정상가`·`할인가`)

**예외 3가지**

| 예외 | 라벨 |
|---|---|
| 히어로의 사진 | `메인 이미지` · `로고 이미지` |
| 링크 칸 | 용도를 앞에 붙인다 — `유튜브 URL` · `링크` |
| 고르기 칸 | 무엇을 고르는지 — `유형` · `별점` |

**라벨을 붙이는 자리**

- **칸 위에 하나씩** 붙인다
- **반복 항목은 첫 항목에만** 붙인다 — 2번째 항목부터는 라벨 없이 칸만 늘어난다
- 🚫 **칸 라벨을 생략하는 경우 2가지** — 이때는 **그 줄 위에 묶음 라벨 하나**(`문의 연락처` · `후기`)만 붙인다
 | 조건 | 예 |
 |---|---|
 | 첫 칸이 **고르기**이고, **고른 값이 곧 그 항목의 이름**이 될 때 | `전화` ＋ 전화번호 칸 · `인스타그램` ＋ 주소 칸 |
 | 한 줄의 칸이 **전부 선택 칸**일 때 | 별점 ＋ 작성자 ＋ 날짜 |

### 3-5. 필수와 선택

| 분류 | 판정 |
|---|---|
| **필수** | 이 칸이 비면 **그 섹션이 성립하지 않는다** — 항목의 이름·제목, 일시, 가격 |
| **선택** | 비어도 섹션이 성립한다 — 설명 문구 · 안내 문구 · 부가 정보 |

- **칸이 하나뿐인 단계는 무조건 필수**
- **하단 버튼은 한 자리** — 필수가 다 차면 `이건 없어요` → `다음` 으로 바뀐다. AI가 미리 채운 칸도 **찬 것으로 센다**
- **반복 항목은 항목 안에서도 나뉜다** — 항목은 **필수 칸이 다 차야 완성**. 선택 칸만 빈 항목은 그 부분만 빼고 만든다

**자주 쓰는 묶음의 필수 · 선택**

| 묶음 | 필수 | 선택 |
|---|---|---|
| 날짜 ＋ 시간 | 날짜 | 시간 · 종료 일시 |
| 주소 | 주소 (**검색 결과를 고른 상태**여야 찬 것으로 센다) | 상세 주소 |
| 가격 | 판매가 | 정상가 · 할인율 |
| 제목 ＋ 내용 반복 | 제목 · 내용 | — |
| 이미지 ＋ 글 반복 | 이미지 · 제목 | 설명 |
| 이름 ＋ 링크 반복 | **이름 · 링크 둘 다** (하나만으론 버튼이 동작하지 않는다) | — |
| 연락처 반복 | 유형 · 값 | — |
| 예약 회차 | 날짜 · 시간 | 정원 |
| 후기 | 내용 | 별점 · 작성자 · 날짜 · 상품 옵션 |
| 신청 폼의 질문 | 유형 · 질문 · **객관식이면 선택지 2개 이상** | 주관식 답변 유도 문구 |
| 라벨 ＋ 값 표 | 라벨 · 값 쌍 (**채운 행만** 센다 · 빈 행은 지운다) | — |

### 3-6. 플레이스홀더

**왼쪽 입력칸의 빈칸 안내에만 해당한다.** 오른쪽 미리보기에 들어가는 글에는 `예: `를 쓰지 않는다 — 미리보기는 완성된 페이지처럼 보여야 한다.

| 대상 | 형식 | 예 |
|---|---|---|
| 기본 | **`예: ` ＋ 그 칸에 들어갈 법한 값** | `예: 아메리카노` · `예: 4,500원` |
| **날짜 · 시간 · 주소 · 연락처 · 링크** | **지시형** — 입력 방식이 형식을 강제하므로 예시가 필요 없다 | `날짜를 선택해 주세요.` · `링크 URL을 입력해 주세요.` |
| 계좌 · 가격 · 정원 · 작성자 이름 | **예시형** — 어떤 형태로 적을지를 예시가 알려준다 | `예: 국민은행 123456-78-901234` · `예: 20명` |
| 반복 항목 **2번째부터** | 지시형 | `내용을 입력해 주세요.` |

- 지시형 어미는 **`~해 주세요.`** 로 통일한다(마침표 포함)
- **고르기 칸의 플레이스홀더는 고른 유형을 따라간다** — 전화를 고르면 `전화번호를 입력해 주세요.`

### 3-7. 순서

- **단계 순서 = 페이지에서 섹션이 놓인 순서**
- **단계 안의 칸 순서 = 그 섹션에서 정보가 보이는 순서**

### 3-8. 화면 동작

**포커스**

- 단계에 들어가면 **첫 「텍스트」 칸**에 커서를 둔다
- **첫 칸이 고르기면 건너뛰고** 그다음 텍스트 칸에 둔다
- **첫 칸이 이미지면 커서를 두지 않는다**
- `항목 추가`를 누르면 **늘어난 항목의 첫 칸**으로 커서를 옮긴다

**반복 항목**

- **✕(삭제)는 항목이 2개 이상일 때만** 보인다
- **드래그 핸들은 개수와 무관하게 항상** 보인다 · 순서를 바꿀 수 있다
- **1자 이상 입력해야 `항목 추가`가 켜진다**

**켜기·끄기가 하는 일**

| 스위치 | 켜면 |
|---|---|
| `하루종일` | 시간 칸을 숨긴다 (종료 시간까지) |
| `종료일 추가` | 종료 날짜·시간 칸이 생기고, 원래 라벨이 `시작 날짜`·`시작 시간`으로 바뀐다 |
| `인원 제한 없음` | 정원 칸을 잠근다 |
| `할인율 표시` | 끄면 할인율을 숨긴다 |

**그 밖**

- 이미지는 **1장당 10MB까지**
- 사진을 올리면 **남은 빈 업로드 박스를 숨기고**, 올린 개수에 맞춰 폭을 채운다
- **첫 번째 텍스트 칸에 친 글은 오른쪽 미리보기에 바로 반영**한다
- 형식이 틀리면 칸 아래에 빨간 줄로 알린다 — `전화번호를 정확히 입력해 주세요.` · `URL을 정확히 입력해 주세요.`
- **엔터로는 단계가 넘어가지 않는다** — 엔터·탭은 다음 칸으로, 단계 이동은 하단 버튼 또는 Cmd/Ctrl＋엔터

### 3-9. 미리보기에 넣을 수 없는 것

아래는 **입력을 받아도 페이지에 표시할 방법이 없다.** 칸을 만들지 않는다.

- **남은 자리 · 잔여 수량** — 예약이 들어올 때마다 바뀌는 숫자
- **D-DAY · 남은 날짜** — 시간이 지나면 바뀌는 표시

정원은 **`회차당 정원 8명`** 처럼 **바뀌지 않는 문장**으로만 보여준다.
