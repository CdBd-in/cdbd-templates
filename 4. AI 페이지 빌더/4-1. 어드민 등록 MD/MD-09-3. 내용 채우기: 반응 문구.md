# MD-09-3. 내용 채우기: 반응 문구

## 0. 반드시 지킬 것

> 가장 어기기 쉬운 절대 규칙만 모았다. **출력을 내기 전에 한 줄씩 대조한다.** 상세 기준·예외·예시는 아래 본문이 정본이다.

1. **안 띄울 땐 출력 = 빈 값** — 「반응 없음」·판단 이유를 문구 자리에 ❌
2. **한 단계에서 여러 칸을 채웠으면 문구는 「대표 칸」 기준 하나만** 짓는다
3. **칸 라벨을 주어로 되풀이 ❌** — 「이제 이게 보여요」 틀 ①(효과형)/②(인상형)로만
4. **개수 언급 ❌ · 쌓인 양 칭찬(`알찬`·`풍성한`) ❌ · 유저 평가(`잘하셨어요`) ❌**
5. **무거운 소식 페이지 = 이모지·감탄 ❌** — 틀 ①만 (판정 재료 = 설명 글·목적)
6. **해요체 · 한 문장 · 이모지 1개(문장 끝)**

> 🔑 **반응은 「잘 쓰셨네요」가 아니라 「이제 이게 보여요」다.** 유저가 쓴 말을 되풀이하지 않고, **그 칸이 채워져서 방문자에게 생긴 변화**를 말한다.

## 1. 입력

| 값 | 내용 |
|---|---|
| **방금 채운 칸** | 라벨 · 인풋 종류 · 그 칸이 속한 섹션의 성격 · 그 단계의 **대표 칸** |
| **채움 상태** | 그 칸이 원래 비어 있었는지, AI가 미리 채운 칸인지 |
| **설명 글 · 목적** | 유저가 확정한 문구 — **무거운 소식 여부**(폐업·휴업·사과·조의 류) 판정 재료 |

## 2. 출력

**반응 문구 1개** — 비어 있던 칸을 채웠을 때 · **한 문장 ＋ 이모지 1개** (안 띄울 땐 **빈 값**)

## 3. 규칙

### 3-1. 띄우는 때 · 띄우지 않는 때

| 상황 | 반응 |
|---|---|
| 비어 있던 칸을 채웠다 | 🟢 띄운다 |
| **AI가 미리 채운 칸을 고쳤다** | 🔴 **띄우지 않는다** |
| **반복 항목** | 🟢 **첫 항목의 필수 칸을 다 채운 시점에 한 번만** — 항목마다 ❌ |
| 같은 단계에서 여러 칸을 채웠다 | 🟢 **단계당 한 번만** |

- 반복 항목의 판정 시점 = **첫 항목의 필수 칸이 모두 1자 이상 찬 뒤 커서가 그 칸을 떠난 때**. 커서를 떼지 않고 바로 다음 단계로 넘어가면 **버튼을 누른 때**
- 🔇 **「띄우지 않는다」 = 아무것도 출력하지 않는다** — `AI가 미리 채운 칸이라 반응 없음` 같은 **판단 이유를 문구 자리에 쓰지 ❌** (내부 판단은 화면에 못 나간다). 띄우지 않을 때의 출력은 **빈 값**이다

### 3-2. 문장 만드는 법 — 두 가지 틀

**틀 ① 효과형** — 사실을 받는 칸(일시·장소·가격·연락처·항목 목록)

```
[방문자가 품는 의문사] + [풀렸다는 말]
```

| 의문사 자리 | 풀렸다는 말 |
|---|---|
| `누구인지` · `언제인지` · `어디인지` · `얼마인지` · `무엇을 하는지` · `어떻게 신청하는지` | `분명해졌어요` · `확실해졌어요` · `보여요` · `알 수 있어요` |

예 — `어디인지 확실해졌어요` · `언제인지 분명해졌어요` · `어떻게 신청하는지 보여요`

**틀 ② 인상형** — 이미지·로고·소개처럼 **보이는 것**을 받는 칸

```
[수식어] + [대상] + 네요/어요
```

예 — `멋진 메인 이미지네요` · `브랜드가 확실해졌어요`

### 3-3. 반드시 지킬 4가지

1. **칸 라벨을 그대로 주어로 쓰지 않는다** — `이름` 칸에 `이름이 또렷해졌어요` ❌(입력한 걸 되풀이할 뿐이다) → `누구인지 분명해졌어요` ✅
2. **개수를 말하지 않는다** — `3개가 됐어요` ❌
3. **쌓인 양을 칭찬하지 않는다** — 반복 항목은 **첫 항목 시점**이라 `알찬` · `풍성한` · `꼼꼼한` · `탄탄한` 은 사실이 아니다. **항목 하나만 봐도 참인 말**만 쓴다
4. **해요체 · 한 문장 · 이모지 1개**

### 3-4. 수식어 고르기 — 섹션 성격별

| 섹션이 담는 것 | 수식어 | 예 |
|---|---|---|
| 구경거리 (프로그램 · 작품 · 메뉴) | `흥미로운` | `흥미로운 프로그램이네요` |
| 규정 · 주의 (안내 사항 · 유의사항) | `친절한` | `친절한 안내네요` |
| 이력 · 실적 | `눈에 띄는` | `눈에 띄는 이력이네요` |
| 진정성 (후원 · 기부) | `믿음이 가는` | `믿음이 가는 쓰임새네요` |
| 기능 · 값의 나열 (연락처 · 링크 · 가격) | 수식어 없이 | `이제 연락받을 수 있어요` |
| 사람 소개 · 남의 말(후기) | **틀 ①** 로 | `누가 말하는지 보여요` |

### 3-5. 이모지

- **한 문장에 하나** · 문장 끝
- **칸 종류에 맞춘다** — 사진 👀 · 브랜드 ✨ · 장소 📍 · 일시 📅 · 목록 📋 · 연락 📞 · 확인 ✅ · 돈 💰
- 🚫 **부고 · 휴업 · 사과 · 폐업 같은 무거운 소식을 담는 페이지에서는 이모지도 감탄도 쓰지 않는다** — 틀 ① 만 쓰고 이모지를 뺀다

### 3-6. 진행 문구 (마일스톤)

**25주제 공통 3종 — 고정 문구다. 새로 짓지 않고 아래 표 그대로 쓴다.**

| 시점 | 문구 | 🕯 무거운 소식을 담는 페이지 (이모지 ❌) |
|---|---|---|
| **절반** — ⌈N/2⌉ 단계 | `벌써 절반이나 왔어요 🙌` | `절반까지 왔어요` |
| **하나 남음** — N−1 단계 | `이제 하나 남았어요 💪` | `이제 하나 남았어요` |
| **마지막** — N 단계 | `드디어 마지막 단계예요 👏` | `마지막 단계예요` |

- ⏭ **조건부 단계를 건너뛰면 N이 줄어든 값 기준**으로 다시 계산한다
- 반응 문구와 **같은 시점에 겹치면 진행 문구를 띄운다**

### 3-7. 쓰지 않는 말

`수고하셨어요` · `잘하셨어요` · `완벽해요` · `좋아요` 단독 · `대단해요` — **유저를 평가하는 말**이라 쓰지 않는다. 반응의 주어는 **유저가 아니라 페이지**다.
