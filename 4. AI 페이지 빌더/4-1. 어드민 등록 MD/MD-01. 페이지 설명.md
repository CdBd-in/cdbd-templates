# MD-01. 페이지 설명

> 📍 **화면**: v2 · 2 페이지 설명 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9880)
> ✍️ **말투·길이·금지 표현 = [[MD-00. UX 라이팅 기준]]** (01~04 공통)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

「이런 페이지 맞나요?」 화면에 **미리 채워 둘 페이지 설명 문구 1개**를 만든다.

## 2. 입력

① 유저가 올린 자료(파일·링크·붙여넣은 글) ② ①단계 자료 유무 응답

## 3. 출력

**페이지 설명 문구 1개** (수정 가능한 텍스트로 입력창에 채워짐)

## 4. 규칙

- 자료에서 읽어낸 **사실만** 쓴다 — 일시·장소·가격·연락처는 **지어내지 않는다**
- 자료가 빈약하면 **짧게** — 억지로 늘리지 않는다
- 유저가 「아니요」를 누를 수 있게, **틀렸는지 바로 판단되는** 문장으로

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 5. 볼트 근거

- [[MD-00. UX 라이팅 기준]] §5 미리 채우기 원칙
- [[4-7. 입력 단계 안내 문구]] — 「지어낼 칸 / 사실이라 비울 칸」 구분

## 6. 원본 코멘트

```
자료 -> 이런페이지맞나요? 내용으로 텍스트 변환할
```

## 7. 같은 화면의 「MD 아닌 것」 — 어드민 고정값

자료가 **없는** 유저에게 보여줄 **예시 칩**([피그마](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-10395))은 AI가 만들지 않는다. **어드민에서 고정으로 등록**한다.

```
어드민에서 고정으로 설정함, MD 아님
1. 아래 선택지 N개
2. 선택지 당 위에 표시할 글
```

**🚧 등록할 값 (2026-09-11 제안 · 확정 대기)** — 칩 6개 + 각 칩의 예시글.
칩 = `행사·모임을 열어요` · `제품·메뉴를 보여줘요` · `하는 일을 소개해요` · `신청을 받아요` · `포트폴리오를 보여줘요` · `공지를 알려요`
예시글 = **구어체 5줄 · 줄마다 다른 종류의 정보 · 맨 위에 `(예시예요 — 아래를 내 내용으로 바꿔 주세요)` 한 줄**.
근거 = 실사용 549건([[4-3. 목적·주제별 분류]] §4-B) — 「가게」는 업종어라 기관·갤러리를 밀어내고, 페이지 절반이 카탈로그라 「팔아요」보다 「보여줘요」가 넓다.
