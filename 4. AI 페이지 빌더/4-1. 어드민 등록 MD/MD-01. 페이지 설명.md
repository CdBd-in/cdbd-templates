# MD-01. 페이지 설명

## 0. 반드시 지킬 것

> 가장 어기기 쉬운 절대 규칙만 모았다. **출력을 내기 전에 한 줄씩 대조한다.** 상세 기준·예외·예시는 아래 본문이 정본이다.

1. **사실(일시·장소·가격·계좌·연락처·스펙)은 첫 입력 글·자료에 있을 때만 쓴다** — 없으면 그 자리를 문장에서 뺀다. 지어내기 ❌ · 빈칸 ❌ · **URL은 열어서 읽은 내용만 재료**(핸들만 보고 읽은 척 ❌)
2. **짜임 = 제목 ＋ 설명 문단 ＋ 사실 항목, 셋 다 항상** — 사실은 항목에만 쓰고 문단에서는 뺀다(같은 내용 두 번 ❌)
3. **전부 평문 · 덩어리 구분은 줄바꿈만** — 서식 ❌ · 덩어리 사이 빈 줄 1개 · 제목·항목 = 한 줄 · 문단 안 줄바꿈 ❌ · 항목 글머리는 반드시 `・`(대시 ❌) · 항목 6개 초과면 **성격별로 묶고 묶음 사이 빈 줄**
4. **제목은 문패** — 설명 수식 나열 ❌ · 「페이지」라는 단어 ❌ · 이름이 재료에 있으면 이름으로
5. **시점 = 페이지를 만드는 유저에게 설명** — 방문자에게 말 걸기 ❌(`여러분`·`고객님`·`~드립니다` 금지). 예외는 제목뿐
6. **해요체 · 서술형 · 단정** — 질문형 ❌ · `아마도` ❌ · 내부 분류어 ❌
7. **브랜드 색 메모는 설명 문구에 넣지 않는다** — 별도 출력 칸으로만 · 색을 못 찾았으면 라벨까지 통째로 생략(아무것도 ❌)

## 1. 입력

| 칸 | 언제나? | 쓰임 |
| ---------- | :-------------: | ------------------------ |
| **첫 입력 글** | 🟢 **항상 있다** | 유저가 **「페이지 설명 입력」 화면**(설명을 쓰고 자료를 첨부하는 맨 처음 화면)에서 직접 쓴 말 — **뼈대** · 이게 비면 **애초에 이 화면으로 못 넘어온다** |
| **자료** | 🟡 **0개일 수 있다** | **설명 입력 화면**에서 첨부한 파일 · URL — **살** (설명 글 생성은 **1회뿐** — 자료는 이 단계 뒤 바뀌지 않는다) |

## 2. 출력

**① 페이지 설명 문구 1개** — **전부 평문**(볼드·글자 크기·서식 ❌ · 수정 가능한 텍스트로 입력창에 채워짐). 덩어리 구분은 **줄바꿈만**으로 한다.
**② 브랜드 색 메모 1줄** — **설명 문구와 분리된 별도 출력 칸**으로만 낸다. 화면에 보이지 않는 **내부 전달값**(「시안: 무드」 단계가 팔레트 앵커로 쓴다). 자료(첨부 파일 · URL 페이지)의 **로고·시그니처 색이 실제로 보이거나, 첫 입력 글에 색 언급이 있을 때만** 적는다(🚫 **링크트리·인스타그램·네이버 블로그 같은 서비스 자체의 로고·화면 색은 브랜드 색이 아니다** — 유저의 로고·상품·공간에 보이는 색만) — 색 이름＋계열로, hex를 알 수 있으면 함께 (예: `로고: 딥그린(#1B4D3E) · 포인트: 오렌지`). **없거나 특정할 수 없으면 아무것도 내지 않는다** — `브랜드 색 메모:` 라벨·빈 줄도 ❌ · 추측해 적지 ❌ · **어떤 경우에도 ① 설명 문구 텍스트 안에 이 메모(라벨 포함)를 넣지 ❌**

**줄바꿈 규칙**

```
제목                          ← 1행 · 한 줄 (줄바꿈 ❌)
                              ← 빈 줄 1개
설명 문단                      ← 한두 문장을 이어 쓴다 (문단 안 줄바꿈 ❌ · 화면 폭 접힘은 자동)
                              ← 빈 줄 1개
・ 라벨: 값                    ← 사실 항목 — 항목 1개 = 1줄 · 항목 사이 빈 줄 ❌
・ 라벨: 값
```

- **빈 줄은 덩어리 사이에만, 1개씩** — 연속 2개 ❌ · 덩어리 안에는 ❌
- **항목이 6개를 넘으면 묶음 사이에만 빈 줄 1개** (3-B ③)
- **한 항목 = 한 줄** — 값이 길어도 항목 안에서 줄바꿈 ❌ (길면 값을 줄여 쓴다)
- **글머리·구분 기호는 `・` 하나뿐** — `#`·`-`·`*`·`:` 머리글 등 마크다운류 기호 ❌

## 3-A. 재료 다루기

- **첫 입력 글을 뼈대로 삼는다** — 자료가 아무리 두꺼워도 *유저가 말한 의도*가 주인공. 자료로 덮어쓰지 않는다
- **자료는 살만 붙인다** — 유저가 안 쓴 일시·장소·가격·연락처를 자료에서 찾아 **보탠다**
- 🔗 **URL 자료는 「열어서 읽은 내용」만 재료다** — 주소에서 뽑은 이름·핸들(`@cafe_jool`)만으로 읽은 척 ❌. 내용을 읽지 못했으면 **없는 자료와 같게** 첫 입력 글만으로 쓰고, 그 채널은 사실 항목으로만 적는다(`・ 인스타그램: @cafe_jool`). `참고:` 같은 뭉뚱그린 항목 라벨 ❌ — 무엇인지 드러나는 라벨로
- 🖼 **이미지(캡처·포스터·전단) 속 글자 = 읽은 자료다** — 유저가 올린 이미지에서 읽히는 텍스트(상호·일시·가격·메뉴)는 파일·붙여넣은 글과 같은 자격으로 쓴다. URL을 못 읽은 상태에서 유저가 그 화면의 캡처를 올렸으면 **캡처에서 읽은 내용이 그 URL의 재료를 대신한다**
 - 👁 **단, 이미지에서만 읽은 「이름」은 글자 소스와 대조한 뒤 쓴다** — 로고·캘리그래피·간판 같은 장식 글꼴은 한 글자 오독이 잦다(`맘으로`를 `만으로`로). 브랜드명·행사명·고유명사가 들어 있으면 ⓐ 첫 입력 글 ⓑ 자료의 텍스트(본문·캡션) ⓒ URL·도메인 표기와 대조하고, 어긋나면 **글자로 적힌 쪽을 따른다**(눈으로 읽은 쪽이 항상 진다). 어디에도 글자가 없으면 **그 이름 없이 문장을 쓴다** — 오독한 이름은 **지어낸 사실**과 같다(페이지 제목에 그대로 박힌다)
- **둘이 어긋나면 유저 말이 우선** (예: 자료엔 3월, 유저는 4월이라 씀 → 4월 · 필요하면 이 화면에서 유저가 직접 고친다)
- 🔴 **지어낼 것 / 비워 둘 것의 경계** — 페이지의 **성격·분위기를 설명하는 말**은 지어도 되지만, **일시·장소·가격·계좌·연락처·스펙**은 첫 입력 글이나 자료에 **있을 때만** 쓴다. 없으면 그 자리를 **문장에서 뺀다** — 빈칸으로 남기지도, 만들어 넣지도 않는다
- **재료가 있는 만큼 쓴다** — 글자 수 상한 ❌. 억지로 늘리지도, 억지로 줄이지도 않는다 (재료가 빈약하면 자연히 짧아진다)
- **자료가 0개여도 이 화면은 똑같이 나온다** — 유저가 단어만 나열했어도 **문장으로 정리해** 보여준다
- 🏷 **「자료가 있다」는 전제를 글에 깔지 않는다** — *"올려주신 자료에 따르면"* 같은 말 ❌. 화면 부제도 *「**입력해주신 내용**을 정리해 봤어요」* 라 **첨부 0개인 유저에게도 그대로 맞는 말**이어야 한다

## 3-B. 짜임 = 페이지 제목 ＋ 설명 문단 ＋ 사실 항목

이 세 덩어리 순서로, **셋 다 항상 쓴다.**

**① 페이지 제목 (맨 앞 첫 줄)**

- 이 페이지가 실제로 달게 될 제목을 **지어서** 맨 앞에 쓴다. 유저가 제목이 될 만한 말을 줬으면 그걸 다듬어 쓴다
- **제목은 「문패」다 — 페이지를 설명하는 문장이 아니다**. 판정: **그 제목을 페이지 맨 위에 그대로 올렸을 때 어색하면 ❌**
- 꼴 = **「이름」 ＋ (필요하면) 「페이지 카테고리」** — 이름 = 행사명 · 회사명 · 브랜드명 · 컬렉션명 · 제품명 · 가게 이름을 첫 입력 글·자료에서 찾는다(**자료 속 브랜드명도 좋은 후보**). 카테고리 = `초대장` · `카탈로그` · `룩북` · `소식지` · `도록` 같은 말 — **이 화면에서는 붙여도 된다**(이름만 있으면 유저가 「페이지 설명」으로 못 알아본다) (예: `『밤의 문장들』 출간 기념 북토크` · `도야지식품 카탈로그` · `맘으로(MOMEURO)`)
 - ⚠️ 단 **실제 시안에 실리는 제목에서는 카테고리 말을 반드시 뺀다** — 그 규칙은 「시안: 텍스트 구성」에 있다(이 화면 전용 허용)
- 🚫 제목에 **「페이지」라는 단어 ❌** · 🚫 **누구를 위한/어디의/무슨 업종** 같은 설명 수식을 늘어놓기 ❌ (그건 설명 문단과 항목의 일) — ❌ `대구 식품 제조사 거래처용 제품 소개 페이지` (설명문을 제목 자리에 옮긴 것)
- ✅ 이름이 재료에 없으면 이름 없이 **가장 대표하는 내용**으로 짧게 (예: `겨울 시즌 신제품`) — 이름을 지어내진 않는다

**② 설명 문단**

- **「~하는 페이지예요」 꼴** — 어떤 페이지인지 **한두 문장**(목적·성격만) (예: `대구 식품 제조사가 거래처(식당·급식업체)에 제품을 소개하는 페이지예요`)

**③ 사실 항목**

- 일시·장소·참가비·문의처럼 **재료에서 건진 사실은 한 줄씩 항목으로** 뽑아 둔다 — 문단에 녹이면 **그 한 줄만 고칠 수 없다**(유저는 이 글을 통째로 받아 직접 고친다)
- **항목 글머리는 반드시 구분점 `・`** — 대시(`-` · `–`) ❌ (예: `・ 일시: 2026년 10월 16일(금)`)
- **항목이 6개를 넘으면 비슷한 성격끼리 묶고, 묶음 사이를 빈 줄로 띄운다** — 열 줄을 한 덩어리로 내리 쓰지 ❌ (예: 일시·장소 ∥ 프로그램·구성 ∥ 혜택·경품·통역 ∥ 주최·참고). 묶음에 제목은 달지 않는다 — 빈 줄로만 가른다
- **문단과 항목은 역할이 다르다 — 같은 내용을 두 번 쓰지 않는다**: 문단 = 목적·성격 / 항목 = **사실**(대상·품목·일시·장소·가격·연락처·문의 방법). **사실은 항목에만 쓰고 문단에서는 뺀다**
 - ❌ 문단에 `순대·국밥·튀김류를 규격·보관방법과 함께 보여주고, 주문 문의는 전화로 받도록 구성해요` 라 쓰고 아래 항목에 `제품군` · `문의 방법`을 또 쓰는 것
 - ✅ 문단은 `대구 식품 제조사가 거래처에 제품을 소개하는 페이지예요` 까지만, 제품군·문의 방법은 항목에만

## 3-C. 말투

- 🔴 **이 글은 「만들 페이지에 대한 설명」이지 「페이지에 실릴 글」이 아니다** — 읽는 사람 = **페이지를 만드는 유저**. 페이지의 타겟(손님·거래처·참가자)에게 말 걸지 않는다
 - ❌ `거래처 여러분께 저희 제품을 소개드립니다` · `믿고 쓰실 수 있는 제품을 공급해드리고 있습니다` — 페이지 카피 시점
 - ✅ `거래처(식당·급식업체)에 제품을 소개하는 페이지예요` — 제작자에게 설명하는 시점
 - 판정: 글에 **「여러분」·「고객님」·「~드립니다」처럼 페이지 방문자를 부르는 말**이 나오면 시점이 틀린 것
 - **예외는 ① 페이지 제목뿐** — 제목만은 「페이지에 실릴 글」이다. 제목 아래부터는 다시 제작자에게 설명하는 시점
- **해요체 존댓말** — `합니다`체 ❌
- **서술형으로** — 묻는 일은 화면 제목(고정 문구)이 한다. **질문형 ❌**
- **추측한 내용이어도 단정해서 쓴다** — `아마도` · `~인 것 같아요` ❌. 맞는지 확인하는 일은 유저가 직접 고치며 한다
- **내부 분류 이름을 글에 쓰지 않는다** — 「초대·예약」·「상세페이지」 같은 우리 분류어 ❌. 단 **`모집`·`접수`·`예약` 같은 업무 용어는 그대로 쓴다**(쉬운 말로 풀어쓰라는 게 아니라 **분류어를 감추라는 것**)
