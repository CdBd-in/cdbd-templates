# MD-08-2. 무드 (시안 A)

> 📍 **화면**: 7 · 시안 생성 → 11 · 무드 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6919-10907)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

시안 A에 쓸 **무드 1개** ＋ 무드 확인 화면에 보여줄 **추천 무드 N개**.

## 2. 입력

**타겟 라벨** · **내부 판정 주제코드·무드 후보** · **자료**의 브랜드 자산(로고 색 등 · 첨부가 0개일 수 있다)

> 📥 칸 정의 = [[MD-01. UX 라이팅]] §8 부록

## 3. 출력

무드 1개(= 3토큰 팔레트 + 서체) ＋ 추천 무드 N개 ＋ **생성 기록**(팔레트 · 배경 명도 칸)

## 4. 규칙

- 팔레트는 **라이브러리 316개 안에서 고른다** — 새로 만들지 않는다
- **대비 2개**(텍스트↔배경 · 버튼↔배경) 각 **3.6:1 이상**을 hex에서 직접 계산
- **표 맨 윗줄부터 집지 않는다** — 무드 서랍 안에서 **랜덤**
- **배경 명도 칸**을 기록한다 → [[MD-09. 시안 B·C]]가 남은 칸에서 고른다(3안이 전부 같은 명도 방향 ❌)
- 주제·브랜드 성격과 어긋나는 무드 ❌ (신뢰형 = 프로/비즈니스 · 미니멀 브랜드 = 저채도 뉴트럴)

> 🚧 여기에 실제 생성 지침을 채운다.
