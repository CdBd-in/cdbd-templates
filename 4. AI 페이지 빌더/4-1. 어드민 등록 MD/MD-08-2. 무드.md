# MD-08-2. 무드 (시안 A)


## 1. 입력

- **타겟 라벨** — 유저가 타겟 화면에서 고른 라벨
- **주제 코드 · 무드 후보** — 앞 단계에서 자동 판정한 값 (**화면 노출 ❌**)
- **자료** — 유저가 맨 처음 화면에서 첨부한 파일 · URL 속 브랜드 자산(로고 색 등 · **0개일 수 있다**)

## 2. 출력

무드 1개(= 3토큰 팔레트 + 서체) ＋ 추천 무드 N개 ＋ **생성 기록**(팔레트 · 배경 명도 칸)

## 3. 규칙

- 팔레트는 **라이브러리 316개 안에서 고른다** — 새로 만들지 않는다
- **대비 2개**(텍스트↔배경 · 버튼↔배경) 각 **3.6:1 이상**을 hex에서 직접 계산
- **표 맨 윗줄부터 집지 않는다** — 무드 서랍 안에서 **랜덤**
- **배경 명도 칸**을 기록한다 → [[MD-09. 시안 B·C]]가 남은 칸에서 고른다(3안이 전부 같은 명도 방향 ❌)
- 주제·브랜드 성격과 어긋나는 무드 ❌ (신뢰형 = 프로/비즈니스 · 미니멀 브랜드 = 저채도 뉴트럴)

### 무드를 정하는 순서 6단계

> 🚫 **표 맨 윗줄부터 집지 말 것.** 여기가 가장 자주 뚫린다 — 예전에 3안이 전부 같은 출처·표 상단 팔레트로 나왔다. **표 상단만 집는 버릇은 랜덤보다 나쁘다**(랜덤은 매번 다르지만, 이건 매번 같은 걸 낸다).

1. **🎬 주제의 실제 장면에서 색을 뽑는다** — 그 페이지가 존재하는 공간·사물의 색. **표를 열기 전에**(북토크라면 잉크 · 크림 · 전구 호박 · 가죽 · 야간 남색)
2. **🏷 브랜드 자산을 앵커로** — 로고 색·시그니처 색이 있으면 3토큰 중 하나에 반영
3. **🎨 무드로 톤 조정** — 같은 「전구빛」도 모던이면 차분한 황동, 드리미면 밝은 호박
4. **✅ 대비 2개 직접 계산** — `텍스트↔배경 ≥ 3.6:1` **그리고** `버튼↔배경 ≥ 3.6:1`
5. **🔁 3안 분산** — 아래 표
6. **📚 그 무드 서랍에서 채택** — ①~③을 검색 조건 삼아 고른다. **새로 만들지 않는다**

### 3안 분산

| 축 | 규칙 |
|---|---|
| **배경 명도** | 3안이 방향을 나눠 갖는다. **금지 = 3안 전부 같은 방향.** 비율은 자유(밝음2:다크1도, 다크2:밝음1도 OK) |
| **순백/순흑 탈피** | 라이트 = 크림·오트·베이지·세이지 / 다크 = 딥네이비·딥그린·잉크 · 중간 명도도 OK |
| **액센트 계열** | **최소 2계열**(따뜻함 / 차가움 / 중립). **3안 전부 따뜻한 색 ❌** — 명도만 벌리는 건(황동 vs 호박) 같은 계열이라 부족 |

### 색 규칙

- **3색이 기본** — 색1 `{배경색}` · 색2 `{텍스트색}` · 색3 `{버튼색}`. 2색이면 텍스트색과 버튼색이 같아져 **액센트가 없다**
- **보조 텍스트는 `{텍스트색} × 60%` / `× 40%`** — 별도 회색 ❌ · **강조 배경은 `{버튼색} × N%`**
- 🔴 **버튼 글자는 `{배경색}` 고정** — 그래서 **버튼↔배경 대비가 낮으면 버튼 글자도 같이 안 읽힌다.** 팔레트 표의 「대비」 값은 **텍스트↔배경만** 잰 것이므로 **버튼 대비는 반드시 직접 계산**

### 「무드에 맞음」이 「주제에 맞음」은 아니다

- **3안 중 최소 1안은 주제 장면이 연상되는 색** — 바다 = 블루/틸 · 녹차 = 그린 · 원두 = 브라운
- **담는 그릇이 되어야 하는 주제**(기관 · 전시 · 도록 · B2B)는 **뉴트럴 배경** — 파스텔 핑크·마젠타 배경 ❌
- **신뢰형**(세무 · 법무 · 컨설팅 · 명함)은 **차분한 톤** — 쨍한 원색·형광 ❌
- **화보·미니멀·여리여리한 주제**는 대비는 지키되 **채도를 낮춘다**

> 🚧 여기에 실제 생성 지침을 채운다.
