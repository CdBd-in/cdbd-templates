# MD-09. 시안 B·C

> 📍 **화면**: 9 추가 2안 물어보기 → 10 시안 비교 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6979-17853)

## 1. 무엇을 정하는 MD인가

시안 A와 **같은 근거**(07-1·07-2·07-3)를 쓰되 **서로 다르게** 나오도록 B·C를 만드는 규칙과 **노출 순서**.

## 2. 입력

**시안 A 기록** — 시드 · 레이아웃 유형 · 팔레트 id · 배경 명도 칸 · 쓴 섹션 id 배열

> 📥 칸 정의 = [[MD-00. 단계별 누적 정보]]

## 3. 출력

시안 B · C ＋ 보여줄 순서

## 4. 규칙

### ⏱ 만드는 시점 = 유저가 요청한 뒤

🚫 **미리 만들어 두지 않는다**. ⑨에서 `지금 시안으로 충분해요`(짧은 길)를 고르면 **미리 만든 2벌이 통째로 버려진다.**
💡 나중에 만들면 ⑦에서 **유저가 채운 최신 내용**이 그대로 들어간다.

### 🎲 다양성 = 「기록 제외」로 확보

시안 A가 **실제로 쓴 값**을 제외 목록으로 쓴다 — 3안을 나란히 놓고 비교할 필요가 없다.

```
섹션마다: 후보에서 「A가 쓴 섹션」 제외 → 랜덤 (후보 ≤3개면 공용 허용)
무드:     「A가 쓴 배경 명도 칸」 제외 → 남은 칸에서 랜덤
레이아웃:  A가 쓴 유형 제외 → 남은 2개
```

### 📋 노출 순서

- **A와 가장 다른 것을 B로** (차별화 레버)
- 단 [[MD-08-1. 레이아웃 유형]]의 **배제 규칙은 그대로 적용** — 배제된 유형은 C로 밀거나 쓰지 않는다
- 📮 **문의 섹션은 3안 모두 다른 것으로** — 버튼만 있어 제일 복붙되기 쉬운 섹션

> 🚧 여기에 실제 생성 지침을 채운다.

## 5. 함께 지키는 것 — 차별화 레버

같은 속성이 **한 안 안에서는 「통일」**, **안 사이에서는 「차별화」** 로 쓰인다.

| 레버 | 한 안 **안**에서 | 안 **사이**에서 |
|---|---|---|
| 버튼 모양 | 1종 (테마 전역) | **최소 2종** (각진 · 둥근 · 원형 중) |
| 섹션 제목 형식 | 1형식 | 안마다 다른 형식 |
| 모서리 | 1값 | **각진 ↔ 둥근**으로 가른다 |
| 좌우 여백 | 1값 | 미니멀 32 / 에디토리얼 20 / 볼드 20 |
| 색 | 3토큰 역할 고정 | **배경 명도 방향 + 액센트 계열** 분산 |
| 구조 | — | 도입 · 정보 밀도 · 이미지 비중 · 카드 타입 · 순서 중 **3개 이상** 다르게 |
| 문의 섹션 | 그 안의 버튼 스타일로 통일(수미상관) | **3안 모두 다른 섹션** |

> ⚠️ **통일만 잘하면 「각자 잘 통일된 쌍둥이」가 된다** — 실제로 세 시안이 전부 같은 라벨 크기 · 원형 버튼 · 다크＋따뜻한 색이었던 적이 있고, **각 안 안에서는 완벽히 통일**돼 있었다. 통일 점검으로는 이걸 못 잡는다.
