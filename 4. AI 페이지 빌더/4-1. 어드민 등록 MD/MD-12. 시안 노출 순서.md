# MD-12. 시안 노출 순서

> 📍 **화면**: 7 · 시안 생성 (과정) · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6979-17853)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)
> 🚧 **상태**: 골격만 — 본문 지침 작성 대기

## 1. 무엇을 정하는 MD인가

2·3안을 **볼드 · 에디토리얼 · 미니멀** 중 어떤 순서로 보여줄지를 만든다.

## 2. 입력

**안1 생성 기록** — 실제로 쓴 레이아웃 스타일(MD-08) · 무드·팔레트 명도 칸(MD-09) · 섹션 id 목록

## 3. 출력

2·3안을 **볼드 · 에디토리얼 · 미니멀** 중 어떤 순서로 보여줄지

## 4. 규칙

- 1안과 가장 다른 것을 2안으로 (차별화 레버)
- ⏱ **결정 시점 = 유저가 ⑨에서 「네, 보여주세요」를 누른 뒤** — 안1을 만들 때 미리 정해 둘 필요가 없다(안 볼 수도 있다)
- 🔑 **안1 기록을 제외 목록으로 쓴다** — 이것만 지키면 1안이 두 번 나오지 않는다(MD-08과 미리 짝지어 둘 필요 ❌)

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.
