# MD-01. UX 라이팅 (전체 공통)

> 📏 **여기엔 「모든 화면에 공통인 것」만 둔다.** 일부 MD에만 해당하는 규칙은 **그 MD 안에** 쓴다 — 매 작업마다 여는 문서라 짧아야 한다.
> 🔗 **적용 범위** = **서비스 화면에 나가는 글**(질문·부제·버튼·칩) — **아래 4개뿐**. 읽는 사람이 **페이지를 만드는 유저**인 글이다.
> 🚫 **시안 안 텍스트는 대상 아님**(읽는 사람이 그 유저의 **손님**) → [[MD-08-3. 텍스트 구성·보이스톤]]
> 📌 **화면 제목·부제·버튼 라벨**(어드민에 등록해 두는 고정 문구)도 같은 기준을 따른다 — 거기가 딱딱한데 AI 문장만 상냥하면 **한 화면에서 말투가 튄다.**

## 1. 말투 5줄

- **해요체 존댓말** — `합니다`체 ❌
- **한 문장 = 한 가지** — 두 가지를 `~고, ~며`로 잇지 않는다
- **유저가 쓰는 말로** — 아래 내부 용어는 화면에 **절대 노출 ❌**
  > 주제 분류 · 목적 분류(P1~P6) · 섹션 목적 · 레이아웃 스타일(미니멀/에디토리얼/볼드) · 무드 이름 · 카테고리 · 섹션 · 카드
- **단정하되 바꿀 수 있게** — *"○○로 만들어 드릴게요"* ＋ `바꾸기`
- **질문형은 화면당 1개** — 제목만 질문, 나머지는 서술

## 2. 길이 상한

| 자리 | 상한 |
|---|:--:|
| 화면 제목 | **20자** |
| 부제 | **35자** |
| 미리 채운 문장 | **40자** |
| 선택지 라벨 | **12자** |

## 3. 금지 표현

| 유형 | ❌ | ✅ |
|---|---|---|
| 기계 말투 | *"자료를 분석했습니다"* | *"올려주신 내용을 정리해 봤어요"* |
| 과장·감탄 남발 | *"완벽해요! 놀라운 페이지가 ✨🎉"* | 감탄사는 화면당 1개까지 |
| 사과·불확실 | *"죄송해요"* · *"아마도"* | 사실만 · 단정 |
| 유저 탓 | *"잘못 입력하셨어요"* | *"이 부분만 다시 알려 주시겠어요?"* |
| 분류 노출 | *"5-② 모집 페이지네요"* | *"사람을 모으는 페이지네요"* |
| 「블록」 | *"블록을 추가할까요?"* | 개별 = **카드** · 묶음 = **섹션** |

## 4. 이 규칙들이 나온 자리

- 🥇 **「고르게 하지 말고, 정해서 보여주고, 바꿀 수 있게」** — 빌더 전체를 관통하는 원칙이다. 화면은 선택지를 늘어놓지 않고 **AI가 정한 값을 보여준 뒤 `바꾸기`를 붙인다.** 「말투」의 **단정하되 바꿀 수 있게**가 이 원칙의 화면판이다.
- 🔒 **화면 제목·부제·버튼 라벨은 이미 정해져 있다** — 어드민에 등록해 둔 고정 문구를 그대로 쓴다. AI가 새로 짓지 않는다.
- 📦 **내용 채우기 팁도 미리 써 둔 문구다** — 주제·칸마다 한 번 써서 등록해 둔 목록에서 **고르기만** 한다(고르는 규칙 = [[MD-10. 내용 채우기 팁]]). 그 문구가 지켜야 할 기준 = **15자 이내 · 그 칸에서만 성립하는 말 · 사실 정보 칸엔 개수·분량 조언 ❌ · 마땅치 않으면 비워 둘 것**.

## 5. 부록 — 단계별 누적 정보 (전 MD 공통 입력 계약)

> 📌 각 MD의 입력은 **여기 있는 이름 그대로** 적는다(줄임 기호·번호 ❌).

| 칸 | 담기는 값 | 채우는 MD |
|---|---|---|
| **첫 입력 글** | 유저가 ① 화면에서 **직접 쓴 말** (예시 칩으로 채운 글 포함) — 🟢 **항상 있다** | (①화면) |
| **자료** | ① 화면에서 **첨부한** 파일 · URL — 🟡 **0개일 수 있다** | (①화면) |
| **설명 글** | 유저가 ②에서 **확인·수정을 끝낸** 페이지 설명 1개 | [[MD-02. 페이지 설명]] |
| **목적** | 유저가 확정한 목적 문구 1개 | [[MD-03. 목적]] |
| **추가 항목** | 유저가 **켠 칩만** `{문구, 섹션 목적, 들어갈 자리}` 배열 | [[MD-04. 추가 항목]] |
| **타겟** | 타겟 문구 1개 ＋ 유저가 고른 **라벨 배열** | [[MD-05. 타겟]] |
| **내부 판정** | 주제코드(25) · 목적 분류(P1~P6) · 무드 후보 — **화면 노출 ❌** | 02~05 진행 중 자동 |
| **페이지 유형** | `원페이지 / 멀티페이지` (근거 한 줄은 유형별로 미리 써 둠) | [[MD-06. 페이지 유형 판정]] |
| **구성** | `{섹션 목적, 섹션 id, 순서, 페이지 번호}` 배열 | [[MD-07. 페이지 구성]] |
| **시안 A 기록** | 시드 · 레이아웃 유형 · 팔레트 id · 배경 명도 칸 · 쓴 섹션 id 배열 | 08-1 · 08-2 · 08-3 |
| **채운 내용** | 유저가 채운 칸 / 비어 있는 칸 | (⑦화면) |

| 09 시안 B·C | **시안 A 기록** | 안 B · C |
| 10 채우기 팁 | 구성 · 채운 내용 | 칸별 팁 **선택**(미리 써 둔 문구에서) |

🔄 **2026-09-11 — 「첫 입력 글」이 새로 생겼다.** ① 화면이 **설명 입력과 자료 첨부를 한 번에** 받도록 바뀌면서, 유저가 직접 쓴 말이 **자료와 별개로** 항상 들어온다. 옛 설계처럼 *자료가 없을 때만 설명을 받는* 갈래는 **없다** — **설명은 항상, 자료는 선택.**

⚠️ **「내부 판정」은 화면에 절대 나오지 않는다** (「말투」 내부 용어 금지).
