# MD-01. UX 라이팅 (전체 공통)

> 📏 **여기엔 「모든 화면에 공통인 것」만 둔다.** 일부 MD에만 해당하는 규칙은 **그 MD 안에** 쓴다 — 매 작업마다 여는 문서라 짧아야 한다.
> 🔗 **적용 범위** = **서비스 화면에 표시되는 텍스트**(질문·부제·버튼·칩) — **아래 4개뿐**. 읽는 사람이 **페이지를 만드는 유저**인 글이다.

## 1. 말투·표현

- **해요체 존댓말** — `합니다`체 ❌ (문장 3개에 적용 · 칩 라벨은 명사구)
- **서술형으로** — 묻는 일은 화면 제목(고정 문구)이 한다. 문장도 칩도 **질문형 ❌**
- **추측한 내용이어도 단정해서 쓴다** — `아마도` · `~인 것 같아요` ❌. 맞는지 확인받는 일은 화면이 한다
- **내부 용어는 화면에 절대 노출 ❌** (`5-②` 같은 분류 코드 포함)
  > 주제 분류 · 목적 분류(P1~P6) · 섹션 목적 · 레이아웃 스타일(미니멀/에디토리얼/볼드) · 무드 이름 · 카테고리 · 섹션 · 카드
  - ⚠️ **감추라는 것이지 쉬운 말로 풀어쓰라는 게 아니다** — `모집·접수·예약` 같은 **업무 용어는 그대로 쓴다**(`사람을 모으는` ❌ → `신입 회원을 모집하는` ✅)
  - **누구·무엇인지 채워서 구체적으로** — 분류 이름을 뺀 자리는 **대상**으로 메운다

## 2. 부록 — 단계별 누적 정보 (전 MD 공통 입력 계약)

> 📌 각 MD의 입력은 **여기 있는 이름 그대로** 적는다(줄임 기호·번호 ❌).

| 칸 | 담기는 값 | 채우는 MD |
|---|---|---|
| **첫 입력 글** | 유저가 ① 화면에서 **직접 쓴 말** (예시 칩으로 채운 글 포함) — 🟢 **항상 있다** | (①화면) |
| **자료** | ① 화면에서 **첨부한** 파일 · URL — 🟡 **0개일 수 있다** | (①화면) |
| **설명 글** | 유저가 ②에서 **확인·수정을 끝낸** 페이지 설명 1개 | [[MD-02. 페이지 설명]] |
| **목적** | 유저가 확정한 목적 문구 1개 | [[MD-03. 목적]] |
| **추가 항목** | 유저가 **켠 칩만** `{문구, 섹션 목적, 들어갈 자리}` 배열 | [[MD-04. 추가 항목]] |
| **타겟** | 타겟 문구 1개 ＋ 유저가 고른 **라벨 배열** | [[MD-05. 타겟]] |
| **내부 판정** | 주제코드(25) · 목적 분류(P1~P6) · 무드 후보 — **화면 노출 ❌** | 02~05 진행 중 자동 |
| **페이지 유형** | `원페이지 / 멀티페이지` (근거 한 줄은 유형별로 미리 써 둠) | [[MD-06. 페이지 유형 판정]] |
| **구성** | `{섹션 목적, 섹션 id, 순서, 페이지 번호}` 배열 | [[MD-07. 페이지 구성]] |
| **시안 A 기록** | 시드 · 레이아웃 유형 · 팔레트 id · 배경 명도 칸 · 쓴 섹션 id 배열 | 08-1 · 08-2 · 08-3 |
| **채운 내용** | 유저가 채운 칸 / 비어 있는 칸 | (⑦화면) |

**읽기·쓰기 한눈에**

| MD | 읽는다 | 쓴다 |
|---|---|---|
| 02 페이지 설명 | **첫 입력 글** · 자료 | 설명 글 |
| 03 목적 | 설명 글 | 목적 |
| 04 추가 항목 | 설명 글 · 목적 · 내부 판정 | 추가 항목 |
| 05 타겟 | 설명 글 · 목적 | 타겟 · 내부 판정(무드 후보) |
| 06 페이지 유형 | 설명 글 · 목적 · 추가 항목 · 타겟 | 페이지 유형 (근거 문구는 고르기만) |
| 07 페이지 구성 | 설명 글부터 페이지 유형까지 | 구성 |
| 08-1 레이아웃 | 설명 글 · 내부 판정 · 구성 | 시안 A 기록(유형) |
| 08-2 무드 | 타겟 · 내부 판정 | 시안 A 기록(팔레트·명도 칸) |
| 08-3 텍스트 | 목적 · 타겟 · 내부 판정 · 구성 | 시안 텍스트 · 비운 칸 목록 |
| 09 시안 B·C | **시안 A 기록** | 안 B · C |
| 10 채우기 팁 | 구성 · 채운 내용 | 칸별 팁 **선택**(미리 써 둔 문구에서) |

⚠️ **「내부 판정」은 화면에 절대 나오지 않는다** (「말투」 내부 용어 금지).
