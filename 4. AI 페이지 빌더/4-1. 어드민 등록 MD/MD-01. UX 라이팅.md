# MD-01. UX 라이팅 (전체 공통)

> 🔗 **적용 범위** = **유저가 쓰는 서비스 화면에 나가는 글 전부**. 아래 표의 ✅ 항목.
> 🚫 **시안 안에 들어가는 글에는 적용하지 않는다** — 그건 [[MD-08-3. 텍스트 구성·보이스톤]]이 담당한다. **읽는 사람이 다르기 때문**이다.
>
> | | 누가 읽나 | 어느 규칙 |
> |---|---|---|
> | **서비스 화면 문구** (질문·부제·버튼·칩·팁) | **페이지를 만드는 유저** | **이 문서** |
> | **시안 안 텍스트** (섹션 제목·본문·버튼 문구) | 그 유저의 **손님** | [[MD-08-3. 텍스트 구성·보이스톤]] |
>
> 같은 「글」이지만 목적이 다르다 — 화면 문구는 *유저를 안내하는 말*, 시안 텍스트는 *유저가 손님에게 하는 말*이다. 여기 규칙(해요체·안심 표현 등)을 시안에 적용하면 **유저의 브랜드 말투를 우리가 덮어쓰게 된다.**

|---|---|:--:|
| [[MD-02. 페이지 설명]] | 미리 채운 설명 글 | ✅ |
| [[MD-03. 목적]] | 미리 채운 목적 문구 | ✅ |

| [[MD-10. 내용 채우기 팁]] | 칸마다 붙는 **팁 문구** | ✅ |
| [[MD-07. 페이지 구성]] · [[MD-08-1. 레이아웃 유형]] · [[MD-08-2. 무드]] · [[MD-09. 시안 B·C]] | 없음(내부 결정만) | — |
| [[MD-08-3. 텍스트 구성·보이스톤]] | 시안 안 텍스트 | 🚫 **대상 아님** |

> ⚠️ **이 문서는 AI에게 그대로 주는 지침이 아니다** — §0처럼 **AI가 만드는 글**과 **우리가 한 번 써서 박는 글**이 한 화면에 섞여 있어서, **양쪽이 같은 기준을 쓰도록** 모아 둔 문서다. AI 프롬프트에 넣을 것은 **🤖 표시된 규칙만**.

## 0. 한 화면에 글이 세 종류 있다 (2026-09-11 이선호 지적)

| | 무엇 | 누가 쓰나 | 어디 저장 | 예 |
|---|---|---|---|---|
| 🔒 **고정 문구** | 화면 제목 · 부제 · 버튼 라벨 · 안내 | **우리** (1회 작성) | 코드/어드민 상수 | *"이런 페이지 맞나요?"* · *"수정할 곳이 없는지 확인해 주세요."* |
| 🤖 **AI 생성 값** | 미리 채운 문장 · 매번 만드는 선택지 | **AI** (매 유저마다) | — | 설명 글 · 목적 문구 · 추가 항목 칩 5 · 타겟 칩 5 |
| 📦 **고정 데이터** | 예시 칩과 예시글 | **우리** (1회 작성) | 어드민 등록 | [[MD-02. 페이지 설명]] §7 칩 6개 |

- **🔒·📦는 MD 대상이 아니다** — 피그마 코멘트의 *"어드민에서 고정으로 설정함, MD 아님"* 이 이 얘기다.
- **그래도 기준은 같이 따른다** — 고정 문구가 딱딱한데 AI 문장만 상냥하면 **한 화면 안에서 말투가 튄다.**

## 1. 화면 공통 구조

| 자리 | 종류 | 하는 일 | 예 |
|---|:--:|---|---|
| **제목** | 🔒 | 무엇을 확인하는지 | *"이런 페이지 맞나요?"* |
| **부제** | 🔒 | 왜 묻는지 + 안심 | *"수정할 곳이 없는지 확인해 주세요."* |
| **미리 채운 값** | 🤖 | AI가 만든 답 (수정 가능) | 설명 글 · 목적 문구 · 타겟 |
| **선택지** | 🤖 | 더할 것 (선택) | 추가 항목 5 · 타겟 5 |

## 2. 말투 5줄 — 🔒🤖 **둘 다 적용**

- **해요체 존댓말** — `합니다`체 ❌ (딱딱함)
- **한 문장 = 한 가지** — 두 가지를 `~고, ~며`로 잇지 않는다
- **유저가 쓰는 말로** — 아래 내부 용어는 화면에 **절대 노출 ❌**
  > 주제 분류 · 목적 분류(P1~P6) · 섹션 목적 · 레이아웃 스타일(미니멀/에디토리얼/볼드) · 무드 이름 · 카테고리 · 섹션 · 카드
- **단정하되 바꿀 수 있게** — *"○○로 만들어 드릴게요"* ＋ `바꾸기` (원칙 7 = 고르게 하지 말고 정해서 보여주고 바꿀 수 있게)
- **질문형은 화면당 1개** — 제목만 질문, 나머지는 서술

## 3. 길이 상한

| 자리 | 종류 | 상한 | 왜 |
|---|:--:|:--:|---|
| 화면 제목 | 🔒 | **20자** | 모바일 1줄 |
| 부제 | 🔒 | **35자** | 1줄 유지 |
| 미리 채운 문장 | 🤖 | **40자** | 한눈에 맞는지 판단 가능한 길이 |
| 선택지 라벨 | 🤖 | **12자** | 칩 1줄 · 2열 배치 |

## 4. 🤖 선택지 규칙 (04 · 05)

- **개수 5개 고정** — 3개면 빈약해 보이고, 7개면 읽지 않는다
- **라벨 = 유저의 행동·상태 언어** — `폼` ❌ → `참석 신청 받기`
- **나열 순서 = 근거가 센 것부터** ① 자료에 실제로 나온 것 → ② 그 주제에서 흔한 것 → ③ 일반적인 것
- **서로 겹치지 않게** — 포함 관계(`문의` ↔ `상담 문의`) ❌
- **이미 확정된 것은 다시 올리지 않는다** — 앞 단계에서 정해졌거나 레시피에 이미 들어가는 것

## 5. 🤖 미리 채우기 원칙 (02 · 03 · 05)

- **비워 두고 고르게 하지 않는다** — 빈칸은 유저를 멈추게 한다
- 🔴 **사실 정보는 자료에 있을 때만** — 일시·장소·가격·계좌·연락처·스펙을 **지어내면 사고**다. 없으면 그 자리를 **문장에서 뺀다**(빈칸으로 남기지도, 만들어 넣지도 않는다)
- **틀렸는지 한눈에 보이게 구체적으로** — *"행사 페이지예요"*(판단 불가) ❌ → *"11월 15일 북토크에 초대하는 페이지예요"* ✅

## 6. 금지 표현 — 🔒🤖 **둘 다 적용**

| 유형 | ❌ | ✅ |
|---|---|---|
| 기계 말투 | *"자료를 분석했습니다"* | *"올려주신 내용을 정리해 봤어요"* |
| 과장·감탄 남발 | *"완벽해요! 놀라운 페이지가 ✨🎉"* | 감탄사는 화면당 1개까지 |
| 사과·불확실 | *"죄송해요"* · *"아마도"* | 사실만 · 단정 |
| 유저 탓 | *"잘못 입력하셨어요"* | *"이 부분만 다시 알려 주시겠어요?"* |
| 분류 노출 | *"5-② 모집 페이지네요"* | *"사람을 모으는 페이지네요"* |
| 「블록」 | *"블록을 추가할까요?"* | 개별 = **카드** · 묶음 = **섹션** |

## 8. 부록 — 단계별 누적 정보 (전 MD 공통 입력 계약)

> 🔴 **왜 필요한가**: 각 MD가 입력을 *"앞 단계 내용"* 이라고만 쓰면, MD를 나눠 만든 사람마다 **다른 걸 가정**한다. 아래가 **유일한 정의**다. 각 MD §2는 여기 **칸 번호**로만 적는다.

| 칸 | 이름 | 담기는 값 | 채우는 MD |
|:--:|---|---|---|
| **S1** | 자료 | 업로드 파일 · URL · 붙여넣은 글 · `자료 없음` 여부 | (①화면) |
| **S2** | 설명 글 | 유저가 **확인·수정을 끝낸** 페이지 설명 1개 | [[MD-02. 페이지 설명]] |
| **S3** | 목적 | 유저가 확정한 목적 문구 1개 | [[MD-03. 목적]] |
| **S4** | 추가 항목 | 유저가 **켠 칩만** `{문구, 섹션 목적, 들어갈 자리}` 배열 | [[MD-04. 추가 항목]] |
| **S5** | 타겟 | 타겟 문구 1개 ＋ 유저가 고른 **라벨 배열** | [[MD-05. 타겟]] |
| **S6** | 내부 판정 | 주제코드(25) · 목적 분류(P1~P6) · 무드 후보 — 🔒 **화면 노출 ❌** | 02~05 진행 중 자동 |
| **S7** | 페이지 유형 | `원페이지 / 멀티페이지` ＋ 근거 한 줄 | [[MD-06. 페이지 유형 판정]] |
| **S8** | 구성 | `{섹션 목적, 섹션 id, 순서, 페이지 번호}` 배열 | [[MD-07. 페이지 구성]] |
| **S9** | 시안 A 기록 | 시드 · 레이아웃 유형 · 팔레트 id · 배경 명도 칸 · 쓴 섹션 id 배열 | 08-1 · 08-2 · 08-3 |
| **S10** | 채운 내용 | 유저가 채운 칸 / 비어 있는 칸 | (⑦화면) |

| 02 페이지 설명 | S1 | S2 |
| 03 목적 | S2 | S3 |
| 04 추가 항목 | S2 · S3 · S6 | S4 |
| 05 타겟 | S2 · S3 | S5 · S6(무드 후보) |
| 06 페이지 유형 | S2~S5 | S7 |
| 07 페이지 구성 | S2~S7 | S8 |
| 08-1 레이아웃 | S2 · S6 · S8 | S9(유형) |
| 08-2 무드 | S5 · S6 | S9(팔레트·명도 칸) |
| 08-3 텍스트 | S3 · S5 · S6 · S8 | 시안 텍스트 · 비운 칸 목록 |

| 10 채우기 팁 | S8 · S10 | 칸별 팁 문구 |
