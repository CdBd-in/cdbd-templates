# MD-02. 페이지 설명

> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)

## 1. 입력

| 칸          |      언제나?       | 쓰임                       |
| ---------- | :-------------: | ------------------------ |
| **첫 입력 글** |  🟢 **항상 있다**   | 유저가 **「페이지 설명 입력」 화면**(설명을 쓰고 자료를 첨부하는 맨 처음 화면)에서 직접 쓴 말 — **뼈대**  |
| **자료**     | 🟡 **0개일 수 있다** | 같은 화면에서 첨부한 파일 · URL — **살** |

## 2. 출력

**페이지 설명 문구 1개** (수정 가능한 텍스트로 입력창에 채워짐)

## 3. 규칙

- **첫 입력 글을 뼈대로 삼는다** — 자료가 아무리 두꺼워도 *유저가 말한 의도*가 주인공. 자료로 덮어쓰지 않는다
- **자료는 살만 붙인다** — 유저가 안 쓴 일시·장소·가격·연락처를 자료에서 찾아 **보탠다**
- **둘이 어긋나면 유저 말이 우선** (예: 자료엔 3월, 유저는 4월이라 씀 → 4월 · 필요하면 이 화면에서 유저가 직접 고친다)
- 읽어낸 **사실만** 쓴다 — 유저 말에도 자료에도 없는 일시·장소·가격·연락처는 **지어내지 않는다**
- **재료가 있는 만큼 쓴다** — 글자 수 상한 ❌. 억지로 늘리지도, 억지로 줄이지도 않는다 (재료가 빈약하면 자연히 짧아진다)
- **짜임 = 제목 줄 ＋ 설명 문단 ＋ 사실 항목 나열** — 일시·장소·참가비·문의처럼 **자료에서 건진 사실은 한 줄씩 항목으로** 뽑아 둔다(문단에 녹이면 **그 한 줄만 고칠 수 없다** — 유저는 이 글을 통째로 받아 직접 고친다)
- **자료가 0개여도 이 화면은 똑같이 나온다** — 유저가 단어만 나열했어도 **문장으로 정리해** 보여준다

- 🔴 **지어낼 것 / 비워 둘 것의 경계** — 페이지의 **성격·분위기를 설명하는 말**은 AI가 지어도 되지만, **일시·장소·가격·계좌·연락처·스펙 같은 사실 정보는 첫 입력 글이나 자료에 있을 때만** 쓴다. 없으면 그 자리를 **문장에서 뺀다** — 빈칸으로 남기지도, 만들어 넣지도 않는다.

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.
