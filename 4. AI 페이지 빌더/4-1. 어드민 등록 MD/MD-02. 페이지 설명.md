# MD-02. 페이지 설명

> 📍 **화면**: v2 · 2 페이지 설명 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9880)
> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

「이런 페이지 같은데, 맞나요?」 화면에 **미리 채워 둘 페이지 설명 문구 1개**를 만든다.

> 🔄 **2026-09-11 플로우 변경 반영** — ① 화면이 **설명 입력과 자료 첨부를 동시에** 받도록 바뀌었다([[4-2. AI 유저 플로우]] §1). 그래서 이 MD의 입력이 달라졌다:
> - 옛 설계 = *자료가 있으면* 정리본을 만들고, *없으면* 이 화면에서 직접 쓰게 했다(두 갈래)
> - **확정** = **설명 글은 언제나 있다.** 자료는 **있을 수도, 없을 수도** 있는 보조 재료다 → **한 갈래**

## 2. 입력

| 칸 | 언제나? | 쓰임 |
|---|:--:|---|
| **첫 입력 글** | 🟢 **항상 있다** | 유저가 ①에서 직접 쓴 말 — **뼈대** |
| **자료** | 🟡 **0개일 수 있다** | ①에서 첨부한 파일 · URL — **살** |

> 📥 칸 정의 = [[MD-01. UX 라이팅]] §8 부록

## 3. 출력

**페이지 설명 문구 1개** (수정 가능한 텍스트로 입력창에 채워짐)

## 4. 규칙

- **첫 입력 글을 뼈대로 삼는다** — 자료가 아무리 두꺼워도 *유저가 말한 의도*가 주인공. 자료로 덮어쓰지 않는다
- **자료는 살만 붙인다** — 유저가 안 쓴 일시·장소·가격·연락처를 자료에서 찾아 **보탠다**
- **둘이 어긋나면 유저 말이 우선** (예: 자료엔 3월, 유저는 4월이라 씀 → 4월 · 필요하면 ②에서 고치게)
- 읽어낸 **사실만** 쓴다 — 유저 말에도 자료에도 없는 일시·장소·가격·연락처는 **지어내지 않는다**
- 재료가 빈약하면 **짧게** — 억지로 늘리지 않는다
- 유저가 「아니요」를 누를 수 있게, **틀렸는지 바로 판단되는** 문장으로
- **자료가 0개여도 이 화면은 똑같이 나온다** — 유저가 단어만 나열했어도 **문장으로 정리해** 보여준다

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 7. **앞 화면(①)** 의 「MD 아닌 것」 — 어드민 고정값

> 🔄 **2026-09-11 이동** — 예시 칩은 옛 설계에선 **이 화면(②)** 에 있었으나, 설명 입력이 ①로 올라가면서 **① 화면으로 함께 옮겨졌다.** 이제 **자료 유무와 상관없이 항상** 보인다(막막함 해소용).

**예시 칩**([피그마](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9491))은 AI가 만들지 않는다.

```
어드민에서 고정으로 설정함, MD 아님

```
