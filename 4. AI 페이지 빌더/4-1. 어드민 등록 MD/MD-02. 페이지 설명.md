# MD-02. 페이지 설명

> 📍 **화면**: v2 · 2 페이지 설명 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9880)
> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)

## 1. 무엇을 정하는 MD인가

「이런 페이지 맞나요?」 화면에 **미리 채워 둘 페이지 설명 문구 1개**를 만든다.

## 2. 입력

① 유저가 올린 자료(파일·링크·붙여넣은 글) ② ①단계 자료 유무 응답

## 3. 출력

**페이지 설명 문구 1개** (수정 가능한 텍스트로 입력창에 채워짐)

## 4. 규칙

- 자료에서 읽어낸 **사실만** 쓴다 — 일시·장소·가격·연락처는 **지어내지 않는다**
- 자료가 빈약하면 **짧게** — 억지로 늘리지 않는다
- 유저가 「아니요」를 누를 수 있게, **틀렸는지 바로 판단되는** 문장으로

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 5. 볼트 근거

- [[MD-01. UX 라이팅]] §5 미리 채우기 원칙
- [[4-7. 입력 단계 안내 문구]] — 「지어낼 칸 / 사실이라 비울 칸」 구분

## 6. 원본 코멘트

```
자료 -> 이런페이지맞나요? 내용으로 텍스트 변환할
```

## 7. 같은 화면의 「MD 아닌 것」 — 어드민 고정값

자료가 **없는** 유저에게 보여줄 **예시 칩**([피그마](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-10395))은 AI가 만들지 않는다. **어드민에서 고정으로 등록**한다.

```
어드민에서 고정으로 설정함, MD 아님
1. 아래 선택지 N개
2. 선택지 당 위에 표시할 글
```

**🚧 등록할 값 (2026-09-11 제안 · 확정 대기)** — 칩 6개 + 각 칩의 예시글.
칩 = `행사·모임을 열어요` · `제품·메뉴를 보여줘요` · `하는 일을 소개해요` · `신청을 받아요` · `포트폴리오를 보여줘요` · `공지를 알려요`
예시글 = **구어체 5줄 · 줄마다 다른 종류의 정보 · 맨 위에 `(예시예요 — 아래를 내 내용으로 바꿔 주세요)` 한 줄**.
근거 = 실사용 549건([[4-3. 목적·주제별 분류]] §4-B) — 「가게」는 업종어라 기관·갤러리를 밀어내고, 페이지 절반이 카탈로그라 「팔아요」보다 「보여줘요」가 넓다.

<details><summary>예시글 6개 초안 (펼치기)</summary>

**① 행사·모임을 열어요** — `무엇 / 언제·어디 / 순서 / 조건 / 신청`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
다음 달에 동네 책방에서 북토크 열어요
11월 15일 토요일 저녁 7시, 성수동 책방 오래
작가님 강연 1시간이랑 질문 받는 시간 있어요
20명까지만 받고 참가비 1만원, 음료 포함이에요
신청은 인스타 DM으로 받고 있어요
```
**② 제품·메뉴를 보여줘요** — `품목 수 / 항목마다 반복되는 것 / 공통 정보 / 사진 / 구매 경로`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
이번 가을 신상 가방 8개를 한 번에 보여주고 싶어요
품목마다 이름이랑 가격, 색상 옵션이 있어요
전부 소가죽이고 크기는 조금씩 달라요
사진은 품목당 2~3장씩 있어요
자세한 건 스마트스토어에서 보라고 링크 걸고 싶어요
```
**③ 하는 일을 소개해요** — `정체성 / 하는 것 / 영업시간 / 규모·예약 / 주의사항`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
망원동에서 2년째 하는 작은 파스타집이에요
점심엔 파스타 한 접시, 저녁엔 와인도 같이 팔아요
화요일부터 일요일 11시-21시, 월요일은 쉬어요
테이블이 3개뿐이라 예약 받고 있어요
주차가 어려워서 근처 공영주차장 안내해야 해요
```
**④ 신청을 받아요** — `대상·인원 / 무슨 활동 / 조건·혜택 / 받을 항목 / 마감`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
올해 대학생 서포터즈 20명을 뽑으려고 해요
8주 동안 SNS에 저희 브랜드 콘텐츠 올리는 활동이에요
활동비 월 20만원이랑 수료증 드려요
지원서에 이름, 연락처, 간단한 자기소개 받고 싶어요
9월 30일까지 받고 10월 초에 발표할 거예요
```
**⑤ 포트폴리오를 보여줘요** — `누구 / 경력 / 작업물 개수 / 작업 하나의 구성 / 연락`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
브랜드 로고랑 패키지 디자인하는 프리랜서예요
5년 정도 했고 카페랑 화장품 브랜드 위주로 작업했어요
보여주고 싶은 작업이 8개쯤 있어요
작업마다 어떤 브랜드였는지랑 사진을 같이 넣고 싶어요
의뢰 문의는 이메일로 받을게요
```
**⑥ 공지를 알려요** — `무엇이 바뀌나 / 전후 비교 / 적용일·대상 / 오해 방지 / 문의`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
다음 달부터 수업 시간이 바뀐다고 알려드리려고요
지금 저녁 7시인데 7시 30분으로 30분 밀려요
12월 1일부터고 주말반은 그대로예요
학원이 옮기는 건 아니고 시간만 바뀌는 거예요
궁금한 건 전화 주시라고 번호도 넣어주세요
```
</details>
