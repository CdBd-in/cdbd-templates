# MD-02. 페이지 설명

> 📍 **화면**: v2 · 2 페이지 설명 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9880)
> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)

## 1. 입력

| 칸 | 언제나? | 쓰임 |
|---|:--:|---|
| **첫 입력 글** | 🟢 **항상 있다** | 유저가 ①에서 직접 쓴 말 — **뼈대** |
| **자료** | 🟡 **0개일 수 있다** | ①에서 첨부한 파일 · URL — **살** |

> 📥 칸 정의 = [[MD-00. 단계별 누적 정보]]

## 2. 출력

**페이지 설명 문구 1개** (수정 가능한 텍스트로 입력창에 채워짐)

## 3. 규칙

- **첫 입력 글을 뼈대로 삼는다** — 자료가 아무리 두꺼워도 *유저가 말한 의도*가 주인공. 자료로 덮어쓰지 않는다
- **자료는 살만 붙인다** — 유저가 안 쓴 일시·장소·가격·연락처를 자료에서 찾아 **보탠다**
- **둘이 어긋나면 유저 말이 우선** (예: 자료엔 3월, 유저는 4월이라 씀 → 4월 · 필요하면 ②에서 고치게)
- 읽어낸 **사실만** 쓴다 — 유저 말에도 자료에도 없는 일시·장소·가격·연락처는 **지어내지 않는다**
- **40자 이내** · 재료가 빈약하면 **짧게** — 억지로 늘리지 않는다
- 유저가 「아니요」를 누를 수 있게, **틀렸는지 바로 판단되는** 문장으로
- **자료가 0개여도 이 화면은 똑같이 나온다** — 유저가 단어만 나열했어도 **문장으로 정리해** 보여준다

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 4. 함께 지키는 것

- 🔴 **지어낼 것 / 비워 둘 것의 경계** — 페이지의 **성격·분위기를 설명하는 말**은 AI가 지어도 되지만, **일시·장소·가격·계좌·연락처·스펙 같은 사실 정보는 첫 입력 글이나 자료에 있을 때만** 쓴다. 없으면 그 자리를 **문장에서 뺀다** — 빈칸으로 남기지도, 만들어 넣지도 않는다.

## 5. **앞 화면(①)** 의 「MD 아닌 것」 — 어드민 고정값

**예시 칩**([피그마](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9491))은 AI가 만들지 않는다.

```
어드민에서 고정으로 설정함, MD 아님
1. 아래 선택지 N개
2. 선택지 당 위에 표시할 글
```

**칩 6개와 순서** — 칩을 누르면 그 예시글이 입력창에 **채워진다.** 순서는 **실사용이 많은 쪽부터**(첫 칩이 가장 많이 눌리므로).

| 순서 | 칩 |
|:--:|---|
| 1 | `행사·모임을 열어요` |
| 2 | `제품·메뉴를 보여줘요` |
| 3 | `하는 일을 소개해요` |
| 4 | `신청을 받아요` |
| 5 | `포트폴리오를 보여줘요` |
| 6 | `공지를 알려요` |

> 🏷 **이름 두 가지** — 「가게」 대신 **「하는 일」**(주체로 이름 지으면 갤러리·교회·기관이 자기 것으로 안 본다) · 「팔아요」 대신 **「보여줘요」**(실사용 절반이 구매 링크 없는 카탈로그다).

**예시글 6개 쓰는 규칙** (칩마다 1개 · 어드민에 등록해 두는 고정 데이터)
- **일부러 못 쓴 글로** — 반듯한 완성 문장이면 유저가 *"나는 이렇게 못 쓰는데"* 하고 막힌다
- **구어체 5줄 · 한 줄에 한 가지** — 유저는 글이 아니라 **줄 구성**에서 *"이런 걸 적으면 되는구나"* 를 배운다
- **칩마다 정보 구조를 다르게 · 업종이 겹치지 않게**(문화 · 리테일 · 요식 · 기업 · 개인 · 교육)
- 맨 위에 *"(예시예요 — 아래를 내 내용으로 바꿔 주세요)"* 한 줄을 남긴다 — 그대로 제출하는 사람이 반드시 나오고, 이 줄이 남아 있으면 **AI가 「안 고쳤다」를 알아챌 수 있다**

⚠️ **[[MD-04. 추가 항목]]의 칩과 다른 것** — 이 칩은 **① 화면에서 글쓰기 예시를 주는 것**(고정 · 항상 노출)이고, 04의 칩은 **페이지에 섹션을 추가하는 것**(매번 생성 · 5개)이다.
