# MD-07-2. 무드 (시안 A)

## 1. 입력

- **타겟 라벨** — 유저가 타겟 화면에서 고른 라벨 → **㉡ 안 맞는 무드를 빼는 재료**
- **주제 코드** — 앞 단계에서 자동 판정한 주제(25개 중 1개)
- **자료** — 유저가 맨 처음 화면에서 첨부한 파일 · URL 속 브랜드 자산(로고 색 등 · **0개일 수 있다**)

## 2. 출력

무드 1개(= 3토큰 팔레트 + 서체) ＋ 추천 무드 N개 ＋ **생성 기록**(팔레트 · 배경 명도 칸)

## 3. 규칙

- **배경 명도 칸을 기록해 둔다** → [[MD-08. 시안 B·C]]가 남은 칸에서 고른다

### 무드를 정하는 순서 5단계

> 🚫 **표 맨 윗줄부터 집지 말 것.** 여기가 가장 자주 뚫린다 — **표 상단만 집는 버릇은 랜덤보다 나쁘다**(랜덤은 매번 다르지만, 이건 매번 같은 걸 낸다).

1. **🎬 주제의 실제 장면에서 색을 뽑는다** — 그 페이지가 존재하는 공간·사물의 색. **표를 열기 전에**(북토크라면 책의 잉크 · 종이 크림 · 서가 조명의 호박빛 · 가죽 의자)
2. **🏷 브랜드 자산을 앵커로** — 로고 색·시그니처 색이 있으면 3토큰 중 하나에 반영
3. **🎨 무드로 톤 조정** — 같은 「전구빛」도 모던이면 차분한 황동, 드리미면 밝은 호박
4. **🔁 3안 분산** — 아래 표
5. **📚 그 무드 서랍에서 채택** — ①~③을 검색 조건 삼아, **라이브러리 316개 안에서** 고른다. **표 맨 윗줄부터 집지 말고 랜덤** · **새로 만들지 않는다**
   - 무드 자체는 **아래 「무드 후보 추리기」가 남긴 후보 안에서** 고른다 — 후보 밖 무드 ❌

### 무드 후보 추리기 — 주제가 만들고, 타겟이 뺀다

**㉠ 주제 → 후보를 만든다**

| 무드 | 이런 주제·업종일 때 |
|---|---|
| 🌿 내추럴/오가닉 | 카페 · 웰빙 · 친환경 · 식물 · 수제 |
| 🌸 페미닌/로맨틱 | 뷰티 · 웨딩 · 플로리스트 · 디저트 |
| ✨ 럭셔리/엘레강스 | 호텔 · 주얼리 · 파인다이닝 · 갤러리 |
| 💼 프로페셔널/비즈니스 | 세무 · 법무 · 컨설팅 · 의료 · 금융 · B2B · 명함 |
| 🌑 모던/시크 | 패션 · 디자인 스튜디오 · 미니멀 |
| 🔥 비비드/대담한 | 프로모션 · 세일 · 스포츠 · 신상품 · 이벤트 |
| 🎨 빈티지/노스탤직 | 책방 · 아카이브 · 레트로 · 매거진 · 핸드메이드 |
| 🎉 펀/플레이풀 | 아동 · 교육 · 캐릭터 · 로컬 푸드 · 굿즈 |
| 🌙 드리미/감성적 | 시 · 에세이 · 향수 · 명상 · 감성 굿즈 · 갤러리 카페 |

**㉡ 타겟 라벨 → 뺀다** 🚧 **초안 — 검토 필요**

| 타겟 성격 | 빼는 무드 | 왜 |
|---|---|---|
| 기업·기관 담당자 (B2B · 관공서 · 협력사) | 🎉 펀 · 🌙 드리미 · 🌸 페미닌 | 결재·검토하며 보는 화면 |
| 아이 · 학부모 | ✨ 럭셔리 · 🌑 모던/시크 | 차갑고 격식 차린 인상 |
| 어르신 · 지역 주민 | 🌑 모던/시크 · 🌙 드리미 | 옅은 색·작은 글씨로 읽힌다 |
| 동종업계 전문가 (수주 · 포트폴리오) | 🎉 펀 · 🎨 빈티지 | 취미처럼 보인다 |
| 10~20대 · 팬 | 💼 프로페셔널 | 딱딱하다 |
| 예비 신랑신부 · 기념일 손님 | 💼 프로페셔널 · 🔥 비비드 | 사무적이거나 소란스럽다 |

**안전장치 3개**
- **㉠이 지목한 무드는 빼지 않는다** — 주제가 우선 (예: 아동 교육 주제의 🎉펀은 `학부모` 타겟이어도 유지)
- **후보가 3개 미만으로 줄면 제외를 멈춘다** — 다 빼면 [[MD-08. 시안 B·C]]가 쓸 후보가 없다
- **㉡ 표에 없는 타겟은 아무것도 빼지 않는다** — 애매하면 **남긴다**

### 3안 분산

| 축 | 규칙 |
|---|---|
| **배경 명도** | 3안이 방향을 나눠 갖는다. **금지 = 3안 전부 같은 방향.** 비율은 자유(밝음2:다크1도, 다크2:밝음1도 OK) |
| **순백/순흑 탈피** | 라이트 = 크림·오트·베이지·세이지 / 다크 = 딥네이비·딥그린·잉크 · 중간 명도도 OK |
| **액센트 계열** | **최소 2계열**(따뜻함 / 차가움 / 중립). **3안 전부 따뜻한 색 ❌** — 명도만 벌리는 건(황동 vs 호박) 같은 계열이라 부족 |

### 색 규칙

- **3색이 기본** — 색1 `{배경색}` · 색2 `{텍스트색}` · 색3 `{버튼색}`. 2색이면 텍스트색과 버튼색이 같아져 **액센트가 없다**
- **보조 텍스트는 `{텍스트색} × 60%` / `× 40%`** — 별도 회색 ❌ · **강조 배경은 `{버튼색} × N%`**
- 🔴 **버튼 글자색 = 팔레트 표의 「버튼글자」 열 그대로** — 기본은 `{배경색}`이고, **14개 팔레트만 `{텍스트색}`**으로 적혀 있다. 대비는 **다시 계산하지 않는다**(라이브러리 316개는 통과한 것만 올려 둔 것)

### 「무드에 맞음」이 「주제에 맞음」은 아니다

- **3안 중 최소 1안은 주제 장면이 연상되는 색** — 바다 = 블루/틸 · 녹차 = 그린 · 원두 = 브라운
- **담는 그릇이 되어야 하는 주제**(기관 · 전시 · 도록 · B2B)는 **뉴트럴 배경** — 파스텔 핑크·마젠타 배경 ❌
- **신뢰형**(세무 · 법무 · 컨설팅 · 명함)은 **차분한 톤** — 쨍한 원색·형광 ❌
- **화보·미니멀·여리여리한 주제**는 대비는 지키되 **채도를 낮춘다**
