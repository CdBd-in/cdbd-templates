# MD-05. 페이지 유형 판정

## 1. 입력

- **설명 글** — 유저가 확인·수정을 끝낸 페이지 설명 1개
- **목적** — 유저가 확정한 목적 문구 1개
- **추가 항목** — 유저가 **켠 칩만** (문구 · 추가할 섹션 목적 · 들어갈 자리)
- **타겟** — 타겟 문구 1개 ＋ 유저가 고른 라벨
- **주제 코드** — 앞 단계에서 자동 판정한 주제(25개 중 1개 · **화면 노출 ❌**) → 그 주제의 **조립 레시피**를 펼친다
- **조립 레시피** — 그 주제의 섹션 목록. **관문 1(큰 분류 수)·관문 3(카드 수)을 재는 자**다

## 2. 출력

페이지 유형 1개 (원페이지 / 멀티페이지)

## 3. 규칙

- 유저에게는 **통보형** — 고르게 하지 않고 정해서 보여준 뒤 `바꾸기`만 둔다
- **애매하면 원페이지** — 멀티로 나누면 표지·목차·페이지마다 반복되는 헤더 때문에 **카드가 오히려 늘어난다**

### 3-A. 4관문 — 앞에서 걸리면 거기서 끝

|       | 묻는 것                                     | 판정                      |
| ----- | ---------------------------------------- | ----------------------- |
| **0** | 목적이 **알림 · 초대 · 접수**이고, **알리는 대상이 1건**인가 | 둘 다 ✅ → **원페이지 확정 (끝)** |
| **1** | 유저 자료를 나누는 **큰 분류가 3개 이상**인가             | ❌ → **원페이지 확정 (끝)**     |
| **2** | 같은 항목이 **3개 이상** 반복되고, 항목마다 **이미지 1장 이상 ＋ 글 3줄 이하**인가 | ✅ → **멀티 확정 (끝)** |
| **3** | 카드가 **35장 이상**인가                         | ✅ → 멀티 / ❌ → 원페이지       |

### 3-B. 관문별 판정 기준

- **관문 0 · 「대상이 1건」** — 행사 1건짜리 초대장·예약 페이지는 페이지를 넘기게 하면 신청이 샌다 → 원페이지.
  ⚠️ **단 대상이 여러 건이면 여기서 끝내지 말고 다음 관문으로 넘긴다** — 행사 19건이 묶인 안내 책자, 매장 20곳 목록, 품목 50종 카탈로그는 목적이 「알림」이어도 원페이지가 아니다. **세는 것 = 행사 수 · 매장 수 · 품목 수 · 모집 건수.**
- **관문 1 · 「큰 분류 3개」** — 큰 분류 = **그것 하나만으로 페이지 한 장이 되는 묶음**. 아래 **셋을 다 만족할 때만 1개로 센다**:
  1. **이름이 붙는다** — 명사 제목 한 줄을 달 수 있다 (`제품` · `채용` · `프로그램`)
  2. **속에 섹션이 2개 이상** 들어간다 — 섹션 하나짜리(오시는 길 · 문의)는 분류가 아니라 **그냥 섹션**이다
  3. **혼자 읽어도 된다** — 앞 묶음을 안 읽어도 말이 되고, 독자가 그것만 보고 나가도 된다. **순서대로 읽어야 이해되는 글**(도입 → 본문 → 마무리)은 통째로 **1개**다
  - 🔎 **세는 재료 = 유저가 준 자료·설명이 이미 나뉘어 있는 윗단 항목** (조립 레시피의 섹션 목록을 세는 게 ❌)
  - ✅ **3개** — 회사 홈: `회사 소개`(연혁·구성원) / `제품`(목록·상세) / `채용`(공고·지원)
  - ❌ **1개** — 카페: `소개` `메뉴` `오시는 길` → 메뉴 말고는 섹션 하나씩이라 **분류가 아니라 섹션** → 원페이지
  - **2개면 그냥 아래로 스크롤하는 편이 낫다.**
- **관문 2 · 「반복되는 이미지 항목」** — 룩북·포트폴리오·도록·신제품이 여기 걸린다. **셋을 다 만족할 때만 ✅**:
  1. **같은 형식의 항목이 3개 이상** 반복된다 (룩 1·2·3 / 프로젝트 1·2·3 / 작품 1·2·3)
  2. **항목마다 이미지가 1장 이상** 있다 — 한 장이라도 이미지가 없는 항목이 있으면 ❌
  3. **항목에 붙는 글이 3줄 이하**다 — 이미지가 본체이고 글은 이름·짧은 설명뿐이다
  - ➕ 보조 확인 — 항목끼리 **동급이라 순서를 바꿔도 되는가**(1번을 안 보고 3번부터 봐도 되는가)
  - ❌ **반례** — 메뉴판·품목표: 항목은 반복되지만 **이미지가 없거나 글(이름·가격·설명)이 본체** → 여기서 끝내지 말고 관문 3으로
  - **카드 수가 적어도 멀티**다 (룩북은 한 장에 4~5장뿐)
- **관문 3 · 「35장」** — 조립 레시피를 펼쳐 **카드 수를 세어** 판정한다.
