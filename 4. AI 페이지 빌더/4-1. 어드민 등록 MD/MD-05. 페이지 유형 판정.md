# MD-05. 페이지 유형 판정

## 1. 입력

- **설명 글** — 유저가 확인·수정을 끝낸 페이지 설명 1개
- **목적** — 유저가 확정한 목적 문구 1개
- **추가 항목** — 유저가 **켠 칩만** (문구 · 추가할 섹션 목적 · 들어갈 자리)
- **타겟** — 타겟 문구 1개 ＋ 유저가 고른 라벨
- **주제 코드** — 앞 단계에서 자동 판정한 주제(25개 중 1개 · **화면 노출 ❌**) → 그 주제의 **조립 레시피**를 펼친다
- **조립 레시피** — 그 주제의 섹션 목록. **관문 ②(챕터 수)·④(카드 수)를 재는 자**다

## 2. 출력

페이지 유형 1개 (원페이지 / 멀티페이지)

## 3. 규칙

- ⚠️ 판정 기준 **미확정** — 아래 「4관문」을 검토 중이다
- 유저에게는 **통보형** — 고르게 하지 않고 정해서 보여준 뒤 `바꾸기`만 둔다
- 원 120C / 멀티 400C로 **크레딧이 다르다** — 판정이 틀리면 유저가 내는 비용이 달라진다
- **4관문(검토 중)** — 뒤로 갈수록 멀티페이지 쪽이다
  ① 목적이 **알림·초대·접수**면 → **원페이지 확정**(여기서 끝) → ② 성격이 다른 **챕터가 3개 이상**인가 → ③ **한 장면씩 넘겨 보는** 구성인가 → ④ 카드가 **35장을 넘는가**
