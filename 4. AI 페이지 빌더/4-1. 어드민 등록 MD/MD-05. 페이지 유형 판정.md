# MD-05. 페이지 유형 판정

## 1. 입력

- **설명 글** — 유저가 확인·수정을 끝낸 페이지 설명 1개
- **목적** — 유저가 확정한 목적 문구 1개
- **추가 항목** — 유저가 **켠 칩만** (문구 · 추가할 섹션 목적 · 들어갈 자리)
- **타겟** — 타겟 문구 1개 ＋ 유저가 고른 라벨
- **주제 코드** — 앞 단계에서 자동 판정한 주제(25개 중 1개 · **화면 노출 ❌**)

## 2. 출력

페이지 유형 1개 (화면에 나가는 근거 한 줄 = 미리 써 둔 문구를 그대로)

> 📌 **근거 한 줄은 AI가 짓지 않는다** — 유형(원/멀티)마다 **미리 써 둔 문구**를 그대로 내보낸다. 이 MD는 **유형만 판정**하고, 문구는 **어드민에 등록해 둔 두 줄**(원페이지용·멀티페이지용) 중 하나를 부른다.

## 3. 규칙

- ⚠️ 판정 기준 **미확정** — 아래 「4관문」을 검토 중이다
- 유저에게는 **통보형** — 「○○페이지로 만들어 드릴게요」 + 근거 한 줄 + `바꾸기`
- 크레딧이 다르므로(원 120C / 멀티 400C) **근거가 납득되어야 한다** — 다만 문구는 고정이라 **판정만 틀리지 않으면 된다**
- **4관문(검토 중)** — 뒤로 갈수록 멀티페이지 쪽이다
  ① 목적이 **알림·초대·접수**면 → **원페이지 확정**(여기서 끝) → ② 성격이 다른 **챕터가 3개 이상**인가 → ③ **한 장면씩 넘겨 보는** 구성인가 → ④ 카드가 **35장을 넘는가**
- **유저가 유형을 고르게 하지 않는다** — 앞 단계에서 이미 충분히 말했으므로 **정해서 보여주고 `바꾸기`만** 둔다
