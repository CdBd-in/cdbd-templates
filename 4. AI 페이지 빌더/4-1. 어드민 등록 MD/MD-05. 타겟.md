# MD-05. 타겟

> 📍 **화면**: v2 · 4 타겟 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6918-10557)
> ✍️ **말투·길이·금지 표현 = [[MD-01. UX 라이팅]]** (02~05 공통)

## 1. 입력

**설명 글** · **목적**

> 📥 칸 정의 = [[MD-00. 단계별 누적 정보]]

## 2. 출력

① 타겟 문구 1개(입력창에 채워짐) ② 선택지 5개 ③ 나열 순서 ④ 라벨 → 무드 매핑

## 3. 규칙

**타겟 문구 (입력창에 미리 채움)**
- **40자 이내** · **비워 두지 않는다** — 앞 단계 내용에서 읽어낸 타겟을 **문장으로 채워** 보여준다
- **틀렸는지 한눈에 보이게 구체적으로** — *"고객을 위한 페이지예요"* ❌ → *"책을 좋아하는 동네 단골을 위한 페이지예요"* ✅

**선택지 5개**
- 선택지는 **「누가 볼 페이지인가」**로 — 주제를 다시 묻지 않는다
- **개수 5개 고정** · 라벨 **12자 이내**(칩 1줄)
- **라벨 = 유저가 쓰는 말로** — 분류·업종 용어 ❌
- 📋 **나열 순서 = 근거가 센 것부터** ① **첫 입력 글·자료에 실제로 나온 것** → ② 그 주제에서 흔한 것 → ③ 일반적인 것
- **서로 겹치지 않게** — 포함 관계 ❌
- 무드 기준은 **라벨 → 무드 9개 중 하나**로 떨어지게
- ⚠️ 무드는 **여기서 정하고 [[MD-08-2. 무드]]가 색·폰트로 바꾼다** — 두 곳이 다른 무드를 고르지 않도록 **라벨 → 무드 매핑은 아래 §5 표 하나만** 쓴다

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 4. 라벨 → 무드 매핑 (무드 9개)

| 무드 | 이런 타겟·주제일 때 |
|---|---|
| 🌿 내추럴/오가닉 | 카페 · 웰빙 · 친환경 · 식물 · 수제 |
| 🌸 페미닌/로맨틱 | 뷰티 · 웨딩 · 플로리스트 · 디저트 |
| ✨ 럭셔리/엘레강스 | 호텔 · 주얼리 · 파인다이닝 · 갤러리 |
| 💼 프로페셔널/비즈니스 | 세무 · 법무 · 컨설팅 · 의료 · 금융 · B2B · 명함 |
| 🌑 모던/시크 | 패션 · 디자인 스튜디오 · 미니멀 |
| 🔥 비비드/대담한 | 프로모션 · 세일 · 스포츠 · 신상품 · 이벤트 |
| 🎨 빈티지/노스탤직 | 책방 · 아카이브 · 레트로 · 매거진 · 핸드메이드 |
| 🎉 펀/플레이풀 | 아동 · 교육 · 캐릭터 · 로컬 푸드 · 굿즈 |
| 🌙 드리미/감성적 | 시 · 에세이 · 향수 · 명상 · 감성 굿즈 · 갤러리 카페 |

- **무드 이름은 내부 기준** — 화면에 노출하지 않는다(타겟 칩은 유저 말로)
- **무드 하나가 정해지면 색과 폰트가 함께 정해진다** — 색·폰트로 바꾸는 일은 [[MD-08-2. 무드]] 소관
