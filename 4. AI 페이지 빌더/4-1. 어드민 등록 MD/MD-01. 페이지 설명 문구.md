# MD-01. 페이지 설명 문구

> 📍 **화면**: v2 · 2 페이지 설명 확인 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-9880)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)
> 🚧 **상태**: 골격만 — 본문 지침 작성 대기

## 1. 무엇을 정하는 MD인가

「이런 페이지 맞나요?」 화면에 띄울 **페이지 설명 문구 1개**를 만든다.

## 2. 입력

① 유저가 올린 자료(파일·링크·붙여넣은 글) ② 1단계 자료 유무 응답

## 3. 출력

「이런 페이지 맞나요?」 화면에 띄울 **페이지 설명 문구 1개**

## 4. 규칙

- 자료에서 읽어낸 사실만 쓴다 — 일시·장소·가격·연락처는 **지어내지 않는다**
- 자료가 빈약하면 짧게 — 억지로 늘리지 않는다
- 유저가 「아니요」를 누를 수 있게, 틀렸는지 바로 판단되는 문장으로

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 5. 볼트 근거

- [[4-7. 입력 단계 안내 문구]] — 「지어낼 칸 / 사실이라 비울 칸」 구분

## 6. 원본 코멘트

```
자료 -> 이런페이지맞나요? 내용으로 텍스트 변환할
```

## 7. 같은 화면의 「MD 아닌 것」

이 화면 아래쪽 변형([피그마](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6691-10395))에 달린 코멘트 —

```
어드민에서 고정으로 설정함, MD 아님
1. 아래 선택지 N개
2. 선택지 당 위에 표시할 글
```

→ **선택지 N개와 그 위 문구는 AI가 만들지 않는다. 어드민에서 고정값으로 설정한다.** MD 작성 대상 아님.
