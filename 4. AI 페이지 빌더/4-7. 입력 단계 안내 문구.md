# 입력 단계 안내 문구 — 주제 25개

> **무엇** — 유저가 시안을 보며 내용을 채우는 화면의 **모든 문구**.
> **어디서 나왔나** — 단계 구성은 [[4-4. 조립 레시피]] 5절 레시피 카드, 문구 규칙은 `.data/tips/_SPEC.md`(정본).
> **검수** — 전수 자동 검사 통과(열 수 · 주제 내 중복 · 금지표현).

| ---------------- | --- | ----------------- |

| **② 말풍선 — 마일스톤** | 단계  | 절반 · 하나 남음 · 완료   |

우선순위 `반응 > 마일스톤`

- 🫥 **평소엔 말풍선을 숨긴다** — 반응·마일스톤이 뜨는 순간에만 나타나고, 그 밖엔 **자동차만** 보인다.
- 🚫 **팁은 띄우지 않는다 (2026-09-14 이선호)** — 옛 「팁」(칸 단위 기본값 · 미리보기 위 노출)은 **폐기**했다. 안내는 **왼쪽 패널의 제목이 전담**한다.
- 🚫 **기대효과도 없앴다 (2026-09-17 이선호)** — 옛 「제목 아래 기대효과 한 줄」 폐기 · 왼쪽 패널 = **제목 + 입력칸**만.

## 🔒 이 문구는 「고정 문구」다 — AI가 짓지 않고 **고른다**

## 규칙 요약 (풀버전 = `.data/tips/_SPEC.md`)

**채움 열 — AI / 사실**
- **AI** = 문장을 지어서 미리 채워둠 (인사말·소개글·스토리·카피)
- **사실** = 자료에 있으면 뽑아 채우고 **없으면 비워둠. 지어내기 절대 ❌** (이름·일시·장소·가격·계좌·연락처·정원·마감일·스펙·경력·작품 정보·통계·후기·이미지)
- 왜 — 표현은 틀려도 고치면 그만이지만 **사실은 틀리면 사고**

**제목 — 런타임 상태가 정한다**
- 그 단계에 **한 칸이라도 비어 있으면** `{항목}을 추가하면 좋아요`
- **전부 채워져 있으면** `{항목}을 미리 채워뒀어요 / 수정할 곳이 없는지 확인해 주세요.`
- 표에는 **비어 있을 때 버전만** 적는다

**🟣 제목의 주어 = 명사형 섹션 타이틀 (2026-09-17 이선호 확정)** — `{주어}를 추가하면 좋아요`의 주어 자리 규칙 5개.
1. **주어 = 그 단계가 채우는 섹션의 「명사형 섹션 타이틀」(AI 생성) 그대로** — 화면에서 **포인트(primary) 색**으로 표시하고, 오른쪽 미리보기의 그 섹션 타이틀 영역과 **연결선**으로 잇는다. (표의 「단계 / 칸」 이름은 자리 표시 — 런타임에 실제 타이틀로 치환)
2. **조사 을/를** — 타이틀 **마지막 글자에 받침이 있으면 `을`, 없으면 `를`**(`프로그램을` · `행사 정보를`). 숫자·영문으로 끝나면 **읽는 소리** 기준(`LOOK 1을`·`FAQ를`).
3. **2단 타이틀(제목 ＋ 한줄카피)** = 카피는 빼고 **「제목」 부분만** 주어로.
4. **히어로 3단계(메인 이미지·로고·히어로 텍스트) = 고정 이름 유지** — 히어로엔 섹션 타이틀이 없다(eyebrow뿐 · 편집 제외).
5. **문장형 타이틀 섹션**(⑨ 상하선·em대시 계열 — 예 `주문하시면 2일 안에 / 문 앞에 도착합니다`)도 **AI가 명사형 이름표를 함께 생성**해 두고 주어는 그것을 쓴다(예 → `가격과 발송 안내를 추가하면 좋아요`). 화면에 그 명사가 안 보여도 무방 — 연결선이 위치를 가리킨다. 이름표 작법 = 섹션 타이틀 「이름표」 규칙(명사＋역할어 · [[4-8. 시안 검수 체크리스트]] 75번).
→ 즉 **주어 = 항상 「명사형 섹션 이름표」 하나의 규칙**이고, 예외는 히어로뿐. "명사를 뽑을 수 있나" 같은 판단이 필요 없다(항상 있음).

**📍 장소 ≠ 찾아오시는 길 (2026-09-15 이선호 확정)** — 둘은 **받는 방식이 달라 단계가 따로**다.
| | **장소** | **찾아오시는 길** |
|---|---|---|
| 섹션 | 핵심 정보 | 위치 안내 (지도) |
| 입력 | **단순 텍스트** 한 줄 | **주소 검색** ＋ **상세주소**(텍스트) = **칸 2개** |
| 예 | `그랜드 하얏트 서울 그랜드볼룸` | `서울 강남구 테헤란로 521` ＋ `3층 그랜드볼룸` |
- 🔑 주소는 **검색 목록에서 골라야** 지도·길찾기가 열린다(타이핑만 하면 안 열림). 층·호수는 검색에 안 잡히니 **상세주소로 따로** 받아 **지도 아래 주소 옆에** 붙인다. 📍 **그래서 필수 충족 판정도 「선택 완료」 기준 (2026-09-17 이선호)** — 타이핑만 한 상태는 「채워짐」으로 안 치고, 검색 결과에서 1개를 고른 순간에만 충족(버튼 `다음` 전환·반응 말풍선 모두 이 시점).
- 단계 자리 = **문의 바로 앞** · 찾아올 곳이 없는 주제(온라인 전용·고객 집 방문·오프라인 매장 없음)는 **단계째 건너뜀**.


**반응** — **따뜻한 한마디 ＋ 이모지 1개**(`멋진 메인 이미지네요 👀` · `브랜드가 확실해졌어요 ✨`) · 이모지는 **칸 종류별 고정 10종** · **채움이 `AI`인 칸은 반응 없음(`—`)** · 🕯 **무거운 소식(6-① 공지·알림)만 예외 — 이모지·감탄 ❌**

**🔘 필수/선택 칸 ＋ 하단 버튼 (2026-09-16 이선호)** — 각 단계의 칸은 **필수/선택**으로 나눈다(필수 = 이름·제목·일시처럼 없으면 섹션이 성립 안 되는 칸 · 선택 = 설명·부가 문구 — 예: 프로그램 단계는 날짜·시간＋제목이 필수, 설명은 선택). **필수 칸이 다 차면 하단 `이건 없어요` 버튼이 `다음`으로 바뀐다**(누가 채웠는지 무관 — AI가 미리 채운 것도 「참」). 분류 기준·버튼 규칙 정본 = [[4-12. 입력 유형 카탈로그]] §2-0 · ✅ **아래 25주제 표에 「필수」 열 반영 완료 (2026-09-16 · 2026-09-17 정정 후 279칸 = 필수 236 · 선택 43)** — 판정 기준은 「작성 메모 › 필수/선택 판정」.

**공통 안내**(최초 1회 · 입력칸 옆) — `엔터로 줄을 나눌 수 있어요`

**유저 말로** — 내부 분류 이름·전문 용어 ❌ · **「블록」이라는 말 ❌**(개별 = **카드**, 묶음 = **섹션**)

🔑 **`채움 = AI`인 칸도 입력칸을 준다 (2026-09-15 이선호 확정)** — AI가 지어 채웠더라도 **유저에게 고칠 기회를 준다.** 값이 들어간 채로 보여 주고(제목 = `○○을 미리 채워뒀어요 / 수정할 곳이 없는지 확인해 주세요.`) 그 자리에서 편집할 수 있게 한다. 즉 **「AI가 채움」은 칸의 종류가 아니라 칸의 상태**다.

🚫 **편집 범위에서 빼는 것은 딱 둘 — 「eyebrow(제목 위 문구)」와 「섹션 타이틀」** (2026-09-15 이선호 확정 · 2026-09-10 eyebrow 규칙을 섹션 타이틀까지 확장) — 이 둘은 AI가 넣고 유저는 건드리지 않는다. **단계·칸에 등장하지 않는다.** 둘 다 **섹션 디자인에 딸린 표현**이라(eyebrow = 히어로 21개 섹션의 2단 타이틀 윗줄 · 섹션 타이틀 = 공용 팔레트 8유형) 유저가 고치면 레이아웃 언어가 깨진다. ℹ️ 값의 이름표인 **필드 라벨**(`일시`·`장소`)도 문항이 아니다 — 유저는 **값만** 고친다. ℹ️ 4단계(에디터)로 넘어간 뒤에는 이 셋도 당연히 편집 가능하다 — 제외되는 건 **빌더의 「내용 채우기」 화면**뿐.

### 🎨 반응·마일스톤 이모지 — 칸 종류별로 고정 (2026-09-14 이선호)

> 🔄 **옛 「담백 규칙」(2026-09-10 · 이모지·감탄 ❌) 폐기.** 유저가 뭘 채울 때마다 뜨는 한마디라 **격려가 목적**이다. 다만 **아무 이모지나 쓰면 산만**하므로 **칸 종류가 이모지를 정한다**(문구를 쓰는 사람이 고르지 않는다).

**문구 규칙**
1. **16자 안팎 · 마침표 없음 · 이모지는 맨 끝에 1개**(앞에 반각 공백 한 칸)
2. 두 갈래만 — ⓐ **감탄형** `멋진 {무엇}이네요` (이미지 칸) ⓑ **효과형** `{무엇}이 확실해졌어요 / 또렷해졌어요 / 분명해졌어요 / 쉬워졌어요` (정보 칸)
3. **반복 입력은 개수 변화 유지** — `{무엇} N개가 됐어요`. 무엇인지 앞에 붙여 준다(❌ `5개가 됐어요`)
4. **한 주제 안에서 같은 문구·같은 서술어 연달아 ❌**(이모지는 종류가 정하므로 겹쳐도 됨)
5. **채움이 `AI`인 칸은 반응 없음(`—`)** — 유저가 채우는 행위가 없다. 🔒 **유저가 AI 값을 고쳐도 반응 없음을 유지한다 (2026-09-15 이선호 확정)** — AI 칸에도 입력칸은 주지만(§「`채움 = AI`인 칸도 입력칸을 준다」), **고쳤다고 말풍선을 띄우지는 않는다.** 반응은 **빈칸이 채워진 순간**의 격려지 편집의 확인이 아니다

🕯 **예외 = 무거운 소식** — `6-① 공지·알림`(휴관·이전·폐업 포함)은 **이모지·감탄 없이 담백하게**. 반응뿐 아니라 **마일스톤도 이모지 없이**([[4-4. 조립 레시피]] 「무거운 소식의 톤 규칙」).

1. **단계에 칸이 하나뿐이면 무조건 「필수」** — 그 칸이 곧 그 단계의 건너뛰기 판단이다. 선택으로 두면 버튼이 처음부터 `다음`이 되어 `이건 없어요`(원래 없음 표시)가 영영 안 뜬다. → 소개·SNS·쿠폰·진행 중 이벤트처럼 **내용상 부가여도 단독 단계면 필수**.
