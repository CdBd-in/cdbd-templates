# 입력 단계 안내 문구 — 주제 25개

> **무엇** — 유저가 시안을 보며 내용을 채우는 화면의 **모든 문구**.
> **어디서 나왔나** — 단계 구성은 [[4-4. 조립 레시피]] 5절 레시피 카드, 작성 규칙은 `1. 작업 가이드/.data/tips/_SPEC.md`.
> **검수** — 전수 자동 검사 통과(열 수 · 주제 내 중복 · 금지표현).

## 화면 구조 — 문구가 놓이는 자리 3곳

```
┌ 왼쪽 입력 패널 ─────────┐ ┌ 오른쪽 미리보기 ───────┐
│ ① 제목 │ │ ╭──────────╮ │
│ [ 입력칸 ] │ │ │ ② 말풍선 │ │
│ │ │ ╰───╮╭─────╯ │
│ │ │ ━━━━━━━━🚗────────── │
│ │ │ 진행 바 ＋ 자동차 │
│ │ │ ┌────────────────────┐ │
│ │ │ │ 시안 │ │
└─────────────────────────┘ └─┴────────────────────┴─┘
```

🚗 **진행 인디케이터** ([Figma 7010-23500](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=7010-23500))
— 진행 바 위를 **자동차가 달려** 진행률을 보여주고, 자동차 위 **말풍선**에 메시지가 뜬다. 숫자(`3/8`)를 대신한다.

| 자리 | 단위 | 언제 |
| ---------------- | --- | ----------------- |
| **① 제목** | 단계 | 항상 |
| **② 말풍선 — 반응** | 칸 | 칸 **「완료」 직후 2초** — 완료 시점 판정 = [[4-12. 입력 유형 카탈로그]] §2-0 「⏱ 칸 완료 판정」 |
| **② 말풍선 — 마일스톤** | 단계 | 절반 · 하나 남음 · 마지막 |

우선순위 `반응 > 마일스톤` — **겹치면 순차 노출**: [다음] 클릭으로 트리거되는 리액션은 단계 완료와 동시라 **마일스톤과 겹칠 수 있다** → **리액션 먼저 2초 → 사라진 뒤 마일스톤 ON**(마일스톤을 버리지 않는다)

- 🫥 **평소엔 말풍선을 숨긴다** — 반응·마일스톤이 뜨는 순간에만 나타나고, 그 밖엔 **자동차만** 보인다.
- 채울 때의 안내는 **왼쪽 패널의 제목이 전담**한다 — 왼쪽 패널 = **제목 ＋ 입력칸**. 제목 아래 상시 노출 문구(팁·기대효과 류)는 두지 않는다.

### 확정 화면([Figma 7024-7692](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=7024-7692))과의 대응

이 문서의 구조는 확정 플로우 화면과 1:1이다 — 플로우 전체 = [[4-2. AI 유저 플로우#7. 내용 채우기 — 1/8 ~ 8/8 (🟢 단계 필수 / 🟡 칸 선택) — `v2 · 8 내용 채우기`]].

- **런타임 상태가 제목을 고른다** — 비어있음 = `추가하면 좋아요` / 다 찼음 = `미리 채워뒀어요` · 제목 한 줄만(상태 3형·주어 규칙 정본 = [[MD-09-1. 내용 채우기: 질문 구성]] §3-0)
- 반응 = **2초 노출** · 화면 라벨 `격려`는 **마일스톤 묶음의 이름**일 뿐 — 별개 유형이 아니고, 종류는 **절반 · 하나 남음 · 마지막 3종**뿐이다
- 화면 속 문구(*"벌써 절반이나 왔어요! 🙌"* 등)는 **북토크 예시용 샘플** — **주제별 정본은 이 문서의 표**(이모지 사용 여부도 여기서 정한다)

## 🔒 이 문구는 「고정 문구」다 — AI가 짓지 않고 **고른다**

> ⚠️ **예외 = 「채운 직후 반응」** — 반응 문구는 [[MD-09-3. 내용 채우기: 반응 문구]]에서 **AI가 두 가지 틀(효과형·인상형)로 짓는다**. 이 문서의 반응 열은 그 틀의 **견본**이다. 아래 「고른다」는 **왼쪽 제목·마일스톤**에 적용된다.

| | |
|---|---|
| **AI가 받는 것** | 칸과 그 칸이 속한 **섹션 목적** · 유저가 **채운 칸 / 비어 있는 칸** |
| **AI가 하는 일** | 아래 표에서 **그 칸에 맞는 문구를 고른다** · 마땅치 않으면 **비워 둔다** |
| **AI가 하지 않는 일** | **문구를 새로 짓는 것** |

⚠️ **[[MD-08-3. 시안: 텍스트 구성]]과 다른 글이다** — 07-3은 **페이지에 들어갈 글**(손님이 읽음), 이 문서는 **입력 화면에서 유저에게 주는 안내**(유저만 봄).

| 표의 열 · 요소 | 규칙 정본 | 표에서 알아둘 것 |
|---|---|---|
| **왼쪽 제목** | [[MD-09-1. 내용 채우기: 질문 구성]] §3-0 — 상태 3형(추가하면/마저 채우면/미리 채워뒀어요) · 주어 우선순위 · 조사 | 표에는 **비어 있을 때 버전만** 적는다 · `〃` = 같은 단계 |
| **채움 (AI/사실)** | [[MD-09-2. 내용 채우기: 미리 채우기]] §3-1·3-2 | **AI** = 문장을 지어서 미리 채움(표현) · **사실** = 자료에 있으면 뽑아 채우고 **없으면 비워둠 — 지어내기 절대 ❌**(표현은 틀려도 고치면 그만, 사실은 틀리면 사고) |
| **필수/선택 · 하단 버튼 전환** | [[4-12. 입력 유형 카탈로그]] §2-0 ＋ [[MD-09-1. 내용 채우기: 질문 구성]] §3-5 | 집계 = **279칸 = 필수 256 · 선택 23** |
| **방금 채움(반응)** | [[MD-09-3. 내용 채우기: 반응 문구]] — 틀·금지 말·무거운 소식 판정 | 표의 반응 열 = **견본** · `—` = 채움 `AI` 칸(유저가 채우는 행위가 없다 — **고쳐도 반응 없음**) |
| **리액션 표시 시점(칸 완료 판정)** | [[4-12. 입력 유형 카탈로그]] §2-0 「⏱ 칸 완료 판정」 | 조합 항목(주소 검색＋상세주소 등)은 **[다음] 1회 발화** — 대표 행에만 문구를 적는다 |
| **편집 제외** | [[4-12. 입력 유형 카탈로그]] §6 — **섹션 타이틀뿐** · eyebrow는 편집 허용(라벨 = 「제목 위 문구」 고정 · 채움 = AI) | 섹션 타이틀은 단계·칸에 등장하지 않는다 |

- **공통 안내**(최초 1회 · 입력칸 옆) — `엔터로 줄을 나눌 수 있어요`
- **유저 말로** — 내부 분류 이름·전문 용어 ❌ · **「블록」 ❌**(개별 = **카드**, 묶음 = **섹션**) · 칸 라벨 말 규칙 = [[MD-09-1. 내용 채우기: 질문 구성]] §3-0-B
- 🔑 **`채움 = AI`인 칸도 입력칸을 준다** — 값이 들어간 채로 보여 주고 그 자리에서 편집. 「AI가 채움」은 칸의 종류가 아니라 **상태**다([[4-12. 입력 유형 카탈로그]] §2 상태 ②).

### 🟣 제목의 주어 — 이 문서 몫의 보충 (정본 = MD-09-1 §3-0)

주어 우선순위(히어로 고정 이름 → 라벨 영역 → 라벨 줄 → 제목 줄 → 폼 제목 → AI 명사형 이름표)와 금지 규칙은 전부 [[MD-09-1. 내용 채우기: 질문 구성]] §3-0. 아래만 이 문서가 더 정한다.

- **화면 표시** — 주어는 **포인트(primary) 색**으로 표시하고, 오른쪽 미리보기의 그 섹션 타이틀 영역과 **연결선**으로 잇는다. 표의 「단계 / 칸」 이름은 자리 표시 — 런타임에 실제 타이틀로 치환된다.
- **조사 을/를** — 받침 규칙에 더해, 숫자·영문으로 끝나면 **읽는 소리** 기준(`LOOK 1을` · `FAQ를`).
- **라벨＋제목 2줄 타이틀은 서로 다른 정보를 더할 때만**(`가격`＋`봄 첫물차 할인` ✅) — 라벨 단어가 제목에 그대로 들어가면(`신청`＋`참가 신청`) 2줄 대신 **라벨 없는 한 줄 타이틀**로 만든다. 라벨이 주어인 이유 = 라벨은 섹션에 딸린 **고정 이름**이라 제목 문구를 미리 등록할 수 있고, 제목 줄은 AI가 짓는 카피성 이름이라 길고 페이지마다 달라진다.
- **폼 제목은 「명사형」으로 짓는다** — `참가 신청서`·`상담 신청서`·`지원서` ✅ / `신청하기`·`문의 남기기` ❌(주어에 넣으면 `신청하기를 미리 채워뒀어요`처럼 어색). 제출 버튼만 동사형. 예: 폼 제목 `참가 신청서` → 헤딩 `참가 신청서를 미리 채워뒀어요` ([Figma 7356-101437](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=7356-101437))

### 📍 장소 ≠ 찾아오시는 길 — 받는 방식이 달라 단계가 따로다

| | **장소** | **찾아오시는 길** |
|---|---|---|
| 섹션 | 핵심 정보 | 위치 안내 (지도) |
| 입력 | **단순 텍스트** 한 줄 | **주소 검색** ＋ **상세주소**(텍스트) = **칸 2개** |
| 예 | `그랜드 하얏트 서울 그랜드볼룸` | `서울 강남구 테헤란로 521` ＋ `3층 그랜드볼룸` |

- 인풋 종류·충족 판정(주소 칸 = 검색 결과 **「선택 완료」만 채움** · 층·호수는 상세주소로 따로) 정본 = [[4-12. 입력 유형 카탈로그]] §2-0 · [[MD-09-1. 내용 채우기: 질문 구성]] §3-1 🗺.
- **단계 자리 = 문의 바로 앞** · 찾아올 곳이 없는 주제(온라인 전용·고객 집 방문·오프라인 매장 없음)는 **단계째 건너뜀**(마일스톤 N도 줄어든 값 기준).

## 🎨 리액션(방금 채움) 문구 — 수제 · 패턴 · 이모지 (팔레트 정본)

> 문장 틀(효과형·인상형)·금지 말(칸 라벨 주어 ❌ · 개수 ❌ · 유저 평가 ❌)·무거운 소식 판정의 정본 = [[MD-09-3. 내용 채우기: 반응 문구]]. 이 절은 **표의 「방금 채움」 열을 쓰고 고칠 때의 고정 팔레트** — 수식어·서술어·이모지는 여기서만 고른다(짓지 않는다). 문구는 **두 층**이고, **이모지는 두 층 공통으로 「칸 종류」가 정한다**.

| 층 | 무엇 | 어디에 쓰나 |
|---|---|---|
| **Ⓐ 수제 문구 (우선)** | 아래 25주제 표 「방금 채움」 열에 **칸마다 직접 써 둔 문구** — 그 열이 정본 | 문구가 있는 칸 전부 — 항상 패턴보다 우선 |
| **Ⓑ 패턴 문구 (폴백)** | `{섹션타이틀}`만 런타임 치환하는 고정 틀 | **수제 문구가 없던 빈 칸**(복수 항목 등)에만 |

#### Ⓐ 수제 문구 — 칸마다 직접 쓴 문구

두 갈래만 — **감탄형** `멋진 {무엇}이네요`(이미지 칸)와 **효과형(의문사형)**(정보 칸 — 칸 라벨을 주어로 되풀이하지 않고 **방문자의 질문이 풀리는 의문사형**으로 · `누구인지 분명해졌어요` · 라벨과 다른 명사면 효과 주어 OK `브랜드가 확실해졌어요 ✨`). 틀 = [[MD-09-3. 내용 채우기: 반응 문구]] §3-2·3-3. 칸 종류별 수제 문형·예문은 **아래 이모지 팔레트 표의 「예」 열**에 함께 있다.

#### Ⓑ 패턴 문구 — `{섹션타이틀}` 삽입형 2계열

> 수제 없이 비어 있던 칸을 기계적으로 채우는 고정 틀. **왼쪽 제목과 같은 「명사형 섹션 타이틀」을 주어로** 끼운다 — 타이틀만 런타임 치환하므로 「AI가 짓지 않고 고른다」 원칙 그대로다.

**① 효과형** `{타이틀}이(가) ~졌어요` — 조사 = 받침 있으면 `이`, 없으면 `가`

| 서술어 | 어울리는 칸 | 예 |
|---|---|---|
| `확실해졌어요` | 사실 정보 (일시·가격·핵심 정보) · 절차(이용 단계) | `모집 정보가 확실해졌어요 🗓` · `이용 단계가 확실해졌어요 ✅` |
| `준비됐어요` | 기능 (예약 회차·버튼·링크) — **이모지 = ✅ 고정** | `예약 회차가 준비됐어요 ✅` |

**② 감탄형** `{수식어} {타이틀}(이)네요` — 조사 = 받침 있으면 `이네요`, 없으면 `네요` · **수식어도 고정 팔레트에서만**(짓지 않음)

| 수식어 | 어울리는 칸 | 예 |
|---|---|---|
| `멋진` | 이미지 · 사진 · 로고 | `멋진 메인 이미지네요 👀` |
| `흥미로운` | **구경거리형 반복 목록만** (프로그램·볼거리·제품·작품·소식) | `흥미로운 프로그램이네요` |
| `친절한` | 규정·경고성 (유의사항·주의사항·규정·FAQ·참여 조건) | `친절한 유의사항이네요 ✅` |
| `반가운` | 혜택 · 쿠폰 | `반가운 혜택이네요 👍` |

**⚠️ 반복 항목 예외 — `흥미로운`(구경거리형)을 쓰지 않는 부류**

> 반복 항목이라고 전부 구경거리는 아니다. 아래 부류는 `흥미로운 ~이네요`가 톤 사고가 되므로 **다른 경로로 배정**한다.

**패턴 공통 규칙**
- 🔑 **수식어는 「항목 1개만 봐도 참」인 말만** — 반복 항목 리액션은 **첫 항목 완료 시점**이라, 쌓인 양을 칭찬하는 수식어(꼼꼼한·탄탄한·알찬·풍성한)는 그 시점에 거짓말이 됨 → 채택 ❌
- 🚫 **감탄형을 안 쓰는 칸** — 값만 있는 사실 칸(일시·주소·계좌·가격 — 내용의 질을 칭찬할 수 없음) · **사람 칸**(연사 — 평가 말투는 실례) · **문의 채널**(수제 `연락할 방법이 생겼어요 📞` 유지) → 효과형이나 수제 문구로
- **주어 규칙과의 관계** — Ⓐ의 🚫「칸 라벨 주어 ❌」는 **값 라벨**(`이름`·`일시`) 이야기. 패턴 주어는 **섹션 타이틀**(단계 이름 — 왼쪽 제목과 같은 주어 체계)이라 허용
- 길이 = **서술부 기준 16자 안팎**(타이틀이 길면 전체는 초과 가능)
- ✅ **주소 조합(찾아오시는 길) 대표 문구 = `찾아오기 쉬워졌어요 📍`** — 주소 검색＋상세주소는 [다음] 1회 발화라 문구도 1개(상세주소 전용 문구는 발화 기회가 없어 두지 않는다)

#### 공통 문구 규칙 (수제·패턴 모두)
1. **16자 안팎 · 마침표 없음 · 이모지는 맨 끝에 1개**(앞에 반각 공백 한 칸)
2. **한 주제 안에서 같은 문구·같은 서술어 연달아 ❌**(이모지는 종류가 정하므로 겹쳐도 됨)
3. 🔁 **복수 항목 칸은 「첫 항목 완료」 때 1회만** — 「＋ 추가」로 항목을 늘리는 리스트·갤러리·반복 묶음(프로그램·메뉴·작품·제품·사진 여러 장 등)은 항목마다 말풍선이 떠 소음이 되므로 **첫 번째 항목이 완료되는 순간 1회만** 띄우고 이후 항목엔 안 띄운다 · `{무엇} N개가 됐어요` 개수 리액션 ❌(첫 항목 시점엔 개수가 무의미) · ℹ️ 라벨＋값 고정 묶음(일시·장소 등)과 문의·SNS는 복수 항목이 아니라 반응 유지 · 표의 남은 `—`는 ⓐ 채움 `AI` 칸 ⓑ **반복·조합 묶음의 하위 행**(발화는 묶음당 1회 — 대표 행에만 문구) 둘뿐
4. **채움이 `AI`인 칸은 반응 없음(`—`)** — 유저가 채우는 행위가 없다. 🔒 **유저가 AI 값을 고쳐도 반응 없음 유지** — AI 칸에도 입력칸은 주지만, **고쳤다고 말풍선을 띄우지는 않는다.** 반응은 **빈칸이 채워진 순간**의 격려지 편집의 확인이 아니다

🕯 **예외 = 무거운 소식** — `6-① 공지·알림`(휴관·이전·폐업 포함)은 **이모지·감탄 없이 담백하게**. 반응뿐 아니라 **마일스톤도 이모지 없이**(판정 재료·톤 = [[MD-09-3. 내용 채우기: 반응 문구]] §3-5 · [[4-4. 조립 레시피]] 「무거운 소식의 톤 규칙」).

### 채움 주체

- 가름 규칙(사실 = 자료에 있을 때만 · 표현 = AI) 정본 = [[MD-09-2. 내용 채우기: 미리 채우기]] §3-1·3-2.
- 📌 **「사실」 = 「시안에서 그 자리가 빈다」는 뜻이 아니다** — 시안에는 형식이 보이는 플레이스홀더가 들어가고, 이 화면에서만 **흐리게 ＋ 입력칸 비어 있음**으로 보인다. 끝까지 안 채우면 자동 삭제([[4-12. 입력 유형 카탈로그]] §2 상태 ③ · [[MD-08-3. 시안: 텍스트 구성]]).
- **히어로 제목·설명 = 25주제 전부 「AI」** — 히어로 카피는 페이지 설명에 재료(이름·주제)가 반드시 있어 AI가 항상 지어 채울 수 있고, 일시·오픈 날짜·접수 마감 같은 **사실은 설명에 넣지 않고 그 주제의 사실 단계**(핵심 정보·모집 정보·참가 요강 등)가 받는다. 제목 안의 사실 조각(할인율·전시명·발행일)은 페이지 설명·자료에서 온 값만 쓰고 지어내지 않는다. AI 칸 규칙대로 **반응 = `—`**.

### 왼쪽 제목 판정

- **라벨로 나뉜 영역(일시·장소·참가비)은 반복 항목이 아니면 단계를 나눈다 — 왼쪽 제목도 영역마다**(`일시를 …` · `장소를 …` · 묶은 `일시와 장소를 …` ❌) — 정본 = [[MD-09-1. 내용 채우기: 질문 구성]] §3-3 🔪.
