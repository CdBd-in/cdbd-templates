# 페이지 설명 예시 칩 — 개발 등록값

> 📌 **정본 = [[4-10. 어드민 고정값]] §1** (칩 목록·예시글 규칙·결정 근거 전부 그쪽). 이 문서는 **개발에 그대로 넘기는 등록값 사본**이다. 예시글을 고치면 **정본을 먼저 고치고 이 사본을 다시 뽑는다.**

## 등록 사양

- **위치** — ① 페이지 설명 입력 화면 · 설명 입력칸 바로 아래
- **노출** — 자료 첨부 여부와 무관하게 **항상 노출** · 5개 고정
- **동작** — 칩을 누르면 그 예시글이 입력창에 **채워진다** (맨 위 괄호 안내 줄 포함 6줄)
- **칩 위 라벨(고정)** — `✨ 무엇을 적을지 막막하다면, 아래 예시로 시작해 보세요`

⚠️ **칩 이름 표기 주의** — 개발 메모의 `행사를 열어요` · `서비스를 소개해요`는 옛 표기. 정본 이름은 **`행사·모임을 열어요`** · **`브랜드·서비스를 소개해요`** (가운뎃점 포함, 아래 표 그대로).

| 순서 | 칩 이름 |
| :-: | --- |
| 1 | `행사·모임을 열어요` |
| 2 | `제품을 판매해요` |
| 3 | `브랜드·서비스를 소개해요` |
| 4 | `신청을 받아요` |
| 5 | `공지를 알려요` |

## 예시글 5개

**① 행사·모임을 열어요**
```
(아래 예시를 지우고 실제 내용을 적어 주세요)
고객사를 초청하는 신규 서비스 세미나를 엽니다.
11월 15일 목요일 오후 2시, 삼성동 코엑스 3층 회의실.
1부는 서비스 소개, 2부는 도입 사례 발표입니다.
정원은 100명이고 참가비는 없습니다.
신청은 이 페이지에서 바로 받으려고 합니다.
```

**② 제품을 판매해요**
```
(아래 예시를 지우고 실제 내용을 적어 주세요)
이번 가을 신상 가방 12종을 한 페이지에 소개하려고 합니다.
품목마다 이름과 가격, 색상 옵션이 있습니다.
전부 소가죽이고 크기는 조금씩 다릅니다.
사진은 품목당 3장씩 준비돼 있습니다.
구매는 공식몰로 연결하고 싶습니다.
```

**③ 브랜드·서비스를 소개해요**
```
(아래 예시를 지우고 실제 내용을 적어 주세요)
기업 브랜드 아이덴티티를 설계하는 디자인 스튜디오입니다.
로고와 패키지, 공간 디자인까지 브랜딩 전반을 맡고 있습니다.
2016년에 설립했고 구성원은 20명입니다.
주요 클라이언트는 식품과 뷰티 브랜드입니다.
프로젝트 문의는 이메일로 받고 있습니다.
```

**④ 신청을 받아요**
```
(아래 예시를 지우고 실제 내용을 적어 주세요)
올해 대학생 서포터즈 20명을 모집합니다.
8주 동안 SNS에 브랜드 콘텐츠를 올리는 활동입니다.
활동비는 월 20만원이고 수료증을 드립니다.
지원서에 이름, 연락처, 자기소개를 받으려고 합니다.
9월 30일 마감이고 10월 초에 발표합니다.
```

**⑤ 공지를 알려요**
```
(아래 예시를 지우고 실제 내용을 적어 주세요)
다음 달부터 고객센터 운영시간이 변경됩니다.
지금은 저녁 6시까지인데 5시까지로 한 시간 앞당겨집니다.
12월 1일부터 적용되고 주말 상담은 그대로입니다.
서비스가 중단되는 것은 아니고 상담 시간만 조정됩니다.
급한 문의는 채팅 상담으로 안내하려고 합니다.
```

## 입력칸 플레이스홀더 (칩과 별개 · 1개)

빈 입력칸에 흐리게 보이는 글 — 입력을 시작하면 사라진다.

```
다음 달 성수동에서 브랜드 팝업 스토어를 엽니다.
신제품 소개와 현장 이벤트를 함께 안내하려고 합니다.
```
