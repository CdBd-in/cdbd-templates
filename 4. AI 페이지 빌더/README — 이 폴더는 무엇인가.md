## 여기에 없는 것 (일부러 남긴 것)

- [[1-8. 섹션 프리셋 라이브러리]] — 프리셋은 **디자인 자산**이라 작업 가이드에 둠. 내가 시안을 조립할 때도 계속 쓴다.
- [[1-3. 색상 팔레트]] · [[1-4. 폰트]] · [[1-6-2. CdBd 카드 기능]] — AI도 쓰지만 **사람 작업에도 그대로 쓰이는 공용 자산**.
- `.data/` 폴더들(tips · preset-index · persona-200 …) — **스크립트가 경로로 참조**하므로 원래 자리에 둠.

## 파일 이름 번호에 대해

문서 번호(`1-9`·`3-5`)는 **옮기기 전 이름 그대로**다. 볼트 전체에 200곳 넘게 걸린 링크를 안 깨뜨리려고 유지했다.
`4-1`·`4-2`… 로 다시 매기려면 링크 일괄 교체가 필요하니, 원할 때 한 번에 처리한다.
