# MD-11. 블록(프리셋) 설명 문구

> 📍 **화면**: 6 · 페이지 유형 · [피그마에서 보기](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/AI-%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=6919-10907)
> 🗒 **출처**: 피그마 코멘트 (2026-09-10, codeisneverodd)
> 🚧 **상태**: 골격만 — 본문 지침 작성 대기

## 1. 무엇을 정하는 MD인가

마일스톤 단계에서 블록마다 표시할 **설명 문구** (예: 메인 이미지, 로고)를 만든다.

## 2. 입력

시안에 배치된 각 프리셋(블록)

## 3. 출력

마일스톤 단계에서 블록마다 표시할 **설명 문구** (예: 메인 이미지, 로고)

## 4. 규칙

- 유저 말로 — 프리셋 내부 이름·전문 용어 ❌
- 한 블록 = 한 문구, 짧게

> 🚧 여기에 실제 생성 지침(프롬프트 수준의 규칙·예시·금지 사항)을 채운다.

## 5. 볼트 근거

- [[1-14. 입력 단계 안내 문구]] 팁 규칙(15자 · 그 칸에서만 성립)

## 6. 원본 코멘트

```
시안 생성 후 마일스톤 단계에서, 각 프리셋(블럭)을 설명할 문구를 지정. 예시) 메인이미지, 로고 등
```
