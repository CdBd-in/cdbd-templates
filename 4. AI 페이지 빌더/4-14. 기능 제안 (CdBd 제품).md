# 4-14. 기능 제안 (CdBd 제품)

> 🎯 **이 문서의 역할** — 좋은 레퍼런스를 「CdBd로 못 만들어서」 버린 순간을 모아, **어떤 기능이 생기면 무엇이 풀리는지**를 개발에 제안한다.
> 📥 **쌓는 법** — 레퍼런스 채점([[4-13. 데일리 퀄리티 루프]] §3)에서 「재현 불가」로 뺀 요소가 아래 제안과 같으면 **그 제안의 「막힌 사례」에 한 줄 추가**, 새 기능이면 **새 제안**을 만든다. 사례가 쌓일수록 우선순위를 올린다.
> 🔧 **버그·확인 요청은 여기 아님** — 그날 리포트의 「🔧 개발 요청」에 적는다.

## 제안 1. 2열 카드 칸 디자인 — 칸마다 배경·테두리

**지금** — 2열 카드의 배경·테두리·모서리는 **카드 전체에 하나**만 줄 수 있다. 칸(요소)마다 따로 박스를 그릴 수 없다.

**막힌 사례**
- Mintlify — 고객 사례 칸마다 다른 색 밴드 + 지표 2칸 → 탈락
- Postevand — 테두리 두른 숫자 타일 2×2 → 우리 「수치표 + 각주」 섹션 철회 사유 중 하나
- LinusBio — 단계 칸마다 흰 박스 4개 → 우리 「이모지 단계」는 **틴트 패널 한 장**으로 타협

**제안 동작**
- 2열 카드 디자인 탭의 **요소 선택 드롭다운**(이미 있음)에서 요소마다 **「칸 디자인」**: 배경색 · 테두리(두께·색) · 모서리(각진/둥근) · 안쪽 여백
- 기본값 = 없음(지금과 똑같이 보임) → 기존 페이지 영향 없음
- 칸 높이는 같은 줄에서 **가장 높은 칸에 맞춤**(박스 높이가 들쭉날쭉하면 타일처럼 안 보임)

**쓰이는 곳** — 실적·수치 타일(2~4칸) · 요금제·옵션 비교 · 단계 칸 · 전/후 비교 · 세션 카드 2개 나란히

## 제안 2. 태그 줄 — 짧은 라벨 여러 개를 한 줄에

**지금** — 알약·배지 **1개**는 텍스트 카드(카드 배경 + 둥근 모서리 + 좌우 여백)로 만들 수 있지만, **여러 개를 가로로 이어 붙일 수 없다**. 가장 가까운 건 메뉴 카드 「한눈에 보기」 스타일 4(테두리 알약)인데:
- 항목 폭이 **글자 길이와 무관하게 같다**(짧은 라벨도 넓게 벌어짐)
- 한 줄에 **최대 4개**
- 이동용 메뉴라 추가하면 **상단 고정**이 걸리는 등 본문 중간 태그로 쓰기 어렵다

**막힌 사례**
- Gaskuy 여행 — 시설 칩 줄(투어 가이드 · 패키지 · 숙박 · 교통) → 탈락
- Rollin 베이커리 — 빵 카테고리 칩 줄 → 탈락
- Amie — 신뢰 배지 줄 → 탈락

**제안 동작**
- 새 카드 **「태그」**(또는 텍스트 카드 옵션 「태그 모양」): 항목 = 라벨(+ 선택: 링크)
- 항목 폭 = **글자 길이에 맞춤**, 넘치면 **다음 줄로 자동 줄바꿈**
- 모양 = 페이지 버튼 모양을 따름(원형·각진·둥근) · 스타일 = 테두리 / 틴트 / 채움(메뉴 카드 스타일 4·5·3 계열 재활용) · 크기 · 정렬(좌·중) · 간격

**쓰이는 곳** — 시설·편의(주차 · 와이파이 · 반려동물 동반) · 특징 키워드(#비건 #당일 배송) · 취급 분야·메뉴 카테고리 · 수상·인증 배지 줄

## 제안 3. 갤러리 넘겨보기 확장 — 글 붙은 항목을 옆으로 넘기기

**지금**
- 갤러리 「넘겨보기」 = **사진만**, 한 장씩 넘김(항목마다 제목·설명을 붙일 수 없음)
- 상품 카드 「옆으로 넘겨보기」 = **URL로 불러온 상품 전용**
- → 상품이 아닌 **이미지 + 제목(+ 설명) 항목**을 옆으로 넘기는 줄은 못 만든다. 그래서 세로로 길게 쌓는다

**막힌 사례**
- Icebug — 카테고리마다 신상품을 옆으로 넘기는 줄 → 우리 「카테고리 진열 행」은 2단 그리드로 타협
- 우리 섹션 — 인물·후기·작품처럼 항목이 많은 나열은 페이지가 길어진다

**제안 동작** (새 카드 대신 **갤러리를 넓힌다** — 이미지별 링크는 이미 있음)
- 이미지마다 **제목 · 설명(선택)** 입력칸
- 넘겨보기에 **「한 화면에 보일 개수」**(예: 1.2 · 1.5 · 2.2장 — 다음 항목이 살짝 보여 넘길 수 있다는 걸 알게)
- 손가락으로 밀어 넘김 · 항목 수 제한 = 갤러리와 같음(15장)

**쓰이는 곳** — 신상품·추천 메뉴 줄 · 후기 카드 줄 · 강사·인물 줄 · 포트폴리오 · 공간 사진 + 이름
