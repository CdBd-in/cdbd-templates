# 4-10. 어드민 고정값

> 🔒 **이 문서의 값은 AI가 만들지 않는다.** 우리가 한 번 쓰고 **어드민에 등록**하면, 직접 고치기 전까지 **모든 유저에게 그대로** 나간다.
> 📌 근거 = 피그마 코멘트(2026-09-10, codeisneverodd) — *"어드민에서 고정으로 설정함, MD 아님"*
> ✍️ 말투·금지 표현은 [[MD-01. UX 라이팅]]을 따른다 — 여기 문구가 딱딱한데 AI 문장만 상냥하면 한 화면에서 말투가 튄다.
> 📏 **길이 상한** — 화면 제목 **20자**(모바일 1줄) · 부제 **35자**(1줄 유지)

### 🚫 고정 문구 금지 표현

| 유형 | ❌ | ✅ |
|---|---|---|
| 기계 말투 | *"자료를 분석했습니다"* | *"올려주신 내용을 정리해 봤어요"* |
| 과장·감탄 남발 | *"완벽해요! 놀라운 페이지가 ✨🎉"* | 감탄사는 화면당 1개까지 |
| 사과 | *"죄송해요"* | 사실만 · 단정 |

## 1. 페이지 설명 예시 칩 6개

**뭘 적을지 막막한 유저**에게 주는 마중물. 칩을 누르면 그 예시글이 입력창에 **채워진다**.

> 화면 라벨(🔒 고정) — *"✨ 무엇을 적을지 막막하다면, 아래 예시로 시작해 보세요"*

> 🔄 **2026-09-11 변경 2가지** ([[4-2. AI 유저 플로우]] §1 · ①② 통합)
> - **자리** — 옛 ②(페이지 설명 확인) → **① 화면**(설명 입력칸 바로 아래)
> - **조건** — *"자료 없이 시작한 유저에게만"* → **자료를 올렸든 안 올렸든 항상 보인다.** 칩의 역할이 「자료 없는 사람 구제」가 아니라 **「빈 칸 앞 막막함 해소」**로 바뀌었기 때문. 자료를 잔뜩 올려도 *뭐라고 설명해야 할지*는 여전히 막막하다
> - ⚠️ 그래서 예시글 안에 **「자료가 없으니」 류의 전제를 깔면 안 된다**

### 1-A. 칩 목록과 순서

| 순서 | 칩 | 덮는 영역 |
|:--:|---|---|
| 1 | `행사·모임을 열어요` | 1 행사·안내 |
| 2 | `제품·메뉴를 보여줘요` | 4 상품·홍보 · 3-② 메뉴 |
| 3 | `하는 일을 소개해요` | 3 소개·홈페이지 |
| 4 | `신청을 받아요` | 5 신청·문의 |
| 5 | `포트폴리오를 보여줘요` | 2 프로필·명함 |
| 6 | `공지를 알려요` | 6 소식·자료 |

**순서 근거** = 첫 칩이 가장 많이 눌리므로 **실사용 무게 순**. CdBd 실사용 549건에서 페이지 **절반이 카탈로그**, 행사 페이지 60건이 그다음이다([[4-3. 목적·주제별 분류]] §4-B).

**이름 근거 2가지**
- 「가게」 ❌ → **「하는 일」** — 주체로 이름 지으면 반드시 누군가 빠진다(가게 → 갤러리·교회·기관이 자기 것으로 안 봄). 4-3이 대분류 3을 「매장」→「브랜드·단체」→「소개」로 두 번 고친 것과 같은 이유.
- 「팔아요」 ❌ → **「보여줘요」** — 실사용 절반이 **카탈로그**이고, 핏플랍 30종·빙그레 54품목이 **구매 링크 0개**였다([[1-6-2. CdBd 카드 기능]]). CdBd 페이지는 대체로 **파는 게 아니라 보여주는** 페이지다.

### 1-B. 예시글 쓰는 규칙

- **일부러 못 쓴 글로** — 반듯한 완성 문장이면 유저가 *"나는 이렇게 못 쓰는데"* 하고 막힌다. 화면이 이미 *"단어만 나열해도 괜찮아요"* 라고 했으니 예시도 그 수준이어야 한다
- **구어체 5줄 · 한 줄에 한 가지** — 유저는 글이 아니라 **줄 구성**에서 *"이런 걸 적으면 되는구나"* 를 배운다
- **칩마다 정보 구조를 다르게** — 6개가 같은 구조면 예시가 6개일 이유가 없다
- **맨 위에 안내 한 줄** — 그대로 제출하는 사람이 반드시 나온다. 이 줄이 남아 있으면 **AI가 「안 고쳤다」를 알아챌 수 있는** 덤도 있다
- **업종을 겹치지 않게** — 문화 · 리테일 · 요식 · 기업 · 개인 · 교육

### 1-C. 예시글 6개

**① 행사·모임을 열어요** — `무엇 / 언제·어디 / 순서 / 조건 / 신청`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
다음 달에 동네 책방에서 북토크 열어요
11월 15일 토요일 저녁 7시, 성수동 책방 오래
작가님 강연 1시간이랑 질문 받는 시간 있어요
20명까지만 받고 참가비 1만원, 음료 포함이에요
신청은 인스타 DM으로 받고 있어요
```

**② 제품·메뉴를 보여줘요** — `품목 수 / 항목마다 반복되는 것 / 공통 정보 / 사진 / 구매 경로`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
이번 가을 신상 가방 8개를 한 번에 보여주고 싶어요
품목마다 이름이랑 가격, 색상 옵션이 있어요
전부 소가죽이고 크기는 조금씩 달라요
사진은 품목당 2~3장씩 있어요
자세한 건 스마트스토어에서 보라고 링크 걸고 싶어요
```

**③ 하는 일을 소개해요** — `정체성 / 하는 것 / 영업시간 / 규모·예약 / 주의사항`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
망원동에서 2년째 하는 작은 파스타집이에요
점심엔 파스타 한 접시, 저녁엔 와인도 같이 팔아요
화요일부터 일요일 11시-21시, 월요일은 쉬어요
테이블이 3개뿐이라 예약 받고 있어요
주차가 어려워서 근처 공영주차장 안내해야 해요
```

**④ 신청을 받아요** — `대상·인원 / 무슨 활동 / 조건·혜택 / 받을 항목 / 마감`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
올해 대학생 서포터즈 20명을 뽑으려고 해요
8주 동안 SNS에 저희 브랜드 콘텐츠 올리는 활동이에요
활동비 월 20만원이랑 수료증 드려요
지원서에 이름, 연락처, 간단한 자기소개 받고 싶어요
9월 30일까지 받고 10월 초에 발표할 거예요
```

**⑤ 포트폴리오를 보여줘요** — `누구 / 경력 / 작업물 개수 / 작업 하나의 구성 / 연락`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
브랜드 로고랑 패키지 디자인하는 프리랜서예요
5년 정도 했고 카페랑 화장품 브랜드 위주로 작업했어요
보여주고 싶은 작업이 8개쯤 있어요
작업마다 어떤 브랜드였는지랑 사진을 같이 넣고 싶어요
의뢰 문의는 이메일로 받을게요
```

**⑥ 공지를 알려요** — `무엇이 바뀌나 / 전후 비교 / 적용일·대상 / 오해 방지 / 문의`
```
(예시예요 — 아래를 내 내용으로 바꿔 주세요)
다음 달부터 수업 시간이 바뀐다고 알려드리려고요
지금 저녁 7시인데 7시 30분으로 30분 밀려요
12월 1일부터고 주말반은 그대로예요
학원이 옮기는 건 아니고 시간만 바뀌는 거예요
궁금한 건 전화 주시라고 번호도 넣어주세요
```

## 2. 페이지 유형 근거 한 줄 — 2개

유형을 **통보**하는 화면(`6 · 페이지 유형`)에서 추천 카드 아래 붙는 **이유 한 줄**. 🔑 **AI는 원/멀티만 판정**하고 아래 문구를 그대로 부른다 — **두 줄이 전부다** (2026-09-11 이선호 확정). 판정 4관문 = [[4-2. AI 유저 플로우]] ⓒ.

| 유형 | 근거 한 줄 | 글자 수 |
|---|---|:--:|
| **원페이지** | *"한 화면에서 쭉 읽는 게 잘 맞는 내용이에요."* | 23 |
| **멀티페이지** | *"여러 장으로 나눠 보는 게 잘 맞는 내용이에요."* | 24 |

**고칠 때 지킬 것 3가지**
- **두 문구는 짝** — 문장 구조를 같게 (`쭉 읽는` ↔ `나눠 보는`)
- **유형 이름 넣지 않기** — 카드 제목이 이미 `원페이지`·`멀티페이지`
- **크레딧 넣지 않기** — 금액은 카드 안 별도 자리([[4-2. AI 유저 플로우]] ⑤)

> 📎 화면 부제 *"지금까지 답변한 내용을 바탕으로 추천드리는 페이지 유형이에요"* 는 **유형과 무관한 고정 안내**라 이 줄과 겹치지 않는다.

## 3. 앞으로 여기 들어올 것

이 문서는 **화면 고정값 전부**를 모으는 자리다. 아직 안 옮긴 것 —

- 화면 **제목·부제** (현재 [[4-2. AI 유저 플로우]] 「화면별 상세」에 서술형으로 있음)
- 버튼 라벨 (`다음` · `네, 보여주세요` · `지금 시안으로 충분해요` 등 · 🗑 `없어요, 그냥 시작할게요`는 ①② 통합으로 **없어짐**)
- 로딩 문구 (⑥ 24%→62%→91% · ⑫ 무드→카드→텍스트→이미지→점검)

⚠️ **옮길 때 주의** — 4-2는 **흐름을 설명하는 문서**라 문구가 예시로 섞여 있다. 여기로 옮기면 4-2에는 *"문구 정본 = 4-10"* 만 남긴다.
