## 1. 이 체계는 무엇인가

### 1-1. 용도 — 순수 내부 기준

> **유저는 대분류도 주제도 보지 않는다.** 이 체계는 **AI 페이지 빌더**의 내부 기준일 뿐이다.

| 역할 | 쓰임 |
|---|---|
| **① 조립 레시피 서랍** | 페이지를 만들 때 "어떤 섹션을 어떤 순서로" |
| **② 질문 세트 열쇠** | 이 유형이면 무엇을 물어야 하나 |
| **③ 커버리지 지도** | 템플릿·섹션 제작 시 빈칸 확인 |

**여기서 따라 나오는 것 3가지**
- 🗑 **이름을 「유저가 찾기 쉽게」 다듬지 않는다.** 내부 이름의 기준은 **정확성**뿐이다.
- 🗑 **어드민 카테고리·템플릿 진열대와 맞출 필요가 없다.** 그쪽은 **템플릿 상품 진열용**이고 이쪽은 **AI 빌더의 서랍**이라, 두 체계는 별개여도 무방하다.
- ✅ **주제를 나누는 잣대가 하나로 좁혀진다** — **「섹션 구성이 다른가」**. *「물어볼 항목만 다르다」*는 주제를 나누지 않고 **조건부 필드**로 처리한다(3-1).

### 1-2. 유저에게 닿는 유일한 층 = 화면 어휘

화면의 *"이 내용에는 **[가맹점 모집 안내]**를 추천해요"* 에 나오는 이름은 **내부 주제 이름(`5-②` 모집)과 같을 필요가 없다.**

| | 성격 | 개수 |
|---|---|---|
| **내부 서랍** | 닫힘 · 구성 기준 · 정확성 우선 | **주제 25개 고정** |
| **화면 어휘** | 열림 · 유저 말을 따라감 (직원 채용 공고 · 가맹점 모집 · 체험단 모집 · 서포터즈 모집…) | **무한** |

→ 같은 `5-②` 서랍이라도 유저가 "직원 뽑아요"라 쓰면 「채용 공고」, "가맹점 찾아요"라 쓰면 「가맹 모집 안내」로 부른다. **내부 주제는 안 늘고 유저 어휘만 늘어난다.**
🔑 **선택지는 닫혀야 하고, 사전은 열려야 한다.**

### 1-3. 대상 범위 — 비즈니스용 페이지만

> **CdBd의 지향점은 「비즈니스용 모바일 페이지」**다. 따라서 **개인 경조사(청첩장·돌잔치·환갑·백일)와 부고·추모는 이 체계에서 제외**한다.

| | |
|---|---|
| **제외된 주제 2개** | 옛 `1-①` 경조사 초대장 · 옛 `1-⑥` 부고·추모 |
| **결과** | 1번 대분류 6개 → **4개** · 1번만 재번호(옛 ②③④⑤ → 새 **①②③④**) |

**왜 빼는가 4가지**
1. **사업이 아니다** — 나머지 25개는 전부 「사업체가 고객·지원자·후원자에게 무언가를 하려는」 페이지다.
2. **말투가 체계 전체와 어긋난다** — 부고 하나 때문에 「초대 어휘 금지」·「푸터 금지」·「무채색 강제」 같은 **예외 규칙이 여러 곳에 번졌다.** 빼면 그 예외들이 함께 사라진다.
3. **경쟁이 포화** — 모바일 청첩장·부고장은 전용 서비스가 이미 촘촘하다. 우리 강점(B2B·기관)과 겹치지 않는다.
4. **실사용 근거가 얇다** — CdBd 실사용 549건 중 개인 경조사는 4건 남짓(5-2).

> ⚠️ **「제외」 = 주제를 설계하지 않는다는 뜻이지, 유저를 막는다는 뜻이 아니다 ** — 막을 수단도 없고 새 주제를 만들 수도 없다. 유저가 청첩장을 만들려 하면 **가장 가까운 주제**(`1-①` 행사 초대장)로 정하고 **해당 없는 섹션은 뺀다** → [[MD-03. 주제 판정]] 3-E.

|---|---|---|---|

| **3** | **소개·홈페이지** | **공간·조직** | 매장 · 회사 · 병원 · 학원 · 교회 · 동호회 · 비영리 · 갤러리 · 공공시설 |
| **4** | **상품·홍보** | **물건·출시** | 상세페이지 · 룩북 · 카탈로그 · 판매 · 출시 예고 · 프로모션 |

### 2-2. 이름 규칙

> ℹ️ 이 이름들은 **유저에게 노출되지 않는다**(1-1). 규칙의 목적은 *「유저가 못 찾는다」*가 아니라 **「우리 분류 판단이 흔들린다」**를 막는 것이다. **유저 친화성을 이유로 이름을 다시 다듬지 않는다.**

- 🚫 **업종어 금지** (카페·병원·학원) → **목적어**로. 대분류는 목적축이므로 업종이 섞이면 축이 오염된다.
- 🚫 **주체어 금지** (매장·브랜드·단체) → **주체로 이름 지으면 반드시 누군가 빠지고, 그 순간 분류가 틀린다.**
 - `매장` → **갤러리**가 빠진다 · `브랜드` → **교회**가 빠진다 · `단체` → **1인 사업자**가 빠진다
- ℹ️ **「홈페이지」 단독은 쓰지 않는다** — 상위어라 형제 자리에 못 온다. 다만 **비디자이너에게 가장 익숙한 말**이고 네이버 모두 종료(2025-06)로 갈 곳 잃은 소상공인의 검색어라 `소개·홈페이지`로 품었다.

### 2-3. 대분류를 가르는 기준

**① 상시인가, 한 건인가** — 같은 주체가 만들어도 **목적이 다르면 다른 대분류**다. 테스트 케이스 = 「아트갤러리」.

| 만들려는 것 | 대분류 |
|---|---|
| 아트갤러리 **홈페이지** (공간을 상시 소개) | **3 소개·홈페이지** |
| 《○○ 개인전》 **초대장** (전시 한 건) | **1 행사·안내** |
| 《○○ 展》 **도록** (작품 기록) | **6 소식·자료** |
| 작품 **판매** 페이지 | **4 상품·홍보** |

**② 3번은 「종합형」 — 다른 대분류를 페이지 단위로 품는다**

```
아트갤러리 홈페이지 (대분류 = 3)
├ P1 홈 갤러리 소개 · 대표 이미지 · 현재 전시
├ P2 전시 전시명 · 기간 · 작가 · 오프닝 안내 ← 1번 유형을 빌려옴
├ P3 작품 작품 이미지 + 캡션 ← 6번(도록) 유형
└ P4 방문 안내 위치 · 관람시간 · 휴관일 · 예약 ← 1번(예약)
```
> 🔑 **대분류는 3번 하나인데 안의 페이지들이 1·4·6의 유형을 빌려온다.** 나머지 5개는 단일 목적이라 이런 중첩이 없다. 그래서 3번이 멀티페이지 본진이다.

**③ 2번 ↔ 3번 = 히어로에 무엇이 오는가**

「사람이 주인공/조직이 주인공」은 말로만 하면 애매하다. **페이지 맨 위에 무엇을 놓는지**로 정한다.

| | **2 프로필·명함** | **3 소개·홈페이지** |
|---|---|---|
| 히어로 | **내 얼굴·이름** | **상호·로고·공간 사진** |
| 구성 | 인물 사진 + 이름·직함 + 소개 + 작업물 + 연락처 저장 | 로고 + 대표 이미지 + 소개 + **서비스·가격** + **위치·영업시간** + 문의 |
| 사진작가 **김OO** | ✅ | |
| **OO 스튜디오** | | ✅ |

> **테스트 — 프리랜서가 스튜디오 페이지를 만들면?** → **3번.** 「스튜디오」라고 말한 순간 이미 **상호를 내건 사업체**이고, 페이지에 서비스·가격·위치·예약이 들어간다.
> **같은 사람이 둘 다 만들 수 있고 그게 정상이다.** 목적이 다르기 때문.

## 3. 주제 25

### 3-1. 나누는 잣대 — 「섹션 구성이 다른가」 하나

업종·상황이 페이지를 바꾸는 방식은 **층이 3개**이고, **①만 주제로 나눈다.**

| 층 | 무엇이 바뀌나 | 처리 |
|---|---|---|
| **① 섹션 구성** | 어떤 섹션이 들어가는지 자체 | 🔪 **주제로 분할** |
| **② 필드 항목** | 섹션은 같고 안에 넣는 항목만 다름 | 📋 **조건부 필드** (주제 안 나눔) |
| **③ 톤·문구·색** | 구조 동일 | 🎨 무드 |

🔴 **가장 자주 틀리는 지점 = ②를 ①로 착각해 주제를 늘리는 것.**
- 사례 ㉮ **채용 공고**를 별도 주제로 뒀다가 `5-② 모집`에 흡수 — 섹션이 1:1 대응하고 다른 건 필드뿐이었다.
- 사례 ㉯ **B2B 카탈로그**에 「수치 현황·규격표·이용 절차」가 없다며 레시피를 늘리려다 취소 — 표는 `[★구매]` 안에, 절차는 `[안내 사항]`의 **내용만 바꾸면** 된다.

**설계 원칙 3**
1. **주제도 목적어로** — 업종어·주체어 금지(대분류에서 겪은 문제 반복 방지)
2. **구성이 갈리는 지점에서만 나눈다**
3. **균등 배분 ❌** — 편중이 정상이다(3-4)

## 4. 갈릴 때 — 갈림 질문 7축

> 🤖 **실행 절차는 [[MD-03. 주제 판정]] 3-C에 있다.** 여기엔 **왜 이 방식인지**와 **축 목록**만 둔다.

### 4-1. 왜 「묻는」 게 맞나

[[4-2. AI 유저 플로우]]의 *「판단 어려운 건 묻지 말고 보여준다」*(원/멀티 · 무드)와 상충하는 것처럼 보이지만 **대상이 다르다.**

| | 묻는다 | 보여준다 |
|---|---|---|
| **무엇** | 유저만 아는 것 = **내 상황** | 유저가 미리 판단 못 하는 것 = **어떻게 보일지** |
| 예 | "손님이 시간을 직접 고르나요?" | 원/멀티 · 무드 · 시안 |

➕ **이 답은 버려지지 않는다.** "회차를 고른다"고 답하면 → 예약 카드가 필요하고 → 회차 정보를 물어야 한다. **질문이 늘어난 게 아니라, 어차피 받을 정보를 앞당긴 것.**

🔑 **판별 기준을 문서에만 적어두면 죽은 규칙이 된다.** 그래서 AI가 갈릴 때 **유저에게 직접 묻는 장치**로 바꿨다.

### 4-2. 일곱 축

| 축 | 확인 문장 (유저 언어) | 가르는 짝 |
|---|---|---|
| **①** | "이 페이지를 본 사람이 **어딘가로 오게 되나요?**" | **1번 ↔ 6번** · `3-②`↔`4-③` |
| **②** | "**내용을 충분히 보여주고** 받을까요, **바로 받을까요?**" | `1-②`↔`5-①` · `2-②`↔`5-④` · `4-①`↔`4-④` |
| **③** | "**지금 주문·결제를 받나요?**" | `4-④`↔`4-⑤` · `5-②`↔`4-④` |
| **④** | "**고를 수 있는 시간(또는 정원)이 있나요?**" | `1-④`↔`5-④` · `5-②`↔`5-④` |
| **⑤** | "보여줄 게 **사진·작업물**인가요, **글·경력**인가요?" | `2-③`↔`2-④` · `6-②`↔`6-③` |
| **⑥** | "**마감 있는 할인·혜택**이 주인공인가요?" | `4-⑥`↔`4-③` · `4-⑥`↔`4-②` |
| **⑦** | "한 가지에 **사진이 여러 장**인가요, **한 장**인가요?" | `4-②`↔`4-③` |

> 🥇 **①이 가장 상위** — 1번↔6번을 가른다. 팝업 오픈 안내 = 보러 간다 → 1번 / 휴무 공지 = 읽고 끝 → 6번 / 안전수칙·매뉴얼 = 읽고 끝 → 6번.
> 🆕 **⑥⑦은 2026-09-14 추가** — 백테스트에서 드러난 3쌍(룩북↔카탈로그 · 프로모션↔카탈로그 · 룩북↔프로모션)을 기존 5축이 못 갈랐다(5-4 ③).

### 4-3. 작동 방식과 지킬 것

**갈림은 별도 단계로 띄우지 않는다.** AI가 갈리면 **후보 둘을 가르는 섹션을 「있으면 더 좋은 것들」 칩으로 함께 올리고** 유저가 고르게 한다.

- **카테고리 이름을 문장에 쓰지 않는다** — `예약형인가요 상담형인가요` ❌ → **상황 문장**으로. (국내에선 「랜딩페이지」·「상세페이지」조차 실무자끼리도 안 통한다 → 부록 A)
- **추천을 미리 찍어 두고 확인만 받는다** — 고르게 하는 게 아니라 맞는지 보는 것
- **상한 1개** — 갈림이 둘 이상 겹치면 나머지는 AI가 정하고 시안에서 보여준다. 안 지키면 *「카테고리를 안 고르게 하려고 만든 플로우」*가 다시 설문이 된다.
- **"둘 다예요"에 대비** — 둘 다면 **더 많이 담는 쪽**으로(예: 예약＋상담 → 예약 페이지에 문의 버튼 추가). 되묻지 않는다.

| **시간 슬롯 배분**(날짜×시간대별 정원) | 케이크 |
| **다국어 한 페이지**(한/영/베트남/태국어) | 안전수칙 |
| **법정 표기 대량**(식품 · 가맹사업법) | 식품 · 가맹 |
| **내부 문서**(비밀번호 · 마케팅 톤 아님) | 매뉴얼 |
| **복제 후 한 부분만 교체가 유일한 사용법** | 매달·월2회·매년 반복 행사 |
| **페이지가 도중에 유형을 갈아탄다** | 가림막 QR (`4-⑤` → 오픈 후 `3-①`) |

### 5-4. 백테스트 24건 — 진짜 구멍과 유령

> 실제 유료 고객 12건 + 유저 셀프 제작 12건 **전수 대조**.
> ✅ **25개 주제 자체는 거의 안 틀린다** — 대분류 배정은 **24건 모두** 맞았고, 「완전히 새 주제」 요구는 **0건**이었다.

**① 「한 페이지 = 한 주제」가 깨진다던 2형 → 🗑 유령 **

구멍이 아니라 **배정이 틀린 것**이었다.

| 사례 | 적혀 있던 것 | 실제 | 왜 틀렸나 |
|---|---|---|---|
| **대아청과** | 「소식지」 = `6-②` + `6-①` + `6-④` **합본** | **`4-③` 카탈로그** | 본체가 기사가 아니라 **취급 품목 목록**이었다. **제목의 「소식지」를 보고 배정**한 오분류(= 아래 ④가 말하는 바로 그 실수) |
| **서초 프로그램북** | `3-①` 안에 `1-②` **×19 챕터** | **`6-②` 매거진·소식지** | 목적이 「학교를 상시 소개」가 아니라 **「이번 시즌 프로그램을 펼쳐 보이기」**다. 사보·프로그램북처럼 **한 권으로 묶인 것**은 `6-②`가 원래 자리 |

🗑 **「합본」·「챕터」 개념 폐기** · 「25개 위에 2층 구조를 얹자」는 제안도 폐기. **새 개념을 만들지 않는다.**
✅ **대신 실제로 고친 것** — `6-②` 레시피에 **여는 말·목차·부가 안내**가 없었다(`4-③`엔 이미 있었다). 세 줄을 조건부로 추가하고 **"꼭지 하나가 한 화면을 넘으면 꼭지당 한 장으로 편다"** 주석을 달았다 → [[4-4. 조립 레시피]] `6-②`.

**② 대응 주제가 없다던 3유형 → 2건은 해소, 1건은 분류 밖**

| 유형 | 실측 | 판정 |
|---|---|---|
| **사후 설문·피드백** | 행사 후 만족도 조사 | ✅ **해소** — `5-①`의 `[핵심 정보] 일시·장소`가 **`(있으면)` 조건부**라 빠지면 그만. `5-①` 그대로 쓴다 |
| **B2B 거래처 전용** | 빙그레 B2B 카탈로그 | ✅ **주제는 `4-③` 그대로** — 「거래처 전용 접근·회원 영역」은 **기능**이지 주제가 아니다(별도 쟁점) |
| **사양 확정 발주** | 산청군청(색·폰트·4페이지를 확정해서 옴) | ⚠️ **분류 문제가 아니다** — 「무엇을 만들까」가 아니라 「이대로 만들어라」 → [[4-2. AI 유저 플로우]] 소관 |

**③ 갈림 질문이 없던 3쌍 → ✅ 축 ⑥⑦ 신설로 해소**

| 짝 | 실측 | 왜 5축으로 안 갈렸나 |
|---|---|---|
| `4-②` 룩북 ↔ `4-③` 카탈로그 | 수트서플라이 · 핏플랍 · 타미힐피거 | 둘 다 P4 · 둘 다 사진이 주인공 · 둘 다 결제 없음 |
| `4-⑥` 프로모션 ↔ `4-③` 카탈로그 | 신세계 L&B · 산청군청 | **목적은 `4-⑥`(할인), 구조는 `4-③`(품목 카드 반복)** |
| `4-②` 룩북 ↔ `4-⑥` 프로모션 | 타미힐피거 | 요청서가 스스로 `2. 프로모션 :`이라 적음 |

> ⚠️ **이 3쌍이 CdBd 실사용 물량이 가장 큰 구역**이다(실사용의 절반이 패션·리테일 시즌 카탈로그).
> 🔴 **처음 제안했던 문구는 틀렸다** — *「품목마다 가격·SKU를 붙이나 / 화보만 보여주나」*. **룩북에도 가격·구매 링크가 붙는다**(`4-②` 레시피에 `[구매] 구매 링크 (선택)`). → **「한 가지에 사진이 여러 장인가 / 한 장인가」**로 대체(축 ⑦).

**④ 제목이 아니라 「본문 동사」로 배정해야 한다**

**태극무궁화예술대전** — 제목·슬러그는 `2026 나라사랑 태극무궁화예술대전 **공모전**`인데 본문은 **시상식 초대장**이다(`초대합니다` / 이미 뽑힌 수상자 시상식). 제목으로 배정하면 `5-⑤`로 가고 레시피 커버리지 **0%**가 나온다(응모 자격·접수 기간·참가비·부문·심사·제출물·저작권·신청 폼 **8개 전부 해당 없음**).

→ 같은 사업이 `접수 → 심사·발표 → 시상·전시` **시점마다 다른 페이지**가 된다. 유저는 사업명을 계속 쓰므로 **제목만 보면 반드시 오분류**한다.
✅ **규칙화 완료** → [[MD-03. 주제 판정]] 3-A(제목·파일명은 근거에서 제외 · 맺음 동사 표 · 사업 시점 표).
🔴 **이 문서 스스로가 그 실수를 저질렀다** — 위 ①의 「대아청과 **소식지**」가 정확히 제목으로 배정한 사례다. 규칙이 필요하다는 가장 강한 증거.

> 🥇 **종합** — 구멍 4개 중 **①②는 유령**(배정 오류·레시피 오해)이었고 **진짜는 ③④** 둘뿐이었다. 둘 다 [[MD-03. 주제 판정]]에 들어가 해소됐다.

## 6. 남은 쟁점

### 쟁점 ① — 3번(소개·홈페이지)을 확장할 것인가
- **경위**: *「3개 → 6개 확장」*까지 구두 결정했으나 **어떤 6개인지 기록이 남지 않았다.** 그 사이 옛 `3-③`이 삭제되어 현재 **2개**.
- **당시 근거**: *"업종에 따라 중간 섹션이 다르다"* → 하지만 **잣대가 바뀌었다**. 이제 *「섹션 구성이 진짜 다른가, 필드만 다른가」*로 다시 걸러야 한다.
- **실제 쟁점**: **「프로그램·수업 운영」**(체험마을 = 소개+프로그램+인원별 요금+소요시간+주차+식사)이 `3-②` 메뉴·가격과 **구성이 다른가?**
- **권고**: 🅰 **일단 2개로 두고 레시피를 짜다가 갈라지는 지점에서 나눈다.** 레시피가 곧 구성이므로 써 보면 저절로 드러난다.

### 쟁점 ② — 6번(소식·자료) 존치
- **링크인바이오·모바일 단일 페이지 서비스엔 「블로그·매거진」 축이 거의 없다**(Carrd·Milkshake·Bio Sites 전부 없음). 웹사이트 빌더엔 흔하지만 **모바일 한 장과 안 맞는 유형일 가능성.**
- CdBd 실사용 549건에서도 매거진·도록 성격은 거의 안 보였다. 다만 어드민 체크박스엔 있고 시안도 제작 완료.
- **권고**: **유지하되 우선순위 최하위.** 미확정.

### 쟁점 ③ — 포트폴리오 변형
- `2-③` 안에 **이미지형 · 프로젝트형**(인테리어 · 멀티 4p) **· 영상형**(유튜브 카드 나열)이 있다.
- **권고**: 주제 1개 유지 + **섹션 변형 3종**으로. 구성 차이가 「섹션이 다름」이 아니라 「같은 섹션의 카드 타입이 다름」이라 3-1 층위 ②에 가깝다. 미확정.

### 쟁점 ④ — `5-② 모집` ↔ `5-⑤ 공모전·대회`를 합칠 것인가

| | `5-② 모집` | `5-⑤ 공모전·대회` |
|---|---|---|
| 공통 | 정원·자격·마감 + **지원 폼** | 정원·자격·마감 + **참가 폼** |
| 차이 | 혜택·처우 | **부문 나열** + **시상 내역** |

- 차이가 **「섹션 2개 추가」뿐**이라 잣대(「섹션 구성이 다른가」)는 통과하지만 **약하다.**
- **옛 `5-③` 채용을 `5-②`에 흡수한 것과 같은 논리**를 대면 합쳐야 할 수도 있다(부문·시상을 조건부 필드로).
- **권고**: 레시피를 실제로 써 본 뒤 판정. 지금 합치면 층위 ①(섹션 구성이 다르면 분할)을 반대로 위반할 위험.

### 쟁점 ⑤ — 「거래처 전용 접근」 기능
- B2B 페이지의 **비밀번호·회원 영역** 개념이 25개 어디에도 없다. **주제가 아니라 기능**이므로 이 문서 밖에서 다뤄야 한다. 미착수.

ℹ️ **참고** — 「상세페이지」를 목적 카테고리로 둔 국내 랜딩 빌더는 **0곳**. 미리캔버스는 **제작물 규격**(형제 = 프레젠테이션·카드뉴스), 카페24는 **제작 서비스 항목**이다. 우리 `4-① 상품 상세`는 **랜딩 카테고리가 아니라 커머스 규격**에 가깝다.

| **「내부 불일치를 정합해야 한다」** | 어드민 카테고리(3개)·템플릿 등록 체크박스(5개)는 **템플릿 상품 진열용**이고 이 체계는 **AI 빌더 서랍**이다. **별개 기준이어도 무방** → 정합 불필요 |
| **1번↔6번을 「때·장소가 있나」로 가르던 기준** | 실제로 안 갈린다 — 태풍 휴무 공지도 날짜가 있고 신제품 출시 공지도 날짜가 있다. 갈리는 건 **「받는 사람이 어딘가로 가는가」**(축 ①) |
| **「행사·안내라는 이름이 부고를 밀어낸다」 문제** | 유저가 그 이름을 볼 일이 없다(1-1). *부고 자체는 이후 1-3으로 대상에서 제외.* ℹ️ 국내 모바일 초대장 12곳 전수 확인 결과 **부고/상조는 어느 서비스에서도 초대장 카테고리 안에 없었다** — 업계 관행과도 일치했던 판단 |
| **「합본」·「챕터」 개념** | 두 사례 다 **배정 오류**였다. 새 개념 불필요 → 5-4 ① |
| **갈림 문구 「품목마다 가격·SKU를 붙이나 / 화보만 보여주나」** | **룩북에도 가격·구매 링크가 붙는다.** → 「사진이 여러 장인가 / 한 장인가」로 대체 → 5-4 ③ |
| ~~업계 전문어 금지~~ / ~~구어체 금지~~ | 유저 노출 전제라 무효. 내부 문서 톤 정도로만 |
