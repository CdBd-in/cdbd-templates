# 4. AI 페이지 빌더 — 이 폴더는 무엇인가

**비디자이너 유저가 AI로 모바일 페이지를 만드는 제품**에 대한 문서를 모았다.
사람이 직접 템플릿을 만드는 작업 가이드(`1. 작업 가이드`)와 **독자가 다르다** — 이쪽은 **제품 설계 정본**이다.

## 번호 = 읽는 순서 (위계)

번호는 중요도·의존 순서다. **위가 아래의 전제**가 된다 — 플로우가 정해져야 분류가 의미 있고, 분류가 있어야 레시피가 서고, 레시피가 있어야 프리셋을 고른다.

| 번호 | 문서 | 역할 | 층 |
|---|---|---|---|
| **4-1** | `4-1. 어드민 등록 MD/` | 개발·어드민에 넘길 **AI 지침 MD 12개** (피그마 코멘트에서 역산) | 📤 **산출물** |
| **4-2** | [[4-2. AI 유저 플로우]] | 유저가 밟는 **7단계** 제품 플로우 — 뭘 언제 묻고 언제 보여주나 | 🧭 **뼈대** |
| **4-3** | [[4-3. 목적·주제별 분류]] | 내부 분류 체계 — 대분류 6 × **주제 25** (유저 비노출) | 🧭 뼈대 |
| **4-4** | [[4-4. 조립 레시피]] | 주제 25개를 **어떤 섹션 · 어떤 순서**로 조립할지 | 🧱 **생성 규칙** |
| **4-5** | [[4-5. 섹션 프리셋 라이브러리]] | AI가 꺼내 쓰는 **섹션 프리셋 서랍**(355개) + 조립·통일 규칙 | 🧱 생성 규칙 |
| **4-6** | [[4-6. 무드]] | **무드 9개 = 색 + 폰트를 한 번에 결정**하는 기준 | 🧱 생성 규칙 |
| **4-7** | [[4-7. 입력 단계 안내 문구]] | 「내용 채우기」 화면 문구 — 제목·팁·반응·마일스톤 | 💬 **화면 문구** |

| **4-9** | [[4-9. 200 페르소나 플로우 검증]] | 7단계 플로우를 페르소나 200명으로 채점 | 🧪 **검증 자료** |
| **4-10** | [[4-10. 16 시나리오 테스트]] | 질문 세트 검증 (가상 유저 답변으로 역산) | 🧪 검증 자료 |
| **4-11** | [[4-11. 16종 시나리오 테스트 2차]] | 질문 세트 재검증 2차 | 🧪 검증 자료 |

## 여기에 없는 것 (일부러 남긴 것)

- [[1-3. 색상 팔레트]] · [[1-4. 폰트]] · [[1-5. 이미지]] · [[1-6-2. CdBd 카드 기능]] — **CdBd가 제공하는 재료·기능의 사양서**. AI도 사람도 똑같이 읽는다 → `1. 작업 가이드`에 유지.
  - 단 1-3·1-4에서 **AI 플로우에 필요한 판단 기준만** 뽑아 [[4-6. 무드]]로 만들어 뒀다. **목록이 바뀌면 원본(1-3·1-4)을, 판단 기준이 바뀌면 4-6을 고친다.**
- `.data/` 폴더들(tips · preset-index · draft75 · persona-200 …) — **스크립트가 경로로 참조**하므로 원래 자리에 둔다. 특히 프리셋 색인 `1. 작업 가이드/.data/preset-index/`는 [[4-5. 섹션 프리셋 라이브러리]]가 이 폴더로 옮겨진 뒤에도 그대로다.

## 파일 이름 규칙

- **폴더 번호 = 파일 접두사** (`4. AI 페이지 빌더/` → `4-N. …`). 2026-09-11에 옛 번호(`1-8`·`1-9`·`3-2` …)에서 일괄 변경하고 **볼트 전체 링크 476곳을 함께 갱신**했다.
- 새 문서를 넣을 땐 **위 「층」에 맞는 자리**에 번호를 준다. 층이 밀리면 뒤 번호를 당기지 말고 소수점(`4-6-1`)이나 맨 뒤 번호를 쓴다 — 번호를 다시 매기면 링크를 또 전부 고쳐야 한다.
