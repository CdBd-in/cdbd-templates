## 디자인 특성

- **전체 인상**: 럭셔리·포멀·헤리티지 — 페일 그레이 배경에 차콜 세리프 헤딩과 아이보리 강조 카드로 모노톤 럭셔리 초대장
- **페이지 테마**: 배경 페일 그레이 #FAFAFA / 텍스트 차콜/딥 퍼플 (검정에 가까운 무채색) / 버튼 다크 퍼플 999px 풀라운드
- **포인트 컬러**: 아이보리/베이지 카드 배경 (장소·일정 강조 박스)
- **컬러 대비**: 중 — 차분한 톤끼리의 매칭으로 의도적으로 부드러운 대비
- **모서리 처리**: 둥근 (단, 버튼은 원형/풀라운드 999px) — 정보형 라벨 박스는 약 12px 라운드, CTA 버튼은 캡슐형
- **카드 배경**: 페일 그레이 페이지 위에 화이트/아이보리 카드로 섹션 분리
- **텍스트 사이즈 대비**: 큼 — 세리프 헤드라인(The Heritage Summit)이 매우 크게, 본문은 작고 단정
- **반복되는 디자인 요소**:
  - 큰 세리프 디스플레이 타이포그래피
  - 차분한 모노톤 + 화이트/아이보리 카드의 격조 있는 위계
  - 일시·장소·지도가 1열로 정렬되는 정통 초대장 흐름
- **레이아웃 특징**: 페일 그레이 페이지 위에 큰 헤딩 → 초대 본문 → 일시·장소 박스 → 지도 → 프로그램 타임라인의 정통적 초대장 흐름, 카드 간격이 넉넉하고 격식 있음
