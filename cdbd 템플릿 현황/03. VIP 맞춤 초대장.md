## 페이지 구조

```
헤더(로고+초대장 제목/내용)
→ 행사 정보(일시·장소·지도)
→ 진행 순서 3단계 (번호+제목 반복)
→ 참석자 정보 등록(RSVP)
→ 맺음말 + 문의(버튼)
→ 푸터(로고+상호명)
```

> 세미나/공식 행사용. 진행 순서를 시각적으로 강조하는 구조.
