```
헤더(소속명+수신자명) → 초대글(본문+이미지+발신자)
→ 초대장 메인(제목+본문)
→ 행사 소개(소개+주소+공간+이미지)
→ 행사 관련 인물 2명 (프로필+내용+SNS)
→ 예약 시스템(내용+버튼)
→ 서비스 제공 설문
→ 푸터(로고+SNS)
```
