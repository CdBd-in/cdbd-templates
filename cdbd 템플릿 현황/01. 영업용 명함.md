## 디자인 특성

- **전체 인상**: 안정적·신뢰감·기업형 — 짙은 네이비 단색 헤더와 정제된 본문 구성으로 B2B 보안/금융 카테고리에 어울리는 프로페셔널한 인상
- **페이지 테마**: 배경 화이트 #FFFFFF / 텍스트 다크 네이비 #1F3A8A / 버튼 비비드 블루 #2563EB
- **포인트 컬러**: 짙은 네이비 #1F3A8A (브랜드 헤더 카드 배경)
- **컬러 대비**: 강 — 네이비 헤더와 흰 본문, 파란 버튼의 대비가 또렷함
- **모서리 처리**: 둥근 — 카드·버튼·입력 필드 전반에서 부드러운 라운드
- **카드 배경**: 흰색 카드가 페이지 배경(연회색/네이비) 위에 떠 있는 구조
- **텍스트 사이즈 대비**: 보통 — 헤딩은 굵은 다크 네이비, 본문은 회색 톤으로 위계 분리
- **반복되는 디자인 요소**:
  - 원형 프로필 사진 (네이비 보더)
  - 풀-와이드 파란 CTA 버튼
  - 일러스트형 아이콘 배지 (체크리스트, % 등)
- **레이아웃 특징**: 상단 네이비 헤더로 브랜드 컨테이너를 명확히 구획 → 프로필 카드 → 정보 블록 → CTA → 폼 → 푸터 순의 세로 1열 흐름, 섹션 간 충분한 여백
