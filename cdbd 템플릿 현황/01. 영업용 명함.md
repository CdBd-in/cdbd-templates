## 디자인 특성

- **전체 인상**: 안정적·신뢰감·기업형 — 다크 네이비 풀-블리드 캔버스에 화이트 카드와 시안 액센트로 B2B 보안/금융 카테고리에 어울리는 임팩트 있는 명함
- **페이지 테마**: 배경 다크 네이비 #1F2B5A 풀배경 / 텍스트 화이트 / 버튼 시안 #30C1FF
- **포인트 컬러**: 시안 #30C1FF (CTA 버튼·강조 액센트)
- **컬러 대비**: 강 — 다크 네이비 배경 ↔ 화이트 카드 ↔ 시안 CTA의 또렷한 3단 대비
- **모서리 처리**: 둥근 — 카드·버튼·입력 필드 전반에서 부드러운 라운드
- **카드 배경**: 흰색 카드가 다크 네이비 페이지 배경 위에 떠 있는 구조 (페이지 자체가 네이비, 카드가 흰색)
- **텍스트 사이즈 대비**: 보통 — 헤딩은 굵은 화이트, 본문은 라이트 그레이/네이비 톤으로 위계 분리
- **반복되는 디자인 요소**:
  - 다크 네이비 ↔ 흰 카드의 강한 명도 대비
  - 일러스트형 아이콘 배지 (체크리스트, % 등)
- **레이아웃 특징**: 다크 네이비 풀-블리드 페이지 위에 화이트 카드를 적층 → 프로필 카드 → 정보 블록 → CTA → 폼 → 푸터 순의 세로 1열 흐름, 섹션 간 충분한 여백
