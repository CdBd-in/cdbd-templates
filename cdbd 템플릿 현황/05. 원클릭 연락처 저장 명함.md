## 디자인 특성

- **전체 인상**: 모던·미니멀·기업형 — 라일락/연보라 액센트와 정돈된 카드 명함 스타일로 깔끔하고 세련된 비즈니스 카드 느낌
- **주조 컬러톤**: 거의 화이트 #FFFFFF + 연한 라벤더 #ECEAFB 섹션 구분
- **포인트 컬러**: 라벤더/페일 퍼플 #6E63E0 계열 (CTA, 헤딩 라인 배경)
- **컬러 대비**: 약~중 — 무채색 + 옅은 보라가 절제된 정보형 인상
- **모서리 처리**: 둥근 (약 10–14px) — 명함 카드, 정보 박스, 버튼 모두 부드러운 라운드
- **카드 배경**: 흰색 카드 + 연보라 강조 섹션 박스가 교차
- **텍스트 사이즈 대비**: 보통 — 이름과 라벨이 분명히 구분되나 헤딩 자체가 과하게 크진 않음
- **반복되는 디자인 요소**:
  - "OUR VISION / ESG TEAM MISSION" 같은 보라색 라벨 박스
  - 우측 화살표 행 (정보 → 액션)
  - 전체화면 폭의 보라 CTA 버튼 ("연락처 저장하기")
- **레이아웃 특징**: 명함 헤더 → 연락처 라인 리스트 → 지도 → CTA → 비전 섹션 → 영상 → 푸터의 비즈니스 카드형 흐름, 정보 밀도 높음
