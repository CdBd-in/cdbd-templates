## 디자인 특성

- **전체 인상**: 레트로·빈티지·유쾌함 — 다크 벽돌색 + 페일 민트 그린의 70년대 키치한 팝업 스토어 무드
- **페이지 테마**: 배경 다크 토마토/벽돌색 #A23721 / 텍스트 화이트 (다수) + 아이보리 (일부 카드 텍스트만) / 버튼 페일 민트 그린 #9FDDB9
- **포인트 컬러**: 페일 민트 그린 #9FDDB9 (Buttery Moment 카드 배경), 오렌지 #E37735 (라벨, 슬로건)
- **컬러 대비**: 강 — 보색에 가까운 레드/그린 조합이 비비드
- **모서리 처리**: 둥근 — 라벨 카드 일부에 노치/스티커 형태 빈티지 컷 추가
- **카드 배경**: 다크 벽돌색 풀블리드 + 페일 민트 그린/아이보리 강조 박스 / 사진 카드 점선 보더
- **텍스트 사이즈 대비**: 큼 — 시리얼 레이블 같은 굵은 디스플레이 헤드라인이 큼
- **반복되는 디자인 요소**:
  - 빈티지 라벨 스타일 박스 ("NOTICE", "SPECIAL GIFT", "RESERVATION")
  - 점선 테두리 + 모서리 마커
  - 오렌지/그린 정보 배지 (POPUP DURATION 등)
  - 한글+영문 믹스 키치 헤딩
- **레이아웃 특징**: 다크 벽돌색 풀 캔버스 위에 라벨 카드를 쌓아 가는 팝업 광고지 같은 흐름, 시각적 강도와 분위기 일관성 매우 높음
