## 페이지 구조

```
헤더(창업문의 홍보+프로필) → 타이틀+본문+이미지
→ 카드박스 비교(타이틀1 vs 타이틀2, 각 본문 3개) — 화살표로 연결
→ 타이틀+본문+박스 본문+세부사항
→ 아이콘 이미지2 + 본문
→ 질문과 답변(정보일치 확인)
→ 🌟 서명 (안내글+버튼)
→ 푸터(로고+이미지+인사말+상생지원정책+버튼)
```

> **'질문과 답변 - 정보일치'** + **'서명 안내글/버튼'** = 모바일 동의/서명 워크플로 특화.
