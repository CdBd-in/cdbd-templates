## 디자인 특성

- **전체 인상**: 캐주얼·F&B 프랜차이즈·식감 — 따끈한 푸드 사진과 따뜻한 옐로우/오렌지로 외식 가맹 모집의 군침 도는 인상 강조
- **페이지 테마**: 배경 화이트 / 텍스트 블랙 / 버튼 오렌지 #FF5800
- **포인트 컬러**: 크림 #FFF3EC (헤더 카드 배경), 오렌지 강조
- **컬러 대비**: 강 — 흰 배경 + 진한 오렌지 강조의 또렷한 식감 콘트라스트
- **모서리 처리**: 둥근 — 음식 사진/카드/버튼이 부드럽게 라운드
- **카드 배경**: 흰색 카드 + 크림/베이지 강조 박스 + 오렌지 풀배경 비교 카드
- **텍스트 사이즈 대비**: 큼 — 굵은 헤드라인(더 바삭 페이/무엇이…)이 강하게 잡힘
- **반복되는 디자인 요소**:
  - 음식 풀블리드 사진 카드
  - 비교표 박스 (기존 vs 신규 강조)
  - 굵은 헤딩 + 본문 짧은 라인 반복
  - 크림 헤더 카드 (상단 브랜드 컨테이너)
- **레이아웃 특징**: 음식 이미지 헤더 → 슬로건 → 차별점 비교 → 일정/조건 → 동의·서명 → 액션 CTA 순의 영업·계약 안내 흐름, 정보가 단계적으로 정리됨
