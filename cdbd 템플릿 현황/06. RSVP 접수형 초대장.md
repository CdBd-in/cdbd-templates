## 페이지 구조

```
헤더(모양+여백+로고+여백+이미지+행사부제+행사명)
→ 행사 정보(시간/장소/지도)
→ 초대장(제목+내용)
→ 행사 컨텐츠(제목+사진 목록+버튼)
→ 인물 프로필(타이틀+이미지+경력+SNS)
→ 행사 일정 표(시간1/일정1, 시간2/일정2)
→ 문의(제목+내용+담당자+버튼)
→ 설문(제목+내용+설문지)
→ 푸터(로고+SNS)
```

> '모양'과 '여백' 카드를 다수 사용 — 디자인 절제미와 화이트스페이스 강조. 가장 풍부한 구조(50개).
