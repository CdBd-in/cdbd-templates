## 페이지 구조

```
헤더(병원 전경+프로필) → 치과 소개+병원 영문명
→ 진료 일정 → 프로모션 갤러리 + 이벤트 상담 CTA
→ 인기 치료 3개(치아미백/교정/라미네이트) — 각 본문+유튜브
→ 치료 전/후 이미지 + 방문 상담 예약
→ 의료진 프로필 3명
→ 외국인 고객 안내 (서브타이틀+설명3개)
→ FAQ → 진료 비용 + 주의 문구
→ 위치 + SNS
```
