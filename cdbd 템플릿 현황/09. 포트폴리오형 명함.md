## 디자인 특성

- **전체 인상**: 따뜻함·친근함·퍼스널 브랜딩 — 살몬·피치 톤으로 포트폴리오 명함에 사람 냄새와 호감을 더한 인상
- **페이지 테마**: 배경 따뜻한 베이지 #F6E9DA / 텍스트 다크 브라운 / 버튼 코랄/살몬 #F08A6E
- **포인트 컬러**: 흰색 카드 (섹션 구분)
- **컬러 대비**: 중 — 베이지+코랄의 자연스러운 톤온톤
- **모서리 처리**: 둥근 — 모든 카드·버튼·이미지가 부드럽고 큰 라운드
- **카드 배경**: 흰색 카드 + 베이지 페이지 배경, 살몬 버튼 강조
- **텍스트 사이즈 대비**: 보통 — 이름과 직함이 명확, 본문은 단정
- **반복되는 디자인 요소**:
  - 인물 풀블리드 헤더 사진
  - 코랄 풀-와이드 라운드 버튼 반복
  - 일러스트 아이콘 박스(이메일/포트폴리오 등)
  - 둥근 카드 위 이모지/심볼 작은 마커
- **레이아웃 특징**: 인물 헤더 → 명함 정보 → 빠른 연락 버튼 → 폼 → 포트폴리오 갤러리 순의 퍼스널 브랜드 흐름, 따뜻하고 친밀한 톤이 일관됨
