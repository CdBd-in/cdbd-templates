## 디자인 특성

- **전체 인상**: 강한 마케팅·랜딩 페이지 톤 — 진한 네이비 배경 위에 노란 강조, 큰 헤딩으로 컨버전을 적극 유도하는 인포머셜 느낌
- **페이지 테마**: 배경 짙은 네이비 #0F1A3D / 텍스트 화이트 / 버튼 시안블루 #2DA8F0
- **포인트 컬러**: 형광 옐로우 #F6D547 (강조 단어 하이라이트)
- **컬러 대비**: 강 — 다크 네이비 + 노랑 + 흰색 조합이 매우 명료한 콘트라스트
- **모서리 처리**: 둥근 — 버튼/입력 필드가 큼직하게 라운드
- **카드 배경**: 전체 페이지가 단일 네이비 캔버스, 후기/카드 영역은 약간 더 밝은 다크블루로 분리
- **텍스트 사이즈 대비**: 큼 — 헤드라인이 매우 굵고 크며 본문과 위계 차이가 뚜렷
- **반복되는 디자인 요소**:
  - 형광 옐로우 형광펜 스타일 단어 강조
  - 폴더·플레이 버튼 같은 일러스트 아이콘 카드
  - 큰 굵은 헤딩 + 우측 정렬 보조 텍스트 조합
- **레이아웃 특징**: 단일 다크 캔버스 위에 카드 블록을 쌓아가며 세로 1열 길게 흐르는 구조, 섹션 구분은 색상/아이콘 차이로 분리
