## 디자인 특성

- **전체 인상**: 강한 마케팅·랜딩 페이지 톤 — 페일 그레이 배경 위에 진한 네이비 텍스트와 블루 3톤 카드 블록을 빽빽이 쌓아 컨버전 인포머셜 무드
- **페이지 테마**: 배경 페일 블루 그레이 #F2F4F6 / 텍스트 다크 네이비 #094067 / 버튼 미디엄 블루 #1860BF
- **포인트 컬러**: 라이트 블루/시안 #3DA9FC (보조 CTA), 다크 네이비 #094067 (헤더 리본·강조 박스 배경)
- **컬러 대비**: 강 — 페일 배경 + 진한 네이비 텍스트 + 비비드 블루 블록이 또렷한 위계 형성
- **모서리 처리**: 둥근 — 버튼/입력 필드/카드가 큼직하게 라운드
- **카드 배경**: 페일 그레이 페이지 배경 위에 흰 카드 + 다크 네이비/미디엄 블루/라이트 블루 풀-와이드 강조 블록이 교차 배치
- **텍스트 사이즈 대비**: 큼 — 헤드라인이 매우 굵고 크며 본문과 위계 차이가 뚜렷
- **반복되는 디자인 요소**:
  - 다크 네이비 / 미디엄 블루 / 라이트 블루 3톤 블루 시스템의 일관된 사용
  - 굵은 볼드 텍스트로 수치·키워드 강조 ("1,000회 강의", "500명")
  - 폴더·플레이 버튼 같은 일러스트 아이콘 카드
  - 큰 굵은 헤딩 + 우측 정렬 보조 텍스트 조합
- **레이아웃 특징**: 페일 그레이 배경 위에 블루 강조 블록을 빽빽하게 쌓아가며 세로 1열 길게 흐르는 구조, 섹션 구분은 블루 톤 차이와 아이콘 카드로 분리
