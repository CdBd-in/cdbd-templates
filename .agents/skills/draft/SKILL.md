# /draft — 프리셋 조합으로 시안 3안 만들기

> 설계 정본: `docs/superpowers/specs/2026-07-16-cdbd-draft-pipeline-design.md`
> 공통 규칙: `.Codex/cdbd-draft-shared.md` (**D1~D5가 모두 먼저 읽는다**)
> ⚠️ **테스트 단계** — 현재 [[1-1. 워크플로우]] 2단계(Codex.ai/design 생성)를 **대체하지 않는다.** 옆에서 돌려 검증 후 교체.

## 입력

| 항목 | 필수 | 기본값 |
|---|---|---|
| 기획 문서 경로 (또는 주제 + 세부 카테고리) | ✅ | — |
| 3안의 (레이아웃 스타일 × 무드) 3쌍 | ❌ | 스타일 3종 고정 + **무드는 주제에서 서로 다른 3개 자동 선정** |

- 세부 카테고리 → [[1-8. 섹션 프리셋 라이브러리]] 「🧩 조립 레시피」에서 **섹션 목적 순서**를 읽는다.
- 시나리오 테스트면 [[3-2. 16 시나리오 질문 응답 테스트 세트]]의 **답변만** 재료로 쓴다(카피만 AI).

## 파이프라인

```
D1 내용 ─ 1회 (3안 공통)
   ├─ 안1 미니멀   × 무드A : D2 조합 → D3 통일 → D4 무드
   ├─ 안2 에디토리얼 × 무드B : D2 → D3 → D4
   └─ 안3 볼드     × 무드C : D2 → D3 → D4
D5 검수 ─ 1회 (3안 전체 · 읽기 전용)
   └ 문제 → 담당(D2/D3/D4) 재실행 → D5 재검수 (최대 2회) → 초과 시 사용자 게이트
```

## 🚨 직렬 강제 (병렬 ❌)

**Figma는 한 번에 한 곳만 안전하게 쓸 수 있다.** `figma.currentPage`가 **파일 전역**이라 동시 실행하면 서로의 페이지 전환을 덮어써 **엉뚱한 페이지에 쓴다.**
→ 안1 완주 → 안2 → 안3. **D2~D4를 병렬로 띄우지 말 것.**

## 실행 순서

1. **레시피 확정** — 세부 카테고리 → 섹션 목적 순서. 재료 없는 섹션은 **생략**(D1 `missing[]`).
2. **D1** 1회 → 콘텐츠 팩. `brandAssets`·`scene`이 비면 **D4 팔레트 ①②가 죽으므로** 반드시 채운다.
3. **무드 3개 선정** — 주제에 맞는 무드 중 서로 다른 3개. **㉮배경 명도 라이트/다크 나눠 갖기 · ㉯액센트 hue 최소 2계열**.
4. **안1 → 안2 → 안3**: D2 → D3 → D4 (각 안 완주 후 다음)
5. **D5** 1회 → 라우팅 재실행(≤2) → 리포트

## 🔒 게이트

- **D5 `verified:false` = "미검증"** — "통과"로 보고하지 말 것. 재시도 2회 초과 시 **사용자 게이트**.
- **프리셋 원본 훼손 발견 시 즉시 중단** → 원복 후 재개.
- **D5 `crossDraft.needsHumanCall:true`** — 차별성 정량 판정은 미정이라 **사람이 눈으로** 본다. 근거만 제시.
