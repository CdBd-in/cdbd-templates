# 이미지

CdBd 템플릿 제작 시 예시 일러스트/아이콘이 필요한 경우의 소싱·관리 가이드.

> 실제 디자인 톤·색상 매칭은 [[01. 에디터 페이지 제작]], [[02. 색상 팔레트 라이브러리]] 참조.

## 📦 소스

**Thiings** — https://www.thiings.co/things

- 무료 3D 렌더 아이콘 라이브러리 (10,000+ AI 생성)
- 일관된 입체감·재질 표현 → 한 페이지 내에서 여러 개 써도 톤이 흐트러지지 않음
- 키워드 기반 검색 (`/things/{slug}` 구조)

## 🎯 선정 기준

| ✅ Do | ❌ Don't |
|---|---|
| 범용적이고 한눈에 알아보기 쉬운 아이콘 | 너무 구체적이거나 복잡한 아이콘 |
| 상징성 높은 보편적 모티프 | 특정 브랜드·인물·문화권에 종속된 모티프 |
| 1~2초 안에 의미 파악 가능 | 설명이 필요한 추상적 표현 |

**판단 기준**: "이 아이콘을 처음 본 사람도 의미를 즉시 이해할 수 있는가?"

## 💾 파일 관리 규칙

| 항목 | 규칙 |
|---|---|
| **저장 위치** | `~/Downloads/` (로컬 다운로드 폴더) |
| **볼트 내 저장** | ❌ 하지 않음 — 옵시디언 볼트를 가볍게 유지 |
| **파일명** | 검색에 사용한 영문 키워드 그대로 (예: `download.png`, `earth.png`) |
| **확장자** | `.png` (Thiings 기본 1024×1024 PNG, RGBA) |

## 🔍 워크플로우

1. **컨텍스트 분석** → 표현하려는 의미를 영문 키워드 1~2개로 압축
2. **다각도 후보 선정** → 같은 컨셉도 다른 상징으로 표현 가능한지 검토
3. **Thiings 검색** → `https://www.thiings.co/things/{slug}` 페이지에서 메인 이미지 확인
4. **다운로드** → `~/Downloads/{keyword}.png`로 저장
5. **비교·결정** → 컨텍스트 적합도 비교 후 채택

### 후보 제안 시 원칙

같은 섹션이라도 **여러 의미적 각도**에서 후보를 제시 — 사용자가 톤 결정 가능.

예) 환경단체 명함의 'Vision' 섹션 → 3가지 각도
- 보호 대상 = `earth` (환경 자체)
- 미래 지향 = `sprout` (성장·희망)
- 통찰 = `telescope` (비전의 직역)

## 📚 사용 사례 (누적)

| 키워드 | 활용 컨텍스트 | 인상 |
|---|---|---|
| `download` | PDF 다운로드 CTA 버튼 | 파일 + 초록 화살표 = "받기" 액션 직관적 |
| `earth` | 환경단체 Vision 섹션 후보 | 글로벌·보호 대상 |
| `sprout` | 환경단체 Vision 섹션 후보 | 성장·지속가능성 |
| `telescope` | 환경단체 Vision 섹션 후보 | 진취적·미래 조망 |

> 새로운 아이콘을 다운받을 때마다 이 표에 추가.

## 🛠 기술 메모 (자동화용)

Thiings 페이지의 메인 이미지는 `<meta property="og:image">`에서 추출 가능.

```bash
# slug에서 메인 이미지 URL 추출
slug="earth"
url=$(curl -sL "https://www.thiings.co/things/$slug" \
  -H "User-Agent: Mozilla/5.0" \
  | grep -oE '<meta property="og:image" content="[^"]*"' \
  | head -1 | sed 's/.*content="//;s/"$//')

# 다운로드
curl -sfL "$url" -o "$HOME/Downloads/${slug}.png"
```
