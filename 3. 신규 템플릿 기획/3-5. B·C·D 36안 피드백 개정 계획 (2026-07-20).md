## 2. 🔤 폰트 감사 — 전 48안 (최우선 · R1)

> D4가 CdBd 목록 밖 폰트를 다수 채택. **전 시안 폰트를 [[../1. 작업 가이드/1-4. 폰트]] 44종과 대조**해 밖이면 동급 CdBd 폰트로 교체.

- **교체 필요(CdBd 없음)**: IBM Plex Sans KR → Pretendard/본고딕 · Black Han Sans → 검은 계열 CdBd(확인) · Space Grotesk → Montserrat/Poppins · Gothic A1 → 본고딕/Pretendard · Fredoka·Jua → 펀 무드 CdBd 확인 · Syne → CdBd 비비드 확인 · Cormorant → EB Garamond · 제주명조 → 조선일보명조/본명조 · Unbounded → CdBd 확인
- **사용 OK지만 무드 부적합**: 파셜산스 = CdBd에 있으나 **플레이풀 전용** → B③(프로) 등에서 제거
- ⚠️ **각 안 D4 보고의 `fonts` 필드를 전수 확인** 후 목록 밖만 교체. (교체는 색·간격 안 건드리고 폰트만)
