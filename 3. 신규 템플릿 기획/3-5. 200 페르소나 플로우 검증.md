# 200 페르소나 플로우 검증 (2026-09-04)

> **무엇을 했나** — 지금 기획된 **AI 페이지 빌더 7단계 플로우**(자료 입력 → 목적 질문 → 추가 정보 → 원/멀티 → 시안 3안 → 프롬프팅 → 에디터)를 **비즈니스용 페이지를 만들려는 가상 사용자 200명**에게 대입해 결과물이 얼마나 쓸 만한지 점수를 매겼다.
> **왜** — 25칸 체계와 조립 레시피가 **문서 위에서는 깔끔한데 실제 사람들에게 통하는지** 확인이 없었다.

---

## 0. 결론 3줄

1. **전체 평균 16.45 / 25점 (65.8%)** — "만들어지긴 하는데 그대로 장사에 쓰기엔 손이 더 간다" 구간.
2. 🔴 **점수를 가르는 건 업종이 아니라 사람이다.** 업종군 간 차이는 15.6~17.2로 **1.6점**뿐인데, **숙련도 상↔하는 5.8점**, **자료 풍부↔빈약은 5.9점** 차이가 난다.
3. 🚨 **숙련도가 낮거나 자료가 빈약한 사람은 200명 중 단 한 명도 20점을 넘지 못했다.** (해당 인원 **93명 = 47%**)

## 1. 평가 방법

### 페르소나 200명
5개 업종군 × 40명. 연령·숙련도·목적 명확성·자료 상세도를 의도적으로 분산.

| 업종군 | 예시 |

| **A 요식·리테일·생활서비스** | 카페·식당·미용실·헬스장·세탁소·수리·청소·펜션 |
| **B 전문서비스·B2B·의료** | 세무·법무·병원·한의원·중개·제조·도매·물류·대행사 |
| **C 교육·창작·프리랜서** | 학원·공방·강사·사진·디자인·작가·음악·개발 |

|---|---|

## 5. 칸 배정이 흔들리는 짝 — 전 업종군 취합

> 🔑 **원인 1위(목적 2~3개)와 붙어 있는 구조 문제.** 유저가 갈릴 뿐 아니라 **AI도 갈린다.**

| 헷갈리는 짝 | 전형 사례 |
|---|---|
| **1-④ 예약 ↔ 5-② 모집** | 원데이 클래스(=예약) vs 정규반 기수(=모집). 유저 어휘는 둘 다 「클래스 신청」 |
| **4-① 상세 ↔ 4-③ 카탈로그 ↔ 4-④ 판매** | "상품이 3개면 어디?" · 셀러는 「상세페이지」를 판매 페이지의 동의어로 씀 |
| **3-② 메뉴 ↔ 4-③ 카탈로그** | 원두 라인업 = 메뉴판이자 상품 목록 — **대분류를 넘는 충돌** |
| **2-② 명함 ↔ 2-④ 이력서 ↔ 2-③ 포트폴리오** | "나를 판다"는 목적이 같고 ★만 다름 — 유저는 그 차이를 인지 못함 |
| **2-③ 포트폴리오 ↔ 6-③ 도록** | 일러스트·조각·회화. 둘 다 이미지+캡션 나열 |
| **3-① 소개 홈 ↔ 나머지 전부** | 종합형이 하나뿐이라 "홈페이지 만들래"가 전부 여기로 (B군만 40명 중 10명) |
| **4-⑤ 사전예약 ↔ 4-⑥ 프로모션** | 둘 다 "곧 시작합니다"가 히어로 |

## 6. 개선 우선순위 — 효과(인원) × 난이도

### 🥇 1순위 — 지금 구조를 안 깨고 인원을 가장 많이 살리는 것

**① 목적 질문에 「함께 담을 것」 복수 선택 + 「바꾸기」 상시 노출** — *영향 ~87명*
- 목적 질문은 **단일 선택 그대로** 두고, 아래에 **칩 2~3개 복수 선택**: `가격표도` `예약 버튼도` `신청 폼도` `오시는 길도` `후원·계좌도` `자료 받기도`
- 선택된 칩은 **결정 블록이 아니라 보조 블록**으로 삽입 → **25칸 분류 체계를 안 건드린다**
- 칩 3개 이상이면 5단계에서 **멀티페이지를 기본 추천**
- 4·5·6단계 상단에 **"이 페이지는 〈○○〉용으로 만들고 있어요 · 바꾸기"** 칩 상시 노출 → 되돌리기

**② 사실 정보는 지어내지 말고 「빈칸 + 확인 필요」로** — *영향 ~80명 · 규제 15명은 리스크 방지*
- **AI가 채우는 것** = 소개 문장·분위기 카피 (지금대로)
- **AI가 절대 안 채우는 것** = 가격·요금·마감일·정원·자격 요건·환불 규정·효능·수익률 → **빈칸 유지 + `[확인 필요]` 뱃지**
- 발행 직전 1회 **"확인 안 된 항목 N개"** 경고
- 가격 미입력 시 폴백은 **가짜 금액이 아니라 「가격 문의」 배지 + 문의 버튼**
- 🚨 지어낸 금액·효능은 이 업종군들에서 **곧바로 클레임·규제 위반**이 된다

**③ 「짧은 길」 모드 — 자료 없고 서툰 사람용** — *영향 ~62명(완주 실패) · 하·빈약 49명 직격*
- 1단계에서 **자료가 사진 3장 이하이거나 목적이 "전화 오게 하고 싶다"류**면 4~6단계를 건너뛰고 **`2-②` 명함 레시피 1안을 바로 완성해 보여준다**(수정은 에디터에서)
- 열쇠·방충망·세탁소·수선집처럼 **요구가 3분짜리인데 절차 길이에 다치는** 사람들을 그대로 구제
- 지금은 **요구가 가장 단순한 사람이 가장 크게 이탈한다**

### 🥈 2순위 — 카드/프리셋 추가로 해결

**④ 「항목표」 프리셋 3종** — *영향 ~49명* — ⓐ 라벨↔값 N행 요금표(그룹 헤더 포함) ⓑ 요일 7행 시간표 ⓒ 접히는 카테고리 그룹. **엑셀 업로드를 3-②·6-④·1-④에서도 기본 경로로 노출**(현재는 상품 칸에서만).
**⑤ 「주문서」 폼 프리셋** — *영향 ~43명* — 상품 선택·옵션·수량·수령 방법·입금자명·동의 + 계좌 카드 자동 동봉 + **응답 엑셀 다운로드**. 결제는 여전히 외부지만 **주문서까지는 안에서 끝난다**.
**⑥ 「자료 목록」 카드** — *영향 ~25명* — 파일 업로드가 부담이면 **제목·설명·외부 링크 반복 카드**만이라도.
**⑦ 폼 응답 알림(문자·카톡·메일)** — *영향 ~30명* — 카드가 아니라 설정 1줄.

### 🥉 3순위 — 판별 질문 정교화

**⑧ 4번 대분류 진입 시 판별 3문항** (E군 제안 · 전부 탭 1회)
1. "소개할 상품이 몇 개인가요?" → 1개=①/④ · 2~5개=①반복or③ · 6개+=③(엑셀 유도)
2. "지금 바로 살 수 있나요?" → 아직=**4-⑤** · 기간 한정 할인=**4-⑥** · 평소 판매=①③④
3. 🥇 **"이 페이지를 본 사람이 마지막에 무엇을 하길 바라나요?"** → 구매 버튼=**4-④** · 자세히 이해=**4-①** · 분위기를 느낌=**4-②** · 원하는 품목을 찾음=**4-③**

**⑨ 클래스 계열 갈림 1문항** — *"신청하는 분이 ⓐ날짜·시간을 골라 오나요 / ⓑ한 기수를 통째로 등록하나요?"* → ⓐ=`1-④` ⓑ=`5-②`
**⑩ 3-① 쏠림 완화 후속 1문항** — *"보는 사람이 누구인가요? (거래처 / 일반 고객 / 구직자 / 투자·심사)"*

### 그 외 (업종군 특화)
- **「공공·기관」 무드 프리셋** (D군) — 현 무드 9종이 전부 상업 톤이라 공고문에 못 씀
- **규제 업종 분기** (B군) — 필수 표기 필드 권장 강제 + 자동생성 금지 구역 + 발행 전 심의 경고
- **큰글씨 토글** (D군) — 노인복지관·박물관·배리어프리 행사
- **작품 이미지에서 색 추출 → 3안 중 1안 무드** (C군) — 창작자는 개성이 상품
- **측정 팩** (E군) — GA4·픽셀 **ID 입력칸만**(코드 카드 정책 위반 없이) + 카피만 다른 B안 복제 발행

## 7. 이 검증이 확인해 준 것 / 뒤집은 것

| | 내용 |
|---|---|
| ✅ **확인** | **25칸 자체는 거의 안 틀린다** — 200명 중 "대응 칸 없음"은 개인 창작 발표(시인·소설가) 정도. 신설이 필요한 칸은 사실상 없다 |
| ✅ **확인** | **레시피 3층 모델도 버틴다** — D2 감점은 「레시피가 틀렸다」가 아니라 「**CdBd에 카드가 없다**」가 원인 |
| 🔴 **뒤집음** | **분류를 더 정교하게 하는 것은 지금 우선순위가 아니다.** 업종군 폭 1.6점 vs 숙련도 폭 5.8점. `5-②↔5-⑤` 합칠지, 3번을 확장할지보다 **①목적 복수 선택 ②사실 정보 빈칸 ③짧은 길**이 훨씬 크다 |
| 🔴 **뒤집음** | **「전 문항 선택 · 빈칸은 AI가 채움」이 저숙련층에게는 함정으로 작동한다** — 통째로 건너뛰고 껍데기가 발행된다. *선택제는 유지하되 **채우는 것과 안 채우는 것을 나눠야** 한다* |
