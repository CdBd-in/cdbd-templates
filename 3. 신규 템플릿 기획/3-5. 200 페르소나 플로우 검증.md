# 200 페르소나 플로우 검증 (2026-09-04)

> **무엇을 했나** — 지금 기획된 **AI 페이지 빌더 7단계 플로우**(자료 입력 → 목적 질문 → 추가 정보 → 원/멀티 → 시안 3안 → 프롬프팅 → 에디터)를 **비즈니스용 페이지를 만들려는 가상 사용자 200명**에게 대입해 결과물이 얼마나 쓸 만한지 점수를 매겼다.
> **왜** — 25칸 체계와 조립 레시피가 **문서 위에서는 깔끔한데 실제 사람들에게 통하는지** 확인이 없었다.

---

## 0. 결론 3줄

1. **전체 평균 16.45 / 25점 (65.8%)** — "만들어지긴 하는데 그대로 장사에 쓰기엔 손이 더 간다" 구간.
2. 🔴 **점수를 가르는 건 업종이 아니라 사람이다.** 업종군 간 차이는 15.6~17.2로 **1.6점**뿐인데, **숙련도 상↔하는 5.8점**, **자료 풍부↔빈약은 5.9점** 차이가 난다.
3. 🚨 **숙련도가 낮거나 자료가 빈약한 사람은 200명 중 단 한 명도 20점을 넘지 못했다.** (해당 인원 **93명 = 47%**)

## 1. 평가 방법

### 페르소나 200명
5개 업종군 × 40명. 연령·숙련도·목적 명확성·자료 상세도를 의도적으로 분산.

| 업종군 | 예시 |
|---|---|
| **A 요식·리테일·생활서비스** | 카페·식당·미용실·헬스장·세탁소·수리·청소·펜션 |
| **B 전문서비스·B2B·의료** | 세무·법무·병원·한의원·중개·제조·도매·물류·대행사 |
| **C 교육·창작·프리랜서** | 학원·공방·강사·사진·디자인·작가·음악·개발 |
| **D 기관·단체·비영리** | 교회·복지관·NGO·학교·조합·도서관·미술관·지자체 |
| **E 온라인셀러·브랜드·스타트업** | 스토어 셀러·D2C 브랜드·팝업·마케터·창업자 |

### 채점 5축 (각 0~5점 · 합 25점)
| 축 | 묻는 것 |
|---|---|
| **D1 분류 적중** | 1~3단계로 **맞는 칸**에 도달하나 |

## 5. 칸 배정이 흔들리는 짝 — 전 업종군 취합

> 🔑 **원인 1위(목적 2~3개)와 붙어 있는 구조 문제.** 유저가 갈릴 뿐 아니라 **AI도 갈린다.**

| 헷갈리는 짝 | 전형 사례 |
|---|---|
| **1-④ 예약 ↔ 5-② 모집** | 원데이 클래스(=예약) vs 정규반 기수(=모집). 유저 어휘는 둘 다 「클래스 신청」 |
| **4-① 상세 ↔ 4-③ 카탈로그 ↔ 4-④ 판매** | "상품이 3개면 어디?" · 셀러는 「상세페이지」를 판매 페이지의 동의어로 씀 |
| **3-② 메뉴 ↔ 4-③ 카탈로그** | 원두 라인업 = 메뉴판이자 상품 목록 — **대분류를 넘는 충돌** |
| **2-② 명함 ↔ 2-④ 이력서 ↔ 2-③ 포트폴리오** | "나를 판다"는 목적이 같고 ★만 다름 — 유저는 그 차이를 인지 못함 |
| **2-③ 포트폴리오 ↔ 6-③ 도록** | 일러스트·조각·회화. 둘 다 이미지+캡션 나열 |
| **3-① 소개 홈 ↔ 나머지 전부** | 종합형이 하나뿐이라 "홈페이지 만들래"가 전부 여기로 (B군만 40명 중 10명) |
| **4-⑤ 사전예약 ↔ 4-⑥ 프로모션** | 둘 다 "곧 시작합니다"가 히어로 |

## 6. 개선 우선순위 — **이선호 검토 반영판 (2026-09-04 rev.2)**

> 🔄 **1차안 3개 중 2개가 뒤집혔다.** 세 항목이 결국 **원칙 하나**로 수렴한다 —
> 🔑 **「고르게 하지 말고, 정해서 보여주고 바꿀 수 있게」** ([[../1. 작업 가이드/1-9. AI 유저 플로우]] 핵심 원칙 7 신설)
> 저숙련층이 이탈하는 건 **「단계가 많아서」가 아니라 「매 단계가 결정을 요구해서」**다. 답은 **단계를 빼는 게 아니라 결정을 확인으로 바꾸는 것**.

| | 1차안 | rev.2 |
|---|---|---|
| **①** | 함께 담을 것을 **고르게** | ✏️ **미리 켜서 보여주고 근거 한 줄** ＋상시 `바꾸기` |
| **②** | 사실 정보 **빈칸 유지** | 🗑 **철회** → **「빈 자리 처리 규칙」**으로 대체 |
| **③** | 4~6단계 **건너뛰기** | 🗑 **철회** → **③ 단계 필수 + 답하는 방식 개선** · **④는 통보형** |

### 🥇 ① 「함께 담을 것」 칩 — 미리 켜서 보여준다 *(영향 ~87명)*

```
✅ 이 페이지로 가장 하고 싶은 일
   ▸ 메뉴와 가격을 보여주고 싶어요

＋ 이런 것도 같이 넣어드릴게요
   ☑ 오시는 길        └ 올리신 자료에 주소가 있어서요
   ☑ 영업시간·휴무     └ 영업시간이 적혀 있어서요
   ☐ 예약 버튼
```

- 🔴 **1차안(빈 체크박스)이 틀린 이유** — 내가 없애려던 **판단 피로를 하나 더 만드는 꼴**이었다(이선호 지적).
- ✅ **AI가 자료 근거로 미리 켜고 「왜 켰는지」 한 줄** → 저숙련층은 그냥 넘어가고, 아는 사람만 끈다.
- ✅ **근거가 없으면 안 켠다** → **기획이 빈약한 유저는 칩이 적게 떠서 부담이 자동으로 줄어든다.**
- ✅ **칩은 보조 블록으로만** → 25칸 분류 체계를 안 건드린다. **최대 3개 · 3개 이상이면 멀티 가중.**

### 🥇 ② 「사실 정보 빈칸 유지」는 **철회** → 「빈 자리 처리 규칙」으로 *(영향 ~80명)*

> 🗑 **철회 근거 (이선호)** — *"AI 생성 내용은 플레이스홀더고, 직접 채우지 않은 내용은 에디터로 넘어가면서 삭제된다."* → **가짜 가격이 발행될 위험은 없다.** 1차안의 전제가 틀렸다.
> ➕ **입력칸의 예시는 오히려 필요하다** — 없으면 뭘 써야 할지 모른다.

**그래서 문제의 성격이 바뀐다**

| | 1차안이 걱정한 것 | 실제 문제 |
|---|---|---|
| 증상 | 가짜 가격이 그대로 발행 | 🔴 **구멍 난 페이지가 발행** |
| 예 | "아메리카노 4,500원" | 「메뉴」 제목만 남고 **품목이 통째로 사라짐** |

**빈 자리 처리 규칙** (풀버전 = [[../1. 작업 가이드/1-12. 조립 레시피 (제안 초안)]] §1)

| 무엇이 비었나 | 처리 |
|---|---|
| 값만 빔 (가격·요금·기간) | **「가격 문의」·「일정 문의」 + 문의 버튼**으로 대체 |
| 반복 항목이 전부 빔 | **섹션째 제거** — 제목만 남는 게 최악 |
| 보조 블록이 빔 | **섹션째 제거** |
| ★ 결정 블록·히어로가 빔 | **제거 불가** → 그 문항은 다시 묻는다 |

🔑 **핵심 = 「아직 안 채움」과 「원래 없음」을 구분한다** → ③의 **「이건 없어요」 버튼**.

---

### 🥇 ③ 「단계 건너뛰기」는 **철회** → ③ 필수화 + 답하는 방식 개선 · ④ 통보형 *(영향 ~62명)*

> 🗑 **철회 근거 (이선호)** — ⓐ **④(원/멀티)를 건너뛰면** 시안을 다 만든 뒤 유형을 바꾸게 되어 **토큰·시간 낭비가 더 크다.** ⓑ **③(추가 정보)은 기획이 빈약할수록 오히려 필수** — 안 그러면 **껍데기만 그럴듯한 페이지**가 나온다.
> ✅ **문제는 「길이」가 아니라 「무게」였다.**

**③ 추가 정보 — 단계는 필수, 문항은 여전히 선택. 답하는 방식을 바꾼다**

| 지금 | 바꿀 것 |
|---|---|
| 긴 폼 한 화면에 8~11문항 | **한 번에 한 질문** (모바일 스와이프) |
| 빈칸에 타이핑 | **자료에서 뽑아 미리 채워두고 "맞나요?" 확인** — 쓰기보다 고치기가 쉽다 |
| 건너뛰기 = 아무것도 안 누르고 넘김 | 🆕 **「이건 없어요」 버튼** — 누르면 AI가 **그 섹션을 아예 뺀다** |
| 전부 같은 무게 | **핵심 3~5개만 앞에**, 나머지는 접어두기 |
| 타이핑만 | **말로 답하기 · 사진 찍어 올리기** *(60대 이상엔 타이핑이 벽)* |

**④ 페이지 유형 — 「고르세요」 → 「만들어 드릴게요」**

```
❌ 어떤 유형으로 만들까요?   [원페이지]  [멀티페이지]
✅ 한 장짜리 페이지로 만들어 드릴게요          [여러 장으로 바꾸기]
     └ 내용이 한 화면에 담기는 분량이라서요
```
- 🔴 **옛 규칙 「원/멀티 두 안을 만들어 나란히 보여준다」 폐기** — 안을 두 벌 만드는 것 자체가 낭비.
- **AI가 정하는 3요인** = 분량(1차 관문) · 패턴(이탈 비용 ±) · 칸(묶음 분리 ±). ＋칩 3개 이상이면 멀티 가중.
- 📄 반영: [[../1. 작업 가이드/1-9. AI 유저 플로우]] 원칙 4 개정 · 원칙 7 신설 · 7단계 표 · 플로우차트 · 단계별 상세 ③④

---

### 🥈 2순위 — 카드/프리셋 추가로 해결 *(1차안 유지)*

**④ 「항목표」 프리셋 3종** — *~49명* — ⓐ 라벨↔값 N행 요금표(그룹 헤더) ⓑ 요일 7행 시간표 ⓒ 접히는 카테고리 그룹. **엑셀 업로드를 `3-②`·`6-④`·`1-④`에서도 기본 경로로** 노출.
**⑤ 「주문서」 폼 프리셋** — *~43명* — 상품 선택·옵션·수량·수령 방법·입금자명·동의 + 계좌 카드 + **응답 엑셀 다운로드**. 결제는 외부지만 **주문서까지는 안에서 끝난다**.
**⑥ 「자료 목록」 카드** — *~25명* — 파일 업로드가 부담이면 **제목·설명·외부 링크 반복 카드**만이라도.
**⑦ 폼 응답 알림(문자·카톡·메일)** — *~30명* — 카드가 아니라 설정 1줄.

### 🥉 3순위 — 판별 질문 정교화 *(1차안 유지)*

**⑧ 4번 대분류 진입 시 판별 3문항** (전부 탭 1회)
1. "소개할 상품이 몇 개인가요?" → 1개=①/④ · 2~5개=①반복or③ · 6개+=③(엑셀 유도)
2. "지금 바로 살 수 있나요?" → 아직=`4-⑤` · 기간 한정 할인=`4-⑥` · 평소 판매=①③④
3. 🥇 **"이 페이지를 본 사람이 마지막에 무엇을 하길 바라나요?"** → 구매 버튼=`4-④` · 자세히 이해=`4-①` · 분위기를 느낌=`4-②` · 원하는 품목을 찾음=`4-③`

**⑨ 클래스 계열 갈림 1문항** — *"신청하는 분이 ⓐ날짜·시간을 골라 오나요 / ⓑ한 기수를 통째로 등록하나요?"* → ⓐ=`1-④` ⓑ=`5-②`
**⑩ `3-①` 쏠림 완화 후속 1문항** — *"보는 사람이 누구인가요? (거래처 / 일반 고객 / 구직자 / 투자·심사)"*

### 그 외 (업종군 특화)
- **「공공·기관」 무드 프리셋** (D군) — 현 무드 9종이 전부 상업 톤이라 공고문에 못 씀
- **규제 업종 분기** (B군) — 필수 표기 필드 권장 강제 + 발행 전 심의 경고 *(자동생성 금지는 플레이스홀더 삭제로 상당 부분 해소)*
- **큰글씨 토글** (D군) · **작품 이미지에서 색 추출 → 3안 중 1안 무드** (C군) · **측정 팩**(GA4·픽셀 **ID 입력칸만**) (E군)

## 7. 이 검증이 확인해 준 것 / 뒤집은 것

| | 내용 |
|---|---|
| ✅ **확인** | **25칸 자체는 거의 안 틀린다** — 200명 중 "대응 칸 없음"은 개인 창작 발표(시인·소설가) 정도. 신설이 필요한 칸은 사실상 없다 |
| ✅ **확인** | **레시피 3층 모델도 버틴다** — D2 감점은 「레시피가 틀렸다」가 아니라 「**CdBd에 카드가 없다**」가 원인 |

| 🔴 **뒤집음** | **「전 문항 선택 · 빈칸은 AI가 채움」이 저숙련층에게는 함정으로 작동한다** — 통째로 건너뛰고 껍데기가 발행된다. → **③ 단계 자체를 필수화**하고, **「이건 없어요」로 「원래 없음」을 명시**하게 한다 (2026-09-04 이선호 확정) |
| 🔴 **뒤집음** | **「보여주기」에도 비용이 든다** — 원칙 4(*판단 어려운 건 보여준다*)를 그대로 밀어 ④에서 원/멀티 두 안을 만들던 규칙은 **토큰·시간 낭비**. **어차피 만들 것이면 보여주고(⑤ 3안), 비교용으로 더 만들어야 하면 정해서 통보한다(④)** |
