## ⭐ 「지도 보기」 버튼 링크 — ✅ 검증 완료

버튼 카드 → 링크 유형 `URL`에 붙여넣기:

```
https://www.google.com/maps/search/?api=1&query=35.651527%2C139.737037&query_place_id=ChIJ6QCZVaGLGGAR7AIdYzIcx2M
```

✅ 열면 **「재일본대한민국민단중앙본부」 장소 카드가 바로** 뜬다(사진·전화·영업시간·경로 버튼 포함).

### 길찾기 링크는 비추천
초청장은 **행사 전에, 대부분 한국에서** 열어본다 → 길찾기 링크는 서울→도쿄 경로를 계산하려다 무의미해진다.
위 장소 링크 안에 **「경로」 버튼이 이미 있으므로** 당일 현지에서 한 번 더 누르면 된다.

## 🅰 코드 카드 테스트 1 — 가장 단순한 형태 (먼저 이것부터)

**목적**: CdBd 코드 카드가 iframe을 아예 허용하는지만 확인. 디자인 무시.

```html
<iframe
  src="https://maps.google.com/maps?q=35.651527,139.737037&hl=ko&z=16&output=embed"
  width="100%"
  height="220"
  style="border:0;"
  allowfullscreen>
</iframe>
```

- **지도 보이면** → 테스트 2로
- **빈칸이면** → 코드 카드가 iframe 차단. 중단하고 「지도 이미지 + 구글맵 버튼」으로 확정

## 🅱 코드 카드 테스트 2 — 시안 디자인에 맞춘 형태

테스트 1 성공 시에만. 둥근 모서리 + 가로 3:2 = 현재 시안과 동일.

```html
<div style="position:relative;width:100%;padding-bottom:66.67%;border-radius:16px;overflow:hidden;">
  <iframe
    src="https://maps.google.com/maps?q=35.651527,139.737037&hl=ko&z=16&output=embed"
    style="position:absolute;top:0;left:0;width:100%;height:100%;border:0;"
    loading="lazy"
    referrerpolicy="no-referrer-when-downgrade"
    allowfullscreen>
  </iframe>
</div>
```

- 지도는 뜨는데 **모서리가 각지면** → 코드 카드가 `style`을 지우는 것. 테스트 1 형태로 쓰고 모서리는 포기.

## ✅ 테스트 순서

1. 코드 카드 추가 → **테스트 1** 붙여넣기
2. **에디터 미리보기에서 안 보여도 실패로 단정하지 말 것** — **발행(URL 생성) 후 실제 페이지를 휴대폰에서** 확인
3. 뜨면 → 테스트 2로 교체
4. 안 뜨면 → 지도 이미지 + 버튼 방식 (시안은 이미 그렇게 되어 있음)

> 💡 **먼저 확인된 사실** — `output=embed` 주소는 **iframe 안에서만** 열린다. 주소창에 직접 넣으면
> `"The Google Maps Embed API must be used in an iframe."` 만 뜬다. **정상이며 실패가 아니다.**
> 남은 변수는 하나 — **CdBd 코드 카드가 iframe을 허용하느냐.**

> 결과가 나오면 위 표를 채우고 **코드 카드 사용 가능 여부**를
> [[../1. 작업 가이드/1-6-2. CdBd 카드 기능]] 「코드 (0/554) — 🚫 정책상 미사용」에 반영할 것.
> 현재 정책의 근거는 *활용 어려움*이었고 **iframe 렌더 가능 여부는 검증된 적이 없다.**
