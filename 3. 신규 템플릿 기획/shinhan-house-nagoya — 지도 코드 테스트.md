# 구글맵 임베드 — 코드 카드 테스트용

> CdBd **코드 카드**에 붙여넣어 구글맵이 실제로 뜨는지 확인하는 코드.
> 사용처: [[shinhan-house-nagoya — 기획]] 행사장 위치 섹션 (네이버 지도 기반 「위치 안내」 카드가 일본 주소를 못 잡아서 대체 검토 중)

## 행사장 주소 (확정)

```
〒453-0012
愛知県名古屋市中村区井深町16-17 愛知韓国人会館 1F
아이치현 나고야시 나카무라구 이부카초 16-17 아이치한국인회관 1F
```

> 💡 **장소 정식 명칭 단서** — 이 주소의 건물이 **愛知韓国人会館(아이치한국인회관)**. 「재일본대한민국민단 아이치현지방본부」가 이 건물에 있다. 초청장 표기를 확정할 때 참고.

---

## 🅰 테스트 1 — 가장 단순한 형태 (먼저 이것부터)

**목적**: 코드 카드가 iframe을 아예 허용하는지부터 확인. 디자인은 신경 쓰지 않음.

```html
<iframe
  src="https://maps.google.com/maps?q=%E6%84%9B%E7%9F%A5%E9%9F%93%E5%9B%BD%E4%BA%BA%E4%BC%9A%E9%A4%A8&hl=ja&z=17&output=embed"
  width="100%"
  height="220"
  style="border:0;"
  allowfullscreen>
</iframe>
```

- **지도가 보이면** → iframe 허용됨. 테스트 2로.
- **빈칸이거나 아무것도 안 뜨면** → 코드 카드가 iframe을 막는 것. 여기서 중단하고 이미지+버튼 방식으로 전환.

---

## 🅱 테스트 2 — 시안 디자인에 맞춘 형태

**목적**: 테스트 1이 성공했을 때, 지금 시안(둥근 모서리 · 가로 3:2 비율)과 똑같이 보이게.

```html
<div style="position:relative;width:100%;padding-bottom:66.67%;border-radius:16px;overflow:hidden;">
  <iframe
    src="https://maps.google.com/maps?q=%E6%84%9B%E7%9F%A5%E7%9C%8C%E5%90%8D%E5%8F%A4%E5%B1%8B%E5%B8%82%E4%B8%AD%E6%9D%91%E5%8C%BA%E4%BA%95%E6%B7%B1%E7%94%BA16-17%20%E6%84%9B%E7%9F%A5%E9%9F%93%E5%9B%BD%E4%BA%BA%E4%BC%9A%E9%A4%A8&hl=ja&z=17&output=embed"
    style="position:absolute;top:0;left:0;width:100%;height:100%;border:0;"
    loading="lazy"
    referrerpolicy="no-referrer-when-downgrade"
    allowfullscreen>
  </iframe>
</div>
```

- **지도는 뜨는데 모서리가 각지거나 비율이 이상하면** → 코드 카드가 `style` 속성을 지우는 것. 테스트 1 형태로 쓰고 모서리는 포기.

---

## 🔗 「지도 보기」 버튼 링크 (코드 테스트와 무관하게 필요)

코드 카드가 되든 안 되든, **버튼은 구글맵으로 연결**해야 합니다. 버튼 카드 → 링크 유형 `URL`에 붙여넣기:

**① 위치 보기**
```
https://www.google.com/maps/search/?api=1&query=%E6%84%9B%E7%9F%A5%E7%9C%8C%E5%90%8D%E5%8F%A4%E5%B1%8B%E5%B8%82%E4%B8%AD%E6%9D%91%E5%8C%BA%E4%BA%95%E6%B7%B1%E7%94%BA16-17%20%E6%84%9B%E7%9F%A5%E9%9F%93%E5%9B%BD%E4%BA%BA%E4%BC%9A%E9%A4%A8
```

**② 길찾기 (현재 위치 → 행사장)** — 참석자에겐 이쪽이 더 유용
```
https://www.google.com/maps/dir/?api=1&destination=%E6%84%9B%E7%9F%A5%E7%9C%8C%E5%90%8D%E5%8F%A4%E5%B1%8B%E5%B8%82%E4%B8%AD%E6%9D%91%E5%8C%BA%E4%BA%95%E6%B7%B1%E7%94%BA16-17%20%E6%84%9B%E7%9F%A5%E9%9F%93%E5%9B%BD%E4%BA%BA%E4%BC%9A%E9%A4%A8
```

> 두 링크 모두 **휴대폰에서 누르면 구글맵 앱이 바로 열립니다.**

---

## ✅ 확인 순서

1. 코드 카드 추가 → **테스트 1** 붙여넣기
2. **에디터 미리보기에서 안 보여도 바로 판단하지 말 것** — 미리보기에서는 외부 콘텐츠가 막히는 경우가 있음. **발행(URL 생성) 후 실제 페이지를 휴대폰에서** 열어 확인
3. 뜨면 → **테스트 2**로 교체해 디자인 확인
4. 안 뜨면 → 이미지 + 버튼 방식으로 전환
