## 🧩 레시피 대조 — 「초대·예약 ④ 예약·방문 신청」

[[1-8. 섹션 프리셋 라이브러리]]의 원페이지 스택과 이번 답변을 1:1로 맞춰봤다.

| 레시피 섹션 | 채울 재료 | 상태 |
|---|---|---|
| `[헤더/배너: 로고]` | 코어앤코어 로고 (A5) | ✅ |
| `[히어로]` | 카피 = AI 작성 · 이미지 = 생성 | ✅ *(카피는 AI 몫)* |
| `[소개·스토리: 서비스 소개]` | AI 작성 | ✅ *(카피는 AI 몫)* |
| `[핵심정보: 운영시간·가격]` | **운영시간 ⚠️ · 가격 ⚠️** | 🔴 **재료 없음** |
| `[예약: 예약 카드]` ← 핵심 | 회차(A④-1) · 정원(A④-2) | ✅ |
| `[안내 사항: 예약 유의]` | A④-3 | ✅ |

| `[문의]` | 02-461-7788 (A6) | ✅ |
| `[푸터]` | **SNS ⚠️** | 🟠 **재료 없음** |

### 🔴 못 채운 섹션 = `핵심정보 (운영시간·가격)`

**두 항목 다 「사실」이라 AI가 지어낼 수 없다.**

| 없는 정보 | 왜 문제인가 |
|---|---|
| **가격** (체험 수업 요금) | 예약 페이지에서 **가장 먼저 궁금한 정보**. 없으면 예약 전환이 막힌다. 「무료 체험」인지 「3만 원」인지 AI가 정할 수 없다. |
| **운영시간** | `A④-1 예약 일시 옵션`(평일 10/14/19시, 토 11시)이 **예약 가능 회차**일 뿐, 매장 운영시간은 아니다. 둘은 다르다. |

> 🔎 **A2 「일시」가 여기서 헛돈다.** 예약 페이지의 A2는 「상시 운영 (예약제)」처럼 **날짜가 아닌 문장**이 들어온다. 초대장(①②③)에선 `2026년 8월 22일 19:00` 같은 실제 일시인데, ④에선 의미가 완전히 다르다.

### 🟠 못 채운 섹션 = `푸터 (SNS)`

`추가 채널`을 묻는 건 **B 프로필·명함뿐.** A 대분류엔 없다. SNS 주소는 **URL = 사실**이라 AI가 못 지어낸다.
→ 이미 [[3-2. 16 시나리오 질문 응답 테스트 세트]] 검증 대상 2번으로 잡아둔 항목. **A④에서 실증됨.**
