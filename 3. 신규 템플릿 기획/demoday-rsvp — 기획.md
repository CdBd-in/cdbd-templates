## 🧩 레시피 대조 — 「초대·예약 ② 사전 정보 수집 초대장」

| 레시피 섹션 | 채울 재료 | 상태 |
|---|---|---|
| `[헤더/배너: 로고]` | A5 | ✅ |
| `[히어로: 초대장 대형 헤딩]` | 행사명 + AI 카피 | ✅ |
| `[스토리: 초대 본문]` | AI 작성 | ✅ |
| `[핵심정보: 일시·장소]` | A2 · A3 | ✅ |
| `[안내 사항: 응답 마감일·수집 항목 안내]` | **응답 마감일 ⚠️** | 🔴 **재료 없음** |
| `[폼: RSVP + 부가 항목]` ← 핵심 | A②-1 | ✅ |
| `[위치 안내]` | A3 | ✅ |
| `[문의]` | A6 (이메일·전화) | ✅ |
| `[푸터]` | 로고 + 문의 채널 | ✅ |

### 🔴 못 채운 섹션 = `안내 사항 (응답 마감일)`

**응답 마감일은 「사실」이다.** AI가 지어낼 수 없다.
사전 등록형 초대장에서 **마감일 없는 RSVP는 작동하지 않는다** — 언제까지 답해야 하는지 모르면 미룬다.

> 🔎 「수집 항목 안내」 쪽은 A②-1로 채울 수 있다. 문제는 **마감일 하나**다.

### ⚠️ AI가 사실을 지어낼 뻔한 지점

히어로 카피를 쓰려니 「**12개 팀**」이라는 숫자가 필요했다. 유저는 답하지 않았다.
→ **카피에 숫자·고유명사가 들어가면 그건 이미 사실이다.** 원칙 4의 경계가 여기서 흐려진다.
→ 안전한 대안: 「함께 성장한 팀들이 무대에 섭니다」처럼 **숫자를 빼고 쓴다.**
