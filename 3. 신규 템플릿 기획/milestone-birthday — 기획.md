## 구성 (33장)
`eyebrow → 대제목 → 인사 문구 → 일시·장소·마음(라벨+값) → 메인 이미지 → 프로필(주인공) → 모시는 글 → 잔치 순서 6행 → 가족 사진 갤러리(2단·1:1) → 참석 회신(안내+Q&A 폼) → 안내 말씀 01·02·03 → 오시는 길(위치 카드) → 마음 전하실 곳(계좌) → 문의(자녀 2인 버튼) → 가족 일동`

- **Q&A 카드 신규 제작** — 제목 중앙 + `성함`(주관식) · `참석 여부`(객관식 2) · `함께 오시는 분`(객관식 3) + **제출 버튼 카드 하단 내장(채움)**
- **프로필 = 명함형** — 아바타↔텍스트 **28** · 이름↔소개 **12** (CdBd 고정 스펙)
- **화환·선물 사양**을 표지 「마음」 라벨로 올림 — 한국 잔치 실무에서 가장 많이 묻는 항목
