## 1부 — 시안 16종 제작

**산출물**: 시안 16종 사양 문서(옛 3-3) — 질문 세트 검증을 마치고 **2026-07-16 폐기**. 확정 반영본은 [[1-9. AI 유저 플로우 (제품 설계도)]] ③ 질문 3층. *(문서 전문은 git 이력에 보존)*

### 제작 방식

- Figma MCP `use_figma`로 **직접 생성** (claude.ai/design 미경유 — 시나리오 검증이 목적이라 구조 통제가 필요했음)
- 16개 프레임 = 390px 모바일 · **평면 카드 스택**(프레임 직접 자식) · 여백 카드 포함
- 이미지 **70장** OpenAI gpt-image-1 생성(~$2.9), `upload_assets` → `imageHash` → 슬롯 fill 직접 설정
- 로고 16종 = **심볼(도형 프리미티브) + 워드마크(무드 일치 폰트)** 로 직접 작성

### 결정 흐름 (사용자 피드백 사이클)

1. **A 4종 제작** → 색·폰트를 라이브러리에서 선정
2. **"컬러팔레트가 너무 갇혀 있다"** → 16종 전부 **무드 기반 자유 팔레트로 재설계**. 대비 2종(텍스트·버튼)만 지키는 규칙으로 전환 → [[../CLAUDE.md]] 「팔레트는 라이브러리에 갇히지 말 것」
3. **"예약 카드는 뷰어에서 버튼과 동일"** → A④ 예약 카드 목업 삭제, **세션당 버튼 1개**로 → [[../CLAUDE.md]] 카드 식별 절
4. **"D④ 팔레트 구리다"** → `Fat Wallet` **라이브러리에서 삭제**(70→69개)
5. **"로고가 아무데도 적용 안 됐다"** → 색면 플레이스홀더 → 실제 로고 16종 제작
6. **섹션 프리셋 배리에이션 선적용** → 헤더 배너·푸터·카드 배경/테두리·2행 텍스트·버튼 변주·2단 카드 내 버튼

### 재사용 가능한 스크립트 패턴

- **색 일괄 교체**: 프레임별 `{old bg/txt/btn/acc} → {new}` 매핑 + `inBtn(node)` 컨텍스트 판정으로 `fills`/`strokes` 재작성. `txt === btn`인 2색 팔레트도 버튼 내부/외부로 구분 가능
- **이미지 대량 반입**: `upload_assets(count:N)` → submitUrl에 multipart POST(병렬) → `imageHash` 회수 → `use_figma`에서 슬롯 프레임 `fills` 직접 설정 → **임시 배치 노드 `placedOnNodeId` 삭제**
- **누끼 이미지**: `scaleMode:'FIT'` + 흰 배경 (화보는 `FILL`)

### 함정 (재발 방지)

| 함정 | 원인 | 해결 |
|---|---|---|
| **이름이 겹친 카드가 교체 루프에 휩쓸려 삭제됨** (C② 히어로 소실 · LOOK 01 화보가 히어로 자리에 잔류) | `children.find(name.startsWith('이미지: c2-look1a'))` 가 히어로 카드를 먼저 잡음 | 교체 대상은 **정확한 전체 이름**으로 매칭하거나 **id를 먼저 수집**한 뒤 삭제 |
| **한글 CSS 셀렉터** `query('TEXT[name*=문장들]')` 파싱 오류 | Figma `query` 셀렉터가 non-ASCII 미지원 | `findAll(n => n.characters.includes(...))` predicate 사용 |
| **어절 중간 줄바꿈** (`북토\n크`) | 자동 줄바꿈 | 문장 경계에 **명시 개행**(`\n`) 삽입 |
| **백그라운드 이미지 생성이 18/47에서 끊김** | `nohup ... &` 프로세스가 죽은 것처럼 보였으나 실제로는 로그 버퍼링 | `pgrep -f`로 생존 확인 후 대기. 스크립트에 **캐시 스킵**(파일 존재 시 건너뜀) 내장 |
| macOS `setsid` 없음 | GNU 전용 | `nohup ... &` + `pgrep` 확인 |

### 되풀이된 판별 원칙 (이번 세션에서 굳어짐)

1. **한 칸에 두 이미지를 받지 말 것** — `프로필·로고`(A5·B2), `화보·누끼`(C4). 서로 **다른 자리**에 동시에 들어간다.
2. **반복 아이템의 필드는 세부가 늘린다** — `C4` 아이템에 ①상세스펙·상세이미지 / ②화보·누끼. 별도 문항 ❌.
3. **"묻고 넘어가기"** — `A③-3 참석 여부 받을까요?`(예/아니오). 옛 판단("폼이 필요하면 A②를 고른다")을 **부분 철회**. 개인 맞춤 초대장은 개인화가 목적이면서 회신도 받는다.
4. **통짜 문단 ❌, 구조로 받기** — `D④` 내용→Step / `A8` 시간+제목+설명 / `B②-1` 제목+설명. 나중에 못 쪼갠다.
5. **카드 default 기능이 질문 형식을 정한다** — CdBd Q&A는 질문 단위 펼침 → FAQ는 **질문 1개 = 카드 1장**. 예약 카드는 버튼 → **세션 1개 = 버튼 1개**.
6. **사실 vs 카피의 경계가 계속 확장됐다** — 실적·경력·연혁·비전·기획의도·후기·스토리·판권 정보는 전부 **사실**. AI가 지어내면 가짜.
