### 2-3. 🚨 자동화 시행착오 — 다시 반복하지 말 것

> **핵심 메시지**: CdBd 에디터의 mobile preview / 카드 보드 / 우측 패널 / 모달은 **모두 같은 DOM 트리에 공존**한다. 잘못된 selector·focus는 의도치 않은 곳에 입력을 보낸다. **검증 없는 다단계 자동화 위험**.

#### 함정 1: "last contenteditable" = **인사팀 버튼 텍스트**
**증상**: 새 텍스트 카드 추가 후 텍스트 입력하려고 `document.querySelectorAll('[contenteditable=true]')` 마지막 원소에 focus → 실제로는 **mobile preview 최하단의 "인사팀에 문의하기" 버튼 텍스트**가 잡힘 → 4번 반복 시도 결과 사용자가 의도한 텍스트가 인사팀 버튼에 덮어쓰여짐.

**원인**: mobile preview에 모든 카드의 텍스트가 `contenteditable=true`로 렌더링됨. y 좌표 정렬해도 "맨 아래"는 페이지 최하단 카드(인사팀 버튼).

**대응**: 새 카드 추가 직후 카드의 **고유 텍스트 토큰(예: "텍스트를 입력해 주세요")으로 매칭**, 또는 우측 패널에서 카드 선택 후 mobile preview의 **선택 상태(녹색 외곽선)** 카드 내부 contenteditable을 찾기.

#### 함정 2: 카드 추가 모달이 누적 오픈
**증상**: + 카드 추가하기 클릭 후 모달이 안 닫혀서 같은 함수가 모달 안 열어주려는 ensure-modal 체크에서 실패 → 추가 클릭으로 인해 무한 루프 + 모달 누적.

**원인**: 카드 추가 모달의 닫힘 트리거는 텍스트 카드 클릭 후 자동 닫힘인데, 자동화에서 텍스트 카드 클릭이 실패하면(예: viewport scroll 문제) 모달이 열린 채 다음 사이클로 진입.

**대응**: ensure-modal 패턴 ❌ → 모달 닫힘 명시적 확인 후 다음 단계.

#### 함정 3: 모달 X 닫기 버튼은 absolute DIV (button 아님)
**증상**: ESC 키 안 먹음, X 좌표 클릭도 다른 element 잡힘.

**원인**: X는 `.absolute.right-[24px].top-[30px]` DIV(button 아님)에 SVG 내장.

**대응**:
```js
document.querySelector('div.absolute.right-\\[24px\\].top-\\[30px\\]').click()
```

#### 함정 4: 카드 라벨 ✏️ pencil 우발 활성화
**증상**: 카드 보드 행에서 라벨 영역 근처 클릭이 ✏️ pencil을 잡으면 라벨 inline edit 활성화 → 이후 type 명령이 라벨에 들어감.

**증거**: 이미지 카드 라벨이 "이미지" → **"2026 ABC 컴퍼니 채용..."** 으로 변경됨 (예약 카드 제목과 동일 문자열 — 다른 자동화 사이클의 타이핑이 흘러들어옴).

**대응**: 카드 보드의 카드 행 클릭 시 **라벨 텍스트 영역(span x=702 부근)은 회피**. 우측 카드 아이콘 또는 ⋮⋮ 핸들 부근 클릭.

#### 함정 5: 우측 패널 입력값이 React state로 안 들어감
**증상**: `Object.getOwnPropertyDescriptor(...value).set` + `dispatchEvent('input')` 패턴으로 input value 변경했는데, 모달 저장 시 "값 입력해주세요" 빨간 에러.

**원인**: react-hook-form 등이 ref 기반으로 상태 추적 → DOM input value만 바뀌고 form state는 비어있음.

**대응**: `$B fill "input.MuiOutlinedInput-input[placeholder*='제목을']" "값"` (Playwright fill은 keyboard 시뮬레이션) → form state까지 반영.

#### 함정 6: Reload 시 일부 값 손실
**증상**: 인사팀 버튼 mailto 링크가 reload 후 사라짐.

**가설**: 자동저장이 모달 닫힘·blur 트리거 기반 → input 값만 변경하고 blur 안 시키면 비저장.

**대응**: 모든 input 변경 후 `dispatchEvent(new Event('blur', {bubbles:true}))` 강제.

#### 함정 7: Korean character CSS selector 오류
**증상**:
```
Error: in query: Invalid selector: unexpected character (0xec) at position 12
```

**원인**: 피그마 `node.query('FRAME[name*=시안]')` 등 한글 attribute 매처가 파싱 실패.

**대응**: `findAll(n => n.name.includes('시안'))` predicate 사용.

#### 함정 8: 캘린더 next/prev 화살표 위치
**증상**: 캘린더 헤더(6월 2026)의 다음 달 화살표가 y 좌표 추정과 다름.

**대응**: `button[aria-label="Next month"]` 셀렉터 직접 사용 — MUI X DatePicker 표준.

#### 함정 9: $B click 좌표 문법
**증상**: `$B click "795,303"` → CSS selector 파싱 오류.

**대응**: $B click 은 selector 전용. 좌표 클릭은 JS `elementFromPoint(x, y).click()` 또는 selector 기반.

#### 함정 10: $B viewport 명령 인자
**증상**: `$B viewport 1440 1024` → `Unexpected positional arg: 1024`.

**대응**: `$B viewport 1440x1024 --scale 1` 형식.

#### 함정 11: Q&A 질문 유형 변경은 in-place 불가
**증상**: kebab 메뉴에 "복제하기 / 삭제하기" 만 있음. 주관식↔객관식 변환 옵션 없음.

**대응**: **삭제 후 객관식 신규 추가** 다단계 시퀀스만 가능. 신규 추가는 위치가 **마지막**이라 reorder 필요(드래그 자동화 어려움 → 수동).

#### 함정 12: Q&A 객관식 옵션의 input 구조
**관찰**: 새 객관식 질문 추가 시:
- 인풋 0: 질문 내용 ("예시: 아래 2가지 중 선택하세요" placeholder)
- 인풋 1: 옵션1
- 인풋 2: 옵션2
