## 3부 — 🚨 `download_assets` 투명 배경 함정 발견·해결 (사용자 피드백)

**산출물**: 투명 배경 자산 5종 재export·어드민 교체 완료 · [[../1. 작업 가이드/1-3. 이미지#✂️ Figma 노드 투명 배경 PNG export (2026-06-22 기록)]] · [[../CLAUDE.md]] 트러블슈팅 표 신규 행

### 결정 흐름
1. **피드백**: "주요기능 아이콘이랑 메인 이미지 모서리에 색이 들어가있어. Png로 내보냈으면 모서리가 투명해야 하는데."
2. **진단**: PIL로 확인 → 네 모서리 alpha = **(154,154,154,255)** 불투명. = `템플릿 등록` 페이지 배경색 `#f5f5f5`. → `download_assets` `export` URL이 **노드를 페이지 배경과 합성**해서 렌더한 것.
3. **실패한 시도들**:
   - 페이지 배경을 opacity 0으로 바꿔 `download_assets` 재호출 → `export` 경로 여전히 회색(캐시/합성). ❌
   - `exportAsync` 바이트를 hex/base64로 받아 shell 디코딩 → 큰 응답 **truncate로 PNG 깨짐**. ❌
4. **✅ 해결**: `use_figma`에서 `node.exportAsync()` → `figma.createImage(bytes)`(노드 단독=투명 보존) → **임시 RECT에 IMAGE fill** → `download_assets`의 **`rawImages[0].url`** 다운로드. rawImages 경로는 노드 단독 렌더. 작업 후 임시 RECT 제거.
5. **검증**: PIL 네 모서리 = `(0,0,0,0)` 4개 → 투명 OK. Supabase 업로드본도 직접 재확인.

### 핵심 인사이트 (영구 룰로 기록)
- **`download_assets` `export.url` = 페이지 배경 합성 / `rawImages[].url` = 노드 단독(투명 보존).** 카드·그리드 셀 자산은 무조건 rawImages 경로.
- truncate 회피 위해 hex/base64 직접 회수 ❌ → **createImage → RECT → rawImages URL** 경로 고정.
