## 🔧 재사용 기법 (다음 세션 핵심 자산)

### A. HTML → PNG hug 렌더 (browse)
```bash
B="$HOME/.claude/skills/gstack/browse/dist/browse"
$B viewport 760x800 --scale 2
$B goto "file:///tmp/pbook/pages/X.html"; sleep 0.6
H=$($B js "Math.ceil(document.querySelector('.page').getBoundingClientRect().height)" | tr -dc '0-9')
$B viewport 760x${H} --scale 2      # 정확한 hug 높이
$B goto "file:///tmp/pbook/pages/X.html"; sleep 0.6
$B screenshot out.png
```
⚠️ browse `file://`는 **cwd/$TMPDIR만** 허용 → 작업본을 `/tmp/pbook/`에 미러링해 렌더(경로에 한글·공백 있으면 특히).

### B. 인쇄면에서 인물/사진 크롭 = 민트↔사진 색차 투영 (필수 노하우)
초상 사진이 **밝은 회색/흰 배경**이면 단순 이진화가 사진 경계를 못 잡아 **민트 테두리가 남거나 좁게 잘림**. 해결:
- 민트 `#C8E1DD`는 **G−R ≈ 25**(초록기), 사진(회색·흰·검정)은 **G−R ≈ 0** → `nonmint = (G−R) < 15` 마스크.
- 행/열 **투영**(fraction>0.55의 최장 연속 밴드)으로 **사진 사각형 전체**를 잡음. 인접 소개글 텍스트·©크레딧은 밴드 분리로 자동 제외.
- 원본 표준 초상 프레임 = **445×309 (1.44)**. (검정 배경 사진도 nonmint라 동일 동작.)
- 코드는 이 세션 bash 히스토리 `crop_rect()` 함수 참고.

### C. CdBd 멀티페이지 = 썸네일 fiber로 전 페이지 blocks 접근·삭제 (신규 발견)
`card-driver.js`는 **활성 페이지만** 읽지만, **좌측 페이지 썸네일의 fiber `memoizedProps`에 `page.blocks` 통째 + `onDelete`/`onSelect`/`onClone`이 들어있음** → 네비게이션 없이 전 페이지 접근.
- **읽기/수정**: 썸네일 DOM(x<220)들의 fiber에서 `p.page.blocks` 찾아 직접 mutate. **삭제(=페이지 setter)가 autosave를 유발하면 직접 mutate한 다른 페이지 변경도 함께 저장됨**(공유 state 참조라). 이 세션에서 6~18쪽 여백을 이 방식으로 일괄 수정 → 페이지 삭제 저장에 편승해 영속됨(리로드 검증).
- **페이지 삭제**: 썸네일 fiber `p.onDelete()` 호출(→ SweetAlert) → `window.__cdbd.confirmSwal()`. 최고 순번부터 순차. `onDelete`는 `pages.length<=2`면 막힘.
- **주의**: 이 기법은 아직 `cdbd-card-automation` 스킬에 미기록 → **스킬에 추가 검토**(멀티페이지 일괄 수정/삭제).

## 핵심 설계 결정사항

- **원본 충실 + 모바일 적응**: 원본은 텍스트 작게·대비 낮게·얇은 선·넓은 여백. 모바일에선 그보다 크되 대비 과하지 않게. 챕터 단색 전면 배경(민트)은 원본에도 있어 **유지**, 프로그램 정보의 박스/굵은 선은 원본에 없어 **제거→얇게**.
- **오렌지 포인트 = 흰 배경 전용**: 민트/오렌지 배경 페이지에서 오렌지 액센트는 먹색으로 치환(이선호 지시).
- **이미지 = 원본 비율 그대로, 크롭·늘림 금지**: 4:3 강제 object-fit 크롭을 이선호가 거부 → width:100%·height:auto·원본 비율. 초상 사진은 원본 프레임(1.44) 전체.
- **목차 번호**: 제작된 섹션은 CdBd 폴리오, 미제작 챕터(렉처콘서트~예술마스터)는 원본 책 페이지번호(33~86). 최종적으로 **하단 폴리오(2)는 삭제**, 항목 번호는 유지.
- **여백 수렴 논의**: 상단 여백 20→30→24, 목차만 48로 이선호가 실시간 조정(현재값 = 본문 24 / 목차 48).
