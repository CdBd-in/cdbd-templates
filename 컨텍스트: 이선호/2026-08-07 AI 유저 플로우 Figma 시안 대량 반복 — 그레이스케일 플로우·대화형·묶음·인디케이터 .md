## 2. 이번 세션 주요 결정·정정 사이클 (역사적)

1. **진행 인디케이터** — 짧은 가운데 선 → **상단 full-width fill 바**(훨씬 길게). 이어서 "10단계라 길어 보임" → **큰 3구간** 대안. 3구간 라벨은 처음 `입력→생성→완성`이었으나 *"완성은 과정 아니라 결과"* 지적 → **`입력→생성→편집`**으로 정정.
2. **상태 쌍(before/after)** 패턴 — 8·대화, 이미지, 프로그램, 3(행사명/설명), 6(과정/완료) 등을 "같은 단계 두 상태"로 아래에 스택. 이미지·프로그램은 "입력 전=건너뛰기만 / 후=다음".
3. **페이지 유형** — "둘 중 고르기" → **"이 내용엔 원페이지 추천" + 대안 낮은 위계** + 유형별 최소 URL 생성 비용(월 120크레딧~)·멀티=약 4페이지 표기.
4. **무드 변경** — 처음 중앙 덮는 모달 → *"시안 가림"* → 하단 시트 → *"여전히 가림, 팔레트 큼"* → **선택 시안 바로 오른쪽 스크롤 패널(팔레트 3열 소형)·B/C 흐림·바뀌는 시안에 실제 팔레트 적용**.
5. **에디터 투어** — 대상 가리키는 코치마크 → *"마우스 안 움직이게"* → **하단 중앙 고정 안내카드(같은 자리)+단계점+건너뛰기**.
6. **레퍼런스 대화형** — 이선호가 Typeform식 시안(`5219`) 제공 → 10화면 재현(우측 **답변 누적 요약**). 이후 요약을 *평평한 칩 → 내용별 그룹+라벨*로 재구성했다가, 다시 *"11·12px 라벨 삭제"* → 값만 남김.
7. **그레이스케일 통일** — 대화형·변형의 보라 포인트 전부 회색조로. (색 팔레트 화면·실제 에디터만 색 예외)
8. **모든 텍스트박스 height=hug** 전역 적용(고정높이 96개 수정).
9. **시안/필드 정리** — 시안 밖 카드 프레임·A/B/C 라벨 제거, 무드변경 버튼만. 텍스트필드 라벨↕값 상하정렬·글씨 키움·구분선(좌측 액센트바) 삭제.
10. **AI 옵션 + 자료업로드/프롬프트 바**를 모든 질문 화면에 상시 배치.
11. 카테고리 대안 UI 3안(대·소 한 화면) — 단계 축소용.
12. 마지막: **이선호가 직접 사이즈·간격 수정 중** → *"다른건 건드리지 말고 내용 구성만"* 지시(5238:717에 대기 묶음만 추가).

## 4. 🔧 재사용 — use_figma 기술 함정 (이번 세션 반복 확인 · CLAUDE.md 승격 후보)
- 🚨 **`use_figma`는 트랜잭셔널** — 코드가 **throw하면 그 호출의 모든 변경이 롤백**된다. `throw new Error(...)`로 결과 보고하면 **수정이 사라짐**(이번 세션 3회 반복 실수). → **읽기 전용 조회에만 throw 사용, 편집은 정상 return**.
- **`setCurrentPageAsync`는 PAGE 노드 필요** — 중첩 텍스트의 `.parent`는 프레임. `let p=node; while(p&&p.type!=="PAGE") p=p.parent;`로 올라가서 사용.
- **`findChild`는 직계만** / 중첩은 `findOne`(재귀). 오토레이아웃에 감싸인 자식은 findOne로.
- **오토레이아웃 `resize()`는 두 축 sizingMode를 FIXED로 잠금** → "고정 폭 + hug 높이" 원하면 `counterAxisSizingMode="FIXED"` → `resize(w,h)` → `primaryAxisSizingMode="AUTO"` 순서. (안 하면 카드가 height 10으로 붕괴 — 프로그램 카드 사례)
- **자유 배치하려면 AL에서 꺼내기** — `F.appendChild(node)`로 상위 프레임 직계로 옮긴 뒤 x/y.
- **아이콘은 이모지 말고 벡터로** — swap(⇄)·별·chevron은 `createVector` vectorPaths로(이모지·특수문자 렌더 불안정). `↑ ✓ → ↵ ·`는 렌더됨.
- **clone은 컴포넌트 인스턴스·폰트 보존** — 레퍼런스(`5219`, `5304:3002`) 복제로 스타일 그대로 재사용.
- 폰트: 이 파일 텍스트 = **Pretendard**(Bold/Regular/Medium). 삭제된 노드에서 fontName 읽지 말고 `{family:"Pretendard",...}` 직접 로드.
- 조회 패턴: `throw new Error(JSON.stringify(map))`로 재빌드된 프레임 ID 회수(읽기 전용이라 안전).
