## 1부 — 서브에이전트 이름 간소화 (`cdbd-edit-` → `editor-`)

**산출물:** `.claude/agents/editor-*.md` × 14 · 명명 정본 = [[1. 작업 가이드/1-6-1. CdBd 에디터.md]] 「📦 산출 형태」

### 변경 (Before → After)
| 팀 | Before | After |
|---|---|---|
| 빌드(S) | `cdbd-edit-s1-foundation` … `-s6-reservation` | **`editor-s1-foundation` … `-s6-reservation`** |
| 검수(V) | `cdbd-edit-v1-textdesign` … `-v5-carddesign` | **`editor-v1-textdesign` … `-v5-carddesign`** |
| 수정(F) | `cdbd-edit-f1-fix` / `-f2-finalize` | **`editor-f1-fix` / `editor-f2-finalize`** |
| 통일성(C) | — (없음) | **`editor-c1-consistency`** (신규) |

### 결정 흐름
1. 이선호 요청: "호출하기 쉽게 간소화". 3안 제시(`cdbd-s1` / `cdbd-s1-text` / `s1`) → 사용자 커스텀 채택: **접두어 `editor-` + 팀번호 + 뜻 단어**.
2. 뜻 단어(`textdesign`·`imageshape`·`carddesign`)는 **유지** — S팀(`text`·`image`·`cards`)과 V팀을 구분하는 꼬리라 축약 시 충돌(예: `s3-text` vs `v1-text`).
3. `cdbd-edit-shared.md`(모든 에이전트가 먼저 읽는 공통 지침 문서)는 에이전트가 아니므로 **개칭 안 함**.
4. 과거 세션 기록·옛 계획 문서(`docs/superpowers/plans/…`)의 옛 이름은 **역사적 기록이라 그대로** 둠. LIVE 아티팩트(에이전트·워크플로·1-6-1·CLAUDE.md)만 갱신.

## 2부 — 독립 재검증 구조 (자기검사 맹점 차단)

**산출물:** `.claude/workflows/cdbd-editor-pipeline.js`(재작성) · 신규 `editor-c1-consistency` · 풀스펙 = [[1. 작업 가이드/1-6-1. CdBd 에디터.md]]「🆕 2026-07-15」

### 결정 흐름 (Socratic — 왜 이 구조인가)
1. **V·F를 왜 나눴나?** → '피로도' 아님. ①읽기전용(병렬 안전) vs 쓰기(직렬) ②독립 시각(자기검사 맹점 차단) ③권한 분리(검수는 브라우저 접근 금지=안전).
2. **pipeline은 코드, daily는 AI인 이유?** → **판단이 필요 없으면 코드**(pipeline: 고정 순서·기계적 디둡·묶기), **판단이 본질이면 AI**(daily: 주제/무드 선택·품질 합격판정·로그인 복구·리포트 작성). 단 daily의 즉흥 위험은 울타리로 제한(critic gate·retry≤2·절대규칙).
3. **pipeline도 빌드/검수 판단 필요하지 않나?** → 판단은 **작업자 13명(AI)이 이미 함**(V1이 "색 틀렸나", F1이 "어떻게 고치나"). 지휘자(pipeline.js)만 판단 0.
4. **자기검사는 오류 → 재검증 지휘자, 전체 1명 vs 팀마다?** → **팀마다(scoped)**. 전체 1명 전수재검사는 13분할 취지를 무효화(한 머리로 다 보면 얕아짐). 단 대부분 **기존 V 재활용**: S는 이미 V가 검사 / F는 V를 재실행해 검사 / V 자체는 교차확인. **전체 1명은 '통일성'만**(C1) = 카드 하나씩 보면 못 잡는 카드 간 불일치 전용. → daily가 이미 쓰는 하이브리드(스테이지 critic + 최종 통일성 검수)와 동형.

### 추가된 4가지 메커니즘 (풀버전은 1-6-1)
1. **C1 통일성**(신규 전역 크리틱) — 카드 간(≥2) **섹션배경 톤·모서리 톤·버튼모양·폰트 개수·정렬·중복이미지·placeholder 잔존**만. 개별 카드×속성은 V1~V5 소관(중복 금지).
2. **교차확인** — V·C1의 diff를 '반대 눈'(`general-purpose`)으로 재판정 → CdBd-legal 오탐 제거 후에만 F로.
3. **F→V 재검증 루프(≤2, `MAX_REVERIFY`)** — F1 수정 후 재스냅샷 → V+C1 재실행 → diff 남으면 F1 반복(자기 결과를 자기가 판정하지 않게).
4. **거짓클린 게이트** — 검수자 6명 중 성공 수 < 6이면 diff 0이라도 clean 단정 ❌ → `unverified='미검증'` 표기(전멸 시 거짓 클린 방지, CLAUDE.md 파이프라인 게이트 함정 대응).

### 파이프라인 최종 흐름
`S1→S2 → S3→S4→S5→S6 → [스냅샷] → V1~V5∥C1 → 거짓클린 게이트 → 교차확인 → F1(카드별) → [재스냅샷→V+C1 재검증]×≤2 → F2` (mode: `full`/`fix`/`verify`)
