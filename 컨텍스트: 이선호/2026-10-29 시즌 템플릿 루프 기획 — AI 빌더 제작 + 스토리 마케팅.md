### 재사용 스크립트 — 검색 노출 확인 (2026-10-29 실측 · 동작 확인)

```bash
# ① 템플릿 상세의 제목·설명 — 검색 로봇이 받는 첫 화면
curl -sL -A "Mozilla/5.0 (compatible; Googlebot/2.1)" "https://www.cdbd.in/templates/invitation/gala-rsvp" \
 | grep -o -i -E '<title>[^<]*</title>|<meta[^>]*(og:title|name="description")[^>]*>'

# ② 검색엔진용 주소 목록에 주소가 몇 개 들어 있나 (10-29 = 1개)
curl -sL "https://www.cdbd.in/sitemap.xml" | grep -c "<loc>"

# ③ 네이버가 블로그 글을 수집했나 — site: 검색 결과에서 글 주소만 뽑기
q=$(python3 -c "import urllib.parse;print(urllib.parse.quote('site:home.cdbd.in'))")
curl -sL -A "Mozilla/5.0 (Macintosh) AppleWebKit/537.36 Chrome/126.0 Safari/537.36" -H "Accept-Language: ko-KR" \
 "https://search.naver.com/search.naver?where=web&query=$q" \
 | python3 -c "import sys,re,urllib.parse; s=urllib.parse.unquote(sys.stdin.read()); print(sorted(set(re.findall(r'home\.cdbd\.in/post/[^\"<>\s&]+', s)))[:10])"
```
