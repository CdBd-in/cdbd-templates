## 2부 — 〰️ 「구분선 = 선의 종류로 가른다」 규칙 정정 (3곳 반영)

### 결정 흐름
1. 내 기존 규칙: *"한 섹션에만 쓰인 선 = 일회용 → 제거, 애매하면 제거가 기본값"*.
2. 이선호는 A①·A³에서 **정반대(전면 확대)**를 3회 연속 선택 → 규칙 충돌 발생.
3. 확인 결과 **뒤집기가 아니었음** — 기존 규칙에도 *"제거하거나 **확장한다**"* 두 갈래가 이미 있었고, **어느 쪽이 기본값인지가 「선의 종류」에 달렸다**는 걸 못 박은 것.

### 확정된 판정
| 선의 종류 | 한 섹션에만 있을 때 기본 해결 |
|---|---|
| **구조 구분선**(긴 선이 섹션 가름·340×1) | **제거** — 구분은 여백이 이미 함 |
| **섹션 타이틀 액센트바**(짧은 바가 타이틀 아래·60×2~3) | **모든 타이틀에 확장** — 타이틀은 통일 대상 |

- 확장 범위 = **타이틀 있는 콘텐츠 섹션 전부**(히어로·폼·푸터 ❌).
- 스타일별 있음/없음 = **차별화 레버**(A³ 실측: 미니멀·에디토리얼=바 있음, 볼드=0개+틴트/큰 텍스트).
- A³ 액센트바 실측: 미니멀 `60×2·#c9a227·중앙(pad 좌우 160)` / 에디토리얼 `60×3·#57564f·좌측(pad 좌20/우300)`.
