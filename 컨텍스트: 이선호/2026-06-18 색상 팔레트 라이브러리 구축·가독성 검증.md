### WCAG 검증 스크립트 (재사용)
```python
def relative_luminance(hex):
    hex = hex.lstrip('#')
    r, g, b = (int(hex[i:i+2], 16)/255 for i in (0,2,4))
    f = lambda c: c/12.92 if c <= 0.03928 else ((c+0.055)/1.055)**2.4
    R, G, B = f(r), f(g), f(b)
    return 0.2126*R + 0.7152*G + 0.0722*B

def contrast_ratio(bg, fg):
    L1, L2 = relative_luminance(bg), relative_luminance(fg)
    return (max(L1,L2) + 0.05) / (min(L1,L2) + 0.05)
# 등급: AAA≥7 / AA≥4.5 / AA-Large≥3 / 유지 임계값=3.6
```

```js

```
→ 면적 ±0.5%, 원본 비율 유지

- 🅱️ UPNG.js inline 임베드: use_figma 코드 +40KB (50KB 한계 근접)
- 🅲️ 사용자 수동 Figma Crop 툴: 클릭 2회, 자동화 깨짐

**결론**: 빈도 낮으면 PIL 유지. 월 100건+ 시 옵션 🅱️ 검토.

### 6-11. 영구 Anti-pattern 회피 룰 (Anti-pattern → 가이드 기록)

1. **배경색은 이미지에 베이크 X, Figma 프레임에 적용 O** — 재사용·수정 가능
2. **`upload_assets` nodeId 지정해도 fill 자동 안 됨** → `use_figma`로 hash 수동 apply
3. **alpha bbox 크롭 필수** — Figma AI는 캔버스 크기 유지, raw 그대로 쓰면 그리드 셀 면적 불균일
4. **연속 생성 시 60초 간격** — Free-tier throttle 회피
5. **사례 기획 vs 템플릿 등록 헷갈리지 말 것** — CdBd 페이지 내부 자산은 사례 기획에
6. **Slate.js 에디터엔 `fill()` 안 됨** — `page.keyboard.insert_text()` (composition event)
