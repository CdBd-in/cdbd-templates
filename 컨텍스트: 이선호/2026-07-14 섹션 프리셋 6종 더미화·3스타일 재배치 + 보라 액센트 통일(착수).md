**사용자 지시(원문)**: "버튼+포인트텍스트에 보라색 적용 (Ex, node-id=3001-4039)"

**의도**: 더미 섹션 프리셋 라이브러리 전체를 **보라 액센트로 통일**해서 "이건 템플릿 슬롯"이라는 신호를 일관되게. 보라 헤더와 톤을 맞춤.

**변환 규칙 (3가지):**
| 대상 | 처리 |
|---|---|
| 🟣 **버튼** (프레임명 "버튼") | 배경 → 보라 `#6C4CFF`, 글자 → 밝은색(배경색) |
| 🟣 **포인트 텍스트** (대문자 강조 라벨·eyebrow) | 글자색 → 보라 `#6C4CFF` |
| ⚫ **그대로 유지** | 행사명·본문 등 일반 텍스트(진회색 `#292929`), 회색 더미 이미지 |

**보라 색값**: `#6C4CFF` = Figma `{r:0.4235, g:0.298, b:1}` (헤더 보라와 동일)

## 🛠 Figma MCP / 커넥터 기술 메모 (다음 세션 주의)

1. **claude.ai Figma 쓰기 커넥터 만료가 잦음** — 웹 재연결·앱 재시작으로도 **열려 있던 세션엔 반영 안 될 수 있음**. 가장 확실한 복구 = **새 대화 세션 시작**. (이번 세션이 그래서 막힘)
2. **데스크톱 Figma MCP는 읽기 전용** — 구조/스크린샷 확보엔 유용하나 쓰기 불가. `get_metadata`는 fill(색) 정보 없음 → 색 확인은 `get_design_context` 또는 `use_figma` read 필요.
3. **`use_figma` 쓰기 = `figma-use` 스킬 먼저 로드** 필수, 매 호출 `fileKey` 전달, `skillNames:'figma-use'`.
4. **섹션 자식 좌표는 섹션-상대** (절대 아님). 섹션 밖(경계 초과) 좌표로 잠깐 두면 노드가 다른 페이지로 auto-reparent됨 → 항상 경계 안에 배치.
