## 🛠 Figma MCP / 커넥터 기술 메모 (다음 세션 주의)

1. **claude.ai Figma 쓰기 커넥터 만료가 잦음** — 웹 재연결·앱 재시작으로도 **열려 있던 세션엔 반영 안 될 수 있음**. 가장 확실한 복구 = **새 대화 세션 시작**. (이번 세션이 그래서 막힘)
2. **데스크톱 Figma MCP는 읽기 전용** — 구조/스크린샷 확보엔 유용하나 쓰기 불가. `get_metadata`는 fill(색) 정보 없음 → 색 확인은 `get_design_context` 또는 `use_figma` read 필요.
3. **`use_figma` 쓰기 = `figma-use` 스킬 먼저 로드** 필수, 매 호출 `fileKey` 전달, `skillNames:'figma-use'`.
4. **섹션 자식 좌표는 섹션-상대** (절대 아님). 섹션 밖(경계 초과) 좌표로 잠깐 두면 노드가 다른 페이지로 auto-reparent됨 → 항상 경계 안에 배치.
5. **쓰기 커넥터는 세션 중간에도 끊긴다** — 작업 도중 `use_figma`가 사라지고 `mcp__figma-desktop__*`(읽기 전용)만 남을 수 있음. 읽기로 구조·스크린샷은 확인 가능하나 색 적용 불가 → **쓰기 재연결 필요**(ToolSearch `select:mcp__plugin_figma_figma__use_figma`가 "no match"면 아직 끊긴 것).
6. **보라 recolor 기법(재사용·검증됨)**: `fills`만 바꾸면 **폰트 재로드 불필요**(빠름). 텍스트는 **현재 더미 문자열**로 포인트/본문 판별, 비텍스트는 **현재 fill hex**로 버튼(`#242424`→보라)/틴트(`#f4f4f6`→라벤더) 판별. **서랍→lanes→프래그먼트(child idx≥2)만** 순회(라이브러리 크롬=제목·레인헤더·캡션 제외). 채도 있는 stroke(sat>0.15)만 보라 통일(회색 카드 테두리 유지).
7. **`isBtn` 정규식 과매칭 주의** — 카드명에 "상담·전화·예약하기" 등이 들어가면 **컨테이너를 버튼으로 오분류**(통짜 색 덩어리). 클론/변환 시 컨테이너 이름 배제. 사후 감사 = "보라 채움 + 높이>100 + 텍스트≥2" 노드 탐색. (Q&A `3159:146` 사례)
8. **🔤 claude.ai Figma 커넥터의 Pretendard 가용성은 기본 보장 안 됨 → 쓰기 전 확인 필수 (2026-07-14, 중요)** — 이 세션 **초반** `listAvailableFontsAsync`에 **Pretendard 0개**였음(SUIT·Spoqa·나눔고딕·Wanted·Freesentation도 없음). 파일의 기존 Pretendard 텍스트가 "폰트 없음(missing)"으로 대체 렌더돼서 Pretendard로 `set fontName`하면 `loadFontAsync` 실패 → set 에러. **사용자가 Figma에 Pretendard를 추가하니 9웨이트 전부 사용 가능**해짐(이후 Pretendard로 재통일 성공). 🔑 **교훈: 폰트 쓰기 전 항상 `listAvailableFontsAsync`로 존재 확인**. 없으면 → 사용자에게 추가 요청, 또는 로드 가능 대체(**Noto Sans KR** 표준·거의 동일 계열 / IBM Plex Sans KR / Gowun Dodum Regular). ⚠️ **`hasMissingFont:true` 노드도 "로드 가능한 타깃"으로는 fontName 변경 성공** — missing은 *현재* 폰트 로드만 막지, 로드된 타깃으로의 재지정은 허용(3015:26 79/79 변환 검증). 즉 폰트 통일 = **타깃을 로드 가능한 폰트로** 잡으면 missing 소스도 전부 바뀜. 실패는 오직 *타깃*이 로드 불가일 때만.
9. **폰트 로드는 노드의 실제 fontName 객체로** — 하드코딩 `{family,style}`이 파일 등록명과 미세하게 어긋나면 로드 실패 가능. 다만 Pretendard처럼 아예 없는 폰트는 노드에서 캡처해도 로드 불가(위 8) → 로드 가능 폰트로 타깃 교체가 정답.
