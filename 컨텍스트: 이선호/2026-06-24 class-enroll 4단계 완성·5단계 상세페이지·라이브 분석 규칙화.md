## 핵심 정정 사이클 / 교훈 (다음 세션 주의)

1. **slug 혼동으로 "게시 중지" 오인** — 라이브 URL을 `milnbutter`(L 1개)로 봐서 "게시 중지" 페이지가 떴고 "안 됐다"고 잘못 보고. 실제는 `millnbutter`(L 2개). **사용자 대시보드(cdbd.in/home)에서 실 URL 확인이 정답.** + 상세페이지 slug는 또 다른 `class-enroll`(문서 기준).
2. **보드 스크롤 = 다른 에디터로 드리프트** / **`$B viewport`가 이전 네비 replay로 드리프트** → fiber onClick으로 스크롤 없이 카드 선택, viewport는 작업 시작 1회만.
3. **DS Badge 컴포넌트 = 완성 배지 아님, 다크 글리프 1개(#292929).** DS 캔버스의 다크배지+흰글리프는 컨테이너+override 표시. → 다크 컨테이너 프레임 + 글리프 흰색 override 필요. **자작(Lucide) 전에 `Icon/Special/Badge/{카드명}` 검색 필수.**
4. **Figma auto-layout에 `appendChild`하면 맨 끝(아래)** → 순서 중요하면 `insertChild(0, …)`.
5. **풀페이지 fixed-position 모달은 `$B screenshot`(풀페이지)에 안 잡힘** — 별도 처리 필요(이번엔 우회).
