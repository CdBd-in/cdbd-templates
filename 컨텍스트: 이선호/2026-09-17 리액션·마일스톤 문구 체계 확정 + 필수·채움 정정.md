## 오늘 완료한 작업 (2026-09-17)

### A. ⏱ 리액션 표시 시점 확정 (이선호 규칙 제시 → 정정 2회)

| 입력 | 표시 시점 (최종) |
|---|---|
| 이미지 업로드 | **업로드 완료** (파일 선택 ❌) |
| date·time picker | picker **마지막 항목 선택** (연/월/일 중 「일」까지) |
| 단일 텍스트필드 · 조합 항목 | **[다음] 버튼 클릭** |
| 반복 항목 | **첫 항목의 필수 항목 모두 입력(각 1자 이상) 후 focus 해제** — focus 해제 없이 [다음] 직행이면 버튼 클릭 시점 · **둘째 항목부터 안 뜸** |

- 🗑 **주소 검색창 단일 규칙 삭제** — 단일로 쓰일 일 없음(항상 상세주소와 한 묶음 = 조합). 단 **필수 충족 판정은 여전히 「검색 결과 선택 완료」**(충족 ≠ 리액션 시점).
- **[다음] 트리거가 마일스톤과 겹치면 = 순차 노출**: 리액션 2초 → 사라진 뒤 마일스톤 ON.

### B. 복수 항목 리액션 부활 + 📋 이모지 용도 교체

| 변경 전 | 변경 후 |
|---------|---------|
| 복수 항목 칸 = 반응 없음(`—`) | **첫 항목 완료 때 1회만** (개수형 `N개가 됐어요` 폐지는 유지) |
| 📋 = 정원·인원수 | **📋 = 글로 된 반복 목록** (정원 단일 칸 케이스가 없음을 실측 확인 — 예약 회차 반복·5-② 모집 조합 2곳뿐) |

→ 팔레트 10종 유지. 5-② 모집 정보 대표 문구 = `언제까지인지 보여요 🗓`.

### C. 마일스톤 3종 개정

| 시점 | 변경 전 | 변경 후 |
|---|---|---|
| 마지막(N) | `다 채우면 다른 시안도 보여드릴게요 🎉` | **`드디어 마지막 단계예요 👏`** (추가 시안 안내는 ⑨ 화면 전담 · 6-① 담백판 `마지막 단계예요`) |

### D. 패턴 문구 2계열 확정 (여러 정정 사이클 끝 최종형)

- **효과형** `{타이틀}이(가) ~졌어요` — **2개뿐**: `확실해졌어요`(사실 정보·절차·무거운 소식은 이모지 ❌) · `준비됐어요`(기능 · **이모지 ✅ 고정**). *또렷해졌어요·정리됐어요는 삭제 지시.*
- **감탄형** `{수식어} {타이틀}(이)네요` — 수식어 6종: `멋진`(이미지) · `흥미로운`(구경거리형 반복만) · `친절한`(규정) · `반가운`(혜택) · `눈에 띄는`(이력·실적) · `믿음이 가는`(후원 사용처).
- 🔑 **핵심 채택 기준 = 「항목 1개만 봐도 참인 수식어만」** — 반복 항목 리액션이 첫 항목 시점이라, 쌓인 양 칭찬(꼼꼼한·탄탄한·알찬·풍성한)은 거짓말 → 전부 기각. *첫 항목형 패턴(틀이 잡혔어요 계열 8후보)도 전량 삭제 지시.*
- **반복 항목 예외 8부류 표** 신설(4-7) — 규정·사람·이력·남의 말(후기)·기능·진정성·신뢰 업종·무거운 소식은 `흥미로운` ❌ → 각자 경로.
- **적용 범위 = ⓐ 빈 칸 폴백** — 수제 문구 있는 칸은 유지, 패턴은 비어 있던 칸에만.

### E. 25주제 표 전수 스윕 (44건)

- 복수 항목 빈 `—` 셀 44건에 패턴·수제 문구 주입(파이썬 일괄 · 전건 성공). 남은 `—` = ⓐ AI 칸 ⓑ 반복·조합 묶음의 하위 행(발화 묶음당 1회 — 대표 행에만 문구).
- **주소 조합 대표 문구 = `찾아오기 쉬워졌어요 📍`로 통일** — 상세주소 전용 문구(`층·호수까지…`) 9곳 제거.
- ⚠️ **44건 문구는 사용자 검토 전** — 어색한 것 짚어주면 수정하기로.

### F. 4-7 리액션 섹션 재편 (위치 분리 해소)

옛 「🎨 반응·마일스톤 이모지」 + 「🧩 리액션 패턴 문구」 두 절 → **「🎨 리액션(방금 채움) 문구 — 수제 · 패턴 · 이모지」 한 섹션**으로 통합: 두 층 표(Ⓐ 수제 우선 / Ⓑ 패턴 폴백) → Ⓐ 수제 작법 → Ⓑ 패턴 2계열+예외 → 이모지 팔레트 10종 → 공통 규칙 → 마일스톤. `_SPEC`의 앵커 참조 2곳 갱신.

### G. 필수/선택 정정 — 판정 규칙 ⑤ 신설

- **「별도 인풋으로 그려지는 칸 = 필수」** — 필수/선택의 목적은 조합형 인풋의 `이건 없어요`→`다음` 버튼 전환 결정. 히어로 제목/설명은 각각 별도 인풋 → 둘 다 필수. 「선택」은 **한 부품 안의 부가 필드**(상세주소·종료일·제품 부가 행)에만.

| 변경 전 | 변경 후 |
|---------|---------|
| 히어로 · 설명 20곳 = 선택 | **전부 필수** |
| 279칸 = 필수 236 · 선택 43 | **필수 256 · 선택 23** (재집계 검증 완료) |

### H. 히어로 제목 = 항상 채움 「AI」

- 25주제 전부 **히어로 · 제목/설명 채움 = AI** (사실이던 16행 → AI · ① 페이지 설명에 재료가 반드시 있어 항상 지을 수 있음. 단 제목 안 사실 조각은 지어내지 않음).
- AI 칸 규칙(반응 없음)에 따라 그 16행 리액션 → `—`. **히어로 단계는 리액션 없는 단계**가 됨 — 첫 리액션은 메인 이미지·로고 업로드.

### I. 기타 정리

- 무거운 소식(6-①) 빈 칸 처리 = 담백 수제 → **효과형**(`유의사항이 확실해졌어요` · 이모지 ❌).
- `_SPEC` 아래쪽에 남아 있던 옛 「복수 항목 반응 없음」 stale 2곳 정리.
- 무거운 소식 예시 확인(4-4): 폐업·마지막 영업 · 이전 · 휴관·중단 · (확장) 리콜·사과문 · 타 용건의 모집/행사 취소. 중간 톤 = 감사장·연하장·공지.

## 핵심 설계 결정사항

- **리액션 = 「미충족 → 충족」 전환이 아니라 입력 부품별 「완료」 시점** — 이선호가 부품별로 직접 정의(업로드 완료 · picker 마지막 선택 · [다음] 클릭 · 반복 = 필수 전부 입력 후 focus 해제). 주소 충족 판정(검색 선택 완료)과 리액션 시점([다음])은 **별개**.
- **패턴 수식어의 단일 기준 = 「항목 1개만 봐도 참」** — 반복 항목 리액션이 첫 항목 시점이기 때문. 이 기준으로 알찬·풍성한·꼼꼼한·탄탄한 전부 기각되고 흥미로운·친절한·눈에 띄는·믿음이 가는이 채택됨.
- **필수/선택 분류의 존재 이유 = 조합형 버튼 전환** — 그래서 별도 인풋 칸은 무조건 필수(히어로 제목/설명). 「선택」은 한 부품 안의 부가 필드 전용.
- **히어로 카피는 AI가 항상 지을 수 있다** — ① 페이지 설명이 항상 있으므로. 결과적으로 히어로 단계는 리액션 없는 단계.
- **문서 이중 정본 유지** — 4-7(풀버전) ↔ `_SPEC.md`(작성 규칙 요약)를 매 결정마다 양쪽 동기화. `_SPEC`은 이선호도 직접 수정 중(마일스톤 자동 배치·의문사형 정리 등) → 작업 전 diff 확인 필수.
