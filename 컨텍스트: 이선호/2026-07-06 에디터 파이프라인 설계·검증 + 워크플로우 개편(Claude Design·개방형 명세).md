### 🔑 핵심 인사이트 / 재사용 스크립트 (다음 세션 필수)

#### 1. ⭐ F1 수정 영속화 = 참조 mutate + reorder-commit
정렬버튼·패널 컨트롤 트리거(synthetic `.click()`·real `$B click` **둘 다**)는 **커밋 안 됨**(리로드 원복). 검증된 정답:
```js
// (1) block 참조 회수 후 style/content 직접 mutate
var blk = window.__cdbd.blockById('<id8prefix>');
blk.style.fontSize = '40px';
blk.content = blk.content.replace(/font-size: ?[0-9.]+px/g, 'font-size: 40px'); // 텍스트는 content(Lexical) inline도 필수
```
```bash
# (2) reorder 라운드트립으로 커밋(autosave) — bash sleep 필수(동기 2회 ❌)
$B js "window.__cdbd.reorderCard(0,1)"; sleep 1.3
$B js "window.__cdbd.reorderCard(1,0)"; sleep 1.3   # 순서 원복 + 커밋
```
원리: `onDragEnd`가 `n({...l, blocks:u})`로 **실제 blocks 배열(내가 바꾼 참조 포함)을 재직렬화·autosave**.
**설계 함의:** 참조 mutate + 단일 commit이라 **카드별 선택 불필요** → 모든 diff 배치 mutate 후 1회 commit이 최적. "수정=카드별"의 선택-최소화 근거 약화(이미지 업로드 등 패널 필요 수정만 예외).

#### 2. 텍스트 디자인은 2곳에 저장
`block.style`(카드 기본) + `block.content`(Lexical) 안 text 노드 inline `style` + `format`(**1=Bold**). 5025 실카드에서 실제 divergence 관측(`gounDotum` vs `gounBatang`), **렌더는 content 우선**. → V1 비교·F1 수정 모두 **content 기준**.

#### 3. dumpState() / blockById() (드라이버 신규 메서드)
- `window.__cdbd.dumpState()` → `{blocks:[full block...], total, captured, missing, theme}`. 전 카드 full block(style·content·title), sortable 순서, theme(패널 닫히면 null).
- `window.__cdbd.blockById('<id8>')` → block 객체 참조(수정용).

#### 4. kebab(•••) 메뉴 = hover 필요 (`openKebab` 한계)
`openKebab`이 "no-kebab-button" 반환 → kebab은 **hover 시에만 렌더**. 우회:
```js
var row = /* boardRows()에서 id로 찾은 행 */;
['mouseover','mouseenter','mousemove'].forEach(function(ev){row.dispatchEvent(new MouseEvent(ev,{bubbles:true,clientX:row.getBoundingClientRect().right-20,clientY:row.getBoundingClientRect().top+25}));});
[...row.querySelectorAll('button')].pop().click(); // 마지막 버튼 = kebab
// → menuClick('카드 복제하기'/'카드 삭제하기') → confirmSwal()
```

#### 5. 로그인 (5025 등 진입 시)
editor URL 진입 시 `/login` 리다이렉트되면: `$B fill 'input[name=email]' "$CDBD_EMAIL"` + `$B fill 'input[name=password]' "$CDBD_PASSWORD"` (`.env`) → `[...document.querySelectorAll('button')].find(b=>b.textContent.trim()==='로그인하기').click()`.

#### 재사용 기법 — CdBd 빌트인 컴포넌트 간격 실측 (신규)
- 기능 고정 카드(위치·프로필 등) 내부 간격은 **문서 추정 ❌ → 라이브 에디터 DOM 실측**이 정답.
- 방법: 에디터(예 4856) 열고 카드 root `getComputedStyle` → **`rowGap`(flex gap) 직접 읽기**. `getBoundingClientRect`는 프리뷰 CSS scale 영향 → scale 검출(transform matrix) 보정하거나 **flex rowGap 우선**. 위치 카드 root = `display:flex·flex-col·rowGap:16px·padding 0` (scale=1 검증).
