- **어드민 활성본 읽기**: 프리뷰 도메인 로그인(비밀번호 칸 Enter) → `/admin/ai/assembly-docs` → 슬롯 버튼을 `textContent`로 찾아 `.click()` → 2.5초 뒤 `document.querySelector('textarea').value`(frontmatter 포함 전문) · 활성 시각 = `body.innerText`의 `버전 (N) active …자 YYYY-MM-DD hh:mm:ss`.
- **Keynote**: 빈 글 상자는 비우면 높이가 커지고 위로 밀린다 · 레이아웃 기본 자리(크기 0 글 상자)는 지울 수 없다(지우기 루프는 `try`로) · AppleScript 변수 `best`는 Keynote 예약어 · `tell` 안에서 만든 함수는 `my mn()`로 부른다 · 슬라이드 확인 = `export … as slide images` · 사진 교체 = `set file name of image N`(틀 크기 유지 → 틀 비율로 만들어 넣기) · 22pt 본문은 한 줄 약 50자.
- **이미지 처리**: PIL은 `/Library/Developer/CommandLineTools/usr/bin/python3`에 있다(`-I` 붙이면 못 찾음 — 작업 폴더를 스크립트 폴더로 두고 실행) · ffmpeg 없음 → `sips` · BMP 파싱으로 대체.
