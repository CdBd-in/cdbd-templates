## 1부 — 2인 분담안 → 공유 보드

**산출물**: Figma 「AI 마케팅 콘텐츠」 › `*Sketch` 페이지 보드 — [열기](https://www.figma.com/design/mPZeaG9PJVJkbZZS83b7o1/AI-%EB%A7%88%EC%BC%80%ED%8C%85-%EC%BD%98%ED%85%90%EC%B8%A0?node-id=10004-31) (상태 = 「초안 · 팀 논의용」) · [[4-15. 시즌 템플릿 루프]] §1 🔑 · §3-1 👤 역할 · §5-1 🤖

### 결정 흐름
1. **첫 분담안이 이야기(마케팅) 쪽으로 쏠림** → 이선호 「템플릿도 굉장히 중요 · 누락됐다」 → 4-15 §1 🔑(계획 · 분담 · 일정도 목표 순서대로).
2. **결과물 정의** — 3개(템플릿 · AI 원안 · 이야기) → 이선호가 요약을 직접 고침(① 템플릿 ② 마케팅 콘텐츠 ③ 개선 사항 아카이빙) → **「소재 선정」을 맨 앞에 추가 = 4개**. 카드 번호 = 요약 순서, 시간 순서는 「흐름」 줄로 따로. 개선 사항 아카이빙 = **수시 · 모든 결과물의 피드백**(빌더 수정 기록만이 아님).
3. **역할 — 3번 바뀜**
   | 라운드 | 내용 |
   |---|---|
   | ① 첫 안 | 이선호 = 기준 · 템플릿 끝까지 / 강현이 = 알리는 사람 → 3기 운영 |
   | ② 이선호 요약 수정 | 1기 함께 · 2기 강현이 제작 + 이선호 검수 · 3기 자동화 |
   | ③ 받은 피드백 반영 · 확정 | 「담당자 두 명일 필요? · 프로세스 정의 = 이선호, 실행 · 고도화 · 관리 = 현이」 → **이선호 = 처음 기획 · 자동화 구축 · 안정화만, 이후 강현이 단독 · 검수 = Claude 채점 + 강현이 승인** → 4-15 §3-1 👤 |
4. **템플릿 제작 = 처음부터 프로그램**(월요일 밤 `s2js.sh`) · 사람은 검수 · 수정만 → 4-15 §5-1 🤖. 이에 따라 보드의 「2기 화요일 밤 시험(낮 결과와 비교)」 폐기.
5. **한 주 흐름** — 요일 5분할 → 이선호 「연결된 일은 하루에」 → 최종: **월(매달 마지막 주) 회고 → 소재 선정 · 월 밤 빌더 자동 실행 / 화 템플릿 검수 · 수정 · 등록 / 수 콘텐츠 · 발행 / 목 격주 뉴스레터(없는 주 = 여유) / 금 비움**. 발행일 목 → 수(목요일은 근거 없이 정했던 날) · 뉴스레터 월 1회 셋째 목 → **격주 목**.
6. **이선호가 지우라고 한 것** — 「두 사람의 역할」 · 「템플릿 확인(바꿔 보기)」 · 「3기 남는 시간」 · 「둘이 주의할 것」 · 「정해야 할 것」 절 · **「바꿔 보기」 표현 전부** · **「사장님」 표현(보드)** · **「스토리 카드」**(→ 마케팅 콘텐츠 「기획」으로 흡수 · 템플릿 쪽엔 「빌더에 넣을 글」).
7. 업무별 분담 표 17줄 → **결과물 4개 묶음 9줄 + 「자동화 구축 · 관리」 1줄**.

### 핵심 인사이트 (규칙은 정본에 기록 — 링크만)
- 🔑 결과물 우선순위가 일정 · 분담에도 드러나야 한다 → 4-15 §1
- 🔑 역할 · 검수 → 4-15 §3-1 👤 · 템플릿 자동 제작 → 4-15 §5-1 🤖
- 🔍 템플릿 채점 루브릭(100점 · 80점)은 [[4-13. 데일리 퀄리티 루프]] §2에만 있고 **어드민 가이드 MD 14개엔 없다**. 축별 규칙 중 **개인화(치환 테스트) · 줄바꿈 고아**는 MD에서 키워드로 못 찾음 → MD 수정 요청 후보(아래 미해결).

## 2부 — 기준 강화 (채점 · 제목 · 소재 선정)

**산출물**: 4-15 §4-1 · §4-2 · §4-4 · §6-6 · §7-2 + 보드 03 「결과물별 채점 기준」(① 소재 선정 · ② 템플릿 · ③ 마케팅 콘텐츠)

### 결정 흐름

2. **소재 점수 정량화 — 2라운드**
   - R1 「검색량 자료 · 뚜렷/보통 · 얇은 칸이 모호」 → 숫자 · 개수 · 출처
   - R2 「한 번도 안 쓰인 것은 0에 수렴 · 소재 새로움도 · 빌더 못 하면 탈락」 → 새로움 = **최근 12회차 대비 소재 · 구성** · 템플릿 목록 빈자리 = **주제당 평균 대비** · 빌더 준비도 → **§4-4 게이트** · 네 질문 8점 · 6점↑ → 4-15 §4-2 🔑
3. **③ 마케팅 콘텐츠 점수 기준 초안**(제목 25 · 본문 40 · 채널 35 + 0층 게이트 · 합격 80) — 보드에만 「초안」, **4-15 미반영**. 「멈출 이유 · 사장님 말」 → 「눈길 끄는 제목 · 제목 기본 규칙」.
4. **소재 소스 — 5라운드 질문** — 박람회만 넣은 이유? → 행사는 검색량으로 통합 / 업계 자료 선정 근거? → 온라인 쇼핑 치우침 → **25주제 「지켜볼 키워드」**로 대체 / 경쟁사 선정 근거 · 왜 템플릿? → 올해 콘텐츠는 늦은 신호 → **작년 같은 시기 SNS 반응(계정 평균 2배↑)만 보조**, 템플릿 목록은 겹침 확인용 / 경쟁사 목록 = **CdBd 가입 설문 「이용해 본 적 있는 서비스」 선택지** → 4-15 §4-1 🔑 「앞을 보는 신호만」.
5. 이선호 받은 피드백 「후보 선정 기준 필요 · 추후 후보부터 채택까지 AI 자동화」 → §4-1 **후보 형식 · 채택 · 자동화 3단계**.
