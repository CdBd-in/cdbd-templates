### WCAG 검증 스크립트 (재사용)
```python
def relative_luminance(hex):
    hex = hex.lstrip('#')
    r, g, b = (int(hex[i:i+2], 16)/255 for i in (0,2,4))
    f = lambda c: c/12.92 if c <= 0.03928 else ((c+0.055)/1.055)**2.4
    R, G, B = f(r), f(g), f(b)
    return 0.2126*R + 0.7152*G + 0.0722*B

def contrast_ratio(bg, fg):
    L1, L2 = relative_luminance(bg), relative_luminance(fg)
    return (max(L1,L2) + 0.05) / (min(L1,L2) + 0.05)
# 등급: AAA≥7 / AA≥4.5 / AA-Large≥3 / 유지 임계값=3.6
```

#### 🚨 자동화 시행착오 — 다시 반복하지 말 것 (근거·증거)
1. **"last contenteditable" = 인사팀 버튼 텍스트** — mobile preview 모든 카드가 `contenteditable`. y정렬 last = 페이지 최하단(인사팀 버튼). 4회 반복 시 의도 텍스트가 인사팀 버튼에 덮어써짐. → 새 카드 고유 토큰 매칭 또는 선택 상태(녹색 외곽선) 카드 내부 contenteditable 찾기.
2. **카드 추가 모달 누적 오픈** — 텍스트 카드 클릭 실패(viewport scroll) 시 모달 열린 채 다음 사이클 진입 → ensure-modal 패턴 ❌, 명시적 닫힘 확인.
3. **모달 X 닫기 = absolute DIV (button 아님)** — `document.querySelector('div.absolute.right-\\[24px\\].top-\\[30px\\]').click()`.
4. **카드 라벨 ✏️ pencil 우발 활성화** — 증거: 이미지 카드 라벨 "이미지" → "2026 ABC 컴퍼니 채용..."(다른 사이클 타이핑 유입). → 라벨 텍스트 영역(span x=702 부근) 회피.
5. **우측 패널 input이 React state로 안 들어감** — `descriptor.set`+`dispatchEvent('input')` → "값 입력해주세요" 에러. react-hook-form ref 기반. → `$B fill` (Playwright = keyboard 시뮬레이션).
6. **Reload 시 일부 값 손실** (mailto 링크) — 자동저장 blur 트리거 가설. → input 변경 후 `dispatchEvent(new Event('blur', {bubbles:true}))`.
