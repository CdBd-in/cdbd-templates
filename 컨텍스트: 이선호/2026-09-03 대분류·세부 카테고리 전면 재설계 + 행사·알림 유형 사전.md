**② "초대장만 MECE로 최대한 많이"** → 리서치 6건 병렬 실행 (아래 3부)
→ 1차 결과 = **88종, 주최(누가 부르나) 기준 7그룹**.

**③ 🔴 이선호 지적: "단순히 내용이나 무드가 다른 게 아니라 「구성」이 달라야 다른 유형"**
→ **1차 분류 전면 폐기.** 주최 기준은 톤·문구만 바꾸고 카드 구성은 동일 (창립기념식과 졸업식은 주최가 달라도 구성이 같다).
→ **구성 기준 재분류**: 「이 페이지에서 가장 큰 자리를 차지하는 블록(결정 블록)」이 유형을 결정.

**결정 블록 = 유형 13개**
`① 주인공 인물 → 인물 축하형` `② 장례 정보 → 부고·추모형` `③ 본문 글 → 고지형` `④ 기간+볼거리 → 오픈·기간형` `⑤ 식순 → 의식·식순형` `⑥ 연사·세션 → 연사·세션형` `⑦ 회신 폼 → 회신형` `⑧ 준비물·이동 → 준비 안내형` `⑨ 회차 버튼 → 예약형` `⑩ 티켓·좌석 → 티켓형` `⑪ 모집 요강 → 모집·신청형` `⑫ 부문·시상 → 대회·공모형` `⑬ 폼만 → 신청·취합형`

**옵션 블록(유형을 안 가름)**: 지도 · 갤러리 · 계좌 · 문의 · 유의사항 · FAQ · 첨부 · **개인화**
> 🔑 **개인화는 유형이 아니라 「전달 방식」**(수신자마다 다른 링크). 현행 `A③ 개인화 초대장`을 독립 세부로 둔 게 분류 오류였다.
> 🔑 **계좌도 옵션 블록** — 인물 축하형·부고형·모집형에 두루 붙는다.

**④ 🔴 이선호 지적: "부고 같은 부정적 소식은 '초대' 키워드와 안 맞는다"**
→ **말투 그룹 3갈래 신설** (구성 13유형 위에 얹는 톤·이름 층)
| 갈래 | 해당 유형 |
|---|---|
| 🎉 **초대** "와주세요" | 1·4·5·6·7·10 |
| 📢 **알림** "알아두세요" | **2 부고·추모** · 3 고지 · 8 준비 안내 |
| 📝 **접수** "알려주세요" | 9·11·12·13 |
→ **「알림」 톤 규칙**: 축하 표현 ❌ · 무채색 · 이모지 ❌ · 버튼 "조문 안내"
→ **AI 문구 규칙**: 「이 내용에는 **부고장**을 추천해요」 — **「초대장」으로 뭉뚱그리지 않는다**
> ✅ **리서치가 이 지적을 뒷받침**: 국내 모바일 초대장 서비스 **12곳 전수 확인 결과 부고/상조는 어디서도 「초대장 카테고리」 안에 없다. 항상 별도 사이트·별도 서비스.**

  - 테스트: **프리랜서 스튜디오 페이지 = 3번** (「스튜디오」라 말한 순간 상호를 내건 사업체 · 서비스·가격·위치·예약이 들어감)

├ P1 홈    갤러리 소개·현재 전시

├ P3 작품   ← 6번(도록) 유형

- **Eventbrite = 조건부 섹션 스택** — 항상 나오는 블록 + 주최자가 채우면 나오는 블록(Lineup·Agenda·FAQ). **해외 유일의 참고 정본**
- **컨퍼런스형 섹션(연사·타임테이블·참여기업·혜택)은 이벤터스 30만원 상위 요금제 기능** → CdBd는 기본 제공 가능 = 가치 제안
- **국내에선 「랜딩페이지」·「상세페이지」가 실무자끼리도 안 통함**(아이보스 댓글 16건 전부 어긋남) → **비디자이너 라벨은 반드시 목적 문장형**
- **네이버 모두 종료(2025-06-26)** — 소상공인 무료 페이지 수요가 고아 상태 = 3번 대분류의 최대 유입 기회
- **인포크링크 「스마트 등록」** — 공동구매 일정 이미지를 올리면 AI가 인식해 자동 등록. **우리 새 플로우와 같은 발상이 이미 국내에 실사용 중**
- **CdBd 카드에 없는 블록**: 방명록 · BGM · 생중계 · 화환 주문 · 하객 사진 공유 · 리마인더 · 감사장 자동 전환 · 대기자 접수 · 승인제 등록 · 쿠폰 · 참가자 CSV · Q&A 게시판 · 뉴스레터 구독 · 프로모션 코드 · 후기(소셜프루프) · 파일 다운로드+리드수집

### 리서치 방법 메모 (재사용)
