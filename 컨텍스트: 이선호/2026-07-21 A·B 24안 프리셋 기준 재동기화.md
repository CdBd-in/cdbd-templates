## 재사용 스크립트·패턴 (Figma MCP 기술 메모)

1. **구조 읽기 walk**: `getStyledTextSegments`로 텍스트 속성 + `layoutMode` 패딩 + `fills`(bg%)·`strokes`(bd) 플래그. 프레임 3개까지 한 호출(depth 4~5, 짧은 preview)로 읽으면 truncate 안 남. **B② 3개 한 번에 읽었더니 truncate** → 큰 프레임은 2개씩.
2. **S-Core 변환**: `loadFontAsync(7 ExtraBold)` + `4 Regular` → `root.findAll(TEXT)` → 6 Bold 세그먼트 `setRangeFontName(→7 ExtraBold)`. (6 Bold 미로드여도 성공)
3. **패치 = property set + atomic**: 여백은 `n[k]=v`, 크기는 단일런 `n.fontSize`, 혼합런 `setRangeFontSize(by fontSize/family)`, 투명도는 fills clone+opacity, 줄간격 `{unit:'PERCENT',value}`. 실패 시 전체 롤백이라 안전.
4. **바 제거**: 구분선 프레임 `.remove()`. 그 뒤 타이틀 프레임 pb0→8, 다음 카드 pt→8.
5. **지도 비율**: 「지도 임베드/지도 이미지」 텍스트 자식 가진 박스 or 이름에 「지도」 → `ratio=w/h`, `to11 = |r-1|<=|r-1.5|` → h=`w` 또는 `round(w*2/3)`, FILL 폭이면 resize 후 `layoutSizingHorizontal='FILL'` 재설정.
6. **함정**: 리스트 아이템 텍스트 노드 ID 착오(FRAME에 `getStyledTextSegments` 호출 → 에러, 원자적 롤백). 노드 ID는 read에서 확인.
