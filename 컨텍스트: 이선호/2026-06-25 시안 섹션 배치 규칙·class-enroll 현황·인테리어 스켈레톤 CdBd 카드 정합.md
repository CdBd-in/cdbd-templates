## Figma MCP 기술 메모

1. **`mcp__figma-desktop__*`(get_metadata/get_screenshot)는 데스크탑 활성 탭 의존** — 다른 파일/탭이면 "node not found". **`mcp__claude_ai_Figma__get_screenshot`/`use_figma`는 fileKey 인자로 직접 접근**(레퍼런스 다른 파일 읽을 때 유리).
2. **get_metadata 출력이 토큰 초과**(60k+)면 파일로 저장됨 → jq로 슬라이스. 구조만 필요하면 `use_figma`로 필요한 필드만 walk해서 return이 더 효율적.
3. **텍스트 노드의 `textAlignHorizontal`·`fills` 변경도 폰트 로드 필요** — characters뿐 아니라. `getStyledTextSegments(['fontName'])`로 현재 폰트 로드 후 mutate.
4. **clone() = 폰트 로드 불필요**(텍스트 mutate 안 하면). 기존 버튼/카드 복제로 스타일·폰트 정확 재현(2단 버튼 카드를 P5 outline 버튼 클론으로 제작).
5. **DS 마스터 파일(`ZSRFVPLU8wl86ZBvpccgYA`) 프리뷰 컴포넌트 노드(14880:*)는 stale/not found** — 카드 내부 고정 스펙은 마크다운 카드 정의 문서가 더 신뢰성 있음.
6. **라이브 공개 페이지(cdbd.in/2account/...) DOM 스크래핑 불안정** — Next.js SSR 하이드레이션 스크립트(`__next_f`)가 잡힘. 카드 보드/라벨은 **에디터 페이지**가 안정적.
