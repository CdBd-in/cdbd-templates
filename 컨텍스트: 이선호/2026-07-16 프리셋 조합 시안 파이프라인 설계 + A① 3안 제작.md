## 핵심 설계 결정사항

- **🔑 세 축 발견 — 통일 / 차별화 / 위계**: 8항목은 **같게**(페이지 안), 차별화 레버는 **다르게**(시안 사이). **어느 쪽도 「한 시안 내부의 강약」을 안 본다** → 통일만 강화하면 **균일한 회색 죽**. 안1이 8항목 전부 통과한 채 단조로웠던 게 증거.
- **⚠️ 차별화와 위계는 상충**: 안1을 안3과 벌리려 **이미지 0장**(축③)으로 밀고 통일한다고 **구분선 제거** → 강약 수단이 1개만 남음. **레버를 당기면 그 축이 담당하던 강약도 죽는다.**
- **⚠️ ①주제에서 색 뽑기는 3안을 수렴시킨다**: 같은 주제라 같은 재료로 감 → 안1·안3이 둘 다 "다크+웜 앰버"로 붙음. **①을 지키면 ⑤중복회피가 더 중요해진다.**
- **🥇 값 통일 > 시각 균일 (둘 다 얻는 법)**: 시각만 역산하면 카드마다 값이 제각각 → **유저가 카드 하나 지우면 리듬 붕괴**(= 최우선 원칙 위반). `타이틀 하단=PAD` + `본문 첫 카드 상단=PAD` 대칭으로 두고, **안쪽 래퍼의 자체 상단여백을 0으로 몰아** 시각도 균일하게.
- **무드 3안 다르게 확정**: 1-9 ⑤ 채택. ⚠️ 1-8 「디자인 결정」의 *"무드까지 얽을 필요 없음"*과 상충 → **문서 정합 미결**(스펙 §12).
- **시안 조립 위치 = 프리셋 파일 안**: Figma 자동화가 한 번에 한 파일만 다뤄 **파일 건너뛴 복사 불가** → 같은 파일 「조합 테스트」 페이지에서 조립. **원본 훼손 위험**이 생기므로 D2 철칙 = 복제만.

## 🚨 내가 반복한 실패 (다음 세션이 같은 함정을 피하도록)

> **규칙을 아는 것과 지키는 것은 다르다.** 아래는 전부 **규칙이 있는데 내가 안 지킨** 사례.

1. **가드 절 때문에 통일 실패 — 2회**
   - 모서리: `if (cornerRadius !== 0)` → **이미 0(각진)인 카드를 건너뜀** → 안3 나열 5개 각진 채 잔존
   - 좌우 여백: `if (paddingLeft === 20)` → **16·14인 프레임을 건너뜀** → 규칙을 **적은 당사자가 몇 시간 만에 재발**
   - → **「기존 값 무관, 전부 목표값」**. 0은 "값 없음"이 아니라 **"각진"이라는 값**.
2. **측정 실패를 "통과"로 처리** — 안3 INVITATION 거리가 `null`로 나왔는데 **조용히 건너뜀** → 38px 방치. CLAUDE.md의 *"검증 실패를 문제 0건으로 오판"* 함정과 **같은 종류**.
3. **판정을 규칙보다 느슨하게** — 안2 위치안내의 선 2개를 **"이게 기본 언어"**라 부르며 통과시킴. 그 선을 쓰는 섹션이 **하나뿐**이었는데도. → **표본 1개는 언어가 아니다.**
4. **원본에 없는 속성 창작** — 타이틀 `11px`·`16px {텍스트색}`·`20px`는 **어느 서랍에도 없는 값**. 원본 실측 = `12/14/18/22`.
5. **구조 찌꺼기** — 알약 배경만 지우고 **빈 래퍼 2겹**을 남김 → 패딩(하단16)이 거리를 32로 밀고 **타이틀이 섹션 직계가 아니게 되어 측정까지 깨짐**.
6. **런별 색 누락** — 한 텍스트에 두 색이 섞이면 `fills`가 `figma.mixed` → `Array.isArray` 검사에서 **조용히 건너뜀**(안2 프로그램 퍼플 잔존).
7. **테두리 카드를 못 봄** — `visible()`이 **채움만** 검사 → 안2 문의의 **실제 거리 0**을 "16 통과"로 오판.

## Figma MCP 기술 메모

1. **런별 색 교체** — 텍스트에 색이 섞이면 `node.fills === figma.mixed` → `Array.isArray(n.fills)`가 **false**. `getStyledTextSegments(['fills'])` + `setRangeFills`로 처리해야 함. **안 하면 조용히 건너뜀.**
2. **「보이는 것」 판정** — TEXT · 채움 있는 박스 · **테두리만 있는 박스(채움 없어도!)** · 높이 ≥1. 채움만 보면 **테두리 카드를 놓친다.**
3. **타이틀 거리 측정** — 타이틀에서 **위로 올라가 「섹션 직계 조상」**을 찾아야 함(래퍼가 몇 겹일지 모름). **보이지 않는 형제**(높이 0 여백 카드)는 건너뛰고 다음을 볼 것. **`null` = 「통과」가 아니라 「미측정」.**
4. **텍스트 노드 이름은 stale** — `characters`를 바꿔도 layer name이 안 따라옴(예: 이름이 "바람이 지나가는 자리를 옷"인데 내용은 다름). **이름으로 내용을 판단하지 말 것.**
5. **프리셋 원본 보호** — 시안을 **같은 파일**에서 조립하므로 반드시 `clone()` 후 「조합 테스트」 페이지로. 스타일 서랍은 **읽기 전용**.
6. **use_figma는 한 번에 한 파일** — 파일 간 노드 복사 불가. `setCurrentPageAsync`는 **호출당 1회**.
