```js
// Figma plugin
const ratio = node.height / node.fontSize;
const target = Math.max(100, Math.round(ratio * 10) * 10);  // 10% 단위 snap, 최솟값 100
await figma.loadFontAsync(node.fontName);
node.lineHeight = { unit: 'PERCENT', value: target };
```

## 3부 — 여백 우선순위 원칙 진화

### 3-1. 결정 흐름 (라운드)
1. **R1 (이전 세션 정립)**: "상/하 symmetric 우선, 어쩔 수 없으면 spacer 카드". 프로필↔일시 간격 20을 (24,4,20,20) + spacer 20 + (4,4,20,20)로 작성.
2. **R2 (이번 세션 사용자 피드백)**: "프로필↔일시 간격은 프로필 하단 여백으로 옮겨도 될 것 같아. **앞으로 여백은 상하좌우 비슷하게, 불가능한 경우만 예외적으로 구분선(여백) 카드 사용**"
3. **R3 (룰 진화)**: 3순위 규칙으로 재구성
   - **1순위 — 4면 비슷한 padding** (top≈bottom≈left≈right). 인접 카드 padding 합이 시각 간격 형성. spacer 없음.
   - **2순위 — top=bottom symmetric** (4면 비슷 불가능할 때만).
   - **3순위 — 여백 카드 (예외)**: intra-section 미세 분리(4~8)처럼 padding으론 표현 어려운 경우만.
   - **🟢 페이지 최상단/최하단 카드는 비대칭 padding OK** (인접 삭제 위험 없음 → page-top/bottom 흡수).

### 3-2. 변환 예시 (구버전 → 신버전)
| 케이스 | ❌ 구버전 (symmetric+spacer) | ✅ 신버전 (4면 비슷) |
|---|---|---|
| 프로필↔일시 (섹션 간 20) | 프로필 (24,4,20,20) + spacer 20 + 일시 (4,4,20,20) | 프로필 (24,**24**,20,20) + 일시 (4,4,20,20) — spacer 제거 |
| 페이지 첫 카드 (로고) | top spacer 40 + 카드 (8,16,40,40) | 카드 (**40**,16,40,40) — 카드 top 흡수 |
| 페이지 마지막 카드 (버튼) | 카드 (12,8,40,40) + bottom spacer 36 | 카드 (12,**36**,40,40) — 카드 bottom 흡수 |
| 분할 텍스트 카드 사이 (intra 4~8) | 카드1 (8,4,20,20) + 카드2 (4,8,20,20) ❌ 비대칭 | 카드1 (4,4,20,20) + **여백 카드 4** + 카드2 (4,4,20,20) |

### 4-2. 카드 padding setter
```js
function setCardPadding(card, t, b, l, r) {
  card.paddingTop = t; card.paddingBottom = b;
  card.paddingLeft = l; card.paddingRight = r;
  card.itemSpacing = 0;
}
```

### 4-3. 여백 카드(spacer) — Figma 표현
```js
function makeSpacer(name, h, w) {
  const sp = figma.createFrame();
  sp.name = name;                  // e.g. "여백 — 섹션 구분"
  sp.fills = [];
  sp.layoutMode = 'VERTICAL';
  sp.paddingTop = sp.paddingBottom = sp.paddingLeft = sp.paddingRight = 0;
  sp.itemSpacing = 0;
  sp.primaryAxisSizingMode = 'FIXED';
  sp.counterAxisSizingMode = 'FIXED';
  sp.resize(w, h);
  return sp;
}
```

### 4-4. 텍스트 카드 split (한 카드 → 속성별 N개)

## 9부 — 🥇 파일 업로드 자동화 (CdBd 라이브러리 dropzone React onDrop)

**산출물**: 라이브 에디터 4856 OG 이미지 적용 완료 · [[../1. 작업 가이드/1-4-1. 에디터 페이지#함정 23: 파일 업로드는 React 합성 이벤트로 onDrop 핸들러 직접 호출 (2026-06-19 기록)]] · CLAUDE.md 자동화 트러블슈팅 표 + 매트릭스 업데이트

### 결정 흐름 (5라운드 시행착오)
1. `$B upload` 직접 업로드 → DOM에 영구 file input 없음, 실패
2. `document.createElement('input')` 후킹 → React 자체 경로 우회, 캡쳐 안 됨
3. `HTMLInputElement.prototype.click` 후킹 + DataTransfer → React 합성 이벤트와 다름, 미작동
4. Playwright `$B click` 실제 click → OS 파일 다이얼로그 대기로 timeout
5. **(성공) 이미지 라이브러리 모달의 dropzone div(`div.border-dashed`)에 React `onDrop` props 발견** → `props.onDrop({preventDefault, stopPropagation, dataTransfer: dt, target, currentTarget})` 직접 호출 → 즉시 업로드 처리됨

### 핵심 인사이트 (영구 룰)
- CdBd 파일 업로드 UI는 **react-dropzone 류** — dropzone div React props에 onDrop
- 합성 이벤트의 `dataTransfer` 필드만 진짜 `DataTransfer`면 핸들러 안 `e.dataTransfer.files` 정상 접근
- OS 파일 다이얼로그 완전 우회 → Playwright timeout 회피
- 7-step 시퀀스: 트리거 onClick → 라이브러리 dropzone onDrop → 적용하기 onClick → 저장하기 onClick

### 재사용 검증 스크립트
```js
// Bash에서: B64=$(base64 -i file.jpg) → $B js로 inject + onDrop 호출
window.__OG_B64 = "{base64...}";
const bin = atob(window.__OG_B64);
const bytes = new Uint8Array(bin.length);
for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
const blob = new Blob([bytes], {type: 'image/jpeg'});
window.__OG_FILE = new File([blob], 'og.jpg', {type: 'image/jpeg'});

// 1. 트리거 클릭 (라이브러리 모달 오픈)
const trigger = document.querySelector('...');
trigger[Object.keys(trigger).find(k=>k.startsWith('__reactProps'))].onClick({preventDefault:()=>{}, stopPropagation:()=>{}});

// 2. dropzone 찾기 (React fiber 검색)
const dropzone = [...document.querySelectorAll('*')].find(el => {
  const pk = Object.keys(el).find(k => k.startsWith('__reactProps'));
  return pk && el[pk]?.onDrop;
});

// 3. DataTransfer + onDrop 직접 호출
const dt = new DataTransfer();
dt.items.add(window.__OG_FILE);
const props = dropzone[Object.keys(dropzone).find(k => k.startsWith('__reactProps'))];
props.onDrop({preventDefault:()=>{}, stopPropagation:()=>{}, dataTransfer: dt, target: dropzone, currentTarget: dropzone});

// 4. 라이브러리에 alt=파일명 IMG 추가됨 → 적용하기 버튼 onClick
const ogImg = [...document.querySelectorAll('img')].find(i => i.alt === 'og');
let card = ogImg.parentElement;
for (let i = 0; i < 5; i++) {
  const btn = [...card.querySelectorAll('button')].find(b => b.textContent?.trim() === '적용하기');
  if (btn) { btn[Object.keys(btn).find(k=>k.startsWith('__reactProps'))].onClick({preventDefault:()=>{}, stopPropagation:()=>{}}); break; }
  card = card.parentElement;
}

// 5. 부모 모달 저장하기 onClick → "URL 정보가 저장되었습니다." 토스트
```

### 자동화 가능 범위 확장 (매트릭스 업데이트)
- 이미지 업로드 (로고/OG/카드 이미지·썸네일) — ❌ → **✅**
- OG 이미지 설정 (URL 정보 편집 모달) — ⚠️ 부분 → **✅**
