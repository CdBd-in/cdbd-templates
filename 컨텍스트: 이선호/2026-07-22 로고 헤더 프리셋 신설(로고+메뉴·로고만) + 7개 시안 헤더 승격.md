## 1부 — 로고 헤더 프리셋 신규 (헤더 12→17종)
**산출물**: [[../1. 작업 가이드/1-8. 섹션 프리셋 라이브러리]] (헤더 항목 · [Figma 3311-10135](https://www.figma.com/design/24O01lprp5i2ufl7CbZXXx/CdBd-%ED%85%9C%ED%94%8C%EB%A6%BF--%EC%84%B9%EC%85%98-%ED%94%84%EB%A6%AC%EC%85%8B?node-id=3311-10135))

### 결정 흐름
1. **발견**: 기존 헤더 7종 = 전부 **텍스트 브랜드명 + 메뉴 아이콘**(로고 이미지 헤더 원본 ❌). 조립 레시피 도식엔 `[헤더: 로고]`로 표기돼 있으나 실제 프리셋은 텍스트였음.
2. 이선호 결정 → **로고 헤더를 프리셋에 신규 추가**.
3. 기존 2단 헤더 5종을 클론 → 좌측 텍스트를 **로고 placeholder**(변주별 전경색 대비 맞춤)로 교체 = **ⓑ 로고+메뉴형 5종**.
4. 이선호 지시(원페이지엔 메뉴 아이콘 무의미) → 로고+메뉴형 클론 후 아이콘 제거 = **ⓒ 로고만형 5종**.

### 핵심 (영구 룰은 1-8에 기록, 여기선 링크만)
- 헤더 = **ⓐ 텍스트형 7 + ⓑ 로고+메뉴형 5 + ⓒ 로고만형 5 = 17종**. 배경 변주 5(화이트·배경색·틴트·버튼색·텍스트색) 공통.
- 🧭 **메뉴 아이콘 = 멀티페이지·상시 이동 액션 있을 때만**(원페이지=로고만형). → 1-8 헤더 항목.

### 판단 기준 (이선호 "일부만, 3안 중복 없이, 너가 판단")
- 승격 대상 = **로고가 히어로 최상단 스트립(index0)**인 것만 → 중복 0. (판정법·금지 케이스는 1-8 「승격 패턴」)
- **유형별 3안 중 1스타일만** 적용(나머지 2안 헤더 없이 = 차별화). C 3 + D 2.
- 제외: **에디/볼드 다수**(로고가 큰 이미지 히어로 아래 index1 → 중복) · **B 프로필·명함 12안**(인물=브랜드).

### 재사용 스크립트 (승격 1안 처리 · use_figma)
`frame.children[0]`=히어로 → `[0]`=로고 스트립. 로고노드 clone(placeholder 텍스트 자식 제거) → h22 비율 유지. 헤더 = VERTICAL AL(bg=프레임 fill) + 배너(HORIZONTAL px18 py12, 로고셀 FILL) + 구분선(rect, 헤드라인 텍스트색×20% FILL). `frame.insertChild(0, header)` 후 `header FILL` → `strip.remove()`. **구분선 텍스트색은 placeholder("로고" 회색 0.549) 말고 헤더 제외한 최대 fontSize TEXT의 fill로.**
