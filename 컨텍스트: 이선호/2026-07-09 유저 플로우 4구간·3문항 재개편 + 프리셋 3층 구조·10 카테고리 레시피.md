## 2부 — 프리셋: 목적 13칸 확정 → 멀티 적용 검토 → 3층 구조 + 10 레시피

**산출물**: [[1. 작업 가이드/1-8. 섹션 프리셋 라이브러리]] (3층 구조 + 10 페이지 카테고리 레시피) · [[CLAUDE.md]] 1-8 줄(목적13칸·3층)

### 결정 흐름
1. **섹션 목적 13칸 = 정본** (직전 확정본을 이번에 CLAUDE.md까지 동기화). 표현/기능형=배리에이션 방식 라벨(개방8/정원5) · 카테고리=섹션 서랍 아님(태그+조립).
2. **멀티페이지에 13칸 적용 검토 → 그대로 유효.** 섹션 "목적"은 페이지 수와 무관(히어로는 어느 페이지든 히어로 · 오히려 재사용↑). 유일한 신규 = **내비게이션**(표지 목차·서브페이지 복귀 헤더) → **13칸 아님, 구조 뼈대(헤더/푸터) 멀티용 확장.** ⚠️ 목차=페이지 이동(구조) ≠ 나열(콘텐츠). 멀티는 조립이 **2단계**(페이지 배분→페이지 내 순서).
3. **"섹션이 아니라 페이지 프리셋이 필요?" → 3층 구조 도출.** 섹션(원자)은 유지, 페이지는 그 위 층. **섹션=목적으로 분류 / 페이지=카테고리로 분류**(층이 달라 "카테고리는 서랍 아님"과 모순 아님). 멀티=페이지+내비. 🔑 아래층이 위층을 **참조**(얼려 복사 ❌) → 세션 초기 "프리셋 폭발" 우려 해소.
4. **카테고리 세분화 반영** — 옛 어드민 5분류 → 유저 플로우 **10 페이지 카테고리**. 1-8 조립 레시피를 5→10개로 교체(목적 순서 표기·원/멀티 가중치·어드민 5분류 대응·유연 기준 유지).

## 3부 — ① 카테고리 세분화 확정: 4 대분류 × 세부 4 (목적 문장형)

**산출물**: [[1. 작업 가이드/1-9. AI 유저 플로우 (제품 설계도)]] ① 카테고리 표 교체(옛 **flat 10-옵션 삭제**) + 참조 2곳(🔑주제/목적·② 생성 원/멀티) 정합.

### 결정 흐름 (flat 10 → 4×4 문장형)
1. **문제 인식** — 1부에서 만든 ① 카테고리 = **업종 명사 flat 10개**(상품 카탈로그·회사 명함…). 업종 축이면 구조가 안 갈려 "색·폰트만 다른 시안" 위험 + 페르소나 누락(가이드·신청 등).
2. **피벗 = 목적 문장형** — 세부를 **업종 명사 → "무엇을 하기 위한" 목적 수식어 문장**으로. 원리: **목적 = 페이지 구조(카드 구성), 업종·주제 = 자유입력**(같은 목적이면 업종 달라도 구조 동일 → 업종·주제는 세부 질문/프롬프트로).
3. **대분류 4** — 초대·예약 / 프로필·명함 / **룩북·카탈로그**(옛 '홍보·카탈로그' 리네임, **상품 전용으로 좁힘**) / 소식·매거진. 어드민 5분류 중 **가이드·신청은 대분류에서 제외**, '가이드'만 D 세부(가이드북)로 흡수.
4. **세부 4씩 큐레이션 (사용자 주도·정정 다회)** — 특히 D(소식·매거진) 후보 5개 중:
   - 브랜드스토리·인터뷰·후기 = "그것만으로 별도 페이지 만들기 드묾" 탈락 · 리포트 = "핵심인 **도식 지표를 커스텀 제공 불가** → 매거진과 차별성 없음" 탈락.
   - **자료·가이드만 채택 → '이용 안내 가이드북'으로 발전** (STEP 순서 + FAQ 구조가 매거진과 차별점 · FAQ = Q&A 카드가 처리).
   - D-3 = 전시 **도록**(작품+캡션+관람안내 · 룩북/포트폴리오와 구분: 도록 = 특정 전시를 기록하는 출판물).
5. **16개 확정 → 1-9 반영, flat 10 삭제.**

### 확정 taxonomy (정본 = 1-9)
| 대분류 (원:멀티) | 세부 4 |
|---|---|
| **초대·예약** (원2:멀티1) | 행사 알림 초대장 · 사전 정보 수집 초대장 · 개인 맞춤 메세지 초대장 · 방문 일정 예약 페이지 |
| **프로필·명함** (원2:멀티1) | 연락처·채널 프로필 · 상담·문의 영업용 명함 · 작업물·이력 포트폴리오 · 매장·브랜드 홈페이지 |
| **룩북·카탈로그** (원1:멀티2) | 상품 상세 페이지 · 컬렉션 룩북 · 바로 구매 판매 페이지 · 메뉴·품목 메뉴판 |
| **소식·매거진** (원1:멀티2) | 공지 페이지 · 매거진 · 전시 도록 · 이용 안내 가이드북 |

- 대분류 원/멀티 = **옛 flat 매핑과 100% 일치** → 1부 생성 로직(답변①로 원/멀티 비중) 그대로 유효.
- ⚠️ 대분류를 A·B·C·D로 부르면 **3안(A·B·C)과 충돌** → 1-9엔 **이름**으로 표기(사용자 채팅 A/B/C/D ↔ 문서 이름).

### 미해결 (열어둠)
- **강의·수강신청·멤버십·프랜차이즈 모집** 페르소나 = 룩북·카탈로그를 상품 전용으로 좁히며 4대분류 어디에도 자리 없음. **2회 플래그 후 미채택 = 의도적 제외로 간주**(필요 시 5번째 대분류 또는 A-4 예약/B로 재검토).
- **1-8의 '10 페이지 카테고리 조립 레시피' ↔ 1-9의 16 세부 = 아직 1:1 아님.** 내일 세부 질문 구성 때 정합 필요(16 세부가 10 레시피를 참조? 레시피를 16으로 확장?).

## 4부 — 페이지 프리셋 구성 계획 (제시함, 미확정)

계획만 제시하고 **문서엔 미반영**(사용자 요청 "우선 계획만"). 요지:
- **방식 = top-down** — 섹션 라이브러리가 비어 있어(검증=ROOFTOP 이벤트 세트뿐) **완성 페이지를 만들며 그 안 섹션을 목적 서랍으로 추출.** 현재 "피그마 우선" 단계.
- **카테고리당 3안(A/B/C)** = 유저 플로우 생성 3안 재료. **원/멀티는 카테고리 가중치대로 배분**(예: 상품 카탈로그 원1:멀티2 = 원1+멀티2), 3안은 도입·정보밀도·이미지비중·카드타입·순서+무드 **≥3축 다르게**, 색·폰트 없음·CdBd-legal.
- **Phase 1 파일럿 3개** = 상품 카탈로그(멀티·상품 카드 0회 살리기·내비 검증) · 행사 초대(원페이지·ROOFTOP 재활용) · 소식·매거진(0개 개척). Phase 2 = 나머지 7개(섹션 재사용).
- **부산물** = 페이지 제작마다 섹션이 목적 서랍 13칸에 적립 → "서랍당 3~4개" 되면 카드 데이터 승격 전환.
