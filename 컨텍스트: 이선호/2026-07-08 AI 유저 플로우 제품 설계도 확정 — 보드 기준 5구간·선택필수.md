## 1부 — 유저 플로우 초안 비판 검토 → 방향 결정

**산출물**: [[1-9. AI 유저 플로우]] (신규 문서)

### 왜 이 작업
프리셋 제작·분류 기준을 세우려면 그 근거인 **"유저에게 무엇을·어떤 순서로 물을지"**를 먼저 확정해야 함.

### 결정 흐름 (초안 → 개선)
1. **사용자 초안**: `카테고리 → 주제/목적 → 필수 기능 → 바이브(무드) → 자료 첨부` 질문 후 3안 제시.
2. **비판 검토 2관점**(AI 디자인 UX 트렌드 + 결과물 퀄리티):
   - 트렌드: 질문 다 받고서야 결과 → 이탈 / 정보 제일 많은 '자료'가 맨 뒤 / 무드를 이름으로 물어 비디자이너에게 어려움 / '3안 제시'에서 끝(수정 루프 없음).
   - 퀄리티: 앞에서 과하게 정하면 3안이 '색만 다른 쌍둥이'(차별화 붕괴) / '필수 기능'을 유저가 고르면 열어둔 카드 배치 자유도를 막음.
3. **사용자 결정 (AskUserQuestion)**: ① 정보 방식 = **자료 먼저 → 자동 채움 → 확인만**(content-first) ② 범위 = **전체 플로우**(정보받기 + 3안 + 수정 루프).
4. **무드 질문 제외** — 3안이 진짜 다르게 나오도록 무드는 내용으로 AI가 추론(묻지 않음).
5. **수정 뒤 에디터 직접 편집 추가** · **1단계 자료/한 줄 설명은 선택**(없으면 2단계 질문에 직접 답변).

## 2부 — 사용자 보드 기준으로 플로우 확정

**정본 도식**: [Figma 보드](https://www.figma.com/board/dA9nFFGnHhwjNuQYNVGR2B/Untitled?node-id=2-981) — 사용자가 직접 그린 가로형 플로우차트(FigJam). 앞으로 이 보드가 기준, 바뀌면 1-9도 함께 갱신.

### 보드가 확정한 4가지 (내 1차안 → 보드 정본)
| 항목 | 내 1차안 | 보드(정본) |
|---|---|---|
| 5구간 이름 | 시작 / 확인·보정 / 3안 / 수정루프 / 에디터 | **업로드 · 질답 · 생성 · AI 수정 · 직접 수정** |
| 질문 수 | 5개 | **4개** (담을 정보 + 기능 → '필수 내용/기능' 1문항) |
| 선택/필수 | 없음 | 🟡 선택(자료 업로드·AI 수정) / 🟢 필수(답변·3안·에디터) |
| 수정 | 1개(대화) | **AI 수정(대화) + 직접 수정(에디터)** 2구간으로 분리 |

- 갈림길: 자료 있음(YES) → AI가 채운 답 확인·보정 / 없음(NO) → 직접 답변 → **둘 다 같은 4문항으로 합류**. 3안 = A·B·C.

### 반영 위치 (완료)
- [[1-9. AI 유저 플로우]] **전면 갱신** — 표·상세·Mermaid 플로우차트(색까지 보드 규칙 🟦🟡🟢⬜으로) 교체 + 정본 보드 링크 삽입.
- [[CLAUDE.md]] 파일 맵 1-9 줄 갱신(5구간 이름·4문항·선택/필수·보드 링크).

### 정합성 전수 확인 — 다른 문서 수정 필요 여부 = **0건**
플로우의 **세부(단계 이름·질문 수·선택/필수)는 1-9에만** 존재. 나머지 문서(1-1·1-2·1-8·개별 기획서·과거 컨텍스트)는 **안 바뀐 일반 원칙만 인용** → 손댈 것 없음:
- 여전히 유효한 공통 원칙: 무드 안 물음(내용 추론) · 변주 축 ≥3 · 프리셋 색·폰트 무관 · 정보(WHAT) 고정/카드 배치(HOW) 개방 · 자료는 선택.
- **재사용 확인 커맨드**(다음에 플로우 바꿀 때 재실행):
  ```bash
  # 옛 단계명 잔존 검사 → 0건이어야 정합
  grep -rln --include="*.md" -e "수정 루프" -e "확인·직접답변" -e "대화수정" .
  # '담을 정보' 히트는 유저 질문이 아니라 내부 기획서(Part B, WHAT) 개념 — 오탐 주의
  grep -rn --include="*.md" "담을 정보" .
  ```
- 세션 컨텍스트 파일은 **역사 기록이라 손대지 않음**(CLAUDE.md §🗂 규칙).

### 재사용 팁
- **FigJam 보드(`/board/` URL)** 읽기 = `get_figjam`(구조·텍스트) + `get_screenshot`(시각) 병행. `/design/`이 아니라 `/board/`임에 주의(도구 다름).
