## 4부 — 이미지 생성 (9장, ~$0.62)

전부 gpt-image-1 `quality=medium`. 보관: `~/Desktop/interior-portfolio/`. 해시·슬롯 매핑은 스펙 문서 참조.

### 세피아 뭉개짐 재발 — 해결 프롬프트 확보

1:1 히어로 1차 생성이 **벽·바닥·소파가 전부 같은 크림색**으로 뭉개짐([[../1. 작업 가이드/1-5. 이미지]] 「밝게 ≠ 세피아 단색」의 실증 사례). 3:2 컷들은 1차 통과 — 정사각 구도에서 더 잘 발생하는 듯.

**해결**: 톤 지시(`bright·airy·high-key`)보다 **색 분리를 먼저·구체적으로** 명시.
```
wall tone and floor tone must read as two clearly different colours, not one uniform beige
NOT a sepia, amber, monotone or single-hue colour filter. no yellow cast
```

### BEFORE/AFTER 쌍 = 동일 앵글 필수

`shot from the identical straight-on angle facing X` + 창·가구 위치를 동일 서술 → 주방·욕실 모두 **1회 생성으로 앵글 일치**.

### 로고는 AI 생성 ❌

이미지 모델이 한글을 뭉갠다. **Figma에서 본명조 텍스트로 직접 조판**(심볼 = '여백' 개념의 사각형 + 안쪽 여백).

### 업로드 원칙 (사용자 확인)

- **사진 = 원본 PNG 직행.** Figma 2배 export ❌ — 324px 프레임에서 재추출 = 축소본 확대 = 화질 저하.
- **Figma가 원본인 자산만 2배 투명 export** (로고 · 6단계 어드민 자산). `download_assets`의 `export.url` ❌ (페이지 배경색 합성됨) → `rawImages[].url`.

## 5부 — 재사용 가능한 기법

- **신규 카드는 기존 카드 `clone()`** — 구분선 투명도 12%, 보조 텍스트 55% 같은 값을 손으로 옮기다 틀리지 않음. 0에서 생성 ❌.
- **P1~P4 프레임은 전부 세로 오토레이아웃(gap 0, 높이 HUG)** → 카드 삭제·삽입 시 아래가 자동 리플로우. 지난 세션 스펙의 "y좌표 -162 시프트" 수동 계산은 **불필요했음**.
- **SECTION 자식 좌표는 섹션-상대** (참고 스트립 배치 시). CLAUDE.md 함정표에 기재됨.
- **`use_figma`는 원자적** — 스크립트가 던지면 파일은 그대로. 오타 나도 안전하게 재시도.
