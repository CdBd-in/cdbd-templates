## 3부 — 🥇 OG 이미지 자동 업로드 (CdBd 라이브러리 dropzone React onDrop 패턴 발견)

**산출물**: 라이브 에디터 4856 OG 이미지 적용 완료 · [[../1. 작업 가이드/1-4-1. 에디터 페이지#함정 23: 파일 업로드는 React 합성 이벤트로 onDrop 핸들러 직접 호출 (2026-06-19 기록)]] · [[../CLAUDE.md]] 자동화 트러블슈팅 표 + 매트릭스 업데이트

### 결정 흐름 (5라운드 시행착오)

1. **라운드 1**: `$B upload`로 직접 업로드 시도 → DOM에 영구 file input 없음, 실패
2. **라운드 2**: `document.createElement('input')` 후킹으로 transient input 캡쳐 시도 → React는 자체 createElement 경로로 우회, 캡쳐 안 됨
3. **라운드 3**: `HTMLInputElement.prototype.click` 후킹 + DataTransfer로 files 주입 시도 → React 합성 이벤트와 다름, 미작동
4. **라운드 4**: Playwright `$B click` 실제 click → OS 파일 다이얼로그 대기로 timeout
5. **라운드 5 (성공)**: **이미지 라이브러리 모달의 dropzone div(`div.border-dashed`)에 React `onDrop` props 발견** → `props.onDrop({preventDefault, stopPropagation, dataTransfer: dt, target, currentTarget})` 직접 호출 → 즉시 업로드 처리됨

### 핵심 인사이트 (영구 룰로 기록 완료)

- CdBd 파일 업로드 UI는 **react-dropzone 류** — dropzone div의 React props에 onDrop 핸들러
- 합성 이벤트 객체의 `dataTransfer` 필드만 진짜 `DataTransfer`면 핸들러 안 `e.dataTransfer.files` 정상 접근
- OS 파일 다이얼로그 완전 우회 → Playwright timeout 회피
- 7-step 시퀀스: 트리거 onClick → 라이브러리 dropzone onDrop → 적용하기 onClick → 저장하기 onClick
- 풀패턴: 함정 23 (1-4-1) + CLAUDE.md 트러블슈팅 표

### 재사용 가능한 검증 스크립트

```js
// Bash에서: B64=$(base64 -i file.jpg)
// $B js로 inject + onDrop 호출
window.__OG_B64 = "{base64...}";
const bin = atob(window.__OG_B64);
const bytes = new Uint8Array(bin.length);
for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
const blob = new Blob([bytes], {type: 'image/jpeg'});
window.__OG_FILE = new File([blob], 'og.jpg', {type: 'image/jpeg'});

// 1. 트리거 클릭 (라이브러리 모달 오픈)
const trigger = document.querySelector('...');
trigger[Object.keys(trigger).find(k=>k.startsWith('__reactProps'))].onClick({preventDefault:()=>{}, stopPropagation:()=>{}});

// 2. dropzone 찾기 (React fiber 검색)
const dropzone = [...document.querySelectorAll('*')].find(el => {
  const pk = Object.keys(el).find(k => k.startsWith('__reactProps'));
  return pk && el[pk]?.onDrop;
});

// 3. DataTransfer + onDrop 직접 호출
const dt = new DataTransfer();
dt.items.add(window.__OG_FILE);
const props = dropzone[Object.keys(dropzone).find(k => k.startsWith('__reactProps'))];
props.onDrop({preventDefault:()=>{}, stopPropagation:()=>{}, dataTransfer: dt, target: dropzone, currentTarget: dropzone});

// 4. 라이브러리에 alt=파일명 IMG 추가됨 → 적용하기 버튼 onClick
const ogImg = [...document.querySelectorAll('img')].find(i => i.alt === 'og');
let card = ogImg.parentElement;
for (let i = 0; i < 5; i++) {
  const btn = [...card.querySelectorAll('button')].find(b => b.textContent?.trim() === '적용하기');
  if (btn) { btn[Object.keys(btn).find(k=>k.startsWith('__reactProps'))].onClick({preventDefault:()=>{}, stopPropagation:()=>{}}); break; }
  card = card.parentElement;
}

// 5. 부모 모달 저장하기 onClick → "URL 정보가 저장되었습니다." 토스트
```
